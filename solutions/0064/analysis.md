# 64. 最小路径和 · 解析

## 题目简述

网格从左上到右下（每次向右/向下），求路径上数字和的最小值。

## 核心套路：路径 DP（62 的变体）

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]   # 上方 + 左方 取 min
第一行/列 = 前缀累加
答案 = dp[m-1][n-1]
```

## 补 inf 边界技巧（用户干净版）

用 `(m+1)×(n+1)` 数组多一圈 `inf`，转移统一、不用 if 判越界：

```python
dp = [[float('inf')] * (n+1) for _ in range(m+1)]
dp[m][n-1] = 0    # 终点右方 = 0（终点不需额外 cost）
dp[m-1][n] = 0    # 终点下方 = 0
for i in range(m):
    for j in range(n):
        dp[m-i-1][n-j-1] = min(dp[m-i][n-j-1], dp[m-i-1][n-j]) + grid[m-i-1][n-j-1]
```

**为什么补 inf**：min 运算里，越界的边应该是"无穷大"（不可选），而不是 0（0 会被"白嫖"选成最小值）。

## 62 → 64：求和 → 取 min

| | 62 不同路径 | 64 最小路径和 |
|--|-----------|--------------|
| 目标 | 路径条数 | 路径最小和 |
| 转移 | `+`（求和） | `min`（取小） |
| 边界 | 0（0 条路径） | inf（不可选） |

## 复杂度

- 时间 **O(m×n)**；空间 O(m×n)（可滚动到 O(n)）。

## 考点

- 路径 DP（min 变体）
- 补 inf 边界技巧
- 从终点回填

## 易错点

1. 边界用 0 而非 inf（min 会白嫖）；
2. 第一行/列要单独累加（只能从一个方向来）；
3. 忘加 grid[i][j]（当前格子的值）。
