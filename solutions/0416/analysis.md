# 416. 分割等和子集 · 解析

## 题目简述

数组能否分成两个和相等的子集。等价于：能否凑出 sum/2 的子集。

## 核心套路：0/1 背包（DP 最后一个新套路）

**转化**：数字 = 物品（重量 = 价值 = num），容量 = sum/2。问"能否装满容量 sum/2"。

```python
dp[i][j] = max(dp[i-1][j], dp[i-1][j-nums[i]] + nums[i])
#          不放物品 i        放物品 i
```

**为什么价值==重量就行**：因为 dp 值 = 凑出的重量总和，`dp[target] == target` 恰好说明凑出了 target。

## 二维版 → 一维滚动版

```python
# 二维（用户版）：O(n×target) 空间
dp = [[0]*(target+1) for _ in range(n)]

# 一维滚动（标准）：O(target) 空间
dp = [0] * (target + 1)
for num in nums:
    for j in range(target, num - 1, -1):   # ★ 从后往前
        dp[j] = max(dp[j], dp[j - num] + num)
```

**为什么从后往前**：一维数组复用"上一轮"的值，从后往前遍历，`dp[j-num]` 才是上一轮（还没被本轮污染）的旧值；从前往后会读到本轮已更新的值 → 物品被重复使用（变成完全背包）。

## 0/1 背包 vs 完全背包

| | 0/1 背包 | 完全背包 |
|--|---------|---------|
| 物品 | 每个只能用一次 | 每个可用无限次 |
| 一维遍历 | **从后往前** | 从前往后 |

**记忆锚点：0/1 从后往前，完全从前往后**（方向决定物品能否重复用）。

## ⚠️ 用户踩坑总结（三个）

1. **浅拷贝 `[[0]*n]*m`**：m 行共享，改一行全改 → 用列表推导式；
2. **量纲 `i >= nums[i]`**：应 `j >= nums[i]`（容量 vs 重量）；
3. **本地/力扣不同步**：力扣网页改了没同步回 test.py，导致"本地对、力扣错"。

## 复杂度

- 时间 **O(n×target)**；空间 O(n×target)（二维）/ O(target)（一维）。

## 考点

- 0/1 背包建模（能否装满）
- 一维滚动 + 从后往前
- sum/2 的转化

## 易错点

1. 浅拷贝二维数组；
2. 一维版从前往后（应后往前，否则变完全背包）；
3. 奇数 sum 直接返回 False；
4. 忘 dp[0]=0 的初始化（不放任何物品）。
