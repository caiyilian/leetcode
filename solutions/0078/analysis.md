# 78. 子集 · 解析

## 题目简述

给定不含重复元素的数组 `nums`，返回其所有可能的子集（幂集，2ⁿ 个）。

## 核心套路：回溯模板 + "每选一个就记录"

**46 全排列 vs 78 子集，模板只有一个区别**：

| | 46 全排列 | 78 子集 |
|--|----------|--------|
| 答案 | 只有叶子（长度 = n） | **沿途所有状态**都是答案 |
| 记录时机 | `len(path) == n` 时 | **每 append 一次就记录**（result 初始 `[[]]`） |
| 去重判定 | `in path`（值用过没有） | start 索引 / 递增（只往前走） |

子集定义是"任意长度的任意组合"——所以 `[]`、`[1]`、`[1,2]`、`[1,2,3]` 全都要，**基线判断 `len(path) == n` 整个删掉**，走到 start 越界自然停。

## 解法一：标准 start 索引版（推荐）

```python
class Solution:
    def subsets(self, nums):
        result = [[]]
        def fun(start, path):
            for i in range(start, len(nums)):   # 这层只能从 start 往后选
                path.append(nums[i])
                result.append(path.copy())      # 每个中间状态都是子集
                fun(i + 1, path)                # 下界推到 i+1
                path.pop()
        fun(0, [])
        return result
```

**为什么零重复（下标锁）**：`start` 只增不减 → 走过的下标永不回头 → 子集 `{1,2}` 只会以 [1,2]（按下标升序）出现，`{2,1}` 在"选 2 之后还能选 1"的路径上被 `i+1` 锁死。**"子集用 start、排列用 in path"的分水岭就指这个。**

**为什么每层都记录**：`result.append` 在 for 循环内、`path.append` 之后——选一个记一个，`[[]]` 在开头补空集。

## 解法二：用户递增法（原创替代方案，5 万组验证等价）

```python
class Solution:
    def subsets(self, nums):
        result = [[]]
        def fun(path):
            for n in nums:
                if n in path:            # 不重复选
                    continue
                if len(path) >= 1 and path[-1] > n:   # ★ 强制递增
                    continue
                path.append(n)
                result.append(path.copy())
                fun(path)
                path.pop()
```

**用户的洞察**：46 的 `in path` 搬到子集会重复（{1,2} 和 {2,1} 是同一个子集）——于是用**"加进来的必须比最后一个大"**强制升序，每个子集只以 [a<b<c] 形式出现一次。值互异时数学上完全正确，乱序输入也稳（对拍验证）。

## 两种去重机制的对照（本解析的核心）

> **都是"只往前走，不回头"——一副思想的两副面孔。**

| | 用户递增法 | 标准 start 索引版 |
|--|-----------|------------------|
| 锁的类型 | **值的大小**（`path[-1] > n` 跳过） | **下标的顺序**（`range(start, n)` + `i+1`） |
| 额外判断 | `in path` + 递增检查（2 层） | 无（for 天然限定范围） |
| 依赖 | 值必须可排序 | 无 |
| 原理 | 每个子集以升序出现一次 | 每个子集以下标升序出现一次 |

**记忆锚点**：递增法像"每次只能挑比手里大的"；start 版像"队伍只能往队伍后面走"。效果相同，但 start 版免费（range 自带下界），且不依赖值可比较——所以是标准答案。

## 复杂度

- 时间 **O(2ⁿ×n)**；空间 **O(n)** 递归深度（不含输出）。

## 考点

- 回溯模板的"记录时机"变化（叶子 vs 沿途）
- **去重的两种机制**（值锁 vs 下标锁）
- 46 → 78 的模板迁移（删基线 + 改判定）

## 易错点

1. 忘了 `result = [[]]` 初始空集——空子集丢失；
2. 基线判断没删干净（`len(path) == n: return` 会导致大子集漏掉——其实不影响因为 start 越界自然停，但多余）；
3. `result.append(path)` 不复制——引用陷阱（46 同款）；
4. start 版写 `fun(start, ...)` 不传 `i+1`——死循环/重复；
5. 用户递增法在**重复值**输入下会错（见 90 题，需"排序 + 同层去重"）。
