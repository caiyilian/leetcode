# 72. 编辑距离 · 解析

## 题目简述

word1 转 word2 的最少操作数（插入/删除/替换各算一次）。`horse`→`ros` = 3。

## 核心套路：编辑距离 DP（LCS 的兄弟）

```
dp[i][j] = word1 前 i 个字符 转 word2 前 j 个字符 的最少操作
```

**转移**（看 word1[i-1] 和 word2[j-1]）：

```python
if word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]          # 相等：不用动
else:
    dp[i][j] = min(
        dp[i][j-1] + 1,              # 插入：word2[j-1] 插到末尾
        dp[i-1][j] + 1,              # 删除：删掉 word1[i-1]
        dp[i-1][j-1] + 1,            # 替换：word1[i-1] → word2[j-1]
    )
```

**边界**：`dp[0][j] = j`（空 → word2 全插入）、`dp[i][0] = i`（word1 → 空全删除）。

## 三种操作的方向（记忆）

```
插入：从左来 dp[i][j-1]   （word1 已匹配到 j-1，补一个字符）
删除：从上文来 dp[i-1][j] （word1 多一个字符，删掉）
替换：从左上 dp[i-1][j-1] （把最后一个字符换掉）
```

## 1143 → 72 的进化

| | 1143 LCS | 72 编辑距离 |
|--|----------|-------------|
| 相等 | 左上 +1 | 左上（不变） |
| 不等 | max(上, 左) | min(左+1, 上+1, 左上+1) |
| 目标 | 求最长 | 求最少 |

**同一个"最后一个字符"分析，不同的决策**：LCS 求"最长匹配"用 max，编辑距离求"最少操作"用 min。

## 复杂度

- 时间 **O(m×n)**；空间 O(m×n)（可滚动到 O(n)）。

## 考点

- 编辑距离经典 DP
- 三种操作的转移方向
- LCS 的兄弟（max → min）

## 易错点

1. 边界 dp[0][j]=j、dp[i][0]=i（不是 0）；
2. 三种操作别漏（只写替换会错）；
3. 相等时 dp[i-1][j-1]（不是 +1）；
4. 插入/删除的方向别搞反。
