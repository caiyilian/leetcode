# 538. 把二叉搜索树转换为累加树 · 解析

## 题目简述

BST 每个节点的值改成"原值 + 所有 ≥ 原值的节点值之和"。

## 核心套路：反中序遍历（右→根→左）+ 累加

**关键观察**：BST 中序 = 升序 → **反中序 = 降序**。按降序遍历，累加器就是"所有更大的值之和"：

```python
sums = [0]                # 列表引用：嵌套函数原地改（闭包陷阱解法）
def fun(root):
    if root:
        fun(root.right)       # ① 右子树（全比我大）先处理
        root.val += sums[0]   # ② 当前节点 += 已累加的所有更大值
        sums[0] = root.val    # ③ 把当前值并入累加器
        fun(root.left)        # ④ 左子树（全比我小）后处理
```

## 为什么反中序恰好对

```
累加树定义：新值 = 原值 + 所有 ≥ 原值 的节点值
反中序（降序）访问：先遇到大的 → 累加器持续加上更大的
遇到当前节点时，sums 正好 = 所有更大的值之和 ✓
```

**这就是"用遍历顺序代替额外查找"**——不需要单独求"哪些值比我大"，反中序遍历天然按大到小。

## Python 闭包陷阱（用户自悟的细节）

```python
sums = 0
def fun(root):
    ...
    sums += root.val   # ❌ 报错：sums 被当作新局部变量（闭包陷阱）
```

**解法**：用列表 `sums = [0]`，`sums[0] += x` 改的是列表内容，闭包共享同一个列表对象 ✅。或者用 `nonlocal sums`。

## 复杂度

- 时间 **O(n)**；空间 O(h)（递归栈，额外 O(1)）。

## 考点

- BST 中序/反中序性质
- 遍历顺序设计（降序累加）
- 原地修改
- Python 闭包陷阱

## 易错点

1. 用普通 int 变量保存累加器 → 闭包陷阱（应 nonlocal 或列表）；
2. 忘记先右后左（用正序就错了）；
3. 新建树（不满足原地要求）。
