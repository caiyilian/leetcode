## 解法演进历程（5 版）

| 版本 | 思路 | 力扣表现 |
|------|------|---------|
| v1 | 每个位置重新扫两侧找最高（O(n²)） | ❌ 单调递减数据超时 |
| v2 | 预计算 left/right 最大值数组（O(n) 三遍） | ✅ 23ms / 击败 9% |
| v3 | 两个循环合并（O(n) 两遍） | ✅ 23ms / 击败 9% |
| v4 | 单循环双向汇合（数组 + 奇偶分支） | ✅ 23ms / 击败 9%（常数反而变大） |
| **v5** | **真双指针（O(n) / O(1)）** | ✅ **11ms / 击败 61.58%** |

## 关键转折点

- **v1 → v2**：每个位置两侧最高可以预计算，O(n²) → O(n)；
- **v2 → v5**：意识到**双指针不需要每轮都同时走**——哪侧矮哪侧结算并移动，另一侧原地等待。之前的"两个指针同步收缩"思路本质还是模拟，必须靠数组缓存两侧最高；真正的双指针只需两个变量。
