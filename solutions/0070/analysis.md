# 70. 爬楼梯 · 解析

## 题目简述

一次爬 1 或 2 阶，n 阶有多少种爬法。

## 核心套路：最后一步分析法（DP 的灵魂）

**不要想"从 0 爬到 n"**，反过来想"**最后一步**"：

```
到第 n 阶，最后一步只有两种可能：
  ① 从第 n-1 阶跨 1 步
  ② 从第 n-2 阶跨 2 步

f(n) = f(n-1) + f(n-2)   ← 斐波那契！
f(1)=1, f(2)=2
```

## 动态规划是什么（用户本次核心疑问的答案）

**一句话：把大问题拆成重叠的子问题，每个只算一次、存起来复用。**

通用三步：
1. **定义状态**：f(i) = 到第 i 阶的方法数；
2. **状态转移**：f(i) = f(i-1) + f(i-2)（"最后一步"决定）；
3. **从底向上填表**（可选滚动优化）。

## 三种实现 = DP 进化史

```python
# ① 朴素递归：指数级，重复算 f(3) 无数次 → 超时
def f(n):
    return n if n <= 2 else f(n-1) + f(n-2)

# ② 记忆化：算过的存起来，O(n) 时间 O(n) 空间
memo = {}
def f(n):
    if n <= 2: return n
    if n not in memo: memo[n] = f(n-1) + f(n-2)
    return memo[n]

# ③ 滚动变量：只依赖前 2 个，O(n) 时间 O(1) 空间
a, b = 1, 2
for _ in range(n-1):
    a, b = b, a + b
```

## 滚动变量何时能用 / 不能用（用户担心迁移）

| 题 | 转移式 | 依赖 | 能否滚动 |
|----|--------|------|---------|
| 70 爬楼梯 | f(i-1)+f(i-2) | 前 2 个 | ✅ 2 变量 |
| 121 买股票 | 前 1 个 | 前 1 个 | ✅ 1 变量 |
| 198 打家劫舍 | max(f(i-1), f(i-2)+nums[i]) | 前 2 个 | ✅ 2 变量 |
| **300 最长递增子序列** | max(f(j)) for j<i | 前面所有 | ❌ 必须数组 |

**判断标准**：`dp[i]` 依赖前面哪几个状态，依赖几个压几个变量；依赖不固定（前面所有）就保留数组。

**建议**：先写"数组版 dp"（DP 通用语言，任何题都能写、不会错），再判断能否压缩成滚动变量。滚动变量是"空间优化"加分项，不是 DP 的门槛。

## 复杂度

- 时间 **O(n)**；空间 **O(1)**（滚动版）。

## 考点

- 最后一步分析法
- DP 三要素（状态/转移/滚动）
- 递归 → 记忆化 → 滚动 的进化

## 易错点

1. 边界 n=1 返回 1（不是 0）；
2. 滚动变量 `a, b = b, a+b` 的赋值顺序（必须同时赋值，分开写会错）；
3. 循环次数（n-1 次 vs n 次，取决于 a 初始是 f(1) 还是 f(0)）。
