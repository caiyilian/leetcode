## 解法（用户滚动变量版，命名清晰）

```python
class Solution:
    def climbStairs(self, n):
        if n <= 2:
            return n
        val_im2 = 1       # f(i-2)，初始 f(1)=1
        val_im1 = 2       # f(i-1)，初始 f(2)=2
        for i in range(3, n+1):
            val_i = val_im1 + val_im2   # f(i) = f(i-1) + f(i-2)
            val_im2 = val_im1
            val_im1 = val_i
        return val_i
```

**用户命名亮点**：`val_im2`/`val_im1`/`val_i` 直接对应 f(i-2)/f(i-1)/f(i)，比标准 `a,b=b,a+b` 清晰。

## 🎓 关键认知（为后续 DP 题奠基）

1. **最后一步分析法**：到第 n 阶 = 从 n-1 跨 1 步 + 从 n-2 跨 2 步 → f(n)=f(n-1)+f(n-2)；
2. **DP 三要素**：状态 f(i) → 转移 f(i)=f(i-1)+f(i-2) → 滚动（只依赖前 2 个，2 变量够）；
3. **滚动变量何时能用**：转移式依赖固定几个前面的状态就压几个变量；依赖不固定（如 300 依赖前面所有）则保留数组。
