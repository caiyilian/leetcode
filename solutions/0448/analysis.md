# 448. 找到所有数组中消失的数字 · 解析

## 题目简述

数组长度 n，元素值域 [1, n]，找出 1..n 中没有出现的数字。进阶要求 O(n)/O(1)。

## 核心套路：归位法（数组即哈希）

**关键观察**：值域 1..n 恰好对应下标 0..n-1——"值 v 应该放在下标 v-1"。

```python
for i in range(length):
    while nums[i] != (i + 1):            # 当前元素没归位
        if nums[i] == nums[nums[i] - 1]:
            break                         # 重复元素（目标位置已对），跳过
        index = nums[i] - 1
        nums[i], nums[index] = nums[index], nums[i]   # 换到该在的位置
# 归位后：nums[i] != i+1 → i+1 消失
```

## 为什么 break 是安全的

`nums[i] == nums[nums[i]-1]` 说明位置 `nums[i]-1` 已经有正确的值了——`nums[i]` 是**重复元素**（数组里还有另一个一样的），换了也没意义，直接 break（当前位置保持错位，最后会被识别为缺失）。

## 为什么 O(n)

每个元素**归位一次后就再也不动**（归位的决定不被回退），所以总交换次数 ≤ n，**不是**外层 for × while 的 O(n²)。这是归位法"看起来 O(n²)、实际 O(n)"的关键。

## 复杂度

- 时间 **O(n)**；空间 O(1)。

## 考点

- 数组当哈希（值作下标）
- 归位法 / 原地标记
- O(1) 空间技巧

## 易错点

1. 忘记 break → 重复元素会无限循环（`nums[i]` 和 `nums[nums[i]-1]` 反复互换）；
2. 用 `set` 差值 → O(n) 空间不满足进阶；
3. 返回的是"下标 + 1"（不是错位的值）。
