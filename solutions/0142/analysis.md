# 142. 环形链表 II · 解析

## 题目简述

给定一个链表的头节点 `head`，返回链表**开始入环的第一个节点**（环入口）。如果链表无环，则返回 `null`。

## 核心套路：快慢指针 + 二次相遇（数学推导）

### 第一步：快慢指针找相遇点（141 的做法）

快指针每轮 2 步、慢指针每轮 1 步，有环则必然相遇。

### 第二步：数学推导——从相遇点再走一次找入口

设：
- `a` = head → 环入口的距离
- `b` = 环入口 → 相遇点的距离
- `L` = 环长

**相遇时**慢指针走了 `a+b` 步，快指针走了 `2(a+b)` 步，快指针比慢指针多走的是环的整数倍：

```
2(a+b) - (a+b) = kL  →  a+b = kL  →  a = kL - b
```

**关键结论**：

> 相遇后，`p_start` 从 head 出发、`p_slow` 从相遇点出发，**各走 1 步同步前进，再走 a 步后同时到达环入口**。
> 因为：p_start 走 a 步到入口；p_slow 从相遇点走 a = kL - b 步 = 绕环 k 圈再退 b 步 = 也到入口。

## 定稿解法

```python
class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head:
            return None
        p_fast = head
        p_slow = head
        p_start = head
        while p_fast and p_fast.next:
            p_fast = p_fast.next.next
            p_slow = p_slow.next
            if p_fast == p_slow:               # ① 找到相遇点
                while True:
                    if p_slow == p_start:      # ② 二次相遇 = 环入口
                        return p_slow
                    p_slow = p_slow.next
                    p_start = p_start.next
        return None
```

## ⚡ 重点：步数可以是 0（必须先判断再移动）

推导说"两个指针各走 **a 步**后到入口"——注意 **a 可以是 0**！

当 `head` 本身就在环入口（如 `[1,2] pos=0`，链表 `1→2→1`，环入口 = 节点 1）：
- `a = 0`，且快慢指针相遇点恰好就是节点 1（入口）；
- 相遇后 `p_slow`（相遇点=入口）和 `p_start`（head=入口）**一开始就是同一个节点**。

| 写法 | 行为 | 结果 |
|------|------|------|
| **先判断后移动**（定稿版） | 第 0 轮就相等 → 返回入口 | ✅ 正确 |
| 先移动后判断 | 先走 1 步都到节点 2 → 返回节点 2 | ❌ 错（漏了 a=0） |

**为什么"先移动"会错**：两个指针同步各走 1 步，相对位置永远相同——若初始同点（a=0 且相遇点=入口），第一轮移动后它们仍在同一点（下一节点），相等返回——但位置已经不是入口了。

**一句话记忆**：**"相遇点可能就是入口，先看再走"**——`while p_slow != p_start: 移动`（while 条件天然先判断）是最稳写法。

## 复杂度

- 时间 **O(n)**：第一阶段相遇 O(n)，第二阶段最多 O(n)；
- 空间 **O(1)**：三个指针——满足进阶要求（set 记节点是 O(n) 空间，不达标）。

## 考点

- 快慢指针三件套收官：141 判断有环 → 142 找入口（数学推导 `a = kL - b`）
- **a=0 的边界**（head 就在环入口）——本题最大的隐藏坑
- 与 160 相交链表/287 寻找重复数的联系（都是"链表 + 双指针 + 路程推导"）
- 无环返回 None 的兜底

## 易错点

1. 二次相遇必须**先判断再移动**（a=0 的坑，本解析重点标记）；
2. 第一阶段相遇后 p_slow 停在与 p_fast 相遇的节点（不能丢）；
3. `p_start` 从 head 重新出发（不是从 p_fast/p_slow 的某个中间状态）；
4. 无环时第一阶段自然退出返回 None。
