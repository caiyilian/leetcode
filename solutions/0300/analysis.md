# 300. 最长递增子序列 · 解析

## 题目简述

求数组的最长严格递增子序列长度（不要求连续）。

## 核心套路：dp[i] = 以 nums[i] 结尾的 LIS 长度

```python
dp[i] = max(dp[j] + 1)   对所有 j < i 且 nums[j] < nums[i]
dp[i] 初始 = 1（自身）
答案 = max(dp)
```

```python
def lengthOfLIS(self, nums):
    n = len(nums)
    dp = [1] * n
    best = 0
    for i in range(n):
        for j in range(i):
            if nums[i] > nums[j]:
                dp[i] = max(dp[i], dp[j] + 1)
        best = max(best, dp[i])
    return best
```

## 关键认知：依赖前面所有 → 必须数组（滚动变量的边界）

`dp[i]` 依赖**所有** j < i 的 dp[j]（不是固定前 1/2 个），所以：

```
70 爬楼梯：dp[i] 依赖 dp[i-1], dp[i-2]  → 固定 2 个 → 滚动变量 ✅
198 打家劫舍：依赖 dp[i-1], dp[i-2]     → 固定 2 个 → 滚动变量 ✅
300 LIS：依赖所有 dp[j] (j<i)           → 不固定 → 必须数组 ❌
```

**这是"滚动变量何时能用"判断标准的经典案例**——依赖固定几个就压几个，依赖不固定（前面所有）就保留数组。

## O(n log n) 优化（耐心排序，面试加分项）

维护 `tails`：`tails[k]` = 长度为 k+1 的递增子序列的**最小可能末尾**。遍历 x，二分找第一个 `>= x` 的位置替换（或追加），最后 tails 长度即答案。贪心 + 二分，把 O(n²) 降到 O(n log n)。

## 复杂度

- 时间 **O(n²)**（DP）/ O(n log n)（耐心排序）；空间 O(n)。

## 考点

- dp[i] 以 i 结尾的经典定义
- "依赖前面所有" → 数组（滚动变量的边界）
- 答案 = max(dp)（而非 dp[n-1]）

## 易错点

1. 答案取 `max(dp)` 而非 `dp[n-1]`（LIS 可能不以最后一个元素结尾）；
2. 严格递增用 `nums[i] > nums[j]`（不是 >=，全相等时答案 1）；
3. dp[i] 初始化为 1（自身单独成序列）；
4. 忘内层 j 的 `nums[j] < nums[i]` 条件。
