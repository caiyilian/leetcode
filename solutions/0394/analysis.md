# 394. 字符串解码 · 解析

## 题目简述

解码 `"3[a2[c]]"` → `"accaccacc"`：`k[编码串]` 表示括号内串重复 k 次，**支持嵌套**。

## 核心套路：栈 = 显式的"下钻/返回"状态管理

**两种等价视角**（用户选一即可）：

| | 单栈混合版（用户） | 双栈元组版（标准） |
|--|------------------|------------------|
| 栈内容 | 数字串/字母/`[` 混存 | (重复次数, 前缀) |
| `[` 语义 | 数字串+`[` 入栈 | 压栈 (num, cur)，重置 |
| `]` 语义 | while 弹到 `[` 拼乘 | 弹元组直接合并 |
| 优点 | 单栈简单直觉 | 语义最清晰，cur 永远当前层 |
| 本质 | 同一算法两种表达 | 递归版的显式化 |

**核心思想**（两版共享）：

```
'[' = 下钻一层：把当前进度（已拼字符串 + 重复次数）存起来，进去处理内层
']' = 返回一层：用存好的进度合并内层结果
```

**为什么栈天然适配嵌套**：`[` `]` 的配对天然是后进先出（LIFO）——**最近的 `[` 对应最先遇到的 `]`**，完美匹配栈语义。这也是"括号类问题一律想到栈"的原因（20 有效括号同源）。

## 双栈版逐步图解（3[a2[c]]）

```
3    → num=3
[    → stack=[(3,"")]; cur="", num=0
a    → cur="a"
2    → num=2
[    → stack=[(3,""),(2,"a")]; cur="", num=0
c    → cur="c"
]    → pop(2,"a") → cur = "a" + "c"*2 = "acc"
]    → pop(3,"")  → cur = "" + "acc"*3 = "accaccacc" ✅
```

## 递归版（= 隐式栈，用户原始直觉）

```python
def decodeString(self, s):
    i = 0
    def dfs():
        nonlocal i
        res, num = "", 0
        while i < len(s):
            if s[i].isdigit(): num = num*10 + int(s[i])
            elif s[i] == '[':
                i += 1
                res += dfs() * num; num = 0   # 递归进内层 = 压栈
            elif s[i] == ']':
                return res                    # 返回 = 弹栈
            else: res += s[i]
            i += 1
        return res
    return dfs()
```

**三种写法（单栈/双栈/递归）是同一个算法的三副面孔**——理解"下钻存进度、返回合结果"就全通了。

## 复杂度

- 时间 **O(结果长度)**（最终串多长就必须输出多长，下限不可破）；
- 空间 **O(结果长度)**（栈 + cur）。

## 考点

- **括号配对 → 栈**（LIFO 天然匹配嵌套）
- "下钻/返回"的状态管理（存进度 + 恢复进度）
- 多位数字解析（num*10 + digit）

## 易错点

1. **`[` 的数字忘记转换**：数字入栈前是字符串，`]` 时 `int()` 转换（用户正确处理）；
2. 多位数字只取一位（`100[leetcode]` 应读"100"不是"1""0""0"——num_str 累加 / num*10+digit）；
3. 单栈版 `]` 处理时**弹到 `[` 为止**，别忘了弹数字那一下（`int(result.pop())`）；
4. `cur`/`num` 在 `[` 后必须重置（下钻是新层，从零开始）；
5. 空串/纯字母串（无括号）也应正确返回原串。
