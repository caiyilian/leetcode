# 160. 相交链表 · 解析

## 题目简述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的**起始节点**。如果两个链表不存在相交节点，返回 `null`。

> 注意：判定的是**节点引用相同**（内存地址），不是值相同——两条链可能含相同值的不同节点。

## 核心套路：双指针换边法（O(1) 空间最优解）

**思路**：两个指针分别从 `headA`、`headB` 出发，各自走完自己这条链后**换到另一条链的开头继续走**。因为"换边"抹平了长度差，两个指针会在交点相遇。

```python
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        if not headA or not headB:
            return None
        pA, pB = headA, headB
        while pA != pB:
            pA = pA.next if pA else headB
            pB = pB.next if pB else headA
        return pA
```

### 为什么必然相遇（核心论证）

设 A 链非公共部分长 `a`、B 链非公共部分长 `b`、公共部分长 `c`（A 全长 `a+c`，B 全长 `b+c`）：

| 指针 | 轨迹 | 总路程 |
|------|------|--------|
| `pA` | 走完 A（a+c）→ 换到 B → 走 b 步（B 的非公共部分）→ **到交点** | `a+c+b` |
| `pB` | 走完 B（b+c）→ 换到 A → 走 a 步 → **到交点** | `b+c+a` |

**`a+c+b == b+c+a`**——两个指针路程相同、步速相同（每轮各走一步），所以**同时到达交点**，`pA == pB` 退出。

- **不相交**（c=0）：都走 `a+b` 步后同时到 `None`，`None == None` 退出，返回 None；
- **无死循环**：每轮两指针同步各进一步，最多 `a+b` 步内结束。

### 复杂度

- 时间 **O(m+n)**；
- 空间 **O(1)**——比"哈希表记 A 链节点"（O(n) 空间）高一个档次，面试加分点。

## 其他解法对比

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 哈希表（set 记 A 链节点，再扫 B） | O(m+n) | O(n) | 直观，但空间不合格 |
| 双指针换边（本题定稿） | O(m+n) | **O(1)** | 最优，需理解"路程相等" |

## 考点

- 链表节点比较用 `==`（引用相等），不是值相等
- **换边抹平长度差**（双指针经典思想）
- 与 142 环形链表 II 呼应：同样是"双指针 + 路程推导"找相遇点
- 空链表边界（`if not headA or not headB`）

## 易错点

- `pA = pA.next if pA else headB`：**在 pA 为 None 时才换边**（走完换），不是比较值；
- 必须两个指针**同步各走一步**，不能一个快一个慢；
- 不能提前 break（要等 `pA == pB` 自然成立），否则不相交时可能死循环。
