## 版本记录（三个都验证通过，5 万组对拍 0 错误）

| 版本 | 思路 | 空间 | 本机测速（n=10⁵） |
|------|------|------|------------------|
| v1（提交用） | 链式切片赋值 `nums[:k], nums[k:] = nums[-k:], nums[:length-k]` | O(n) | **~1.0 ms** ⚡ |
| v2（面试思路） | 手写三次反转（整体反转 + 前 k 反转 + 后 n-k 反转） | **O(1)** ✅ | 4.0~5.3 ms |
| v3 | 内建反转三次 `nums.reverse()` + `reversed()` 切片 | O(n) | ~1.4 ms |

**结论**：三版逻辑等价（对拍全过）。Python 中手写 O(1) 空间循环（v2）反而比 C 层切片（v1/v3）慢 4~5 倍——**"O(1) 空间" vs "速度"在 Python 里此消彼长**：
- 面试讲思路 / 题目进阶要求：v2 三次反转（O(1) 空间）价值最高；
- 力扣提交提速：v1 切片版最快；
- 折中美观：v3 内建反转。
