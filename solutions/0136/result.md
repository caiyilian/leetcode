**经典手滑**：`return result == 0` 多了 `== 0`（调试残留），应 `return result`。

## 解法（用户异或，标准）

```python
def singleNumber(self, nums):
    result = 0
    for n in nums:
        result ^= n      # 异或：a^a=0, a^0=a
    return result
```

## 核心技巧：异或的三个性质

```
① a ^ a = 0      （成对的自相抵消）
② a ^ 0 = a      （异或 0 不变）
③ 交换律 + 结合律（顺序无所谓）
```

`[4,1,2,1,2]` 全异或 = `4^(1^1)^(2^2)` = `4^0^0` = 4——成对的湮灭，单身的浮出。

## 验证

- 官方样例：`[2,2,1]→1`、`[4,1,2,1,2]→4`、`[1]→1`。

## 复杂度

- 时间 **O(n)**；空间 O(1)（不用哈希表/排序，最优）。
