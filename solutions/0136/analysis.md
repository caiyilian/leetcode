# 136. 只出现一次的数字 · 解析

## 题目简述

数组中除了一个数字出现一次，其余都出现两次，找出那个单身数字。

## 核心套路：异或 XOR

```
① a ^ a = 0      （自己异或自己，湮灭为 0）
② a ^ 0 = a      （异或 0，不变）
③ 交换律 + 结合律
```

```python
def singleNumber(self, nums):
    result = 0
    for n in nums:
        result ^= n
    return result
```

## 为什么"全异或"有效

`[4,1,2,1,2]` 全部异或 = `4 ^ 1 ^ 2 ^ 1 ^ 2` = `4 ^ (1^1) ^ (2^2)` = `4 ^ 0 ^ 0` = `4`。成对出现的数抵消成 0，单身数字浮出。

## 对比其他解法

| 解法 | 复杂度 | 说明 |
|------|--------|------|
| 哈希表计数 | O(n) / O(n) | 朴素 |
| 排序找落单 | O(n log n) / O(1) | 慢 |
| **异或** | **O(n) / O(1)** | 最优，位运算技巧 |

## 复杂度

- 时间 **O(n)**；空间 O(1)。

## 考点

- 异或的性质（a^a=0）
- 位运算技巧
- "配对抵消"直觉

## 易错点

1. `return result == 0` 返回布尔（用户 WA，应 `return result`）；
2. 误用加法（两个相同数相加不会抵消）；
3. 用哈希表也能过但空间 O(n)，非最优。
