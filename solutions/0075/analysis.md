# 75. 颜色分类 · 解析

## 题目简述

原地把只有 0/1/2 的数组排成 [0...0, 1...1, 2...2]。

## 核心套路：荷兰国旗三指针

```
low  = 0 区域右边界（下一个 0 放这里）
curr = 当前扫描位置
high = 2 区域左边界（下一个 2 放这里）
```

```python
while curr <= high:
    if nums[curr] == 0:
        swap(curr, low); curr += 1; low += 1    # 0 归左，都前进
    elif nums[curr] == 2:
        swap(curr, high); high -= 1             # 2 归右，high 后退（curr 不动！）
    else:
        curr += 1                               # 1 留在中间
```

## 为什么遇到 2 时 curr 不动

从 `high` 换过来的元素**还没检查过**（可能是 0/1/2），必须下一轮再判断。这是荷兰国旗最容易错的地方——如果 curr 也前进，会把换来的未检查元素漏掉。

## 三个指针的分工

```
[0 ... 0 | 1 ... 1 | 未处理 | 2 ... 2]
         ↑        ↑        ↑
        low      curr     high
```

扫描过程中，三个区域逐渐收缩"未处理"区间，最终 `low~high` 之间的 1 自动归位。

## 复杂度

- 时间 **O(n)**；空间 O(1)。

## 考点

- 三指针（荷兰国旗问题）
- 原地排序（不用额外空间）
- 遇到 2 时 curr 不动的细节

## 易错点

1. 遇到 2 交换后 curr 也前进（会漏掉换来的未检查元素）；
2. 循环条件 `curr <= high`（不是 `<`，否则漏一个）；
3. 原地修改（不返回新数组）。
