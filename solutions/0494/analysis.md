# 494. 目标和 · 解析

## 题目简述

给每个数加 `+` 或 `-`，使最终和等于 target，求方案数。

## 核心套路一：记忆化搜索（DFS + memo，自顶向下 DP）

```python
fun(index, target) = 前 index+1 个数凑出 target 的方案数
  = fun(index-1, target + nums[index])   # 当前数取 +
    + fun(index-1, target - nums[index]) # 当前数取 -
终止：index < 0 → return target == 0（用完所有数恰好归零）
```

**本质是二叉树的 DFS**（每层 ± 两个分支），memo 记住 `(index, target)` 避免重复。

## 核心套路二：数学变换 → 01 背包（更优）

**关键推导**：

```
设选择的"正数"和为 P，"负数"绝对值之和为 N：
  P - N = target
  P + N = sum
相加得：2P = target + sum → P = (target + sum) / 2
```

**原问题转成：从 nums 中选若干个数，和恰好为 P 的方案数** —— 就是 416 分割等和子集的"01 背包计数版"！

```python
s = (target + sum) // 2
dp = [0] * (s + 1)
dp[0] = 1
for n in nums:
    for j in range(s, n - 1, -1):   # 逆序遍历 = 每个数只能用一次
        dp[j] += dp[j - n]          # 不选 + 选
return dp[s]
```

**两个无解条件**：
1. `abs(target) > sum` → 0；
2. `(sum + target) % 2` 为奇数 → 0（P 必须是整数）。

## 为什么逆序遍历

01 背包（每个数用一次）必须**逆序**——正序会重复使用同一个数（变成完全背包）。

## 与 416 分割等和子集的对比

| | 416 | 494 |
|--|-----|-----|
| 目标 | 能否分成和相等的两半 | 凑出目标和的方案数 |
| DP | 布尔 | **计数**（`+=`） |
| 背包 | 01 | 01 |

**494 是"416 + 数学变换"**——先转成子集和，再复用背包。

## 复杂度

- 记忆化：时间 O(n×S)，空间 O(n×S)；
- 01 背包：时间 O(n×S)，空间 **O(S)**。

## 考点

- 记忆化搜索 / 自顶向下 DP
- 数学变换（正负分组 → 子集和）
- 01 背包计数
- 奇偶性剪枝

## 易错点

1. 忘判 `(sum+target)%2`（会得出小数 P）；
2. 忘判 `abs(target) > sum`（无解）；
3. 01 背包逆序（正序变完全背包）；
4. 记忆化用 `(index, target)` 双键。
