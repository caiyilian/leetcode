# 283. 移动零 · 解题解析

> 用户独立完成：首版为 `pop`/`insert`（功能正确但最坏 O(n²)），
> 经提示后自行用「双指针交换」重写，达到时间 O(n) + 空间 O(1) 双最优，提交 0 ms / 击败 100%。

## 一句话思路

一次遍历，用 `index_first_zero` 记录**第一个 0 的位置**（写指针）：
遇到非零元素就和该位置**交换**——非零依次前移，0 自然被"挤"到末尾。

## 最终实现

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        length = len(nums)
        index_first_zero = length          # 第一个 0 的位置（初值 n = 还没出现 0）
        for i in range(length):
            if nums[i] == 0:
                if index_first_zero > i:   # 记录最先出现的 0
                    index_first_zero = i
            else:
                if i > index_first_zero:   # 非零出现在 0 之后 → 交换到前面
                    nums[index_first_zero], nums[i] = nums[i], 0
                    index_first_zero += 1
```

- **时间 O(n)**：单次遍历，每个元素访问一次
- **空间 O(1)**：只用一个整数变量，原地修改（无新数组）
- **保序性**：交换只发生在「非零 ↔ 零」之间，非零元素之间的相对顺序不变

## 首版的问题：`pop` 的隐藏代价

```python
nums.pop(i - bias)         # ❌ O(n)：删除中间元素，后面所有元素都要左移一位
nums.insert(length, 0)     # O(1)：插入末尾
```

每个 0 触发一次 O(n) 的删除 → 最坏情况（数组全 0）**O(n²)**。

实测（全 0 数组，最坏情况）：

| n | pop/insert 版 | 双指针版 | 倍数 |
|:---:|:---:|:---:|:---:|
| 2,000 | 4.75 ms | 0.032 ms | 147x |
| 4,000 | 17.6 ms | 0.130 ms | 135x |
| 8,000 | 52.7 ms | 0.135 ms | 390x |
| 16,000 | **327 ms** | 0.256 ms | **1279x** |

> **O(n²) 的指纹**：n 增 8 倍（2000→16000），耗时增 **69 倍**（≈ 8² = 64）；
> 双指针版增 7.9 倍（线性 ✅）。

## 本题考点

| 考点 | 内容 |
|------|------|
| 双指针（读写指针） | 一个指针找非零、一个指针记写入位置 |
