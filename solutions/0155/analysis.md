# 155. 最小栈 · 解析

## 题目简述

实现栈 + `getMin()` 返回栈中最小值，**所有操作 O(1)**。

## 核心套路：辅助栈（同步记录"每个时刻的最小值"）

**难点**：`pop` 后最小值**会变**（弹走的可能恰好是最小值）——"当前最小值"是一个随操作演化的状态。

**洞察（递推关系）**：

```
push(val) 后新最小值 = min(旧最小值, val)
pop() 后最小值      = 上一个时刻的最小值（自动回归）
```

辅助栈第 i 层 = **主栈前 i 层元素的最小值**——与主栈**一一对应、同步 push/pop**：

```
push 3 → 主[3]        辅[inf,3]
push 5 → 主[3,5]      辅[inf,3,3]
push 1 → 主[3,5,1]    辅[inf,3,3,1]     getMin = 1
pop()  → 主[3,5]      辅[inf,3,3]       getMin = 3 ✅（回到 3！）
```

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.time_min_val = [float('inf')]     # 辅助栈 + inf 哨兵（免判空）

    def push(self, value):
        self.stack.append(value)
        self.time_min_val.append(min(value, self.time_min_val[-1]))

    def pop(self):
        self.stack.pop()
        self.time_min_val.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.time_min_val[-1]           # O(1) 看辅助栈顶
```

**为什么 getMin 不用遍历**：每个状态的最小值在 push 时已经"算好并存下"——**空间换时间**。

## 与 DP 的关系（给后面 70 题打伏笔）

`新最小值 = min(旧最小值, 新元素)` 就是**递推公式/状态转移方程**——辅助栈每一层是一个"状态"，新状态只依赖旧状态 + 输入。**"用已经算好的子问题答案拼出当前答案，不再重复计算"——这正是动态规划的核心思想**。最小栈是"DP 思想在数据结构上的应用"。

## 优化位（可谈不可做）

- 辅助栈只在"值 ≤ 当前 min"时才 push（省空间）→ pop 时判断"弹出的 == 辅助栈顶"才弹辅助栈——**省空间但多一个分支**，同步栈更不易错；
- 差值法（存 val - min 的差值，数学技巧）→ 面试炫技用，工程上不推荐。

## 复杂度

- 时间：push/pop/top/getMin 均 **O(1)**；
- 空间 **O(n)**（两个栈）。

## 考点

- **状态递推**（辅助栈同步记录）
- 栈的"历史回退"（pop 自动回归上一状态）
- O(1) 必杀组合：算好存下 + 同步维护

## 易错点

1. `getMin()` 直接 `min(stack)` → O(n)，不符合要求（题目明确卡复杂度）；
2. pop 忘记同步弹辅助栈 → min 记录错位；
3. push 第一个值时 `min_stack[-1]` 越界——inf 哨兵（或判空）解决；
4. 辅助栈存"所有元素"（同步版）vs"只存新低"（省空间版）——两版 pop 逻辑不同，别混；
5. 空栈 getMin/top——题设保证非空调用，但防御式写法更稳。
