# 49. 字母异位词分组 · 解题解析

> 本题由用户独立完成（初稿写在 `test.py`），经 4 轮性能迭代后定稿。

## 一句话思路

两个字符串互为字母异位词 ⟺ **每个字母出现的次数完全相同**。
于是把「26 个字母的计数」当作哈希表的 key，value 收集同组的所有原串。

## 最终实现（v4）

```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        sorted_str_dict = defaultdict(list)
        for each_str in strs:
            cnt = [0] * 26
            for s in each_str:
                cnt[ord(s) - 97] += 1
            sorted_str_dict[tuple(cnt)].append(each_str)
        return list(sorted_str_dict.values())
```

- **时间复杂度**：O(n · k)，n 为字符串个数、k 为平均长度（构造计数 key 为 O(k)）
- **空间复杂度**：O(n · k)，存储全部分组结果
- **要点**：`tuple(cnt)` 可哈希才能当 key；`defaultdict(list)` 省掉 if/else 分支

## 性能迭代历程（4 个版本）

| 版本 | 做法 | 本机耗时（n=10⁴, k=100） | 说明 |
|------|------|------------------------|------|
| v1 | `"".join(sorted(list(s)))` + if/else | 52.0 ms | 初版：功能优先 |
| v2 | 计数法 `tuple(cnt)` | 33.9 ms | 排序 O(k log k) → 计数 O(k)，**-35%** |
| v3 | `bytes(map(s.count, ALPHA))` | 21.0 ms | 长串最优，但依赖数据特征 |
| **v4** | v2 + `defaultdict`（定稿） | 33.4 ms | 常数最优 + 代码清晰 |

### 关键认识：最优写法取决于数据特征

按字符串长度扫描（本机 n=10000）：

| 字符串长度 k | `"".join(sorted(s))` | 逐字符循环计数 | `str.count×26` |
|:---:|:---:|:---:|:---:|
| 1~20 | **最快**（k=20: 8.16 ms） | 9.70 ms | 9.07 ms |
| 35 | 15.77 ms | 14.37 ms | **11.39 ms** |
| 100 | 51.73 ms | 35.69 ms | **20.64 ms** |

- **交叉点在 k≈25~35**：短串排序更快（C 层实现、常数小）；长串计数更快（避免 k log k）。
- 通用心法：**性能敏感处优先用 C 层内置函数**（`sorted` / `count` / `join` / `map`），而不是手写 Python 循环。

## ⚠️ 方法论：力扣的 runtime 数字不能用来比较代码（重要教训）

同一份代码连续提交两次 → **11 ms 和 16 ms**。拉取全部提交样本：

```
[11, 15, 16, 16, 16, 17, 19, 19, 23, 27]   ← 极差 16 ms
```

- **测量噪声（±5ms，极差 16ms）远大于代码优化带来的差异（1~4ms）**；
- 因此"某个写法快 1ms"之类的结论**都是噪声**，包括中途一度怀疑的"str.count 更慢"；
- **可靠做法**：
  1. 本地 benchmark（可控环境、多次取最优）；
  2. 看**内存**指标——比时间稳定得多（同代码两次提交内存均为 23.5 MB）；
  3. 若必须用力扣数据，需多次提交取统计量（最小值/中位数）；
- **通用原则：优化前先量化噪声；噪声大于效应时，任何比较都无意义。**
