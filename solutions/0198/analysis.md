# 198. 打家劫舍 · 解析

## 题目简述

不能偷相邻的房子，求最大金额。

## 核心套路：DP 的"选或不选"决策（爬楼梯的变体）

标准视角——**对最后一家做"偷/不偷"决策**：

```
f(i) = max(f(i-1),            # 不偷第 i 家 → 前 i-1 家的最优
           nums[i] + f(i-2))  # 偷第 i 家 → 第 i 家金额 + 前 i-2 家的最优
```

这是 DP 里最经典的"选或不选"骨架（后面 279/322/416 都是这个骨架的变体）。

## 标准版（滚动变量）

```python
def rob(self, nums):
    prev2 = prev1 = 0
    for n in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + n)   # 不偷 vs 偷
    return prev1
```

## 用户版（记忆化递归，枚举"最后偷哪家"）

```python
max_n = max(nums[n-1] + f(n-2), nums[n-2] + f(n-3))
```

**视角差异**：
- 标准："偷/不偷最后一家"（两个决策分支）
- 用户："枚举最后被偷的房子"（偷 n-1 或偷 n-2）

**等价性证明**：金额非负 → `nums[n-1]+f(n-2) ≥ f(n-2)`，所以标准式的 `f(n-1)`（展开后含 `f(n-2)` 和 `nums[n-2]+f(n-3)`）中的 `f(n-2)` 恒被 `nums[n-1]+f(n-2)` 覆盖 → 两式等价。用户的视角其实更直观（"最后总得偷一家"）。

## 70 → 198：从"组合"到"决策"

| | 70 爬楼梯 | 198 打家劫舍 |
|--|----------|-------------|
| 转移 | f(i)=f(i-1)+f(i-2) | f(i)=max(f(i-1), nums[i]+f(i-2)) |
| 差异 | 两个子问题**都选**（求和） | 两个子问题**选最优**（max） |

**DP 的进化**：70 是"累加所有分支"，198 是"选择最优分支"——**max 是 DP 里"决策"的标志**。

## 复杂度

- 时间 **O(n)**；空间 O(n)（记忆化）/ O(1)（滚动）。

## 考点

- DP"选或不选"决策（max）
- top-down（记忆化递归）vs bottom-up（滚动）
- 相邻约束的处理（不能偷相邻 → 状态后退 2 位）

## 易错点

1. 纯递归忘记忆化 → O(2ⁿ) TLE（用户失败点）；
2. 转移式漏掉"不偷"分支（只写 nums[i]+f(i-2)）；
3. `prev2, prev1 = prev1, max(...)` 的同时赋值顺序（分开写会错）；
4. 单元素数组 `[1]` 单独处理。
