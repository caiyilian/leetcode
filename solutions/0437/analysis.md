## 题目简述

给定二叉树根节点 `root` 和整数 `targetSum`，求节点值之和等于 `targetSum` 的**向下路径**数目（路径可从任意节点出发、到其任意子孙结束，**单节点也算路径**）。

## 核心套路：前缀和 + 哈希表 + 回溯（O(n)）

### 三步推导（为什么这么写）

**Step 1：路径和 = 前缀和之差**

```
前缀和 S(node) = 根到 node 的路径和
路径 (a → b) 的和 = S(b) - S(a 的父节点)
```

**Step 2：查差（560 的"查差值而非枚举对"）**

遍历到 b 时 `cur_sum = S(b)`。要找"路径上祖先 a 的父节点，其前缀和 = cur_sum - targetSum"——**有多少个，就有多少条以 b 结尾的合法路径**：

```python
self.count += prefix.get(cur_sum - targetSum, 0)
```

**Step 3：回溯撤销（树版 560 的唯一新东西）**

前缀和只能来自**当前 DFS 路径上的祖先**。离开节点时必须 `prefix[cur_sum] -= 1`——否则左子树残留的前缀和会让右子树的节点"跨子树配对"，把断路径算进去：

```
       10
      /  \
     5   -3    ← 5 的前缀和不撤销，-3 的子树会错误命中
```

## 完整代码（每行注释）

```python
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        self.count = 0
        prefix = {0: 1}                      # ① 虚拟起点
        def dfs(node, cur_sum):
            if not node:
                return
            cur_sum += node.val              # ② 前缀和
            self.count += prefix.get(cur_sum - targetSum, 0)   # ③ 查差（核心）
            prefix[cur_sum] = prefix.get(cur_sum, 0) + 1       # ④ 入表
            dfs(node.left, cur_sum)
            dfs(node.right, cur_sum)
            prefix[cur_sum] -= 1             # ⑤ 回溯撤销（核心）
        dfs(root, 0)
        return self.count
```

## 三个必答的追问（面试/机考自查）

**Q1：`{0: 1}` 是干嘛的？**
虚拟"根之前"状态。路径可以不从根开始——从根开始的路径在查差时需要 `0` 有计数（如根本身 = targetSum 时 `cur_sum - targetSum = 0`）。

**Q2：单节点算路径吗？**
**算**。路径 [b] ⟺ `S(b) - S(父) = b.val == targetSum`——查差时命中"父节点前缀和"自动 +1，无需特判。

**Q3：为什么要回溯撤销？**
树会分叉。不撤销 = 把不同分支的前缀和混在一起 = 把不连续的"跨子树路径"误算。撤销让哈希表只反映**当前路径**上的前缀和。

## 复杂度

- 时间 **O(n)**、空间 **O(n)**（哈希）+ O(h) 栈。

## 考点

- 前缀和 + 哈希计数（560 → 437 → 525/2488 一条线）
- **回溯撤销**（树上的"作用域"管理）
- 单节点路径的自动覆盖
- 与暴力 O(n²) 的对比（面试常问复杂度）

## 易错点

1. **忘了 `prefix[cur_sum] -= 1`**——头号错误（会多算跨子树路径）；
2. `{0: 1}` 漏写——"从根开始的路径"全部漏算；
3. 查差要在**入表之前**（先查后记，否则当前节点自己会重复命中自己）；
4. 负值节点存在（和可以为负，不能用"剪枝"提前终止——437 的 targetSum 路径可以是负数总和）；
5. `prefix[cur_sum] = prefix.get(cur_sum, 0) + 1` 用 get 防 KeyError（同值前缀和可能重复出现）。
