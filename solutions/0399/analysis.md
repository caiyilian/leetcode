# 399. 除法求值 · 解析

## 题目简述

给定等式 `a/b = 2.0`、`b/c = 3.0`，回答查询 `a/c = ?`（不连通/未知变量返回 -1.0）。

## 核心套路：带权有向图 + DFS

### 第一步：建模成图

```
a/b = 2.0  →  边 a --2.0--> b,  边 b --0.5--> a（反向取倒数）
```

**双向边**是关键——知道 a/b 就知道 b/a。

### 第二步：DFS 搜索路径

```
查询 a/c：
  a --2.0--> b --3.0--> c
  结果 = 2.0 × 3.0 = 6.0（边权连乘）
```

```python
def dfs(cur, target, visited):
    if cur == target: return 1.0
    visited.add(cur)
    for neighbor, weight in graph[cur]:
        if neighbor not in visited:
            res = dfs(neighbor, target, visited)
            if res != -1.0:
                return weight * res      # 边权 × 后续
    return -1.0
```

### 递归直觉

**`a → target` 的答案 = `(a→b 边权) × (b → target 的答案)`**——每次沿一条边前进，把边权乘进去，直到到达 target。

## 为什么需要 visited

图可能有环（`a→b→a`），visited 防止死循环。注意：**每次查询要重置 visited**（`dfs(a, b, set())`），因为不同查询的路径不同。

## 为什么不是"单链走"

图有**分叉**：`graph[b]` 可能有多个邻居（b 同时出现在多条等式里）。必须**遍历所有邻居**并回溯（`res != -1.0` 才返回，否则继续试其他分支）。

## 三个边界

| 情况 | 返回 |
|------|------|
| 变量不在图中 | -1.0 |
| a == b 且都在图中 | 1.0 |
| 不连通 | -1.0 |

## 另一种解法：并查集（带权）

用**带权并查集**记录"到根节点的比值"，查询时 `a/b = (a到根)/(b到根)`。思路更优雅但实现复杂，DFS 更适合入门。

## 复杂度

- 时间 **O(Q × (V+E))**；空间 O(V+E)。

## 考点

- **图的建模**（等式 → 带权边）
- DFS/BFS 图搜索
- 边权连乘
- visited 防环

## 易错点

1. `graph[a]` 是**列表**，要遍历（不能直接 unpack 单个）；
2. 需要 `cur` 变量沿路径推进（不能一直用起点）；
3. 反向边权要取**倒数**；
4. visited 每查询重置；
5. 三个边界（不在图中 / a==b / 不连通）。
