# 17. 电话号码的字母组合 · 解析

## 题目简述

给一个数字串（2~9），每个数字对应手机键盘的字母表（2→abc、3→def……7/9 有 4 个字母）。返回所有可能的字母组合。**空串返回 `[]`**。

## 核心套路：回溯模板的"每层固定选择表"变体

46 全排列每层选"没用过的数字"；17 **每层只能选"当前数字对应的字母表"**——选择列表由 `digits[index]` 决定，这就是多层组合与排列的最大区别：

```python
class Solution:
    def letterCombinations(self, digits: str) -> list[str]:
        if not digits:               # ⚠️ 空串边界（力扣测例可能不覆盖，但必须写）
            return []
        length = len(digits)
        result = []
        num2char = {"2": "abc", "3": "def", "4": "ghi", "5": "jkl",
                    "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"}
        def fun(path, index=0):      # index = 当前处理第几个数字
            if len(path) == length:  # 填满所有数字的字母
                result.append("".join(path))
                return
            for c in num2char[digits[index]]:   # 这层只能选这个数字的字母表
                path.append(c)
                fun(path, index + 1)            # 推进到下一个数字
                path.pop()
        fun([])
        return result
```

**`index` 的角色**：既当"层指针"（选择列表 = `digits[index]` 的字母表），又天然当"去重锁"（只往前不回头，组合无需去重）。**46 的 `in path` 和 78 的 `start` 在这里都不需要**——因为每层的可选集互不相同。

## ⚠️ 本次实战教训：空串边界

本地对拍抓到：`digits=""` 时原版返回 `[""]`（因为 `len(path)==0==length` 直接命中叶子），正确是 `[]`。

```
digits=""  → length=0 → fun([]) 命中基线 → append("") → [" "]  ❌
修复：if not digits: return []                                            ✅
```

**回溯题空输入边界是高频失分点**（46 的空数组返回 `[[]]` 是正确行为，但 17 的空串返回 `[]`——**每题的"空输入语义"要单独确认**，不能套模板）。

## 一个注释修正（引用陷阱的进阶理解）

用户原注释："字符串，所以不用复制"——**原因说反了**。真实机制：

- `path` 是 **list**（append/pop 原地改它）；
- `"".join(path)` 在记录那一刻**创建全新的字符串**——字符串不可变，result 里存的是独立对象；
- 所以不是"path 是字符串所以安全"，而是"**join 生成了新对象所以安全**"（和 46 的 `path.copy()` 是同一个坑的正反两面：list 要手动复制，join 天然复制）。

**记忆锚点**：46/78 存 list → `path[:]` 复制；17 存字符串 → `join` 免费复制。

## 复杂度

- 时间 **O(4ⁿ×n)**（4ⁿ 个组合 × 生成 O(n)）；空间 **O(n)** 递归深度（不含输出）。

## 考点

- 回溯"每层选择表不同"的变体（index 分层）
- **空输入边界**（每题单独确认语义）
- join 与引用陷阱（list 复制 vs 字符串不可变）

## 易错点

1. **空串不处理** → 返回 `[""]`（本次踩坑）；
2. `digits[index]` 越界：index 只到 length-1 就命中基线，不会越界（但别把 `index+1` 写成 `index`——死循环）；
3. `num2char[digits[index]]` 的 key 是**字符串字符** `'2'` 不是数字 `2`（dict 键类型）；
4. 7 和 9 是 4 个字母（pqrs/wxyz），别漏；
5. 结果 join 成字符串（不是字符列表）。
