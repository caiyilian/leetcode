# 41. 缺失的第一个正数 · 解析

## 题目简述

给你一个未排序的整数数组 `nums`，请你找出其中**没有出现的最小的正整数**。要求：**O(n) 时间 + O(1) 额外空间**。

示例：`[1,2,0]` → 3；`[3,4,-1,1]` → 2；`[7,8,9,11,12]` → 1。

## 关键事实

缺失的第一个正数必然落在 **`[1, n+1]`** 范围内（数组只有 n 个元素，`1..n+1` 中至少有一个缺失）。

- 如果 `1..n` 全出现 → 答案是 `n+1`；
- 否则答案在 `1..n` 中。

这给了我们一个 O(1) 空间的抓手：**不需要存所有数，只需要检查每个数是否在"它该在的位置"**。

## 核心套路：把数组本身当哈希表（归位法）

**约定**：数值 `x`（`1 ≤ x ≤ n`）应该待在下标 `x-1` 处（此时 `nums[x-1] == x`，即 `nums[i] == i+1`）。

### 第一遍：归位

遍历每个位置 i，只要当前值 `nums[i]` 满足 `1 ≤ nums[i] ≤ n` 且不在正确位置，就**原地交换**把它送到下标 `nums[i]-1`：

```python
nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
```

- **防死循环**：如果目标位置已有相同的值（重复），`break`——否则 `[1,1]` 这类数据会无限交换；
- **越界值**（`≤ 0` 或 `> n`）直接跳过（它们没有家，不参与归位）。

### 第二遍：找缺口

再扫一遍，**第一个 `nums[i] != i+1`** 的位置就是缺口，答案 `= i+1`；全部归位则答案 `= n+1`。

## 定稿解法

```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        length = len(nums)
        for i in range(length):
            if nums[i] < 1:
                continue
            while (nums[i] != (i+1)) and (1 <= nums[i] <= length):
                if nums[nums[i] - 1] == nums[i]:
                    break
                nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
        for i, now_value in enumerate(nums):
            if now_value != (i+1):
                return i+1
        return length + 1
```

### 正确性检验（手工跑官方样例）

`[3,4,-1,1]`（n=4）：
- i=0: nums[0]=3，应到下标 2 → 与 nums[2]=-1 交换 → `[-1,4,3,1]`；-1 跳过
- i=1: nums[1]=4，应到下标 3 → 与 nums[3]=1 交换 → `[-1,1,3,4]`；nums[1]=1 应到下标 0 → 与 nums[0]=-1 交换 → `[1,-1,3,4]`；-1 跳过
- i=2: nums[2]=3 == i+1 ✅；i=3: nums[3]=4 == i+1 ✅
- 第二遍：i=1 处 nums[1]=-1 != 2 → 答案 **2** ✅

## 复杂度

- 时间 **O(n)**：每次交换至少让一个数归位（且归位后不再移动），**交换总次数 ≤ n** + 外层 n 次遍历 → O(n)；
- 空间 **O(1)**：原地交换，只有循环变量。

## 与其他版本对比（v1/v2 的故事）

同类"找缺失/重复"问题，很多人的第一反应是 set/dict（O(n) 空间）——**力扣判题不查空间，能过但不符合题面要求**。归位法的本质是：**"值域有限 + 下标即位置"时，数组本身就是 O(1) 空间的哈希表**。

| 维度 | set 版 | 归位法 |
|------|--------|--------|
| 思路 | 存见过的数，need_value 连续段推进 | 原地交换归位，找缺口 |
| 时间 | O(n) | O(n) |
| 空间 | O(n) ❌ | **O(1) ✅** |
| 面试观感 | 会被追问"空间呢？" | 标准答案 |

## 考点

- **数组即哈希表**（index-based mapping：值 → 下标 `x-1`）——O(1) 空间的通用技巧（268 丢失的数字、442 重复元素等同类）
- 值域分析（答案 ∈ [1, n+1]）
- 原地交换 + 防死循环（重复值判断）
- 与 128 题的对比：128 只要求 O(n) 时间（set 允许）；41 额外要求 O(1) 空间（必须归位）——**做题前先看清空间要求**

## 易错点清单

1. 交换后的"新值"还要继续检查是否归位（用 while 不是 if）；
2. 重复值防死循环（`nums[nums[i]-1] == nums[i]` 就 break）；
3. 越界值（≤0 或 >n）不参与归位；
4. 全归位时返回 `n+1` 而不是 n。
