## 关键点

- v1/v2 思路的时间复杂度是 O(n)（need_value 单调递增，内层 while 总计 O(n)），但 set/dict 最坏存 n 个元素，**空间 O(n)，不满足题面硬性要求**——力扣判题不检查空间，靠自觉；
- **v3 归位法**：原地交换把每个 `1 ≤ x ≤ n` 的值放到下标 `x-1`，第一遍归位、第二遍找缺口——O(n)/O(1) 双满足；
- 防死循环关键：`if nums[nums[i]-1] == nums[i]: break`（重复值如 `[1,1]`、`[1,5,3,4,5]`）；越界值 `≤0` 或 `>n` 跳过；全归位返回 `n+1`；
- 对拍 10 万组（含重复值专项）0 错误。

## 为什么 v3 是 O(n) 时间（论证）

内层 while 每轮要么交换成功（至少一个数归位，归位后不再移动），要么 break；**交换总次数 ≤ n**，外层 n 次 + 内层总计 O(n) → 总 O(n)。
