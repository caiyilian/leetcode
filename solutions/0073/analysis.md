# 73. 矩阵置零 · 解析

## 题目简述

给定一个 `m × n` 的矩阵，如果一个元素为 **0**，则将其**所在行和列**的所有元素都设为 0。请使用**原地算法**。

题面空间要求三档：
1. O(mn) 额外空间（复制矩阵）——"不是一个好的解决方案"；
2. O(m+n) 额外空间（标记行/列数组）——"仍然不是最好的"；
3. **O(1) 常量空间**（进阶目标）。

## 思路一：set 标记（O(m+n) 空间，基础版）

一个 0 影响整行整列，所以不需要记录每个 0 的位置，只需要知道**哪些行、哪些列**要被清空：

1. 第一遍扫描，遇到 0 就把行号加入 `delete_row`、列号加入 `delete_col`；
2. 第二遍，把标记的行整行清空、标记的列整列清空。

时间 O(mn)，空间 O(m+n)。**正确性无可挑剔，是"改进方案"档**——但没达到常量空间。

## 思路二：第一行/第一列当标记板（O(1) 空间，进阶版）

**核心思想**：用矩阵自己的第一行存"哪些列要置零"、第一列存"哪些行要置零"——不新建数组。

```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        # ① 存档：第一行/第一列原本有没有 0
        first_row_zero = any(matrix[0][j] == 0 for j in range(n))
        first_col_zero = any(matrix[i][0] == 0 for i in range(m))

        # ② 扫描主体 (1,1) 起：0 的信息写进第一行/第一列
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        # ③ 按标记清空主体（不含第一行第一列）
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # ④ 最后处理第一行/第一列（用①的存档）
        if first_row_zero:
            for j in range(n):
                matrix[0][j] = 0
        if first_col_zero:
            for i in range(m):
                matrix[i][0] = 0
```

### 灵魂问题：标记位为什么不用"恢复"？

`matrix[0][j]` 被拿来当"第 j 列要置零"的标记，但这个格子的**最终归宿已经被写死**：

- 第 j 列要置零 → 它最终 = 0；
- 第一行要置零 → 它最终 = 0；
- 两者都不 → 它保留原值。

所以标记写 0 只是**剧透**它本该变成 0，不存在"被污染后无法恢复"的问题——**因为它本来就该是 0（或被验证保留原值）**。借来的格子，命运已定，无需恢复。

### 那为什么还要两个布尔变量存档？

第一行/第一列**整体**要不要清空，取决于它们**原本**有没有 0——这个信息一旦开始写标记就被覆盖了（主体元素为 0 时在第一行写的标记 0，会让第一行看起来"有 0"，但那是假象）。所以 `first_row_zero` / `first_col_zero` 是在"污染"发生前给它们自己存底。

### 三个必须守住的顺序

1. **先存档**第一行/第一列的原始 0 状态（否则被覆盖后无法区分"原本有 0"和"标记 0"）；
2. 主体扫描**从 (1,1) 开始**——第一行/第一列是标记板，不能被当普通数据扫；
3. 主体清空（③）和第一行/第一列清空（④）**分开做**，④ 用存档而不是标记。

### 复杂度

- 时间 **O(m·n)**：扫描一遍 + 清空两遍；
- 空间 **O(1)**：两个布尔变量（借用的格子是矩阵本身）。
