## 两个版本（都对拍验证 0 错误）

| 版本 | 思路 | 空间 | 满足 |
|------|------|------|------|
| v1（用户独立完成） | set 记录需要置零的行/列，第二遍清空 | O(m+n) | 基本要求 ✅（题面"改进方案"档） |
| v2（O(1) 进阶版） | **第一行/第一列当标记板**：先存档第一行/列的原始 0 状态，主体扫描把 0 信息写进标记，再分步清空 | **O(1)** ✅ | 进阶要求 ✅ |

## 关键点

- 用户 v1 力扣 3ms/90%（基本版达标）；leetgo 提交 v2 为 7ms/62%（同复杂度，常数+噪声差异）；
- **v2 核心洞察（用户自己悟出）**：标记格子的最终归宿已被"它所在行/列是否要置零"写死（变 0 或保原值），写 0 标记只是"剧透"，**不需要恢复**；
- 需要提前保护的信息只有两个：**第一行/第一列原本是否有 0**（两个布尔变量存档）——它们自己也是矩阵，会被后续置零覆盖；
- 三个关键顺序：先存档 → 主体扫描写标记（从 (1,1) 起）→ 最后处理第一行/第一列。
