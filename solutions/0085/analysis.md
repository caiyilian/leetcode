# 85. 最大矩形 · 解析

## 题目简述

在只含 '0'/'1' 的矩阵中，找出全 '1' 的最大矩形的面积。

## 核心套路：逐行转柱状图 + 单调栈（84 的二维扩展）

```
① 逐行累加柱高 heights[j]：
   matrix[i][j]=='1' → heights[j] += 1
   matrix[i][j]=='0' → heights[j] = 0
② 每行用 84 的单调栈求 heights 的最大矩形
③ 所有行取 max
```

## 为什么能转成柱状图

每一行作为"底边"，`heights[j]` 是从这一行往上数的连续 '1' 高度——这样"以第 i 行为底边的全 1 矩形"就等价于"柱状图 heights 里的最大矩形"，正是 84 已解决的问题。

## 单调栈（复用 84）

```python
def largestRectangleArea(heights):
    heights = [0] + heights + [0]     # 左右哨兵，免判空
    stack = [0, 1]
    area = 0
    for i in range(2, len(heights)):
        while heights[i] < heights[stack[-1]]:   # 遇到更矮的，弹出计算
            mid = stack.pop()
            w = i - stack[-1] - 1               # 宽 = 右边界 - 左边界 - 1
            h = heights[mid]
            area = max(area, h * w)
        stack.append(i)
    return area
```

## 复杂度

- 时间 **O(m×n)**；空间 O(n)。

## 考点

- 二维 → 一维的转化（逐行累加）
- 单调栈（左右哨兵）
- 84 的知识迁移

## 易错点

1. 遇 '0' 时 heights[j] 要清零（不是跳过）；
2. 单调栈加左右哨兵（[0] + heights + [0]），免边界判断；
3. 宽 = `i - stack[-1] - 1`（左右都是开区间）。
