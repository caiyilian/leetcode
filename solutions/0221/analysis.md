# 221. 最大正方形 · 解析

## 题目简述

在只含 '0'/'1' 的矩阵中，找出只包含 '1' 的最大正方形的面积。

## 核心套路：矩阵 DP（三个方向取 min）

```
dp[i][j] = 以 (i,j) 为右下角的最大正方形的边长
dp[i][j] = matrix[i-1][j-1]=='0' ? 0 : 1 + min(左上, 上, 左)
答案 = max(dp)²
```

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]   # 多一圈 0 边界
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if matrix[i-1][j-1] == '1':
            dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])
```

## 为什么是"三个方向取 min + 1"

想以 (i,j) 为右下角构成边长 k 的正方形，需要：
- (i-1,j-1) 处能构成边长 ≥ k-1 的正方形；
- (i-1,j) 处能构成边长 ≥ k-1 的正方形；
- (i,j-1) 处能构成边长 ≥ k-1 的正方形。

三者取 min 就是"最短板"，+1 得到当前边长。

## 与 85 最大矩形的对比

| | 85 最大矩形 | 221 最大正方形 |

| 目标 | 最大矩形 | 最大正方形 |

## 复杂度

- 时间 **O(m×n)**；空间 O(m×n)（可优化到 O(n)）。

## 考点

- 矩阵 DP（三方向取 min）
- 补 0 边界免越界
- 空间滚动优化

## 易错点

1. 返回 `max²`（面积不是边长）；
2. 三个方向是 左上/上/左（不是上下左右）；
3. 遇 '0' 时 dp 为 0（跳过或置 0）。
