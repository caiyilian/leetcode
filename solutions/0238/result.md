## 解法演进（4 版）

| 版本 | 思路 | 复杂度 | 说明 |
|------|------|--------|------|
| v1 | 暴力：每个位置乘除自身外全部（遇 0 break） | O(n²)/O(n) | 逻辑对，超时 |
| v2 | 前缀积 + 后缀积（两个 dict 存储） | O(n)/O(n) | dict 存储连续下标，慢 |
| v3 | 同上改 list 存储 + 遇 0 双向剪枝 | O(n)/O(n) | 快 55%，0 剪枝数学安全（对拍验证） |
| **v4（定稿）** | **单数组复用：先存后缀积 → 就地乘前缀积 → 反转取序** | **O(n)/O(1) 额外** ✅ | **达到题目进阶要求** |

## 关键点

- v3 → v4 的最大变化：**输出数组自己当"额外空间"用**——第一遍存后缀积，第二遍就地乘前缀积，输出数组不算额外空间 ⇒ **O(1) 额外空间**达标；
- 遇 0 剪枝保留：某侧累积为 0 后，剩余位置答案必含 0，提前 break 数学安全（4 万组含 0/无 0 对拍 + 手工边界全 0 错误）；
- 单元素边界 `[5]→[1]`、`[0]→[1]`（除自身为空乘积 = 1）正确处理。
