# 62. 不同路径 · 解析

## 题目简述

m×n 网格，从左上到右下，每次向右或向下，求路径数。

## 核心套路：路径 DP

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]   # 上方 + 左方
第一行、第一列 = 1（只有一条路）
答案 = dp[m-1][n-1]
```

```python
def uniquePaths(self, m, n):
    dp = [[1] * n for _ in range(m)]
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
    return dp[m-1][n-1]
```

## top-down vs bottom-up 镜像（用户两个版本）

| | 记忆化递归 | 迭代填表 |
|--|-----------|---------|
| 方向 | (0,0) → 终点 | 终点 → (0,0) |
| 转移 | fun(i,j)=fun(i+1,j)+fun(i,j+1) | dp[i][j]=dp[i-1][j]+dp[i][j-1] |
| 实现 | 递归 + mem dict | 循环 + 二维数组 |

**同一个转移式，两个方向**——记忆化"往下找"，迭代"往上填"，本质都是"当前位置 = 两个来源之和"。

## 递归 → 记忆化 → 迭代（用户第 3 次走通）

```
WA：缺 m=n=1 边界
TLE：纯递归 2^(m+n) 指数级
AC：记忆化 + 边界
AC：迭代填表
```

## 一维滚动（空间优化）

每行只依赖上一行，可滚动成一维：

```python
dp = [1] * n
for i in range(1, m):
    for j in range(1, n):
        dp[j] += dp[j-1]   # dp[j] = 上方(旧dp[j]) + 左方(新dp[j-1])
return dp[n-1]
```

## 复杂度

- 时间 **O(m×n)**；空间 O(m×n)（二维）/ O(n)（滚动）。

## 考点

- 路径 DP（经典入门）
- top-down / bottom-up 双方向
- 组合数 C(m+n-2, m-1) 数学解（bonus）

## 易错点

1. m=1 或 n=1 的边界（第一行/列 = 1）；
2. 纯递归忘记忆化（指数 TLE）；
3. 一维滚动时 `dp[j] += dp[j-1]` 用旧值（从前往后即可，因为 dp[j-1] 是本轮已更新的左方值，正是想要的）。
