# 236. 二叉树的最近公共祖先 · 解析

## ⚡⚡ 机考之前必看（用户标记）：递归版，10 行解决面试超高频题

## 题目简述

给定二叉树和两个节点 `p`、`q`，返回它们的**最近公共祖先**（LCA = 同时是 p 和 q 的祖先、且离它们最近的节点）。注意：p 或 q 可能是对方的祖先。

## 解法一：递归版（标准三情况归纳，机考首选）

```python
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if not root or root == p or root == q:
            return root                       # ① 空节点 / 命中 p 或 q
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left and right:
            return root                       # ② p、q 分居两侧 → 当前节点就是 LCA
        return left or right                  # ③ 只有一侧找到 → 返回那一侧的结果
```

**为什么妙**——把 LCA 归纳成三种情况，递归自底向上自然完成：

```
① 基线：走到空 / 遇到 p 或 q → 把"发现"向上传
② 某个节点的左右子树都传回了非空 → p、q 一个在左一个在右 → 当前节点是 LCA
③ 只有一侧非空 → p、q 都在那一侧 → 直接传回那一侧的发现
```

**验证手推**（p=6, q=4）：
```
       3
      / \
     5   1
    / \ / \
   6  2 0  8
     / \
    7   4
节点 6：命中 p → 返回 6
节点 4：命中 q → 返回 4
节点 2：left=7（None 链上来的空），right=4 → 只有右非空 → 返回 4
节点 5：left=6，right=4 → 两侧都非空 → 返回 5 ✅（LCA = 5）
```

## 解法二：BFS 父链版（用户版，160 相交链表思路的树版本）

```python
father_dict[child] = parent          # BFS 记录"每个节点的父节点"
# 深度对齐：深的先上溯到同一层
# 同步上溯直到相遇 → 相遇点就是 LCA
```

**本质**：LCA = "根→p 路径"和"根→q 路径"的**交点**——和 160 相交链表完全同构（160 用 next 走、树用 father_dict 走）。

**剪枝版额外优化**：BFS 找到 p、q 就 break——`father_dict` 只需要 p/q 的祖先链，而 BFS 层序保证祖先已在更早层记录 ✅（3 万组对拍验证正确性）。

## 两版对比

| | 递归版（机考必看） | BFS 父链剪枝版（用户定稿） |
|--|-------------------|--------------------------|
| 思路 | 三情况归纳（自底向上） | 路径交点（160 迁移） |
| 空间 | O(h) 递归栈 | O(n) father_dict |
| 代码 | 10 行 | 较长 |

## 易错点

1. 基线 `root == p or root == q` 要写在递归**之前**（命中即返回，不再往下）；
2. ②的判断是"left **and** right 都非空"——漏掉 and 会提前返回错误节点；
3. ③返回 `left or right`（非 None 的那个）——不是返回 root；
4. BFS 版要用**引用相等**判断 p/q（`node == p`），不要用 `node.val == p`（值可能重复）；
5. p=q 的情况（返回 p 本身）——① 天然处理。
