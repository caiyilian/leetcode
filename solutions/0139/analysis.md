# 139. 单词拆分 · 解析

## 题目简述

判断字符串能否由字典里的单词拼接而成（单词可复用）。

## 核心套路：最后/第一个单词分析（322 的字符串版）

```
dp[i] = 前 i 个字符能否被拆分
dp[i] = any(dp[j] and s[j:i] in wordDict)   对所有 j < i
dp[0] = True（空串可拆）
```

**两种拆法（镜像，都正确）**：

```python
# 从后拆（标准 DP）：枚举"最后一个单词" s[j:i]
dp[i] = any(dp[j] and s[j:i] in wd)

# 从前拆（用户版）：枚举"第一个单词"，startswith 吃掉前缀
if s.startswith(each_s) and fun(s[len(each_s):]):  ...
```

**为什么两个方向都对**：拆分答案与顺序无关——先吃前还是先吃后，最终都能拼完。用户用 `startswith` + 递归吃前缀，是字符串的自然直觉。

## 322 → 139 的迁移（凑的字符串版）

| | 322 零钱兑换 | 139 单词拆分 |
|--|-------------|-------------|
| 转移 | dp[i]=min(dp[i-c]+1) | dp[i]=dp[j] and s[j:i] in dict |
| 凑的东西 | 金额 | 字符串 |
| 决策 | 求最少（min） | 求能否（any） |

**同一"凑"骨架**：322 问"最少几个"，139 问"能不能"——一个用 min，一个用 any。

## 复杂度

- 时间 **O(n²)**（标准 DP：n 个位置 × j 枚举，子串判断 O(1) 用 set）；空间 O(n)。

## 考点

- 字符串 DP（dp[i] 表示前缀）
- "最后一个/第一个单词"分析
- min（最少）→ any（能否）的决策类型切换

## 易错点

1. dp[0]=True（空串基础）；
2. wordDict 转 set（子串查找 O(1)，否则 O(k)）；
3. 内层 j 的枚举范围（0 到 i-1）；
4. 记忆化递归的 key 用字符串本身（子串唯一）而非下标。
