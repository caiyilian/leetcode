# 200. 岛屿数量 · 解析

## 题目简述

给你一个 `m × n` 的二维网格，`'1'` 表示陆地、`'0'` 表示水。岛屿由**水平/垂直相邻**的陆地连成（四连通），返回岛屿数量。

## 核心认知一：网格即图（图论入门视角）

**你不需要学邻接表/邻接矩阵**——网格本身就是图的天然表示：

```
格子 (i, j) = 图节点
上下左右 = 四条边：(i-1,j) (i+1,j) (i,j-1) (i,j+1)
岛 = 连通的 '1' 集合 = 图的一个连通分量
```

"数岛屿" = "数连通分量"——遍历图，每发现一个没访问过的节点就 count+1，并把它的整个连通分量标记掉。**这是所有网格图论题的共同起点**。

## 核心认知二：DFS 泛洪 + 原地沉没（本题灵魂）

```python
class Solution:
    def numIslands(self, grid):
        m, n = len(grid), len(grid[0])
        def dfs(i, j):
            if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] == '0':
                return                      # ① 越界或水 → 停（基线）
            grid[i][j] = '0'                # ② 沉没：原地标记访问（关键！）
            dfs(i+1, j); dfs(i-1, j)        # ③ 四方向扩散
            dfs(i, j+1); dfs(i, j-1)
        count = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == '1':
                    count += 1
                    dfs(i, j)               # 淹掉整片
        return count
```

**三个为什么**：

1. **为什么把 '1' 改成 '0' 而不是用 visited 数组？**——原地修改一行搞定"标记访问 + 防重复计数"两个需求（扫到已经沉没的格子是 '0'，不会重复 count）。题目允许原地修改时这是最优解；
2. **为什么先标记再递归？**——两个相邻的 '1' 会互相调用对方：A 递归 B、B 递归 A、A 递归 B……无限循环。**树的 DFS 天然无环（没有 parent 指针），网格的 DFS 有环（四连通）**——必须"先标记后扩散"；
3. **为什么基线要检查越界？**——树用 `if not root` 判空，网格用 `i<0 or i>=m or j<0 or j>=n` 判越界——这是网格题唯一的"新语法"，和判水 `grid[i][j]=='0'` 合并在同一行。

## 与树的 DFS 对照（用户已会的技能迁移）

| | 树（94/104/226） | 网格（本题） |
|--|-----------------|-------------|
| 节点 | TreeNode | 格子 (i, j) |
| 分支 | left / right（2 个） | 上下左右（4 个） |
| 基线 | `if not root` | `越界 or 是水` |
| 环 | 天然无环 | **有环，必须标记后再递归** |
| 标记 | 不需要 | '1'→'0' 沉没 / visited |

**你的递归 DFS 早就会了——这里只是把树的"2 方向"换成网格的"4 方向"，多一个越界检查和一个防环标记。**

## 解法二：BFS 版（solution_readable.py，另一个武器）

```python
q = deque([(i, j)])
visited[i][j] = True
while q:
    x, y = q.popleft()
    for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
        nx, ny = x+dx, y+dy
        if 边界内 and grid[nx][ny]=='1' and not visited[nx][ny]:
            visited[nx][ny] = True
            q.append((nx, ny))
```

- 用 visited 二维数组标记（不原地改网格，适用于"不能修改输入"的变体题）；
- 空间 O(min(m,n))（队列宽度），深网格比 DFS 省空间；
- 四方向用方向数组 `((1,0),(-1,0),(0,1),(0,-1))` 循环——DFS/BFS 通用的写法。

## 复杂度

- 时间 **O(m×n)**（每格最多访问一次）；
- 空间：DFS 最坏 **O(m×n)**（全 1 网格递归深度）；BFS **O(min(m,n))**。

## 考点

- **网格即图**（连通分量计数）
- DFS 泛洪 + 原地沉没（先标记防环）
- 越界检查四连
- 方向数组 / BFS 队列

## 易错点

1. **先递归后标记**——死循环（两个相邻 '1' 互相调用）；
2. 忘记越界检查——IndexError；
3. 用 `grid[i][j] == 1`（int）——题给的是字符 `'1'`/`'0'`，类型错全盘错；
4. 空网格 `[]` 的 `grid[0]` 会崩——力扣 200 约束 m,n ≥ 1，但防御性可加 `if not grid: return 0`；
5. 递归深度：全 '1' 大网格（200×200）递归 4 万层会超 Python 默认上限——力扣 Python 环境提高了上限所以能过，但超大网格建议 BFS/迭代。

## 变体家族
