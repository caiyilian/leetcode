# 10. 正则表达式匹配 · 解析

## 题目简述

实现带 `.`（任意单字符）和 `*`（前面字符 0 次或多次）的正则匹配，覆盖整个字符串。

## 核心套路：二维 DP（与 72/1143 同款骨架）

```
dp[i][j] = s 前 i 个字符 与 p 前 j 个字符 是否匹配（bool）
答案 = dp[m][n]
```

## 转移：按 p[j-1] 分两类

### ① p[j-1] 是普通字符 或 '.'

```python
dp[i][j] = dp[i-1][j-1]   当 s[i-1] == p[j-1] 或 p[j-1] == '.'
        = False           否则
```

**直觉**：最后一个字符对上，就看前面是否匹配（继承）。

### ② p[j-1] == '*'（难点，两个分支 OR）

`*` 配合它前面的 `p[j-2]`：

```python
分支1 匹配0次：dp[i][j] = dp[i][j-2]     # 丢掉 "x*"，s 不动
分支2 匹配≥1次：dp[i][j] |= dp[i-1][j]   # s 前进一步，p 不动（* 还能继续）
              （要求 s[i-1] == p[j-2] 或 p[j-2] == '.'）
```

**直觉**："x*" 要么整个消失（0 次），要么吃掉一个 s 字符（≥1 次，p 留在原地继续）。

## 初始化

```python
dp[0][0] = True
for j in range(1, n+1):
    if p[j-1] == '*':
        dp[0][j] = dp[0][j-2]   # 空 s 匹配 "x*"（* 匹配 0 次）
    # 普通字符：dp[0][j] 保持 False（空串匹配不了非空模式）
```

**j=1 不用处理**：空串匹配单个普通字符必为 False，默认值即可。

## 复杂度

- 时间 **O(m×n)**；空间 O(m×n)。

## 考点

- 二维 DP（字符串匹配）
- `*` 的"匹配 0 次 / 多次"双分支
- 空串初始化

## 易错点

1. 返回 `dp[m-1][n-1]`（应 `dp[m][n]`——dp 是 (m+1)×(n+1)）；
2. 普通字符 `dp[i][j] = True`（应继承 `dp[i-1][j-1]`）；
3. `dp[i][j-2]` 越界（`*` 前必有字符，j≥2 才进）；
4. 忘初始化第 0 行（`x*` 匹配空串）。
