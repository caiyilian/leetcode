# 32. 最长有效括号 · 解析

## 题目简述

求括号串中最长"有效括号子串"的长度。`(()` → 2、`)()())` → 4。

## 核心套路：栈存下标 + "墙"的概念

**关键洞察**：栈底始终是"最后一个未匹配的右括号"（一堵墙），它把字符串切成两段——墙左边已断，无法与右边连成有效括号。

```python
def longestValidParentheses(self, s):
    max_length = 0
    stack = [-1]                     # 哨兵（初始墙在 -1）
    for i, c in enumerate(s):
        if c == '(':
            stack.append(i)          # 左括号入栈（等待配对）
        else:                        # 右括号
            stack.pop()
            if not stack:            # 栈空 → 这个 ')' 无匹配 → 新的墙
                stack.append(i)
            else:                    # 配对成功 → 有效长度 = 当前 - 墙的位置
                max_length = max(max_length, i - stack[-1])
    return max_length
```

## 栈的结构（用户自悟）

```
栈底 = 最后一个"没人要的右括号"（墙）
上面 = 一堆"等人配对的左括号"
```

**核心等价性**：栈顶是 `)` ⇔ 前面已没有未匹配的左括号（左括号会优先被 pop 配对，留到现在的右括号必然孤立）。

所以每遇到一个"没人要的右括号"，就多一堵墙；`i - stack[-1]` = "从最近的墙到当前右括号"的距离 = 当前连续有效长度。

## DP 解法（略）

dp[i] = 以 s[i] 结尾的最长有效括号长度：
- `s[i]=='('` → 0；
- `s[i]==')'` 且 `s[i-1]=='('` → `dp[i-2]+2`（`...()`）；
- `s[i]==')'` 且左侧是 `(` → `dp[i-1]+2+dp[i-dp[i-1]-2]`（`...))` 套娃）。

栈解法已足够，DP 版存档备用。

## 复杂度

- 时间 **O(n)**；空间 O(n)。

## 考点

- 栈存下标 + 哨兵
- "墙"（未匹配右括号）的边界概念
- 困难题的分段思维

## 易错点

1. 忘 `-1` 哨兵（空栈时 `stack[-1]` 越界）；
2. 栈空时未把当前 `)` 入栈（会漏掉新的墙，导致后续长度算错）；
3. 连续多段有效括号（如 `()()`）需要正确累加（`i - stack[-1]` 自然处理）。
