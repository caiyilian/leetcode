# 647. 回文子串 · 解析

## 题目简述

统计字符串中回文子串的个数（含单个字符）。

## 核心套路：中心扩展法（O(1) 空间）

回文有两种形状，对应两种中心：

```
奇数回文 "aba"   → 中心是单个字符 i
偶数回文 "abba"  → 中心是相邻字符对 (i, i+1)
```

**每向外扩展成功一次（左右相等），就找到一个更长的回文子串** → count += 1。

```python
# 奇数中心（n 个）
for i in range(n):
    l = r = i
    while l >= 0 and r < n and s[l] == s[r]:
        l -= 1; r += 1; count += 1
# 偶数中心（n-1 个）
for i in range(n-1):
    l, r = i, i+1
    while l >= 0 and r < n and s[l] == s[r]:
        l -= 1; r += 1; count += 1
```

## 与 5 最长回文子串（中心扩展版）的血缘

| | 5 | 647 |
|--|----|----|
| 问题 | 最长回文子串 | 回文子串个数 |
| 中心扩展 | 记录 max 长度 | **每扩展成功 count += 1** |
| 空间 | O(1) | O(1) |

**同源同套路**——5 是求极值，647 是求计数。

## 对比其他解法

| 方法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 中心扩展 | O(n²) | **O(1)** | 主流，代码短 |
| DP | O(n²) | O(n²) | `dp[i][j]` 是否回文，空间大 |
| Manacher | O(n) | O(n) | 最优但复杂，面试加分项 |

## 复杂度

- 时间 **O(n²)**；空间 O(1)。

## 考点

- 中心扩展（奇偶双中心）
- 回文性质（左右对称）

## 易错点

1. 漏偶数中心（只数奇数）——"abba" 型漏掉；
2. 扩展时忘边界（`l>=0 and r<n`）；
3. 中心数：奇数 n 个 + 偶数 n-1 个 = 2n-1。
