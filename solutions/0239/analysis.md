# 239. 滑动窗口最大值 · 解析

## 题目简述

大小为 k 的窗口在数组上滑动，求每个窗口的最大值。

## 核心套路：单调队列（递减队列）

维护一个**递减队列**（存索引），队头恒为窗口最大值：

```python
arr = deque()   # 递减：nums[arr[0]] 最大，nums[arr[-1]] 最小
# 加入新元素 i：
while arr and nums[i] > nums[arr[-1]]:   # 队尾比 nums[i] 小的，永不可能成为最大
    arr.pop()
arr.append(i)
# 队头超出窗口：
if arr[0] < 窗口左边界:
    arr.popleft()
# 当前窗口最大值 = nums[arr[0]]
```

## 为什么队尾弹小的不会漏

队尾比 `nums[i]` 小的元素，**位置靠前、值更小**——当它们还在窗口里时，`nums[i]` 也在窗口里（且更大），所以它们永远没机会成为最大，直接弹掉。

## 关键优化：deque 而非 list（用户自悟）

```python
arr.pop(0)      # list：O(n)，要移动整个列表
arr.popleft()   # deque：O(1)，双端队列专为两头操作设计
```

`list.pop(0)` 每次 O(n) → 总 O(n²)；`deque.popleft()` O(1) → 总 O(n)。**这是 239 从慢到快的核心**。

## 复杂度

- 时间 **O(n)**（每个元素入队出队各一次）；
- 空间 O(k)。

## 考点

- 单调队列（递减）
- deque 的 O(1) 两头操作
- 滑窗 + 队列结合

## 易错点

1. 初始化用 `if` 而非 `while`（只 pop 一次，用户 WA 点）；
2. 队头超出窗口范围要 `popleft`（存索引时判断 `arr[0] < 左边界`）；
3. 存的是**索引**而非值（为了判断是否超出窗口）；
4. `list.pop(0)` O(n) 慢，用 deque。
