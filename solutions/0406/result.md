## 解法（贪心 + 插入，标准）

```python
class Solution:
    def reconstructQueue(self, people):
        people.sort(key=lambda x: (-x[0], x[1]))   # 身高降序，同高 k 升序
        result = []
        for h, k in people:
            result.insert(k, [h, k])               # 按 k 插入
        return result
```

## 核心洞察：先处理最高的

`k` 表示"前面有 k 个身高 ≥ 我的人"。**矮的人不会影响高的人的 k**——所以最高的最"自由"：

```
① 按身高降序（同高 k 小在前）
② 逐个 insert(k, person)：高个子先入队定位置，矮个子插入不影响已入队的人
```

**为什么 `insert(k, p)` 正确**：当前插入的人比队列里所有人都矮（或等高且 k 更大），所以插到第 k 位时，前面恰好有 k 个 ≥ 他的人。

## 手推 `[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]`

```
排序： [7,0], [7,1], [6,1], [5,0], [5,2], [4,4]
insert [7,0] k=0 → [[7,0]]
insert [7,1] k=1 → [[7,0],[7,1]]
insert [6,1] k=1 → [[7,0],[6,1],[7,1]]
insert [5,0] k=0 → [[5,0],[7,0],[6,1],[7,1]]
insert [5,2] k=2 → [[5,0],[7,0],[5,2],[6,1],[7,1]]
insert [4,4] k=4 → [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]] ✅
```

## 用户卡点（曾想按 k 排序）

按 k 升序排序不对——**排序的关键维度是"身高"**（k 只在"插入位置"时用）。只有"先高后矮"才能保证"插入不影响已入队的人"。

## 验证

- **5000 组随机合法输入，用户输出全部满足约束（0 失败）**（用约束校验 verify：每个人前面 ≥ 自己身高的人数 == k）；
- 样例：`[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]→[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]`。
