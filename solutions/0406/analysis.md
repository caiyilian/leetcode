# 406. 根据身高重建队列 · 解析

## 题目简述

`people[i] = [h, k]`：第 i 个人的身高 h，前面有 k 个身高 ≥ 他的人。重建队列。

## 核心套路：贪心 + 插入（先高后矮）

```python
people.sort(key=lambda x: (-x[0], x[1]))   # ① 身高降序，同高 k 升序
result = []
for h, k in people:
    result.insert(k, [h, k])               # ② 按 k 插入
```

## 为什么"先高后矮"是关键

k 只被"身高 ≥ 我的人"影响。**矮的人不会影响高的人的 k**（因为他们比自己矮，不算"≥"）。

- 先处理最高的：队列里只有更高/等高的，位置最自由；
- 逐个插入：**当前插入的人比队列里所有人都矮**（或等高且 k 更大），所以插到第 k 位时，前面恰好有 k 个 ≥ 他的人——**正确性由"已入队的人都 ≥ 我"保证**；
- 后面的矮个子插入，不影响前面已经定好位置的人（他们只数比自己高的人，矮个子不算）。

## 为什么不能"按 k 排序"

按 k 升序排序后，同 k 的人谁先谁后没规则，且矮的排后面会破坏前面人的 k 判断。**排序维度是身高，k 只用于插入位置**。

## 正确性论证（为什么贪心成立）

```
处理到 (h, k) 时：
  队列中已有的人身高都 ≥ h（因为按降序处理，更高的先入队）
  插入第 k 位 → 前面恰好 k 个 ≥ h 的人 → k 约束满足
  该插入不影响已入队的人（他们身高 ≥ h，数"≥自己"时 h 这个矮子不算）
```

**归纳成立**：每个 (h,k) 插入后约束满足，且不影响已插入的人。

## 复杂度

- 时间 **O(n²)**（insert O(n)）；空间 O(n)。

## 考点

- 贪心 + 排序维度选择
- 插入法重建
- "谁影响谁"的排序分析

## 易错点

1. 按 k 排序（错，应按身高降序）；
2. 同身高时 k 要升序（`(-h, k)`），否则同高的人互相影响；
3. insert 存 list（leetgo 本地序列化器不认 tuple）。
