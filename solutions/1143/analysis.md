# 1143. 最长公共子序列 · 解析

## 题目简述

求两个字符串的最长公共子序列（不要求连续）。`abcde`/`ace` → 3。

## 核心套路：LCS 的二维 DP

```
dp[i][j] = text1 前 i 个字符 与 text2 前 j 个字符 的 LCS 长度
```

**最后一步分析**（看两个串的最后一个字符）：

```python
if text1[i-1] == text2[j-1]:       # 相等 → 这对必进 LCS
    dp[i][j] = dp[i-1][j-1] + 1    # 左上 +1
else:                              # 不等 → 至少丢一个
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])   # 上/左取 max
```

## 手推 abcde / ace

```
        ""  a  c  e
  ""    0   0  0  0
  a     0   1  1  1     ← a==a → 左上0+1
  b     0   1  1  1     ← b 不匹配 → max(上,左)
  c     0   1  2  2     ← c==c → 左上1+1
  d     0   1  2  2
  e     0   1  2  3     ← e==e → 左上2+1
→ 答案 = 3
```

## 一句话记忆

```
相等：左上 +1      （配对，两串各吃一个字符）
不等：max(上, 左)  （丢一个字符）
```

## 与 62/64 的二维 DP 同构

| 题 | 转移式 | 决策 |
|----|--------|------|
| 62 不同路径 | 上 + 左 | 求和 |
| 64 最小路径和 | min(上, 左) + 值 | 取小 |
| 1143 LCS | 相等?左上+1 : max(上,左) | 分支 |

**二维 DP 的三种形态（加/取小/分支）用户全部掌握。**

## 复杂度

- 时间 **O(m×n)**；空间 O(m×n)（可滚动到 O(n)）。

## 考点

- LCS 经典转移式
- 二维 DP 的"分支"形态
- 最后一步分析

## 易错点

1. dp 数组大小 `(m+1)×(n+1)`（多一行一列存空串）；
2. 字符索引 `text1[i-1]`（dp 的 i 对应字符串的 i-1）；
3. 相等时用 `dp[i-1][j-1]`（不是 max 上左）；
4. 不等时用 `max(dp[i-1][j], dp[i][j-1])`。
