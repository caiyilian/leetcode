# 461. 汉明距离 · 解析

## 题目简述

两个整数二进制表示中，不同位的个数（汉明距离）。

## 核心套路：异或 + 数 1

```python
return (x ^ y).bit_count()   # 或 bin(x^y).count('1') 或 Kernighan
```

**异或是汉明距离的本质**：x^y 的每一位，相同→0、不同→1，所以 x^y 里的 1 的个数就是答案。

## 位运算专题：数 1 的家族（面试常考）

### ① `int.bit_count()`（Python 3.10+，最推荐）
C 语言内建，直接数二进制 1 的个数，最快。

### ② `bin(x).count('1')`
转成 "0b101..." 字符串再数，逻辑对但多一次内存分配。

### ③ Kernighan（纯位操作，面试背这个）
```python
cnt = 0
while x:
    x &= (x - 1)   # 消除最低位的 1
    cnt += 1
return cnt
```
**`n & (n-1)` 是位运算题的万能钥匙**——循环次数恰好 = 1 的个数（只跑"有几个 1"次，比移位快）。

### ④ 逐位移位（最朴素）
```python
cnt = 0
while x:
    cnt += (x & 1)
    x >>= 1
return cnt
```

## 其他 `n & (n-1)` 应用（之前遇到的）

| 场景 | 代码 |
|------|------|
| 计数 1 | `while n: n &= n-1; cnt+=1` |
| 判断 2 的幂 | `n & (n-1) == 0`（且 n>0） |
| 消一个 1 后取数 | `n & (n-1)`（477 计算右下角）

## 复杂度

- 时间 O(1)；空间 O(1)。

## 考点

- 异或（不同位检测）
- 数 1（bit_count / Kernighan / 移位）
- `n & (n-1)` 技巧

## 易错点

1. 漏 `)`（笔误，用户 RE 过）；
2. 以为必须手写位运算（其实 bit_count 内建有）；
3. 汉明距离是"不同位"不是"不同数"。
