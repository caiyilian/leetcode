# 560. 和为 K 的子数组 · 解析

## 题目简述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回**该数组中和为 k 的子数组的个数**。

示例：`nums = [1,1,1], k = 2` → 2（`[1,1]` 出现两次）。

注意：子数组必须是**连续**的，且 `nums` 含**负数**（不能用滑窗双指针，因为和不是单调的）。

## 核心套路：前缀和 + 哈希表计数

### 第一步：前缀和（把子数组和变成两点之差）

定义 `prefix[i] = nums[0] + nums[1] + ... + nums[i-1]`（前 i 个数的和，`prefix[0] = 0`），则：

```
子数组 [i, j) 的和 = prefix[j] - prefix[i]
```

找「和为 k 的子数组」⟺ 找「满足 prefix[j] - prefix[i] = k 的 (i, j) 对」，即：

```
prefix[i] = prefix[j] - k
```

### 第二步：哈希表消灭内层循环（O(n²) → O(n)）

遍历到位置 j 时，`prefix[0..j-1]` 都已经算过——把它们全部"压缩"进一个哈希表 `cnt`（key = 前缀和，value = 出现次数）。那么：

> 有多少个 `i` 满足 `prefix[i] = prefix[j] - k`？—— 直接查 `cnt[prefix[j] - k]`，O(1)。

**一次哈希查询 = 枚举了所有可能的好起点**，这就是 O(n) 的秘密。

## 定稿解法（一遍遍历版）

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        cnt = {0: 1}
        cur = 0
        count = 0
        for x in nums:
            cur += x
            count += cnt.get(cur - k, 0)   # ① 查：之前有几个前缀和 = cur-k
            cnt[cur] = cnt.get(cur, 0) + 1 # ② 记：当前前缀和出现次数 +1
        return count
```

### 两个关键细节（面试必问）

1. **为什么 `cnt` 初始要有 `{0: 1}`？**
   前缀和 `0` 对应"空前缀"，它是子数组 `[0, j)` 的起点。如果不预置，从下标 0 开始的和为 k 的子数组会被漏掉。

2. **为什么先查再记？**
   子数组长度 ≥ 1。如果先记再查，当 `k = 0` 时 `cur - k == cur`，会把"自己对自己"的空子数组也算进去——多算 `cnt[cur]` 个。先查后记保证查到的都是**严格在 j 之前**的前缀和。

### 复杂度

- 时间 **O(n)**：单遍扫描，每步一次哈希查询 + 一次插入，均 O(1)；
- 空间 **O(n)**：哈希表最多存 n+1 个不同前缀和。

## 直观理解：折线 + 水平线

把前缀和序列画成折线（点 j 的高度 = prefix[j]），则：

> 子数组和为 k ⟺ 高度差为 k 的两个点；遍历到 j 时，向下看"高度 = cur - k"的水平线，这条线上之前有几个点，就有几个好起点。

cnt 就是"每条水平线出现过几次"的记账本——每到一个新点，查一条线 + 给自己这条 +1。

## 与滑动窗口的区别（重要）

| | 滑动窗口（3/438 题） | 前缀和哈希（本题） |
|--|---------------------|-------------------|
| 适用 | 窗口和**单调**（全正数）或固定长度 | 含**负数**、任意长度 |
| 核心 | 双指针收缩窗口 | 记录所有历史前缀和 |
| 复杂度 | O(n) | O(n) |

**为什么这题不能用滑窗**：`nums` 有负数，窗口变大和不一定变大，"和太小就扩右"的单调性失效；而前缀和哈希不依赖单调性，任何数据都 O(n)。

## 考点

- 前缀和（子数组和 = 两点前缀和之差）
- **哈希表把"枚举 i"变成"查询一次"**（本题灵魂）
- 边界细节：`{0: 1}` 预置、先查后记
- 与滑动窗口的适用边界（负数数组）
- 418/437/560 系列："和为 k"计数 ← 前缀和类问题的通用钥匙
