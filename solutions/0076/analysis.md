# 76. 最小覆盖子串 · 解析

## 题目简述

在 s 中找最短的、包含 t 所有字符（含重复）的子串。

## 核心套路：滑动窗口 + 双哈希 + valid 计数

```
need    = t 中每个字符需要的次数
windows = 窗口内每个字符的实时次数
valid   = 已达标的字符"种类数"
```

```python
while right < len(s):
    # 扩张 right
    if s[right] in need:
        windows[s[right]] += 1
        if windows[s[right]] == need[s[right]]:
            valid += 1          # 该字符刚好达标
    # 全部达标 → 收缩 left，记录最短
    while valid == class_num:
        更新 best（若更短）
        left 收缩，移出 s[left] 更新 windows/valid
    right += 1
```

## 为什么用 valid（种类数）而非每次全比较

判断"窗口是否覆盖 t"若每次都遍历 need 比较，是 O(字符集)；用 `valid` 计数"达标字符种类数"，`valid == len(need)` 即覆盖，O(1) 判断——这是 76 的核心优化。

## 复杂度

- 时间 **O(n)**；空间 O(字符集)。

## 考点

- 滑动窗口（可变窗口）
- 双哈希 + valid 计数
- 收缩边界的正确维护

## 易错点

1. 收缩 left 时，移出字符要正确更新 windows 和 valid（用户注释"这里要填 left，易错"）；
2. valid 只在 `==` 边界时增减（不是每次 +1）；
3. 空结果返回 `''`；
4. 窗口失效后 break，right 继续扩张。
