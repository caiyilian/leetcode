# 287. 寻找重复数 · 解析

## 题目简述

n+1 个整数，值域 [1, n]，只有一个数重复（可重复多次），找出来。要求 O(1) 空间、不修改数组。

## 核心套路：数组 → 链表 + 快慢指针（Floyd 判圈）

**关键转化**：把 `nums[i]` 看成"节点 i 指向节点 nums[i]"：

```
有重复数 x → 至少两个节点都指向 x → 图里出现环
环入口 = x（被指向两次的数）= 重复数
```

```python
def findDuplicate(self, nums):
    slow = nums[0]
    fast = nums[nums[0]]
    while slow != fast:          # 第一阶段：快慢指针相遇
        slow = nums[slow]        # slow 走一步
        fast = nums[nums[fast]]  # fast 走两步
    slow = 0                     # 第二阶段：slow 回起点
    while slow != fast:          # 同速走，再次相遇 = 环入口
        slow = nums[slow]
        fast = nums[fast]
    return slow
```

## 与 142 环形链表 II 同构

```
142：链表有环，快慢指针两阶段找环入口
287：数组当链表，nums[i] 是 next 指针，环入口 = 重复数
```

**用户已 AC 142，287 是它的数组变体**——同一套"两次相遇"骨架，换了个壳。

## 为什么能 O(1) 空间

哈希表 O(n) 空间不满足进阶要求；快慢指针只用了两个变量，天然 O(1)。

## 复杂度

- 时间 **O(n)**；空间 O(1)。

## 考点

- 数组 → 链表（图）的转化
- Floyd 判圈两阶段
- 142 的数组版

## 易错点

1. 初始化 `slow = nums[0]`、`fast = nums[nums[0]]`（fast 先走两步）；
2. 第二阶段 `slow = 0`（回到起点，不是 nums[0]）;
3. 全重复 `[3,3,3,3,3]` 的边界（环很小，两阶段仍正确）。
