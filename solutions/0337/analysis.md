# 337. 打家劫舍 III · 解析

## 题目简述

二叉树上的打家劫舍：不能同时偷相邻（父子）节点，求最大收益。

## 核心套路：树形 DP（后序遍历 + 双返回值）

```python
def fun(node):
    if not node: return (0, 0)
    rob_l, no_rob_l = fun(node.left)
    rob_r, no_rob_r = fun(node.right)
    rob_now = node.val + no_rob_l + no_rob_r          # 偷自己 → 孩子不能偷
    no_rob_now = max(rob_l, no_rob_l) + max(rob_r, no_rob_r)  # 不偷 → 孩子任选
    return rob_now, no_rob_now
```

## 状态设计（关键）

每个节点返回 **两个值**，而不是一个：

| 返回值 | 含义 |
|--------|------|
| `rob_now` | 偷当前节点时，以它为根的子树最大收益 |
| `no_rob_now` | 不偷当前节点时的最大收益 |

**为什么需要两个**：父节点是否偷，取决于子节点是否偷——所以子节点必须把"两种情况下"的答案都告诉父节点。

## 与 198 打家劫舍的对比

| | 198 数组版 | 337 树版 |
|--|-----------|---------|
| 结构 | 一维数组 | 二叉树 |
| 状态 | `dp[i]` | 每节点 `(偷, 不偷)` |
| 转移 | `max(dp[i-1], dp[i-2]+nums[i])` | 见上 |
| 遍历 | 从左到右 | 后序（先算子树） |

**本质相同**：都是"当前偷不偷"依赖"邻居/子节点偷不偷"。

## 为什么不能"隔层求和"

错误想法：层序遍历，隔层（奇数层 / 偶数层）分别求和取大。**反例**：某些树需要"隔两层"偷才最优，隔层求和会漏解。树形 DP 才是正解。

## 复杂度

- 时间 **O(n)**；空间 O(h)。

## 考点

- 树形 DP
- 双返回值（状态向上传递）
- 后序遍历

## 易错点

1. 只返回一个值（信息不够，父节点无法决策）；
2. 偷当前时忘了"孩子不能偷"（用了 max 而非 no_rob）；
3. 空节点返回 `(0, 0)`。
