# 46. 全排列 · 解析

## 题目简述

给定不含重复数字的数组 `nums`，返回其所有可能的全排列（元素顺序不同的排列）。

## 核心套路：回溯（Backtracking）= 深度优先遍历决策树

**全排列就是一棵决策树**，每层从一个"没用过的数字"里选一个往下走，走到长度 = n 的叶子就是答案：

```
                 []
        /         |         \
      [1]        [2]        [3]
     /   \      /   \      /   \
  [1,2] [1,3] [2,1] [2,3] [3,1] [3,2]
    |     |     |     |     |     |
  123   132   213   231   312   321     ← 6 个叶子 = 6 种排列
```

代码就是"机械地描这棵树"——**递归函数本身即树的 DFS**：

```python
class Solution:
    def permute(self, nums):
        length = len(nums)
        result = []
        def fun(path):
            if len(path) == length:      # 走到叶子
                result.append(path.copy())   # 记录（必须复制！）
                return
            for n in nums:               # 这层能选谁？
                if n in path:            # 已用过的不能再选
                    continue
                path.append(n)           # ① 选它（向前走一步）
                fun(path)                # ② 递归（进入下一层）
                path.pop()               # ③ 撤销（从这步回来，把选择还回去）
        fun([])
        return result
```

## 三个必须懂的细节

### 1. `path.copy()` 为什么必须复制（引用陷阱）

`path` 在整个递归过程中是**同一个列表**（append/pop 原地改）。叶子处如果直接 `result.append(path)`，存的是**引用**——递归返回后 `path.pop()` 会把它改掉，最后 result 里全是同一个空列表：

```
[[], [], [], [], [], []]   ← 不复制的结果（灾难）
```

`path.copy()`（或 `path[:]`）在记录的那一刻**新建一份快照**，后续 pop 不影响它。用户自悟的"类似指针"就是这个。

### 2. `if n in path`：全排列 vs 子集的分水岭

- **全排列**（本题）：每个数字都要用到，但位置任意——判定"**这个数字用过没有**"（`in path` 或 used 数组）；
- **子集**（78 题）：每个数字可选可不选，且不能回头——判定"**从哪个下标开始**"（start 索引）。

这是回溯两类问题唯一的区别，记住这个对比，78 就是改一行的事。

### 3. `path.pop()`：撤销是回溯的灵魂

"选 1 → 递归 → pop 掉 1 → 下一轮循环选 2"——**没有 pop，path 会无限增长**（选过的数字一直留在 path 里，长度永远到不了 n，而且下一层会把已选数字再选一遍）。

**记忆锚点：回溯 = 递归的"可撤销性"。树 DFS 不需要撤销（节点天然分离），但 path 是共享的，必须手动"擦掉脚印"。**

## 优化位（面试可提，本题不必）

- `n in path` 是 O(n) 查找；n ≤ 6 无所谓，但可换 `used = [False]*n` 数组 O(1)；
- 剪枝：全排列没有剪枝空间（所有排列都合法），复杂度就是 O(n!)。

## 复杂度

- 时间 **O(n×n!)**；空间 **O(n)**（递归深度 + path，不含输出）。

## 考点

- **回溯三步模板**（选 → 递归 → 撤销）
- **引用陷阱**（path 快照复制）
- 决策树视角（递归树即答案树）
- "已用判定" vs "起点索引"（排列 vs 子集）

## 易错点

1. `result.append(path)` 不复制——全变空列表（头号错误）；
2. 漏掉 `if n in path`——每个数字被选多次，产生噪声排列；
3. 漏掉 `path.pop()`——path 无限增长 / 死循环；
4. `len(path) == n` 基线放递归**开头**（先判断再选，否则越界）；
5. 46 的 nums **不含重复元素**（含重复是 47 题，要加排序 + 同层去重）。
