# 301. 删除无效的括号 · 解析

## 题目简述

删掉最少数量的括号，使字符串合法（含字母），返回所有结果。

## 核心套路：BFS 逐层删括号

```
while level:                          # level = 当前"已删 k 个括号"的所有结果
    valid = [x for x in level if is_valid(x)]
    if valid: return valid            # 第一个合法层 = 最少删除 → 返回
    level = 下一层(每个串删一个括号)  # set 去重
```

**为什么 BFS**：逐层扩展，**第一次出现合法串的那一层 = 删除数最少**（BFS 的性质）。DFS 会先扎进深层（删很多），不保证最少。

## 为什么 set 去重关键

同一层可能产生**重复字符串**（删不同位置的括号得到同一串，如 `"()(())"` 删两个不同 '(' 都得到 `"()(())"`）——set 自动去重：① 结果不重复 ② 避免重复计算（省时间）。

## 工具函数

```python
def is_valid(s):                       # 计数器法
    cnt = 0
    for c in s:
        if c == '(': cnt += 1
        elif c == ')':
            cnt -= 1
            if cnt < 0: return False   # 右括号多了
    return cnt == 0                    # 配平

def next_level(s):                     # 删一个括号的所有结果
    return {s[:i] + s[i+1:] for i in range(len(s)) if s[i] in '()'}
```

## 奇偶洞察（用户自悟）

合法括号串长度必为偶数。原串长度奇 → 删掉奇个 → 合法层只在奇数层。但 `is_valid` 自动处理（奇数长度 cnt 不可能为 0），无需显式判断——知道这个能帮助理解"为什么不会在错误层停"。

## ⚠️ 两个失败提交的教训

1. **RE**：辅助函数（`is_valid`/`next_level`）提交时漏贴 → 力扣代码框要包含所有辅助定义；
2. **WA**：`elif c == ')'` 写成 `else` → **字母被当成右括号减计数** → 含字母的串全判无效。**判断必须用 `elif`，让字母走空分支**。

## 复杂度

- 时间 **O(2^n)**（最坏）；空间 O(2^n)。set 去重 + 早停通常远好于最坏。

## 考点

- BFS 层数 = 步数（最少删除）
- set 去重（防重复 + 提速）
- 括号合法性判断（计数器）
- 剪枝（只删括号）

## 易错点

1. `else` 误当 `elif`（字母被算右括号——用户的 WA）；
2. 辅助函数漏贴（用户的 RE）；
3. 忘 set（结果重复/超时）；
4. 用 DFS（不保证最少删除）。
