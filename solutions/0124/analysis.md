# 124. 二叉树中的最大路径和 · 解析

## 题目简述

路径 = 任意节点到其**任意子孙**（方向向下，可只含一个节点）。求所有路径中**节点值之和最大**的（**注意：值可正可负**，路径可以不经过根）。

## 核心套路：543 模式的完全版（"两腿更新答案 / 单腿喂父节点"）

任何路径都有唯一"最高点"（路径转折处、最靠近根的节点），在最高点处：

```
路径和 = 最高点.val + 左子树最大贡献 + 右子树最大贡献
```

所以递归后序：**每个节点用"两腿"更新全局答案，用"单腿"喂父节点**——和 543 直径完全同构，只是：

> **124 相对 543 只多一个概念：`max(x, 0)` 负数截断。**

- 543 的"深度"永远 ≥ 0（空子树深度 0），无需截断；
- 124 的"贡献"是**节点值之和**，可以为负——负分支会拖累路径，**直接砍掉（取 0）**，让"贡献"变成"最多能提供多少"。

```python
class Solution:
    def maxPathSum(self, root):
        max_list = [float("-inf")]
        def fun(root):
            if root:
                max_left = max(fun(root.left), 0)     # ① 左贡献（负→0）
                max_right = max(fun(root.right), 0)   # ② 右贡献（负→0）
                now_max = root.val + max_left + max_right      # ③ 两腿：更新答案
                to_father = root.val + max(max_left, max_right)  # ④ 单腿：喂父节点
                max_list[0] = max(max_list[0], now_max)
                return to_father
            return 0
        fun(root)
        return max_list[0]
```

**四个关键点**：

1. **`max(x, 0)` 截断**（①②）：负贡献不要——`max(fun(child), 0)` 比直接 `fun(child)` 多一层截断，这是 124 的灵魂；
2. **两腿 vs 单腿**（③④）：`now_max` 走"经过当前节点拐弯"的路径（更新全局），`to_father` 走"只向上伸一条腿"（父节点才能继续拼）——**同一个节点算两种数**；
3. **`float('-inf')` 初始化**：全负树（如 `[-3]`）时任何路径都 < 0，初始 0 会把答案错成 0——`-inf` 保证至少取到单节点值；
4. 返回值 `to_father` 可能为负（如 `[-3]` 的叶子返回 -3）——父节点那边 `max(x, 0)` 会处理，**不会传染**。

## 543 → 124 演进链（用户自悟迁移）

```
104 最大深度（单腿深度）
  → 543 直径（两腿更新答案 + 单腿喂父节点）★ 模式诞生
    → 124 最大路径和（同模式 + 负数截断）★ 模式完全版
```

用户的 docstring"能组成最大的，以及上报给父节点的不是同一个数"正是 543 归档里标记的**"递归返回值 ≠ 题目答案"**——他已在独立迁移。

## 复杂度

- 时间 **O(n)**（每节点一次）；空间 **O(h)** 递归栈（最坏 O(n)）。

## 考点

- "两腿/单腿"模式（543 → 124 迁移）
- **负数处理**（截断 + -inf 初始化——两个坑都在"负值"上）
- 后序递归（先问完子树再算自己）
- 困难题常考：代码 10 行，概念全在边界值

## 易错点

1. **忘记 `max(x, 0)` 截断**——负子树会把路径和拉低，答案错误；
2. `max_list` 初始 `0`——全负树（`[-3]`）会错成 0，必须 `-inf`；
3. 返回 `to_father` 而不是 `now_max`——父节点需要"单腿"，返回两腿会导致父节点重复计算/路径弯折错误；
4. 空子树贡献 = 0（`fun(None)` 返回 0，不是 -inf）；
5. 混淆"贡献"与"路径和"——贡献是单腿，路径和是两腿，同一节点算两个数。
