# 53. 最大子数组和 · 解析

## 题目简述

给你一个整数数组 `nums`，请你找出一个具有最大和的**连续子数组**（子数组最少包含一个元素），返回其最大和。

示例：`nums = [-2,1,-3,4,-1,2,1,-5,4]` → 6（子数组 `[4,-1,2,1]`）。

注意：**含负数**——所以滑动窗口/双指针失效（和不是单调的，560 学的判断），需要用 DP。

## 核心思想：以位置结尾的局部最优（DP）

定义 `dp[i]` = **以 `nums[i]` 结尾的最大子数组和**。以 i 结尾的子数组只有两种形态：

1. 只含 `nums[i]` 自己（新开一段，扔掉前面）；
2. 由"以 `i-1` 结尾的最佳子数组" + `nums[i]`（接在上一段后面）。

没有第三种——因为"以 i 结尾"的子数组去掉最后一个元素后，剩下的必然是以 `i-1` 结尾的子数组，而我们要其中最大的一段（底子越大，接上同一个 `nums[i]` 后结果越大）。

递推式：

```
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

全局答案 = max 所有 `dp[i]`（最大子数组必然以某个位置结尾，不一定是最后一个——如 `[1,-10,100]` 答案是 100 结尾不是末尾）。

## 定稿解法（Kadane，滚动变量版）

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        length = len(nums)
        curr_sum = nums[0]
        max_sum = curr_sum
        for i in range(1, length):
            if curr_sum < 0:
                curr_sum = nums[i]
            else:
                curr_sum += nums[i]
            max_sum = max(max_sum, curr_sum)
        return max_sum
```

### 与递推式的对应

| 代码 | 递推式 |
|------|--------|
| `curr_sum < 0` → `curr_sum = nums[i]` | 选 `nums[i]`（负前缀扔掉，接上只会更差） |
| 否则 → `curr_sum += nums[i]` | 选 `dp[i-1] + nums[i]` |

`if/else` 只是把 `max` 展开了：`dp[i-1] < 0` 时 `nums[i]` 更大，否则 `dp[i-1]+nums[i]` 更大。`curr_sum` 就是滚动中的 `dp`（只依赖上一个值，无需数组）。

### 复杂度

- 时间 **O(n)**：单遍扫描；
- 空间 **O(1)**：两个变量。

## 为什么 dp 是"对"的（正确性直觉）

想找一个反例推翻它：某个全局最优子数组 `[l..r]`，它内部的每个前缀 `[l..m]`（m < r）……若其中某个前缀和为负，那么从它后面重新开始一段会更优——Kadane 的"扔掉负前缀"正好保证永远不会错过最优起点。**任何一个以负数开头的子数组都不可能成为最优的一部分**（去掉负前缀只会更大），所以每当累计和为负就重置，是安全的。

## 考点

- **Kadane 算法**（面试超高频，必须脱口而出）
- DP 状态定义（"以 i 结尾"）与滚动数组优化
- 边界：全负数（`nums[i]` 单干分支兜底，答案 ≥ 最大负数）；单元素
- 进阶：分治解法 O(n log n)（跨中点最大段），面试可拓展提问
- 变形：最大子数组乘积（152）、环形最大子数组（918）——注意乘法符号问题
