# 279. 完全平方数 · 解析

## 题目简述

用最少的平方数（1,4,9,16...）凑成 n。

## 核心套路：最后一个平方数分析（凑数 DP 模板）

```
dp[i] = min(dp[i - j²] + 1)   对所有 j² ≤ i
dp[0] = 0
```

```python
def numSquares(self, n):
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        best = float('inf')
        j = 1
        while j * j <= i:
            best = min(best, 1 + dp[i - j * j])
            j += 1
        dp[i] = best
    return dp[-1]
```

## 用户的错误思路 → 正确思路

**错误（拆两半 + max）**：

```python
final_count = min(final_count, max(fun(i), fun(n-i)))   # 两处都错
```

1. `max` 应为 `+`（拆分后个数相加，不是取最大）；
2. 根本错在"从哪劈开"的思维——DP 应该问"**最后一个平方数是几**"，而不是"劈成两半"。

**正确（最后一个平方数）**：`dp[i] = min(dp[i-j²] + 1)`，枚举最后一个平方数 j²，剩余 i-j² 的最优解 + 1。

## 最后一步分析法（70/198/279/322 统一）

| 题 | 最后一步问法 | 转移式 |
|----|-------------|--------|
| 70 | 最后跨 1 还是 2 | f(i)=f(i-1)+f(i-2) |
| 198 | 最后一家偷不偷 | f(i)=max(f(i-1), nums[i]+f(i-2)) |
| 279 | 最后一个平方数 j² | dp[i]=min(dp[i-j²]+1) |
| 322 | 最后一块硬币 c | dp[i]=min(dp[i-c]+1) |

**这是 DP 最核心的思维**——"从最后一步往回看"，而不是"从前面往后凑"。

## 数学定理（四平方和定理，非面试重点）

Lagrange 四平方和定理：答案 ∈ {1,2,3,4}。Legendre 三平方和定理：n 能用 ≤3 个平方数 ⇔ n ≠ 4^a(8b+7)。据此 O(√n) 逐个排除。**只对"平方数"有效，322 换硬币面值即失效——DP 才是通用武器。**

## 复杂度

- 时间 **O(n√n)**；空间 O(n)。

## 考点

- 最后一个平方数分析
- 凑数 DP 模板（min(dp[i-x]+1)）
- 记忆化 vs 迭代（凑数题首选迭代）

## 易错点

1. "拆两半 + max" 的错误思路（用户踩坑）；
2. 忘 dp[0]=0 基础（枚举到平方数本身需要）；
3. 内层 j 的枚举范围 `j*j <= i`；
4. 用记忆化递归 n 大时 RecursionError（迭代更稳）。
