# 621. 任务调度器 · 解析

## 题目简述

任务列表 + 冷却时间 n：相同任务执行后必须隔 n 个单位才能再执行，求最短总时间。

## 核心套路：贪心 + 桶

```
max     = 最高频任务的次数
cnt_max = 有几个任务达到最高频
答案 = max( (max-1)×(n+1) + cnt_max, len(tasks) )
```

## 一、贪心：先排最难的

**贪心定义**：每一步做"当下看起来最好"的选择，赌局部最优 = 全局最优。

这里：**先安排最高频任务 A**——它是瓶颈（A 之间必须隔 n 个其他任务），只要 A 排好了，其他任务总能插进 A 的冷却空位。**最难的排好了，其他都不是问题**——这就是贪心的"先难后易"。

**你已做过的贪心题**：55 跳跃（每步跳最远）、121 股票（记录最低价）、763 划分字母区间（贪心扩展）——都是"局部最优 = 全局最优"。

## 二、桶：任务 + n 个冷却位

**桶定义**：把"1 个任务 + 它后面必须空着的 n 个位置"打包成一个周期（n+1 格）。

```
A 出现 max 次 → 排布：
| A | 填 | 填 |   ← 桶 1（n+1 格）
| A | 填 | 填 |   ← 桶 2
...
| A | 填 | 填 |   ← 桶 max-1
| A A A (cnt_max 个)  ← 最后一批（同频最高任务并排，不需冷却）
```

**为什么最后一批是 cnt_max**：如果 B 也和 A 一样是最高频，最后一批要同时放 A、B（它们同频，并列不需要隔开）→ 加的是 cnt_max。

## 三、为什么公式是最优（下界可达）

- **下界**：A 出现 max 次且每次之间必须隔 n 个 → 总长 ≥ `(max-1)×(n+1) + 1`（若只有 1 个最高频）。推广到 cnt_max 个同频 → `(max-1)×(n+1) + cnt_max`。
- **可达**：按"最高频优先"贪心填充，其他任务依次塞进空位，一定能达到这个下界 → **贪心 = 最优**。

## 四、clamp：`max(公式, len(tasks))`

公式假设"有空闲（idle）"。如果其他任务足够多、能填满所有冷却位还有富余 → **全程无空闲** → 答案就是任务总数 `len(tasks)`（直接顺序排）。

## 复杂度

- 时间 **O(n)**；空间 O(1)（26 个字母）。

## 考点

- 贪心（先排最高频）
- 桶思想（周期 = 任务 + 冷却）
- 公式推导 + clamp

## 易错点

1. 忘记 `cnt_max`（多任务同频时最后一批要并排，不是 1）；
2. 忘记 `max(公式, len(tasks))`（无空闲情况）；
3. 以为要模拟调度（其实公式一步算完）。
