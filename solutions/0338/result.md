## 解法（位运算 + DP）

```python
class Solution:
    def countBits(self, n):
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i >> 1] + (i & 1)      # 去掉最低位 + 最低位
        return dp
```

## 💡 为什么 `dp[i] = dp[i>>1] + (i&1)`（用户要求讲透）

**核心观察**：`i` 的二进制 = `i>>1` 的二进制 **在末尾追加一位**。

```
i=5 (101) = (i>>1=2 是 "10") 追加 "1"
i=6 (110) = (i>>1=3 是 "11") 追加 "0"
i=4 (100) = (i>>1=2 是 "10") 追加 "0"
```

所以 **i 的 1 的个数 = (i>>1 的 1 的个数) + (最低位是不是 1)**：

```
dp[i>>1]  ← 去掉最低位后剩下的 1 的个数
i & 1     ← 最低位本身是不是 1（0 或 1）
```

## 手推 dp 表（n=7）

| i | 二进制 | 计算 | dp[i] |
|---|--------|------|-------|
| 0 | 0 | — | 0 |
| 1 | 1 | dp[0] + 1&1 = 0+1 | 1 |
| 2 | 10 | dp[1] + 2&1 = 1+0 | 1 |
| 3 | 11 | dp[1] + 3&1 = 1+1 | 2 |
| 4 | 100 | dp[2] + 4&1 = 1+0 | 1 |
| 5 | 101 | dp[2] + 5&1 = 1+1 | 2 |
| 6 | 110 | dp[3] + 6&1 = 2+0 | 2 |
| 7 | 111 | dp[3] + 7&1 = 2+1 | 3 |

## 三种等价写法

```python
dp[i] = dp[i>>1] + (i&1)      # 去掉最低位 + 最低位
dp[i] = dp[i>>1] + (i%2)      # %2 等价 &1
dp[i] = dp[i & (i-1)] + 1     # i&(i-1) 消掉最低位的 1，计数 +1
```

## 为什么算 DP

- **状态**：`dp[i]` = i 的 1 的个数；
- **转移**：`dp[i] = dp[i>>1] + (i&1)`；
- **依赖**：`i>>1 < i`（保证已算过）。

## 验证

- 样例：`n=2→[0,1,1]`、`n=5→[0,1,1,2,1,2]`。

## 复杂度

- 时间 **O(n)**；空间 O(n)（输出数组）。
