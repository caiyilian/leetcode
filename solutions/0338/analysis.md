# 338. 比特位计数 · 解析

## 题目简述

返回数组 `ans`，`ans[i]` 是 `i` 的二进制表示中 1 的个数（i 从 0 到 n）。

## 核心套路：位运算 + DP

```python
dp[i] = dp[i >> 1] + (i & 1)
```

## 关键观察：二进制"右移一位"的关系

```
i 的二进制 = (i >> 1) 的二进制 在末尾追加一位
```

| i | 二进制 | i>>1 | 关系 |
|---|--------|------|------|
| 5 | 101 | 2 = "10" | "10" 追加 "1" |
| 6 | 110 | 3 = "11" | "11" 追加 "0" |
| 4 | 100 | 2 = "10" | "10" 追加 "0" |

**结论**：`i` 的 1 的个数 = `i>>1` 的 1 的个数 + 最低位是否为 1。

```
dp[i>>1]  ← 去掉最低位，剩下部分的 1 的个数（子问题）
i & 1     ← 最低位本身（0 或 1）
```

## 手推表（n=7）

```
i  二进制   dp[i] = dp[i>>1] + (i&1)
0    0       0
1    1       0 + 1 = 1
2   10       1 + 0 = 1
3   11       1 + 1 = 2
4  100       1 + 0 = 1
5  101       1 + 1 = 2
6  110       2 + 0 = 2
7  111       2 + 1 = 3
```

## 为什么是 DP（而不是纯位运算）

- **状态**：`dp[i]` = i 的 1 的个数；
- **转移**：由更小的 `i>>1` 推出；
- **依赖顺序**：`i>>1 < i`，从小到大遍历即可。

和斐波那契 `dp[i]=dp[i-1]+dp[i-2]` 同构——**用更小的数推更大的数**。

## 三种等价解法

| 写法 | 说明 |
|------|------|
| `dp[i>>1] + (i&1)` | 去掉最低位 + 最低位（推荐） |
| `dp[i>>1] + (i%2)` | `%2` 等价 `&1` |
| `dp[i & (i-1)] + 1` | `i&(i-1)` 消掉最低位的 1，计数 +1 |

## 复杂度

- 时间 **O(n)**；空间 O(n)。

## 考点

- 位运算（右移、与）
- DP 思想（子问题递推）
- 二进制规律

## 易错点

1. `i>>1` 写成 `i>>2`（右移 1 位才是"去掉最低位"）；
2. `i&1` 写成 `i%10`（十进制思维）；
3. dp 数组大小 `n+1`（含 0）。
