# 51. N 皇后 · 解析

## 题目简述

`n×n` 棋盘放 n 个皇后，任意两个不能互相攻击（**不同行、不同列、不在同一对角线**）。返回所有摆法（棋盘字符串数组）。

## 核心套路：回溯收官——"这层能选谁"的判断换成冲突检查

**回溯家族八种"锁"的最后一块拼图**：

| 题 | 这层能选谁（锁） |
|----|----------------|
| 46 全排列 | 没用过的数字（in path） |
| 78 子集 | start 及以后的元素（下标锁） |
| 17 字母组合 | 当前数字的字母表 |
| 39 组合总和 | 可重复选 + 排序 break |
| 131 分割回文串 | 回文段才能切 |
| **51 N皇后** | **列/两条对角线不冲突的格子** |

## 三步推导（用户为什么秒懂）

**① 行不用管**：递归参数 `i` 就是行号——每层放一行、每行一个皇后 → **天然满足"不同行"**。

**② 列用一个 set**：`col.add(j)` 标记被占的列，`j not in col` 判断。

**③ 对角线用"编号"而不是"位置"**（用户提示前的直觉是存位置列表，升级后）：

```
格子 (i, j) 有两条对角线：
  ↘（左上↔右下）：同行斜线所有格子的 i-j 相等 → 用 (i-j) 当编号
  ↙（左下↔右上）：同行斜线所有格子的 i+j 相等 → 用 (i+j) 当编号

例：(1,2) 的 ↘ 编号 = -1； (2,3) 的 ↘ 编号也 = -1 → 同斜线 → 冲突
```

**判断冲突一行**：

```python
if j not in col and (i+j) not in diag1 and (i-j) not in diag2:
```

**回溯撤销**（用户自己想到的"去掉列表"，用集合版）：

```python
col.remove(j); diag1.remove(i+j); diag2.remove(i-j)
```

## 定稿 + 一个聪明优化（用户自驱）

```python
temp = ["."*j + "Q" + "."*(n-j-1) for j in range(n)]   # 预生成：每列对应的整行字符串
path.append(temp[j])                                    # 放皇后 = 直接取用，O(1)
```

不预生成的话每次要 `"."*j + "Q" + "."*(n-j-1)` 拼接——预生成让"放皇后"变成查表，代码也干净。

## 复杂度

- 时间 **O(n!)**（第一行 n 种选择，逐行剪枝后约 n!/2；n=9 时 352 个解，秒级）；
- 空间 **O(n)**（三集合 + 递归栈 + path）。

## 考点

- **对角线编号**（i+j / i-j 的恒等号妙用——本 Core 新概念）
- 行列天然约束 + 集合冲突检查
- 回溯撤销三集合
- 预生成优化

## 易错点

1. **对角线编号的负值**：`i-j` 可为负，set 无妨（布尔数组版要 +n-1 偏移）；
2. 撤销忘了 remove 某个集合 → 后续路径被污染（False 漏解）；
3. `path.copy()` 记录（引用陷阱）；
4. 两条对角线都要检查（只查一条会漏掉斜向攻击）；
5. 不必检查"行冲突"——递归层 i 天然不同行。
