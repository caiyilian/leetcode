# 312. 戳气球 · 解析

## 题目简述

戳破气球 i 得 `nums[i-1]*nums[i]*nums[i+1]`（越界按 1 算），求最大金币。

## 核心套路：区间 DP + 反向思维

### 第一步：为什么不能正向思考

按"第一个戳哪个"分解 → 戳掉一个后左右两边**连通**，边界互相影响 → 子问题不独立 → DP 无法分解。

### 第二步：反向思考（关键）

**枚举最后一个戳的气球 k**（`i < k < j`）：

```
戳 k 时，区间 (i,j) 内其他气球都戳完了
→ k 的左右邻居就是边界 i、j
→ 得分 nums[i] * nums[k] * nums[j]
→ 左半 (i,k) 和右半 (k,j) 独立
```

### 第三步：转移式

```python
dp[i][j] = max over k in (i,j) of:
           dp[i][k] + nums[i]*nums[k]*nums[j] + dp[k][j]
```

## 补哨兵

```
原: [3,1,5,8]
补: [1, 3, 1, 5, 8, 1]
```

两端各补 1，边界恒存在，转移式直接可用。

## 状态定义与遍历顺序

```
dp[i][j] = 开区间 (i,j) 内全部戳完的最大金币（不含 i、j）
答案 = dp[0][n+1]
```

**按区间长度从小到大**填表（长区间依赖短区间）：

```python
for each_len in range(2, length):
    for i in range(0, length - each_len):
        j = i + each_len
        for k in range(i+1, j):
            ...
```

## 空区间 = 0（用户疑惑点）

- `dp[i][i+1]`（长度 1 区间）：内部无气球 → **0**；
- 全 0 初始化恰好覆盖，无需额外 base case。

## 与 5 最长回文子串（DP 版）的联系

| | 5 回文子串 DP | 312 戳气球 |
|--|--------------|-----------|
| 状态 | `dp[i][j]` 是否回文 | `dp[i][j]` 最大金币 |
| 依赖 | 更短的区间 | 更短的区间 |
| 遍历 | 按长度递增 | 按长度递增 |

**都是区间 DP**——`dp[i][j]` 依赖 `(i,k)`、`(k,j)` 等更小区间，必须按长度从小到大填。

## 复杂度

- 时间 **O(n³)**；空间 O(n²)。

## 考点

- 区间 DP
- **反向思维**（枚举"最后一个"而非"第一个"）
- 补哨兵
- 空区间边界

## 易错点

1. 正向思考（枚举第一个戳）→ 子问题不独立，做不出来；
2. 忘补哨兵 → 边界处理麻烦；
3. 遍历顺序（必须按长度从小到大）；
4. 结果取 `dp[0][n+1]`（补哨兵后的整个开区间）。
