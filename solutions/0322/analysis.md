# 322. 零钱兑换 · 解析

## 题目简述

用给定硬币凑 amount，求最少硬币数（凑不出返回 -1）。

## 核心套路：最后一块硬币分析（DP"凑数"模板）

**和 279 完全平方数同构**——枚举"最后一块硬币 c"：

```
dp[i] = min(dp[i - c] + 1)   对所有 c in coins（i-c >= 0）
dp[0] = 0                     凑 0 需要 0 块
凑不出 = inf                  最终 inf → -1
```

```python
def coinChange(self, coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for c in coins:
            if i - c >= 0:
                dp[i] = min(dp[i], dp[i - c] + 1)
    return -1 if dp[amount] == float('inf') else dp[amount]
```

## 279 → 322："凑数 DP"的统一骨架

| | 279 完全平方数 | 322 零钱兑换 |
|--|---------------|-------------|
| 转移 | dp[i]=min(dp[i-j²]+1) | dp[i]=min(dp[i-c]+1) |
| "硬币" | 平方数 j² | 任意面值 c |
| 数学捷径 | Lagrange/Legendre 定理 | 无（定理失效） |

**这是 DP 相对数学定理的优势**：通用、可迁移。硬币面值一变，数学定理全废，DP 骨架不变。

## 用户版（记忆化递归）与标准版（迭代）的对照

- 用户版：自顶向下（照着 `fun(n)=min(1+fun(n-c))` 写），递归栈开销 + 深度风险；
- 标准版：自底向上填表，更快更安全。

**记忆锚点**：279/322 这类"凑数"题，迭代 DP 填表是首选（转移式简单、无递归风险）。

## ⚠️ 易错点（用户 WA 实录）

```python
if n < coins[0]:    # ❌ coins 不一定排序！coins[0] 不是最小面值
if n < min(coins):  # ✅ 用 min
```

**反例** coins=[5,1,2], amount=3：`3 < coins[0]=5` 误判凑不出 → -1，实际 3=1+1+1。**需要最小面值就 `min(coins)`，别假设有序。**

## 复杂度

- 时间 **O(amount × len(coins))**；空间 O(amount)。

## 考点

- 最后一块硬币分析（凑数 DP 模板）
- inf 表示"凑不出" + 最终 -1 转换
- 记忆化 vs 迭代的取舍（凑数题首选迭代）

## 易错点

1. `coins[0]` 当最小面值（用户 WA 点，coins 未排序）；
2. 忘 dp[0]=0 基础；
3. 凑不出用 inf 兜底，最终判断 `dp[amount]==inf → -1`；
4. 内层循环忘记 `if i-c>=0` 越界判断。
