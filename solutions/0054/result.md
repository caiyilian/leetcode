## 解法

用户独立的**方向轮转 + 四边界收缩**写法（无 visited 数组、无方向数组）：

- `dir_max = [right, bottom, left, top]` 四个边界，走过的层向内收缩（`top+1 / right-1 / bottom-1 / left+1`）；
- `use_dir_index` 0→1→2→3→0 轮转（右→下→左→上）；
- `count == m*n` 终止，每个元素恰好访问一次。

同时归档一份**可读性优化版**（`solution_readable.py`）：逻辑完全一致（3 万组对拍 0 差异），仅改清晰变量名 + 去掉 `dir_max[-1]` 负索引写法，便于复习。

## 复杂度

- 时间 **O(m·n)**：每个元素恰好访问一次（理论最优）；
- 空间 **O(1) 额外**：只有 4 个边界变量 + 3 个标量；只读矩阵不改输入，**连进阶要求（O(1) 空间且不修改输入）都满足**。

力扣计时精度 1ms，低于 1ms 显示为 0ms——**击败 100% 是真实的**（属于提交最快档）。原因：O(mn) 下限复杂度 + 无 visited/方向数组的常数开销 + 测试数据规模小（最大 10×10），几十微秒即可跑完。
