# 309. 买卖股票的最佳时机含冷冻期 · 解析

## 题目简述

可以多次买卖，但卖出后第二天是冷冻期（不能买），求最大利润。

## 核心套路：状态机 DP（三状态）

```
dp[i][0] = 第 i 天结束时"持有股票"的最大收益
dp[i][1] = 第 i 天"刚卖出"（进入冷冻）的最大收益
dp[i][2] = 第 i 天"不持有且不在冷冻"的最大收益
```

**转移**：

```python
dp[i][0] = max(dp[i-1][0], dp[i-1][2] - prices[i])   # 继续持有 / 空仓买入
dp[i][1] = dp[i-1][0] + prices[i]                    # 只有持有才能卖
dp[i][2] = max(dp[i-1][1], dp[i-1][2])               # 冷冻结束 / 继续空仓
```

**三个关键约束**（冷冻期的灵魂）：
1. **买入只能从 `rest` 来**（`dp[i-1][2] - price`，不是 `sold`）；
2. **卖出只能从 `hold` 来**；
3. `sold` 只存在一天，第二天就转成 `rest`（冷冻结束）。

## 状态机图

```
      -price（买入）
rest ──────────────→ hold
 ↑                    │
 │ rest（冷冻结束）    │ +price（卖出）
 └────── sold ←───────┘
```

## 与 121/122 的对比

| | 121 单次买卖 | 122 多次买卖 | 309 含冷冻期 |
|--|-------------|-------------|-------------|
| 状态数 | 1（最低价） | 2（持有/空仓） | 3（持有/冷冻/空仓） |
| 约束 | 只交易一次 | 任意次 | 卖出后冷冻一天 |

## 初始化易错点

```python
dp[0][0] = -prices[0]    # 持有 = 买入成本（不是 dp[0][1]！）
dp[0][1] = 0 或 -inf     # 第一天不可能卖出
dp[0][2] = 0             # 第一天不操作
```

**`-price` 是买入成本（持有），`+price` 是卖出收益（卖出）——别放反列。**

## 复杂度

- 时间 **O(n)**；空间 O(n)（三个变量滚动 → O(1)）。
