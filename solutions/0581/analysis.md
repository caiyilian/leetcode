# 581. 最短无序连续子数组 · 解析

## 题目简述

要排序整个数组，找出需要排序的**最短连续子数组**的长度。

## 核心套路一：排序比较法（简单，O(n log n)）

```python
s = sorted(nums)
l = 0; r = len(nums) - 1
while l < len(nums) and nums[l] == s[l]: l += 1   # 第一个站错位置
while r >= 0 and nums[r] == s[r]: r -= 1          # 最后一个站错位置
return r - l + 1 if r >= l else 0
```

排序后就是"应有的样子"，凡是没在应有位置的元素都落在区间里。

## 核心套路二：双指针扫描（进阶，O(n)）★ 用户选用

```
左→右扫，维护"左边已见最大值 max_l"：
  nums[i] >= max_l → 更新 max_l
  nums[i] <  max_l → r = i    ← 最后一个"小于左边最大值"的位置
右→左扫，维护"右边已见最小值 min_r"：
  nums[length-1-i] <= min_r → 更新 min_r
  nums[length-1-i] >  min_r → l = length-1-i  ← 最后一个"大于右边最小值"的位置
答案 = r - l + 1
```

## 为什么 r、l 的定义是对的

- `r` 右边：每个元素都 ≥ 左边的最大值 → 左边的小元素不会跑过来 → 右边天然有序；
- `l` 左边：每个元素都 ≤ 右边的最小值 → 右边的大元素不会跑到左边 → 左边天然有序；
- 中间 `[l, r]` 就是所有"站错位置"的元素的覆盖区间。

## ⚠️ 等号的坑（用户 WA→AC 的关键）

**比较必须带 `=`**（`>=` / `<=`）：

```
[1,3,2,2,2]：排序后 [1,2,2,2,3]，未排序区间 [3,2,2,2] 长度 4
左扫用 > ：2>3 否 → r=1（漏掉后面三个 2）→ 错
左扫用 >=：2>=3 否 → r 逐个更新到 4 → 对
```

**相等元素也要算"站错位置"**（升序后它们要前移）；不带等号会把"相等但降序"的连续段（如 3,2,2,2）后半截漏掉。

## 复杂度

- 排序法：时间 O(n log n)；
- 双指针：**时间 O(n)，空间 O(1)**。

## 考点

- 未排序区间的边界定位
- 左右哨兵扫描（前/后缀最值）
- **等号边界**（相等元素处理）

## 易错点

1. 比较不带等号（漏相等元素，用户的 WA 点）；
2. 只找第一个乱序点（`nums[i] > nums[i+1]` 的首尾）——这只是必要不充分，会漏；
3. 返回长度时 `r - l + 1`，完全有序时返回 0。
