# 152. 乘积最大子数组 · 解析

## 题目简述

求连续子数组的最大乘积（元素含负数）。

## 核心套路：双状态 DP（最大 + 最小）

**为什么不能只用"最大"一个状态**：乘法有符号翻转——一个很小的负数，乘上下一个负数会变成很大的正数。所以必须**同时记录"最大乘积"和"最小乘积"**：

```python
dp_max[i] = max(nums[i], nums[i]*dp_max[i-1], nums[i]*dp_min[i-1])
dp_min[i] = min(nums[i], nums[i]*dp_max[i-1], nums[i]*dp_min[i-1])
答案 = max(dp_max)
```

三个候选的含义：
1. `nums[i]`：从当前元素**重新起一段**（应对 0 或符号）；
2. `nums[i] * dp_max[i-1]`：接上"最大"（正 × 正）；
3. `nums[i] * dp_min[i-1]`：接上"最小"（负 × 负 = 正，反超）。

## 手推 [-2,3,-4]

```
dp_max[0]=-2, dp_min[0]=-2
i=1 (3)：dp_max = max(3, 3×-2=-6, 3×-2=-6) = 3
         dp_min = min(3, -6, -6) = -6
i=2 (-4)：dp_max = max(-4, -4×3=-12, -4×-6=24) = 24 ✅
         dp_min = min(-4, -12, 24) = -12
答案 = 24
```

注意 i=2 的第三个候选 `-4 × dp_min(=-6) = 24`——**正是"最小状态"救了场**。

## 53 → 152：加法到乘法

| | 53 最大子数组和 | 152 乘积最大 |
|--|----------------|-------------|
| 状态 | 单状态（dp[i]=当前最大和） | 双状态（最大 + 最小） |
| 原因 | 求和没有符号翻转 | 乘法负负得正 |
| 转移 | dp[i]=max(nums[i], dp[i-1]+nums[i]) | dp_max/min 三候选 |

## 复杂度

- 时间 **O(n)**；空间 O(n)（双状态数组，可滚动到 O(1)）。

## 考点

- 双状态 DP（负负得正）
- "以 i 结尾"的经典定义
- 三候选（重新起段 / 接最大 / 接最小）

## 易错点

1. 只维护最大、漏掉最小（负负得正会漏）；
2. `best` 初始 `float('-inf')`（全负数时答案也是负数，不能初始 0）；
3. 忘 `nums[i]` 单独候选（遇到 0 会断段）；
4. dp 数组用 [1] 初始化（空段乘积 = 1，乘任何数不变）。
