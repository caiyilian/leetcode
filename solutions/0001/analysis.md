# 1. 两数之和 · 解题解析

## 一句话思路

遍历数组时，把「已经见过的数字 → 它的下标」记进哈希表；对当前数字 `num`，只要 `target - num` 在表里，就说明之前见过它的搭档，直接返回两个下标。

## 核心洞察

暴力法是 O(n²) 的两两配对；哈希表把「查找搭档」从 O(n) 降为 O(1)，一趟遍历 O(n) 解决。关键在于**边遍历边记录**——先查表再存自己，避免配对到自身（如 `[3,3]`, target=6 不会误用同一个 3 两次）。

## 实现

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}
        for i, num in enumerate(nums):
            if target - num in seen:
                return [seen[target - num], i]
            seen[num] = i
        return []
```

- **时间复杂度**：O(n)，单次遍历，哈希查询平均 O(1)
- **空间复杂度**：O(n)，哈希表最多存 n 个元素
- **易错点**：
  1. 先查表、后存自己——保持「当前位置不参与配对」的语义
  2. 返回值是下标不是值；顺序无所谓，但示例习惯（前者下标小）
  3. 不要用字典推导式一次性建表（重复值会被后者覆盖，`[3,3]` 会出错）

## 进阶思路对比

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 暴力双循环 | O(n²) | O(1) | 最朴素，不满足进阶要求 |
| 哈希表（本解法） | O(n) | O(n) | 时间换空间，最优解 |
| 排序 + 双指针 | O(n log n) | O(1)~O(n) | 可解但需自建下标映射，反直觉 |
