# 121. 买卖股票的最佳时机 · 解析

## 题目简述

一次买卖，求最大利润。`[7,1,5,3,6,4]` → 5（1 买 6 卖）。

## 核心套路：一次遍历，记录"历史最低买入价"

**关键洞察**：固定"在第 i 天卖出"，最大利润 = `prices[i] - 历史最低买入价`。所以只需一路扫描，同时维护两个量：

```python
min_price = float('inf')     # 历史最低买入价
max_profit = 0               # 最大利润
for p in prices:
    min_price = min(min_price, p)              # 更新历史最低
    max_profit = max(max_profit, p - min_price) # 今天卖的最大利润
return max_profit
```

## 动态规划视角（这题是 DP 入门第一课）

**为什么它是 DP**：答案（最大利润）是由"子问题的最优解"递推出来的：

```
① 状态定义：dp[i] = 前 i 天能获得的最大利润
② 状态转移：dp[i] = max(dp[i-1], prices[i] - 前 i 天最低价)
             ↑        ↑             ↑
          今天不卖   之前最优      今天卖(用历史最低买)
③ 滚动优化：dp[i] 只依赖 dp[i-1] 和一个全局 min → 不用数组，两个变量
```

**用户版对应**（用户"用了 DP 但不知道"）：
- `min_val` = 转移公式的"历史最低价"
- `all_min` = `dp[i]`（滚动变量）
- 循环 = dp[0] → dp[n-1] 的递推

**记忆锚点：动态规划 = "当前最优解 = 之前最优解 + 当前一步决策"**。121 的"当前一步决策"就是"今天卖（用历史最低买）" vs "今天不卖（保持之前最优）"。理解这一句，后面 118/198/279/322 全是同一骨架换皮。

## 为什么不用贪心的术语也可以

121 同时是贪心和 DP 的经典交集题：
- **DP 视角**：维护 `dp[i]` 状态递推；
- **贪心视角**：每步"局部最优"（记录最低买点）最终导出全局最优。

两者结论一致（都是 O(n) 两变量），因为**这题的"局部最优"恰好能拼出"全局最优"**。面试两种说法都算对。

## ⚠️ 失败教训：暴力 O(n²) → 一次遍历 O(n)

暴力 `for i: for j: max(prices[j]-prices[i])` 枚举所有买卖组合 O(n²)。优化关键：**不需要记住所有买入点，只需"历史最低"一个**——把"两自由度的全枚举"降成"一个全局最优状态 + 一次扫描"。

## 复杂度

- 时间 **O(n)**；空间 **O(1)**。

## 考点

- 一次遍历 + 历史最低（贪心）
- 状态转移 + 滚动优化（DP 入门）
- 两自由度降一自由度（暴力 → 优化的思路）

## 易错点

1. 暴力两层循环（TLE 点）；
2. 忘记"一直跌返回 0"（`max_profit` 初始 0，从不取负）；
3. `min_price` 初始 `float('inf')`（而不是 prices[0]，避免空数组/首元素边界）；
4. 变量命名误导（用户的 all_min 实为最大利润）。
