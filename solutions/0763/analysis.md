# 763. 划分字母区间 · 解析

## 题目简述

字符串切成尽量多片段，使每个字母只出现在一个片段里。返回片段长度。

## 核心套路：记录"最后出现位置"，维护片段右边界 end

**关键洞察**：片段 [l, r] 合法 ⇔ 片段内每个字母的最后出现位置 ≤ r（否则该字母会跨到后面的片段）。

**所以片段右边界 = 片段内所有字母"最后出现位置"的最大值**：

```python
def partitionLabels(self, s):
    last = {}
    for i, c in enumerate(s):          # ① 记最后位置
        last[c] = i

    start = end = 0
    result = []
    for i, c in enumerate(s):          # ② 维护 end，走到 end 切段
        end = max(end, last[c])        # 片段至少延伸到"这个字母最后一次出现"
        if i == end:                   # 追上了 → 段内字母都不会再出现
            result.append(end - start + 1)
            start = end + 1
    return result
```

**为什么 `i == end` 时安全切**：end 是段内所有字母的最后位置最大值，走到 end 说明段内每个字母都已经"最后一次出现"了，后面不会再遇到它们 → 切割合法且片段尽量短（贪心最优）。

## 贪心骨架全家桶（121/55/45/763 统一视角）

| 题 | 维护的"最远值" | 走到边界做什么 |
|----|--------------|--------------|
| 55 | far = 最远可达（i+nums[i]） | 判断能否到终点 |
| 45 | next_far = 下一跳最远 | 跳数 +1（分段） |
| 763 | end = 字母最后位置最大 | 切一段 |

**贪心灵魂**：维护"目前的最优边界"，一路扫描，到边界就做决策——四个题同一个骨架。

## 复杂度

- 时间 **O(n)**；空间 **O(1)**（最多 26 字母）。

## 考点

- 最后出现位置 + 最远边界
- "维护最远 + 到边界切"的贪心骨架（55/45 同源）
- 片段合法性条件（字母最后位置 ≤ 右边界）

## 易错点

1. `last[c] = i` 要**一直覆盖**（记录的是"最后"位置，不是"首次"）；
2. `end = max(end, last[c])` 忘 max（直接赋值会回退）；
3. 记录的是**长度**（`end - start + 1`）而非子串本身；
4. 冗余死代码（用户原版 `if last[c] > end` 恒假）；
5. 忘更新 `start = end + 1`（下一段的起点）。
