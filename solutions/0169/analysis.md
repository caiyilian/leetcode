# 169. 多数元素 · 解析

## 题目简述

数组中出现次数 > n/2 的元素（保证存在）。

## 核心套路一：摩尔投票（最优 O(n)/O(1)）

```
相同 +1、不同 -1、归零换人
```

```python
def majorityElement(self, nums):
    count = 0
    for n in nums:
        if count == 0:
            now = n
            count += 1
        else:
            if now != n:
                count -= 1
            else:
                count += 1
    return now
```

**为什么有效**：多数元素数量 > n/2，即使每个"非多数"元素都抵消掉一个"多数"元素，多数元素仍会剩下来。可以理解为"两军对拼，人多的那方必胜"。

## 核心套路二：排序法（中位数性质）

多数元素出现 > n/2 次 → 排序后中位数（index n//2）一定是多数元素：

```python
nums.sort()
return nums[len(nums) // 2]
```

## 与 136 异或的"抵消"家族

| | 136 只出现一次 | 169 多数元素 |
|--|---------------|-------------|
| 技巧 | 异或 a^a=0 | 摩尔投票 |
| 思想 | 相同的湮灭 | 相同的抱团对抗 |
| 复杂度 | O(n)/O(1) | O(n)/O(1) |

## 复杂度

- 摩尔投票：时间 **O(n)**、空间 O(1)；
- 排序：时间 O(n log n)、空间 O(1)。

## 考点

- 摩尔投票（抵消思想）
- 中位数性质

## 易错点

1. 摩尔投票忘了 `else: count += 1`（相同元素 +1，用户 WA 点）；
2. 排序法 `nums[i + length//2]` 有越界隐患，标准是 `return nums[len(nums)//2]`；
3. 摩尔投票的候选人 `now` 只在 count==0 时更新。
