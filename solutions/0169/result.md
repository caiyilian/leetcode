**摩尔投票精髓**：相同 +1、不同 -1、归零换人——漏了"相同 +1"候选人被错误淘汰。

## 解法（用户两种方法）

**摩尔投票（solution.py，主解，O(n)/O(1)）**：

```python
def majorityElement(self, nums):
    count = 0
    for n in nums:
        if count == 0:
            now = n
            count += 1
        else:
            if now != n:
                count -= 1
            else:
                count += 1      # ★ 相同元素 +1
    return now
```

**排序法（solution_readable.py，用户第一种方法）**：

```python
nums.sort()
return nums[len(nums) // 2]   # 中位数 = 多数元素
```

## 两种方法对比

| 方法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 排序法 | O(n log n) | O(1) | 中位数性质，能用但非最优 |
| **摩尔投票** | **O(n)** | **O(1)** | 最优，抵消思想 |

## 与 136 异或的呼应

```
136 异或：a ^ a = 0              ← 相同的"湮灭"
169 摩尔投票：相同+1 不同-1      ← 相同的"抱团"对抗
```

**都是"抵消/对抗"思想**——多数元素靠数量优势胜出。
