# 141. 环形链表 · 解析

## 题目简述

给你一个链表的头节点 `head`，判断链表中是否有环（链表的尾部节点指向链表中某个节点，形成环）。进阶要求：O(1) 内存。

## 核心套路：快慢指针追及（龟兔赛跑）

两个指针从 head 出发：
- **慢指针**每轮走 1 步；
- **快指针**每轮走 2 步。

- **有环**：快指针进入环后，每轮比慢指针多走 1 步（相对速度 1），**环内必然追上慢指针**——`p_fast == p_slow` 即判 True；
- **无环**：快指针先走到 `None`，循环正常退出，返回 False。

```python
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        if not head:
            return False
        p_fast = head
        p_slow = head
        while p_fast and p_fast.next:
            p_fast = p_fast.next.next
            p_slow = p_slow.next
            if p_fast == p_slow:
                return True
        return False
```

### 为什么快指针不会"跳过"慢指针？

快指针每次 2 步，慢指针每次 1 步——**相对速度恰好 1**，所以每轮两者距离缩短 1，不可能出现快指针从慢指针头顶跳过去的情况（若快指针在慢指针后面 1 格，下一轮正好追上）。这是"步长差 = 1"的妙处（若快指针走 3 步、慢 1 步，步长差 2，就可能跳过）。

## 复杂度

- 时间 **O(n)**：无环 O(n)；有环时快指针至多走 O(n + 环长) 步相遇；
- 空间 **O(1)**：两个指针——满足进阶要求（set 记录 visited 是 O(n) 空间，不达标）。

## 考点

- 快慢指针（第三个用法：找中点 234 → 换边 160 → **追及 141**）
- 判断是否有环的两种思路对比：set 记节点（O(n) 空间）vs 快慢指针（O(1)）
- 边界：空链表、单节点无环/自环
- 与 142 环形链表 II 的关系：142 还要**找环入口**——用"相遇点 + 从头再走"的数学推导，是本题的进阶版

## 易错点

1. 快指针循环条件 `while p_fast and p_fast.next`（防 `p_fast.next.next` 越界）；
2. 相遇判断要在**移动之后**（`p_fast == p_slow` 在步进后检查）；
3. 初始时 `p_fast == p_slow == head`，不能一上来就判相遇（否则单节点自环以外都会误报）；
4. 空链表特判（`if not head`）。
