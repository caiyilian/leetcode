# 118. 杨辉三角 · 解析

## 题目简述

生成杨辉三角前 numRows 行。第 i 行第 j 个数 = 第 i-1 行的第 j-1 + 第 j 个。

## 核心套路：二维 DP（dp[i][j] = 左上 + 正上）

```
dp[i][j] = dp[i-1][j-1] + dp[i-1][j]     （左右越界时邻居视为 0）
dp[0][0] = 1
```

```python
def generate(self, numRows):
    result = [[1]]
    for i in range(1, numRows):
        result.append([])
        for j in range(i+1):
            left  = result[i-1][j-1] if j-1 >= 0 else 0   # 补零法
            up    = result[i-1][j]   if j < i   else 0
            result[-1].append(left + up)
    return result
```

## 70 → 118：一维 DP → 二维 DP

| | 70 爬楼梯 | 118 杨辉三角 |
|--|----------|-------------|
| 状态 | dp[i]（一维） | dp[i][j]（二维） |
| 转移 | dp[i-1] + dp[i-2] | dp[i-1][j-1] + dp[i-1][j] |
| 依赖 | 前 2 个 | 上一行（2 个邻居） |
| 边界 | n≤2 直接返回 | 越界邻居补 0 |

**DP 的"维度" = 状态里有几个下标**。维度变多，骨架不变——都是"当前状态 = 之前状态的组合 + 边界处理"。

## 补零法（二维 DP 边界技巧）

杨辉三角每行首尾是 1，本质是"越界的邻居算 0"。用 `if j-1>=0 else 0` 补零，让每个数走同一个公式，**避免单独处理首尾**——这是二维 DP 处理边界的经典手法（等价于在三角外面铺一圈 0）。

## 复杂度

- 时间 **O(n²)**；空间 **O(n²)**（结果本身）。

## 考点

- 二维 DP（状态两个下标）
- 补零法边界处理
- 一维 → 二维的升维认知

## 易错点

1. `j < i` 判断（第 i 行只有 i+1 个数，正上邻居 `result[i-1][j]` 在 j==i 时越界）；
2. 边界 j-1 < 0 漏判断（首元素左上邻居越界）；
3. `result[i-1]` 用上一行而非当前行（当前行还没填完）；
4. numRows=1 单独处理（result 初始 `[[1]]` 已覆盖）。
