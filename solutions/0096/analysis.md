# 96. 不同的二叉搜索树 · 解析

## 题目简述

给定 n，求 1..n 能构成多少种不同的二叉搜索树。

## 核心套路：卡特兰数 DP（枚举根）

```
dp[i] = i 个节点能构成的不同 BST 数量
dp[0] = 1（空树）
dp[i] = Σ dp[j] * dp[i-1-j]   (j = 0..i-1)
        ↑左子树 j 个      ↑右子树 i-1-j 个
```

```python
def numTrees(self, n):
    dp = [0] * (n + 1)
    dp[0] = 1
    for i in range(1, n + 1):
        for j in range(i):
            dp[i] += dp[j] * dp[i - 1 - j]
    return dp[n]
```

## 为什么枚举根

BST 的性质：以 j 为根时，1..j-1 全在左子树，j+1..i 全在右子树。左右子树分别又是独立的 BST 问题，所以：

```
以 j 为根的数量 = 左子树形态数 × 右子树形态数 = dp[j] * dp[i-1-j]
```

对所有可能的根 j 求和，即得 dp[i]。

## 卡特兰数

递推式 `C[i] = Σ C[j]*C[i-1-j]` 正是卡特兰数，闭式解 `C(2n,n)/(n+1)`：
- C1=1、C2=2、C3=5、C4=14、C5=42…

## 复杂度

- 时间 **O(n²)**；空间 O(n)。

## 考点

- 卡特兰数 DP
- 枚举根节点分解问题
- BST 结构计数

## 易错点

1. dp[0] = 1（空树算一种）；
2. 右子树节点数是 `i-1-j`（不是 i-j）；
3. 内层 j 遍历 0..i-1（枚举所有根位置）。
