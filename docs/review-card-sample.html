#1 两数之和 简单 · 数组/哈希表
在数组中找到两个数，和为 target，返回下标。
nums=[2,7,11,15] target=9 → [0,1]
⚡ 哈希补数：遍历时查「target - 当前值」在不在哈希表里，在就配对。
#15 三数之和 中等 · 双指针
找三个数使和为 0，不能重复三元组。
nums=[-1,0,1,2,-1,-4] → [[-1,-1,2],[-1,0,1]]
⚡ 排序 + 固定一个数 + 双指针夹逼；跳过重复值。
#206 反转链表 简单 · 链表
反转单链表，返回新头。
1→2→3→4→5 → 5→4→3→2→1
⚡ 三指针：p1 指向新链表头，p2 后移，逐个把 p2.next 指回 p1（或递归）。
#312 戳气球 困难 · 区间 DP
戳破气球得分=左×本×右，求最大总分。
nums=[3,1,5,8] → 167
⚡ 反向思维：枚举「最后一个戳的 k」，左右子区间独立。
#437 路径总和 III 中等 · 前缀和+回溯
树中找路径和=targetSum 的路径数（任意起点，向下）。
root=[10,5,-3,3,2,null,11,3,-2,null,1] target=8 → 3
⚡ 前缀和+哈希：查 cur-targetSum；{0:1} 起点；回溯撤销防跨子树。
