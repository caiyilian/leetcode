# 3121. 统计特殊字母的数量 II · 解析（非 HOT100）

## 一、题目

- 中文：统计特殊字母的数量 II
- English：Count the Number of Special Characters II
- 难度：中等
- 规则：字母 c 是**特殊字母** ⟺ 大小写都在 word 中出现，**且每个小写 c 都出现在第一个大写 c 之前**
- 姊妹题：**3120 统计特殊字母的数量 I**（规则更简单：大小写都出现即可，无顺序要求）

## 二、核心思路一：状态机（用户解法）

每个字母只有 4 种状态，遍历一遍即可判定：

| 状态 | 含义 |
|------|------|
| 未遇到 | 没见过该字母 |
| 见过小写 | 出现过小写、还没出现大写 |
| 已确认 | 小写全部在大写之前出现 → 特殊 |
| 已作废 | 违反顺序（大写后又有小写 / 先大写后小写）→ 永不特殊 |

**用户用三个 set 实现**（`meet_small / result / error`）：
- 遇小写：记入 meet_small；若该字母已在 result（即大写已出现过）→ **移除并打入 error**（违反"小写全在大写前"）
- 遇大写：若对应小写已见过 → 加入 result；若小写还没见过 → 直接 error（之后的小写必然在大写后）
- **error 里的字母直接 continue 跳过**——作废后不再参与任何判断

**状态机 vs 位置比较**：位置比较法是"先记录所有位置再统一判定"（两遍概念上），状态机是"边遍历边判定"（一遍）——**时空复杂度完全等价**，状态机代码更"在线"、位置法更直观。

## 三、核心思路二：位置比较法（官方解法）

只需记录两个信息：
- **首个大写位置** `first_upper[c]`
- **最后小写位置** `last_lower[c]`

判定：`first_upper[c] > last_lower[c]`（最后一个小写都在首个大写之前 → 所有小写都在大写前）⟺ 特殊。

**为什么只比"最后小写"和"首个大写"就够了**：
- "每个小写都在第一个大写前" 的最严格情形 = **位置最靠后的小写** 也在第一个大写之前；
- 所以只要 `last_lower < first_upper` 就推出全部满足，反之只要有一个小写（必是最后那个）越位就不满足。

## 四、⚡ 易错点（WA 复盘）

1. **先大写后小写要作废**：`"Cc"` → 小写 c 在大写 C 之后，不是特殊字母。首版若只在"已见小写"时才处理大写，会漏掉"大写先出现"这种情况的作废标记；
2. **大写后又有小写要作废**：`"cCc"` → 第二个小写 c 在首个大写 C 之后 → 作废。处理小写时若该字母已在 result（大写已见过）必须移除 + 标记 error；用户首版用 `and c in result` 的嵌套判断，边界易错；
3. **`result` 去重**：同一字母可能多次遇到大写（`"cCcC"`），已确认的字母遇到更大写要跳过（`if c_lower in result: continue`），避免重复计数/误作废。

## 五、复杂度

- 时间：O(n)（一次遍历，**已达下界**——必须读完整串才知道位置关系）
- 空间：O(1)（set 上限 26 个字母，常数）

| **3120 统计特殊字母的数量 I** | 姊妹题：只需大小写都出现，无顺序约束 → 更简单 |

**识别信号**："字母 + 大小写 + 位置关系（在...之前）" → 要么状态机边扫边判，要么记录首/末位置后统一判。

## 七、一句话记住

> **3121 = 每字母四状态（未见/见小写/确认/作废），遍历一遍：小写已确认→作废；大写未见过小写→作废；⚡ 只比"最后小写位置 < 首个大写位置"（位置比较法）等价；O(n)/O(1) 已达下界。**
