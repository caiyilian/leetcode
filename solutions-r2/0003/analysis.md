# 3. 无重复字符的最长子串 · 二刷解析

## 题目回顾

字符串 `s`，找不含重复字符的最长子串长度。

## 核心思路：滑动窗口 + 字典（"字符 → 最后出现位置"）

**一句话**：`right` 一直右扩（窗口变大）；遇到重复字符时，`left` 直接跳到"该字符上次出现位置 + 1"（窗口内保证无重复）；全程维护最大窗口长度。

```
s = "abcabcbb"
right=0(a): 窗口 [a]        len=1
right=1(b): [a,b]           len=2
right=2(c): [a,b,c]         len=3
right=3(a): a 重复（上次在0）→ left=1，窗口 [b,c,a]  len=3
right=4(b): b 重复（上次在1）→ left=2，窗口 [c,a,b]  len=3
right=5(c): c 重复（上次在2）→ left=3，窗口 [a,b,c]  len=3
right=6(b): b 重复（上次在4）→ left=5，窗口 [c,b]    len=2
right=7(b): b 重复（上次在6）→ left=7，窗口 [b]      len=1
答案 3 ✓
```

## 为什么 left 可以直接跳而不是一格一格挪

暴力：遇到重复 → left 一格一格右移 + 每步检查是否还有重复 → O(n²)。
滑动窗口：**left 直接跳到重复位置+1**——因为 `[left .. 重复位置]` 这一段都是"已污染的"，留在窗口里必重复，一次性扔掉才高效。这正是"滑动窗口"比"暴力收缩"快的地方。

## 两个实现要点（二刷重点）

### 1. "物理清空" vs "逻辑过期"（两种等价写法）

用户写法：遇到重复时，`for i in range(left, index): hash_map[s[i]] = None` **物理清除**窗口外字符的记录。

```python
# 用户版：物理清空
index = hash_map[s[right]]
for i in range(left, index):
    hash_map[s[i]] = None
left = index + 1

# 标准版：逻辑过期（不删，判断 last[c] >= left）
if c in last and last[c] >= left:   # 重复且"上次位置仍在窗口内"
    left = last[c] + 1
```

**为什么标准版能省掉清空**：left 已经跳到 `index+1`，被清的那些字符本来就在窗口外了。留着旧记录也无妨——只要判断"`last[c] >= left`（在窗口内）才算重复"，窗口外的旧记录自然作废。**物理清除 vs 逻辑过期，结果等价**；标准版少一个内层循环、代码更短。

### 2. 循环后的"收尾"更新（本次 WA 的根因）

```python
# 只有"遇到重复"才更新 result → 漏掉最后一个无重复窗口
result = max(result, right - left)       # 在 if 里
...
result = max(result, right - left + 1)   # ★ 循环外补：最后一个窗口
```

**通用教训**：**"循环内条件更新 + 循环外收尾更新"是最值类题目最常见的双坑**——如求最长、最大时，最后一个不触发条件的窗口要单独算。做题时在循环结束后习惯性地补一句 `max(result, 当前窗口)`。

## 复杂度

- **O(n)**：right 扫一遍；物理清空总量 O(n)（每字符最多被清一次）→ 整体 O(n)；
- **O(min(字符集, n))**：字典最多存窗口内字符。字符集固定（如 ASCII 128）时就是 O(1)。

**O(n) 是下界**（必须看每个字符至少一次）→ 最优解。
