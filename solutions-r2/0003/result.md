## 失败提交记录（WA 754100417）

**唯一差别：漏了循环结束后的"收尾"更新**

```python
# WA：循环结束直接 return result
for right in range(length):
    ...
    result = max(result, right - left)     # 只在"遇到重复时"更新
return result                              # ❌ 最后一个无重复窗口没算

# AC：循环外补一句
result = max(result, right - left + 1)     # ★ 收尾：算最后一个窗口
```

**反例**：`"aab"`——right=1 遇到重复时记了 `max(0, 1-0)=1`，但 `"ab"` 这个窗口在循环结束后才完整（right=2 无重复不触发更新），漏掉 → 期望 2 得 1。

**教训**：窗口题在"循环内遇重复才更新"时，**容易漏掉循环结束后的最后一个窗口**——最长/最值类题目记得循环外补一次 `max(result, right-left+1)`。这类 bug 很典型。

## 解法一句话

**滑动窗口 + 字典**：`right` 右扩，遇到重复字符就 `left` 跳到上次出现位置+1，窗口内无重复；字典记"字符 → 最后位置"。O(n)。

## 验证

- **对拍**：1 万组随机（小字母表制造重复），与标准滑动窗口对照，**0 不一致** ✅
- 样例 `abcabcbb→3`、`bbbbb→1`、`pwwkew→3`、`""→0`、`"aab"→2` 全对

## 是否最优解

**是**：O(n) 时间（下界，必须扫每个字符）+ O(min(字符集,n)) 空间。**"物理清空 dict"写法可用但略绕，标准写法用 `last[c] >= left` 判过期更简洁**（性能等价，详见 analysis.md）。
