# 1143. 最长公共子序列 · 解析（二刷）⭐ 考前重点

## 一、题目

- 中文：最长公共子序列
- English：Longest Common Subsequence（LCS）
- 难度：中等（双字符串 DP 两大母题之一）
- 注意：子序列**可以不连续**（vs 5/647 的子串必须连续）

## 二、核心思路：双串二维 DP（与 72 编辑距离同一张表）

**状态**：`dp[i][j]` = text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度。

**转移**（核心是"看末尾"）：
```
text1[i-1] == text2[j-1]：dp[i][j] = dp[i-1][j-1] + 1     ← 末尾匹配，各退一位 +1
text1[i-1] != text2[j-1]：dp[i][j] = max(dp[i-1][j], dp[i][j-1])  ← 删 text1 尾 or 删 text2 尾
```

**不等时为什么取 max 而不是 min**：`dp[i-1][j]` 是"text1 少看一个字符"的 LCS，`dp[i][j-1]` 是"text2 少看一个"——当前字符配不上，那 LCS 要么来自没看 text1 尾、要么来自没看 text2 尾，哪个大取哪个。

```
  ""  a  c  e
"" 0  0  0  0
a  0  1  1  1
b  0  1  1  1
c  0  1  2  2    ← dp[3][2]=2（"abc" vs "ac" 的 LCS="ac"）
d  0  1  2  2
e  0  1  2  3    ← 答案 dp[5][3]=3（"abcde" vs "ace"）
```

## 三、代码（用户 AC 版）

```python
dp = [[0] * (n + 1) for _ in range(m + 1)]        # 边界全 0（空串 LCS = 0）
for i in range(1, m + 1):
    for j in range(1, n + 1):
        if text1[i - 1] == text2[j - 1]:
            dp[i][j] = dp[i - 1][j - 1] + 1
        else:
            dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
return dp[m][n]
```

**为什么边界是 0（对比 72 是 i/j）**：72 的边界是"空串变换的代价"（插入 i 次/删除 j 次），LCS 的边界是"空串的公共子序列长度"——空串和任何串的 LCS 都是 **0**，所以全 0 天然正确，不用特判。

## 四、⚡ 与 72 编辑距离的对照（考前重点，背下这张表）

| | 72 编辑距离 | 1143 最长公共子序列 |
|---|---|---|
| dp[i][j] | word1 前 i → word2 前 j 的**最少操作** | 前缀的**最长公共子序列** |
| 相等 | 继承 dp[i-1][j-1]（不操作）| **+1**（匹配长一截）|
| 不等 | min(替换/插入/删除)+1 | **max(上, 左)**（都不配，退而求其次）|
| 边界 | dp[0][j]=j、dp[i][0]=i（代价）| **全 0**（长度）|
| 语义 | 改造成本最小化 | 公共部分最大化 |

**区别本质**：72 求"最少代价"（min + 边界是代价），1143 求"最大长度"（max + 边界是 0）——**同一张二维表、不同的聚合与边界**。

## 五、复杂度

- 时间：O(m·n)
- 空间：O(m·n)（可滚动到 O(n)，与 72 同款）
