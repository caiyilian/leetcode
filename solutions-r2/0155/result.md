## 解法核心：双栈 — 辅助栈存"历史最小值"

**为什么必须两个栈**（只存一个 min 变量不行）：pop 掉当前最小值后，**不知道下一个最小值是多少**——必须记录"每个历史时刻的最小值"，即辅助栈。

**你的索引版（⚡ 比标准值版更省）**：
```python
push(v):                     # 只在真正更小时 push 索引
    self.stack.append(v)
    if not self.min_stack:   self.min_stack.append(len(stack)-1)
    elif v < self.stack[self.min_stack[-1]]:
         self.min_stack.append(len(self.stack)-1)

pop():
    self.stack.pop()
    if self.min_stack[-1] == len(self.stack):   # 弹掉的是当前最小值索引 → 同步弹
        self.min_stack.pop()

getMin():  return self.stack[self.min_stack[-1]]   # O(1)
```

**索引版 vs 值版**：
- 索引版只在 `严格 <` 时 push → 重复最小值**不撑大**辅助栈（如连续 10 个 5，min_stack 只有 1 个索引）；
- 值版用 `<=` push、`==` pop，简单直白但重复值会让辅助栈和主栈等长；
- 两者都 O(1)，**索引版是空间上的小优化**（本题边界下收益不大，但体现理解深度）。

**⚡ 关键正确性**：pop 后索引会不会失效？—— 不会。每次 pop 只去掉主栈栈顶；若它是当前最小值的索引，min_stack 弹出后栈顶变**上一个最小值索引**，该索引对应元素仍在主栈中（因为只有更小的值才会 push 新索引，而它之上的元素都被 pop 了才轮到它）——索引永远合法。2 万组对拍验证。

## 边界

- 重复最小值 `[2,2]`：push 两个 2 只存 1 个索引 → pop 一个 2 后 min 仍 2 ✓；
- 负值、连续 pop、交替 push/pop 全覆盖对拍 ✓；
- 题目保证合法序列（不会空栈 pop），无需空栈守卫。
