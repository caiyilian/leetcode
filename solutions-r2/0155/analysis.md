# 155. 最小栈 · 解析（二刷）

## 一、核心思路：双栈，辅助栈记录"历史最小值"

**问题**：实现一个栈，额外支持 O(1) 的 getMin。关键难点：**pop 掉当前最小值后，怎么快速知道新的最小值？**

**为什么一个 min 变量不够**：`[3,1,2]` push 完 min=1，pop 掉 1 后 min 应该是 3——但只存一个 min 变量**丢失了"上一个最小值"**。必须记录历史：辅助栈里每个元素 = 某个历史时刻的当前最小值，栈顶永远是"现在"的最小值，pop 掉最小值就自动"回退"。

```
操作          主栈        辅助栈(存索引)    getMin
push 5       [5]         [0]              5
push 3       [5,3]       [0,1]            3   ← 3 是新的最小
push 7       [5,3,7]     [0,1]            3   ← 7 不是最小，不记录
pop 7        [5,3]       [0,1]            3   ← 弹掉非最小
pop 3        [5]         [0]              5   ← ⚡ 弹掉最小值，辅助栈自动"恢复"到上一个最小！
```

## 二、代码（用户 AC 版：索引辅助栈）

```python
class MinStack:
    def __init__(self):
        self.stack = []        # 主栈
        self.min_stack = []    # 辅助栈：存"最小值在 stack 中的索引"

    def push(self, value):
        self.stack.append(value)
        if not self.min_stack:
            self.min_stack.append(len(self.stack) - 1)
        elif value < self.stack[self.min_stack[-1]]:   # 严格更小才记录
            self.min_stack.append(len(self.stack) - 1)

    def pop(self):
        self.stack.pop()
        if self.min_stack[-1] == len(self.stack):      # 弹出的是当前最小值的索引才同步弹
            self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.stack[self.min_stack[-1]]          # O(1) 不遍历
```

**为什么索引不会失效**：只有"比当前最小值更小的新值"才会 push 新索引；若它是当前最小值被 pop，说明它之上的元素已被全部弹走，所以"上一个最小值的索引"必然仍合法（2 万组对拍验证）。

## 三、两种辅助栈写法（面试都认，索引版更省）

| | 索引版（用户） | 值版（标准） |
|---|---|---|
| 辅助栈存 | 最小值在 stack 的**索引** | 最小值**本身** |
| push 条件 | `val < 当前最小`（严格） | `val <= 当前最小` |
| pop 判断 | 栈顶索引 == pop 后长度 | 弹出值 == 最小栈栈顶 |
| 重复最小值 | 辅助栈**不膨胀**（如 10 个 5 只存 1 个索引） | 辅助栈随重复等长膨胀 |
| getMin | `stack[min_stack[-1]]` | `min_stack[-1]` |

索引版是值版的空间优化，值版更直白、面试表达更快——**两个都要会**。

## 四、复杂度

- 时间：push / pop / top / getMin 全部 O(1)
- 空间：O(n)（辅助栈）

## 五、一刷 vs 二刷

- 一刷（9-17）：RE 1 次（空栈/边界没兜住）→ AC ×2；
- 二刷（10-31）："存索引而非值"直接想到，一次 AC——辅助栈记录历史的思路已内化。

## 七、一句话记住

> **最小栈 = 主栈 + 辅助栈：辅助栈存"历史最小值"（索引版 < 更省 / 值版 <= 更直白），pop 弹出最小才同弹，getMin 取辅助栈顶 O(1)；⚡ 只存一个 min 变量不行——pop 后需要"历史"。**
