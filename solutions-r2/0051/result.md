## 解法核心：三个集合判冲突（⚡ 对角线定标是关键）

```python
ban_j = set()      # 已占列 j
ban_idj = set()    # 主对角线：i - j 恒定（↘ 方向）
ban_ipj = set()    # 副对角线：i + j 恒定（↙ 方向）

# 放 (i, j) 前检查：
if (j in ban_j) or (i - j in ban_idj) or (i + j in ban_ipj):
    continue
```

**为什么对角线可以这样判**：
- 主对角线（↘）：同行列差 `i - j` 相同（如 (0,0)、(1,1)）；
- 副对角线（↙）：同行列和 `i + j` 相同（如 (0,3)、(1,2)）。

只要 `i-j` 或 `i+j` 出现过，就说明同一条对角线上已有皇后 → 冲突。**用集合 O(1) 查，比循环扫描快得多**。

## 其他要点

- 按行放（天然保证每行只有一个 Q，不用检查行冲突）；
- `path.copy()` 收集（回溯共享引用，必须 copy）；
- 字符串构造 `"." * j + "Q" + "." * (n - j - 1)`。
