## ⚡⚡ 核心踩坑：可变默认参数（本地对、力扣错）

```python
# ❌ 错误写法（v1，WA 根因）
class MyNode:
    def __init__(self, next={}, is_end=False):   # ★ next={} 只创建一次！
        self.next = next

# ✅ 正确写法（v2，AC）
class MyNode:
    def __init__(self, is_end=False):
        self.next = {}        # 函数体内新建，每个实例独立
```

**为什么 v1 本地对、力扣错**：
- Python 默认参数**只在定义时求值一次**，所有 `MyNode()` 共享**同一个 `next` dict；
- 于是**所有节点的 next 指向同一个字典**——insert("apple") 后，每个节点的 "a"/"p"... 边都加到了同一个 dict 里；
- **跨实例污染**：力扣多组用例连续执行、每个 Trie 独立，A 用例 insert 的字符在 B 用例"看得见"→ `startsWith("a")` 莫名返回 True；
- 本地测试只建一个 Trie 顺序操作，污染没暴露（或恰好掩盖）。

**规则**：**可变对象（dict/list/set）绝不做默认参数**（PEP 8 明令）。想给默认值用 `next=None` + 函数体内 `self.next = {} if next is None else next`。

## 三个方法的语义（面试必背）

| 方法 | 要求 | 实现要点 |
|------|------|---------|
| insert | 建链 | 缺边就建节点，末尾 is_end = True |
| search | **完整单词** | 走到底 + `return p.is_end`（存 apple 找 app → False）|
| startsWith | 前缀即可 | 走到底直接 True（空串是任何串前缀）|
