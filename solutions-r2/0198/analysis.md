# 198. 打家劫舍 · 解析（二刷）

## 一、核心思路：DP"选/不选"状态

**问题**：一排房子，相邻不能同时偷，求最大偷窃金额。

**关键洞察**：到第 i 家做决策时，只有两条路——**偷 i**（则 i-1 必须跳过，收益 = dp[i-2] + nums[i]）或**不偷 i**（收益 = dp[i-1]）。最优一定是两者最大：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
                ↑不偷        ↑偷（跳过 i-1）
边界：dp[0] = nums[0]；dp[1] = max(nums[0], nums[1])
```

## 二、代码（用户 AC 版：滚动数组）

```python
dp_ip1 = nums[0]     # dp[i-1]
dp_ip2 = 0           # dp[i-2]
for i in range(1, len(nums)):
    dp_ip1, dp_ip2 = max(dp_ip1, dp_ip2 + nums[i]), dp_ip1
return dp_ip1
```

**滚动原理**（70 爬楼梯同款）：递推只依赖前两个状态 → 两个变量滚动即可，空间 O(1)。

## 三、⚡ 与 70 爬楼梯的对比（记忆锚点）

| | 70 爬楼梯 | 198 打家劫舍 |
|---|---|---|
| 递推 | dp[i] = dp[i-1] + dp[i-2] | dp[i] = max(dp[i-1], dp[i-2]+nums[i]) |
| 状态关系 | 两条路都走（求和） | 两条路二选一（取 max） |
| 含义 | 计数 | 最优化 |

**"求和 vs 取 max"是 DP 两个基本盘的区分**：数方案数用 `+`，求最优值用 `max/min`。

## 四、复杂度

- 时间：O(n)
- 空间：O(1)（滚动数组；标准版 O(n)）

## 五、一刷 vs 二刷

- 一刷（9-18）：TLE（暴力/朴素递归）→ 改进 AC ×2；
- 二刷（11-01）：**滚动数组一次 AC**——模型与优化都已内化。
