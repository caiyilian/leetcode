| 考察点 | 结论 |
|--------|------|

## 解法核心

**关键洞察**：到第 i 家只有两种选择——**偷**（前一家不能偷，收益 = dp[i-2] + nums[i]）或**不偷**（收益 = dp[i-1]），取较大：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
边界：dp[0] = nums[0]，dp[1] = max(nums[0], nums[1])
```

**滚动数组**（70 爬楼梯同款优化）：

```python
dp_ip1 = nums[0]                                  # dp[i-1]
dp_ip2 = 0                                        # dp[i-2]
for i in range(1, len(nums)):
    dp_ip1, dp_ip2 = max(dp_ip1, dp_ip2 + nums[i]), dp_ip1
return dp_ip1
```

## 验证方式（对拍用）

标准一维 DP（`dp[i]=max(dp[i-1],dp[i-2]+nums[i])`，独立实现）作参照：
- 官方 [1,2,3,1] → 4 ✅；[2,7,9,3,1] → 12 ✅
- 3 万组随机（含单元素/两元素/全0/递增）0 不一致
- 边界：单元素 [5] → 5，两元素 [1,2] → 2，全0 → 0，递增 [1,2,3,4,5] → 9 ✅
