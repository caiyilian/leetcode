# 48. 旋转图像 · 解析（二刷）

## 一、两种标准解法（都是 O(n²)/O(1)）

### 解法 A：逐层旋转 + 四元素轮换（用户选择）

把矩阵看成**一圈一圈的洋葱**：最外层边长 n，往里一层 n-2……

```
外层 (i=0)：[1,2,3]   内层 (i=1)：
           [4,5,6]             [5]
           [7,8,9]     边长 3 → 1，<2 停止
```

**每层做"四元素轮换"**：对 j 从 i 到 n-2-i，四个元素一组旋转移位：

```
上 (i, j)          → 右 (j, n-1-i)
右 (j, n-1-i)      → 下 (n-1-i, n-j-1)
下 (n-1-i, n-j-1)  → 左 (n-j-1, i)
左 (n-j-1, i)      → 上 (i, j)（回到起点，一个环完成）
```

```python
while (n - 2*i) >= 2:                    # 剥层
    for j in range(i, n-1-i):            # 本层每列一个环
        matrix[i][j] ↔ matrix[j][n-1-i]          # 上↔右
        matrix[i][j] ↔ matrix[n-1-i][n-j-1]      # 上↔下
        matrix[i][j] ↔ matrix[n-j-1][i]          # 上↔左（三轮后四元素归位）
    i += 1
```

**三个下标的推导**（最容易写错的点）：
| 元素 | 下标 | 为什么 |
|------|------|--------|
| 右 | `(j, n-1-i)` | 第 i 层右上角列号 n-1-i，行号随 j 走 |
| 下 | `(n-1-i, n-j-1)` | 第 i 层右下角行 n-1-i，列从右往左 |
| 左 | `(n-j-1, i)` | 第 i 层左下角列 i，行从下往上 |

### 解法 B：转置 + 每行反转（更易记忆的等效写法）

```
顺时针旋转90° = 先沿主对角线转置 + 每行左右反转
[1,2,3]    转置    [1,4,7]   每行反转   [7,4,1]
[4,5,6]  ──────→  [2,5,8]  ────────→  [8,5,2]
[7,8,9]          [3,6,9]             [9,6,3]
```

```python
for i in range(n):
    for j in range(i+1, n):
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]   # 转置
for row in matrix:
    row.reverse()                                                  # 每行反转
```

**B 更像"程序员的直觉"**：几何变换拆成两步，下标只需写一次转置（对角线交换）。A 更省事但下标推导复杂。面试两种都认可，B 通常更好讲。

## 二、为什么 O(n²) 是下界

旋转需要移动**每个元素**（n² 个），每个至少被触达一次 → O(n²) 不可再低。O(1) 空间靠原地交换实现（不新开 n×n 矩阵）。

## 三、复杂度

- 时间：O(n²)
- 空间：O(1)

## 四、一刷 vs 二刷

- 一刷（9-13）：独立完成逐层旋转 + 四元素轮换；
- 二刷（10-16）：**逐层旋转一次 AC**，三个轮换下标（上右下左）推导一次写对——套路已内化。

## 六、一句话记住

> **旋转 90° = 逐层剥洋葱 + 上右下左四元素轮换（三轮交换一圈）；或转置 + 每行反转。O(n²) 是下界，原地 O(1) 空间。**
