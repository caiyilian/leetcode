## ⚡ 力扣 AC 但空树崩溃（对拍抓出，已修复）

**症状**：`root = None`（空树）时原版崩溃：

```python
return fun(root.left, root.right)   # root 是 None → AttributeError: 'NoneType' has no attribute 'left'
```

**为什么力扣 AC**：本题约束节点数范围 `[1, 1000]`，官方测试集**没有空树用例**，所以躲过了——又双叒是"力扣 AC ≠ 无 bug"（同 0002/148 空链表）。

**修复**（改一行）：

```python
return fun(root, root)      # fun(None,None) 走 if tree1 or tree2 不成立 → return True
```

`fun(root, root)` 对空树天然返回 True，无需入口守卫。修复后含空树 3 万组对拍 0 不一致。

**⚡ 一刷记忆**：`空树=True` 这个边界一刷标过（模板里就有 `if not root: return True`），二刷入口简化时丢了——**"简化入口"容易丢边界，教训+1**。
