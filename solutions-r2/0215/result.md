| 考察点 | 结论 |

| 空间复杂度 | ✅ O(k)——只维护 k 大小的堆 |
| 正确性 | ✅ 官方示例 + **3 万组随机对拍**（vs 排序参照，含负值/重复/全等/k=1/k=n）0 不一致 |

## 解法核心：最小堆维护"最大的 K 个数"

**关键洞察**：第 K 大 = **"前 K 大的数里最小的那个"**。所以用一个**大小为 K 的最小堆**：
- 堆顶 = 这 K 个数里最小 = 全局第 K 大（答案）；
- 遍历其余元素：比堆顶大就 `heappushpop`（弹走当前最小的，加入它）——堆始终保持"前 K 大"。

```python
heap = nums[:k]
heapq.heapify(heap)                    # 最小堆
for i in range(k, length):
    if nums[i] > heap[0]:              # 比"当前第 K 大"还大 → 替换
        heapq.heappushpop(heap, nums[i])   # = push + pop 合并（O(log k)）
return heap[0]                         # 堆顶 = 第 K 大
```

**为什么 O(n log k) 而不是 O(n log n)**：堆大小固定在 k（不装全部），每次操作 O(log k)；`heappushpop` 一步完成替换。

## 进阶：快速选择（期望 O(n)，面试加分）

第 K 大 = 第 `(n-k)` 小的下标，用快排 partition 不断定位：
```python
target = len(nums) - k
lo, hi = 0, len(nums) - 1
while True:
    p = partition(nums, lo, hi)      # 同快排：pivot 归位，< 在左 > 在右
    if p == target: return nums[p]
    elif p < target: lo = p + 1
    else:            hi = p - 1
```
- **期望 O(n)**（每次只去一半），最坏 O(n²)（可随机 pivot 缓解）；
- 面试**先讲堆（简单可靠），再提快选（最优）**。
