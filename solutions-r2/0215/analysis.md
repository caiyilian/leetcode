# 215. 数组中的第 K 个最大元素 · 解析（二刷）

## 一、核心思路：第 K 大 = "前 K 大里最小的"

**问题**：无序数组中找第 K 大的元素（不要求真的排序）。

**最小堆模型**：维护一个**大小为 K 的最小堆**装"目前见过的最大的 K 个数"：
- 堆顶 = 这 K 个里最小 = **全局第 K 大**（答案）；
- 新元素比堆顶大 → 弹掉堆顶、加入新元素（保持仍是"前 K 大"）。

```
nums = [3,2,1,5,6,4], k=2
建堆 heap=[3,2]（k=2）
i=2: 1 < 堆顶2 → 跳过
i=3: 5 > 2 → pushpop → heap=[3,5]
i=4: 6 > 3 → pushpop → heap=[5,6]
i=5: 4 < 5 → 跳过
返回 heap[0]=5 ✓
```

## 二、代码（用户 AC 版）

```python
heap = nums[:k]
heapq.heapify(heap)                       # 最小堆（Python heapq 默认）
for i in range(k, length):
    if nums[i] > heap[0]:                 # 比"当前第 K 大"大才替换
        heapq.heappushpop(heap, nums[i])  # push + pop 一步（O(log k)）
return heap[0]
```

**⚡ 小细节**：
- 用 **`>`**（严格）——相等元素不替换，因为持平不影响第 K 大的值；
- `heappushpop` 比分开 push 再 pop 快且不会超过 k 大小。

## 三、两种解法的权衡（面试要讲清）

| | 最小堆（本题解法） | 快速选择 |
|---|---|---|
| 时间 | O(n log k) | 期望 O(n)，最坏 O(n²) |
| 空间 | O(k) | O(1)（原地 partition） |
| 实现难度 | 低（heapq 一行建堆） | 中（partition 边界易错） |
| 适用 | k 小 / 流式数据 | n 极大且要 O(n) |

**结论**：面试先答堆（可靠、好写），再补一句"快选可到期望 O(n)"且会写——足够。

## 四、复杂度

- 堆版：时间 O(n log k)、空间 O(k)
- 快选版：期望 O(n)、O(1)

## 五、一刷 vs 二刷

- 一刷（9-18）：堆/快选多次演进才 AC；
- 二刷（10-31）：**最小堆一次 AC**——"前 K 大里最小"模型内化，heappushpop 顺手。

## 七、一句话记住

> **第 K 大 = 最小堆维护前 K 大（堆顶即答案，比顶大才 pushpop，O(n log k)/O(k)）；进阶快选 = 第 n-k 小、partition 定位（期望 O(n)）；"TopK"一律先想堆。**
