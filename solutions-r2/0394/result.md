## 解法核心：单栈混存，遇 `]` "验收一块"

**问题**：`k[encoded]` 表示 encoded 重复 k 次，可嵌套。解码成原字符串。

**你的单栈做法**（比双栈更"原教旨"）：
```python
while i < length:
    if s[i].isdigit():            # 收集多位数 num，压 num 和 '['
        num = 循环收集数字
        stack.append(num); stack.append('[')
    elif s[i] == ']':             # 验收一块
        each_str = 一直 pop 直到 '['（倒着拼回正序）
        stack.pop()               # 去掉 '['
        num = stack.pop()         # 重复次数
        stack.append(num * each_str)
    else:                         # 字母直接压
        stack.append(s[i])
    i += 1
return "".join(stack)
```

- **`'['` 当分块起点标记**：数字和字母压栈，`]` 时弹出直到 `[` 边界，拼接、乘回、再压栈——**嵌套天然由"后弹先算"处理**（内层先被展开成整块）；
- **多位数**：`isdigit` 循环收集，支持 `10[a]`；
- 栈里混合 int 和 str——Python 动态类型友好，`"".join` 时已全展成 str。

## 双栈参考（讲思路更快的标准版）

```python
num_stack, str_stack = [], []
cur, num = "", 0
for c in s:
    if c.isdigit():        num = num * 10 + int(c)
    elif c == '[':         num_stack.append(num); str_stack.append(cur); num, cur = 0, ""
    elif c == ']':         cur = str_stack.pop() + cur * num_stack.pop()
    else:                  cur += c
return cur
```
- 维护"当前展开中"的 `cur`，`[` 把现场快照压栈，`]` 恢复现场并展开——语义更清晰，面试讲解推荐；单栈版代码更短，两者 O(n)。
