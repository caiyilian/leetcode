# 394. 字符串解码 · 解析（二刷）

## 一、核心思路：栈——"遇 ']' 验收一块"

**问题**：`k[encoded]`（encoded 可嵌套）表示 k 次重复，解码展开成原字符串。

**栈为什么合适**：编码串是"层层包裹"的结构——**最内层的块最先需要展开**，正好是"后进先出"：后压入的 `]` 先被处理。栈天然按嵌套深度维护展开现场。

```
"3[a2[c]]"  展开过程：
解析到 2[c] 的 ']' → 弹出 c，乘 2 → "cc" 压回
解析到 3[a cc] 的 ']' → 弹出 a cc，拼接 "acc"，乘 3 → "accaccacc" ✓
```

## 二、代码（用户 AC 版：单栈混存）

```python
stack = []
while i < length:
    if s[i].isdigit():                 # 多位数
        num = []
        while s[i].isdigit(): num.append(s[i]); i += 1
        stack.append(int("".join(num)))
        stack.append(s[i])             # 压 '['
    elif s[i] == ']':                  # 验收一块
        each_str = ""
        while stack[-1] != "[":        # 弹出到 [ 边界
            each_str = stack.pop() + each_str    # 倒着拼回正序
        stack.pop()                    # 去掉 '['
        num = stack.pop()              # 重复次数
        stack.append(num * each_str)   # 展开后压回
    else:
        stack.append(s[i])
    i += 1
return "".join(stack)
```

**要点**：
- **`'['` 就是分块标记**——数字、字母、`[` 全压一个栈，`]` 时弹出直到 `[`，把这块展开后压回（一块变成整体，供外层再乘）；
- 拼接用 `c + each_str`（倒着 pop 时保持正序）；
- 数字压栈前要 `int`，字母是 str，混存没问题——**Python 动态类型的便利**。

## 三、标准双栈版（面试首选讲这个）

```python
num_stack, str_stack = [], []
cur, num = "", 0
for c in s:
    if c.isdigit():        num = num * 10 + int(c)
    elif c == '[':         num_stack.append(num); str_stack.append(cur)
                           num, cur = 0, ""          # 开始新分块
    elif c == ']':         cur = str_stack.pop() + cur * num_stack.pop()
    else:                  cur += c
return cur
```

- 维护 **cur**（当前正在展开的内容）+ **num**（当前数字）；
- `[` 把现场 `(num, cur)` 压栈并清零，`]` 时 `str_stack.pop() + cur*num` 恢复现场——**"快照 + 恢复"**思想，嵌套清晰；
- 两种栈解法等价（O(n)），单栈更短、双栈更讲得清。

## 四、复杂度

- 时间：O(n)（n 为解码后长度；解码结果本身可能指数级，无法避免）
- 空间：O(n)（栈/输出）

## 五、⚡ 易错点

1. **多位数**（`10[a]`、`100[leetcode]`）：要循环收集数字，不能只取一位；
2. **拼接顺序**：`c + each_str`（倒着 pop 保持正序），写成 `each_str += c` 会反转；
3. **弹出边界**：`while stack[-1] != "["` 后要 extra pop 一次去掉 `[`，否则漏。

## 六、一刷 vs 二刷

- 一刷（9-17）：栈 AC ×2；
- 二刷（10-31）：单栈一次 AC——"`[` 作分块标记"写得很顺，嵌套展开与栈的天然契合已理解。
