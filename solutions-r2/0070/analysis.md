# 70. 爬楼梯 · 解析（二刷）

## 一、核心思路：DP 递推（本质斐波那契）

**问题**：一次走 1 或 2 阶，到第 n 阶有几种走法。

**关键洞察**：到第 i 阶的方法 = **到第 i-1 阶的方法 + 到第 i-2 阶的方法**（分别对应最后一步迈 1 阶/2 阶）：

```
dp[i] = dp[i-1] + dp[i-2]
dp[0] = 1   （原地不动也算 1 种"空路径"）
dp[1] = 1   （迈 1 步到达）
```

这就是斐波那契数列（f₁=1, f₂=2, f₃=3, f₄=5...）。

## 二、三版递进（二刷 4 连 AC 的优化链）

**v1 记忆递归（自顶向下）**——先想清楚"大问题拆小问题"：
```python
mem = {}
def fun(n):
    if n == 1 or n == 0:
        return 1
    if n not in mem:
        mem[n] = fun(n-1) + fun(n-2)
    return mem[n]
```

**v2 一维 DP（自底向上）**——把递归翻过来，从边界往目标推：
```python
dp = [1] * (n + 1)
for i in range(2, n + 1):
    dp[i] = dp[i-1] + dp[i-2]
return dp[n]
```

**v3 滚动数组（最终版）**——递推只依赖前两个值，砍掉整个数组：
```python
dp_ip1, dp_ip2 = 1, 1
for _ in range(2, n + 1):
    dp_ip1, dp_ip2 = dp_ip1 + dp_ip2, dp_ip1
return dp_ip1
```

## 三、⚡ 为什么可以压成 O(1)（滚动数组的本质）

**dp[i] 只依赖 dp[i-1] 和 dp[i-2]**——前面算过的 dp[0..i-3] 永远不会再用到。所以只留两个变量不断"滚动"：
- 每轮新值 = 旧 dp[i-1] + 旧 dp[i-2]；
- 下一轮开始前，把两个变量前移一位（`dp_ip1, dp_ip2 = 新, 旧dp_ip1`）。

**推广**：任何"只依赖前 k 个状态"的线性递推都能滚动到 O(k) 空间——不止爬楼梯，198 打家劫舍、213 打家劫舍II 都是同款。

## 四、复杂度

- 时间：O(n)（n≤45；面试加餐可讲矩阵快速幂 O(log n)）
- 空间：O(1)（滚动数组）

## 五、一刷 vs 二刷

- 一刷（9-18）：一次 AC；
- 二刷（11-01）：**4 连 AC，走完整条优化链**（记忆递归 → DP → 滚动数组）——说明递推关系的建立已经内化，这是 DP 入门最标准的心智成长路径。
