## 解法核心

**DP 递推**：到第 i 阶只有两种来路——从第 i-1 阶迈 1 步，或从第 i-2 阶迈 2 步：

```
dp[i] = dp[i-1] + dp[i-2]
边界：dp[0] = 1（起点），dp[1] = 1（一步到）
```

**滚动数组**：递推只依赖前两个值，无需保留整个数组：

```python
dp_ip1 = 1   # dp[1]
dp_ip2 = 1   # dp[0]
for _ in range(2, n + 1):
    dp_ip1, dp_ip2 = dp_ip1 + dp_ip2, dp_ip1
return dp_ip1
```
