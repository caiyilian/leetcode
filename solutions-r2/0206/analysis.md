# 206. 反转链表 · 解析（二刷）

## 一、核心思路：三指针迭代（每个节点"掉头"）

```
p1 = 当前节点（待处理）
p2 = 已反转链的头（初始 None）
p3 = p1 的原后继（暂存）

while p1:
    p3 = p1.next      # ① 先存后继——否则 p1.next 被改后找不到后面的
    p1.next = p2      # ② 当前节点掉头，指向已反转部分
    p2 = p1           # ③ 已反转头前移（p2 前进）
    p1 = p3           # ④ p1 前进到原后继
return p2
```

```
1 → 2 → 3 → None
p1=1: p1.next=None   → None ← 1
p1=2: p1.next=1      → 1 ← 2
p1=3: p1.next=2      → 2 ← 3
p1=None 结束，p2=3 即新头 ✅
```

## 二、为什么必须三步走（存→反→移→进）

**"存后继"是第一步**——`p1.next = p2` 一旦执行，原链表就断了，不用 p3 提前存好，后面的节点全部丢失。**四步顺序不能换**：存 → 反 → 移头 → 前进。

## 三、两种写法对比

| 写法 | 空间 | 特点 |
|------|------|------|
| **三指针迭代（用户）** | O(1) | 面试首选，无栈开销 |
| 递归 | O(n)（递归栈） | 代码短但深度大时栈溢出风险 |

**递归版**（作为对照）：

```python
def reverseList(head):
    if not head or not head.next:
        return head
    new_head = reverseList(head.next)   # 先反转后面
    head.next.next = head               # 后一个指回自己
    head.next = None                    # 断开原正向
    return new_head
```

## 四、空链表/单节点边界（一刷踩过的坑，二刷天然免疫）

- `while p1` 条件：空链表直接跳过循环返回 None（p2 初始值）✅；
- 单节点：p1.next=None，p2=p1，返回 p2 ✅。
- **一刷曾忘特判空链表导致 AttributeError**——`while p1` 写法天然覆盖，不用单独 if。

## 五、复杂度

- 时间：O(n)
- 空间：O(1)
