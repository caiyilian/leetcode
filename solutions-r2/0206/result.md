| 考察点 | 结论 |

| 空间复杂度 | ✅ O(1)——只用了三个指针变量 |
| 正确性 | ✅ 2 万组对拍（含空/单节点）0 不一致 |

## 解法要点（三指针迭代，链表反转的标准形态）

```python
p1 = head; p2 = None
while p1:
    p3 = p1.next     # ① 暂存后继（不存就断了）
    p1.next = p2     # ② 反向指向前一个
    p2 = p1          # ③ 已反转头前移
    p1 = p3          # ④ 前进到原后继
return p2
```

**一句话**：每个节点依次"掉头"，p2 始终是已反转链的头，遍历完 p2 就是新头。

## 一刷 vs 二刷

- 一刷（9-13）：三指针迭代定稿（**曾踩空链表忘特判的 AttributeError**——链表题第一习惯=先查 head）；
- 二刷（10-18）：**一次 AC 无失败**——三指针节奏（存→反→移→进）已成肌肉记忆，且 `while p1` 天然处理空链表（一刷的坑这次没栽）。
