# 64. 最小路径和 · 解析（二刷）

## 一、题目

- 中文：最小路径和
- English：Minimum Path Sum
- 难度：中等（二维 DP 经典）
- 问题：m×n 网格，从左上到右下（只能右/下），求路径上数字和的最小值

## 二、核心思路：与 62 同骨架，加法换 min

**状态**：`dp[i][j]` = 从起点到 (i,j) 的**最小路径和**。

**转移**：从上方或左方进来，选更小的那条：
```
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

**三问三答对照（62 vs 64）**：
| | 62 不同路径 | 64 最小路径和 |
|---|---|---|
| dp 含义 | 路径**条数** | 路径**和的最小值** |
| 聚合 | `+`（上+左） | `min(上, 左)` |
| 边界 | 第 1 行/列 = 1 | 第 1 行/列 = 前缀和 |

## 三、用户 AC 版：记忆化递归（自顶向下）

```python
mem = {}
def fun(i, j):
    if (i, j) not in mem:
        if i == 0 and j == 0:
            return grid[0][0]              # 起点
        if i < 0 or j < 0:
            return float('inf')            # ⚡ 越界 = 不可达，inf 哨兵
        mem[(i, j)] = min(fun(i, j-1), fun(i-1, j)) + grid[i][j]
    return mem[(i, j)]
return fun(m-1, n-1)
```

**两点小技巧**：
1. **inf 作越界哨兵**：`min(inf, x) = x`，越界的路径自然被淘汰，省去判断"哪个方向合法"——和一刷"终点回填 + inf 圈"、85 最大矩阵的哨兵是同一思想；
2. **记忆化消除重复**：不同路径会反复到达同一 (i,j)（和 62 一刷 TLE 的教训同源），mem 字典缓存后每个格子只算一次。

## 四、复杂度

| 版本 | 时间 | 空间 |
|------|------|------|
| 记忆化递归（用户） | O(m·n) | O(m·n)（dict）|
| 迭代二维 | O(m·n) | O(m·n) |
| **滚动一维** | O(m·n) | **O(n)** |

面试可补一句"每行只依赖上一行 → 能滚动到 O(n)"（SolutionRoll 已附）。

## 六、一句话记住

> **64 = 二维 DP 最值版：dp[i][j] = min(上, 左) + grid[i][j]，首行首列是前缀和（或 inf 哨兵越界 + 记忆化递归）；与 62 同骨架、加法换 min；可滚动到 O(n)。**
