## 解法核心

**关键洞察**：杨辉三角的每个元素 = 上一行「左上方 + 正上方」两数之和（组合数性质 C(n,k) = C(n-1,k-1) + C(n-1,k)），每行首尾恒为 1。

```python
result = [[1]]
for layer in range(1, numRows):
    each_list = [1]                               # 首位 1
    for i in range(1, layer):
        each_list.append(result[-1][i-1] + result[-1][i])   # 中间 = 上一行相邻和
    each_list.append(1)                           # 末位 1
    result.append(each_list)
return result
```

第 layer 行有 layer+1 个元素：首尾 1，中间 layer-1 个由上一行两两相加得出。
