# 118. 杨辉三角 · 解析（二刷）

## 一、核心思路：逐行递推，首尾补 1

**问题**：生成杨辉三角前 numRows 行。

**关键洞察**：杨辉三角就是**二项式系数表**——第 n 行第 k 列 = C(n,k)。递推关系：

```
C(n, k) = C(n-1, k-1) + C(n-1, k)      （相邻两项相加）
C(n, 0) = C(n, n) = 1                   （首尾恒为 1）
```

所以构造第 layer 行 = 上一行两两相邻求和，两头各补一个 1。

## 二、代码（用户 AC 版）

```python
result = [[1]]
for layer in range(1, numRows):
    each_list = [1]                                  # 首 1
    for i in range(1, layer):
        each_list.append(result[-1][i-1] + result[-1][i])   # 上邻和
    each_list.append(1)                              # 尾 1
    result.append(each_list)
return result
```

## 三、⚡ 杨辉三角 = DP 二维递推的基本盘

**这题是"从递推公式直接构造"的最朴素样本**：每一行的状态只依赖上一行——正是 DP「当前行 = 上一行 + 转移规则」的原型。背熟这个骨架，62 不同路径、64 最小路径和、5 最长回文子串都从它长出来。

**几个隐藏性质（面试随口可提）**：
- 第 n 行之和 = 2^(n-1)
- 第 n 行第 k 个 = C(n,k)（组合数）
- 每一行左右对称

## 四、复杂度

- 时间：O(numRows²)（总元素 n(n+1)/2，每元素 O(1) 计算）
- 空间：O(1) 额外（答案数组本身必然 O(n²)）

## 五、一刷 vs 二刷

- 一刷（9-18）：AC ×2；
- 二刷（11-01）：一次 AC，递推内化。
