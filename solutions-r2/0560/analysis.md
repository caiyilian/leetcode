# 560. 和为 K 的子数组 · 解析（二刷）

## 一、核心思路：子数组和 = 前缀和之差

```
pre[i] = nums[0] + nums[1] + ... + nums[i-1]   （pre[0] = 0）

子数组 nums[j..i] 的和 = pre[i+1] - pre[j]
```

**找"和为 k 的子数组" ⟺ 找两个前缀和，它们的差等于 k**：

```
pre[i+1] - pre[j] = k   ⟺   pre[j] = pre[i+1] - k
```

所以遍历到当前前缀和 `cur` 时，只需要**查之前出现过多少个 `cur - k`**。

## 二、一遍遍历的骨架（查差值，不枚举对）

```python
hash_dict = defaultdict(int)
hash_dict[0] = 1              # 虚拟前缀和 0
pre = 0
result = 0
for i in range(len(nums)):
    pre += nums[i]
    result += hash_dict[pre - k]    # ★ 查：之前有多少个前缀和 = pre-k
    hash_dict[pre] += 1             # ★ 记：当前前缀和入哈希
return result
```

**为什么 O(n)**：每个前缀和算一次、查一次、记一次，全 O(1)。暴力枚举所有子数组是 O(n²)。

## 三、三个必须想透的细节

| 细节 | 为什么 | 不做的后果 |
|------|--------|-----------|
| `{0:1}` 预置 | 从头开始的子数组 `nums[0..i]`，其和 = `pre[i+1] - 0`，需要前缀和 0 出现过 | 漏掉所有"从下标 0 起"的答案 |
| 先查后记 | k=0 时 `pre-k == pre`，若先记，会把刚算的前缀和自己匹配上 | 每个位置多算 1 个假答案 |
| 记频次不记位置 | 只关心"有几个起点 j"使区间和为 k | 记位置无法处理重复前缀和（如零和连环） |

## 四、为什么滑动窗口不行（这题与 3/438/239/76 的本质区别）

滑动窗口要求窗口和**单调**（右扩变大、左缩变小）→ 只对**非负数组**成立。
本题数组**含负数**：缩左边界反而可能让和变大，窗口失去"能收能放"的性质。
→ 遇到"子数组和 + 可能有负数" → 直接想前缀和。

## 五、复杂度

- 时间：O(n)
- 空间：O(n)（哈希表最多 n 个不同前缀和）

## 六、一刷 vs 二刷

- 一刷（9-12）：暴力 TLE → 2 版演进定稿，31ms/91%，用户标记"面试前重点看"；
- 二刷（10-12）：忘了前缀和做法 → 提示后独立复现，**一次 AC 无失败提交**（21:05，754367559）。

## 八、一句话记住

> **子数组和 = 前缀和之差；含负数不能用滑动窗口，前缀和 + 哈希查 `cur - k` 一遍 O(n)。**
