# 617. 合并二叉树 · 解析（二刷）

## 一、核心思路：以 root1 为主树，递归合并

合并规则：
- 两棵树的**重叠节点**：值相加；
- **不重叠**：直接把非空的那棵子树接过来。

以 root1 为主树（原地改）或新建节点（不改原树）都可以，骨架一样：

```
   1             2             3
  / \     +     / \     =     / \
 3   2       1    3         4   5
/             \     \      / \   \
5              4     7    5   4   7
```

## 二、代码（用户 AC 版，原地改 root1）

```python
if not root1:
    return root2                       # ⚡ root1 空 → 整棵用 root2（入口守卫）

def fun(root1, root2):
    if root1 and root2:                # 都有 → 值相加 + 递归合并左右
        root1.val += root2.val
        root1.left = fun(root1.left, root2.left)
        root1.right = fun(root1.right, root2.right)
        return root1
    else:
        return root1 if root1 else root2   # 单边空 → 返回非空一边（递归边界）
```

**关键边界**：`return root1 if root1 else root2`——当某个节点只有一棵树有时，直接返回那棵子树（包括其全部后代），**不再递归**。这是合并树的"短路"。

## 三、两种风格对比

| | 原地改 root1（用户版） | 新建节点（官方解法一） |
|---|---|---|
| 空间 | 更省（无新节点） | O(n) 新节点 |
| 副作用 | 修改了 root1 | 无副作用（纯函数） |
| 适用 | 只想拿结果 | 想保留原树 |

面试两个都能说，原地版还要提"注意会改掉 root1"。

## 四、复杂度

- 时间：O(n)——两树节点并集（min(节点数) 到 节点数和）
- 空间：O(h)——递归栈

## 五、一刷 vs 二刷

- 一刷（9-26）：WA 1 次（空树处理）→ AC ×2；
- 二刷（10-27）：一次 AC——空树守卫 + 单边返回边界都写对。

## 六、关联题目（双树递归家族）

| 套路 | 相关题 |

| 双树同时递归 | 100 相同的树、101 对称二叉树（镜像交叉） |

**617 是双树递归的入门题**：100（都是才 True）、101（镜像比较）、617（重叠相加、单边接上）——一个骨架三个变体。

## 七、一句话记住

> **合并二叉树 = 双树递归：都有就值相加+递归左右，单边空直接返回非空子树（短路不再往下）；root1 为空整棵用 root2。**
