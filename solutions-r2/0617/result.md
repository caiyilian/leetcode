## 解法说明：以 root1 为主树

```python
if not root1:
    return root2                     # ⚡ 空树守卫：root1 空则整棵用 root2

def fun(root1, root2):
    if root1 and root2:              # 两棵都有 → 值相加，递归合并左右
        root1.val += root2.val
        root1.left = fun(root1.left, root2.left)
        root1.right = fun(root1.right, root2.right)
        return root1
    else:
        return root1 if root1 else root2   # 单边为空 → 返回非空的一边（不再往下）
```

两个细节：
- **`if not root1: return root2`**：入口守卫，root1 为空直接返回 root2（整棵树都是 root2 的）——不需要再进 fun；
- **`return root1 if root1 else root2`**：递归到"一个为空"时，返回非空的那棵子树（直接接上，不用继续合并）——这是递归的边界。

**和官方解法一对比**：官方版在 `if not root1` / `if not root2` 两个入口都守卫 + 新建节点；用户版**原地改 root1**（更省内存，不建新树），逻辑等价。
