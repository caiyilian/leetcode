## 解法核心：切割回溯（start 的又一用法）

**问题**：把 s 切分成若干子串，每段都回文，返回所有切法。

**回溯视角**：每个位置就是一个"切/不切"的选择点——切出来的子串是回文才继续：

```python
def fun(path, start=0):
    if start >= length:          # 切完了 → 收集
        result.append(path.copy())
        return path
    for i in range(start, length):        # 从 start 试切到 i
        if isPa(s[start:i+1]):            # 这刀是回文才切
            path.append(s[start:i+1])
            path = fun(path, i+1)         # 从切点后继续
            path.pop()
    return path
```

- **start 语义**（和 39 组合/78 子集同款）：当前未处理的起点，每层只往后切（不回头）；
- **i 遍历**：start 起的所有可能切点，`s[start:i+1]` 是回文才走；
- **isPa 双指针**：O(n) 判回文（`s == s[::-1]` 也行，Python 切片更快）。

**⚡ 一个细节**：`fun` 里 `if start >= length: ... return path` 有 return——但结构上它后面紧跟 for（无 else），靠 return 挡住"切完还继续 for"；写得更稳的版式是在 `else` 里放 for 或直接把 return 放 if 内。力扣判题下当前写法正确（对拍也验证了），但面试可提"切完就 return 防越界"。

## 优化方向（面试可提）

- **预计算回文表** `dp[i][j]`（区间 i..j 是否回文）：isPa 从 O(n) 降到 O(1)，总复杂度 O(n×2^n) 不变但常数小——已是标准 stardand 优化；
- 极端 "全同字符"（aaaa）：2^(n-1) 种切法，天然指数级。
