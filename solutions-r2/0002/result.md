| 考察点 | 结论 |

## 二刷踩坑记录（本次的宝贵经验）

### 坑 1：测试用例3 少最高位（用户自查发现）

`[9,9,9,9,9,9,9] + [9,9,9,9]` 期望 `[8,9,9,9,0,0,0,1]`，原版得到 `[8,9,9,9,0,0,0]`——**最后一步进位 `1` 没接上**：

```python
if flag:
    l1 = ListNode(1)   # ❌ 只改局部变量，没接进链表 → 孤儿节点
    # 正确：prev.next = ListNode(1)（prev 记录链表末尾的前驱）
```

**教训**：链表里 `指针 = 新节点` 只是让局部变量换指向，**必须挂在某个节点的 next 上**才生效。

### 坑 2：l1 为空时 UnboundLocalError（对拍抓出，力扣未测）

`[] + [5]` 时 `while l1 and l2` 整个跳过，`prev` 从未赋值，`prev.next = l2` 崩溃。力扣老题测试集没有空 l1 用例所以侥幸 AC。**修复**：开头补守卫 `if not l1: return l2; if not l2: return l1`。

## 双解法归档（用户选择：主版 + 标准版都留）

- **主版（SolutionUser）**：原地相加 + `prev` 前驱接尾——用户现场能默写，二刷选它；
