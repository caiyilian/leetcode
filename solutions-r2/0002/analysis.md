# 2. 两数相加 · 解析（二刷）

## 一、核心思路：逆序存储 = 从低位开始

数字按**逆序**存在链表里（个位在 head），所以**从头到尾遍历恰好就是从低位往高位相加**——不需要反转、不需要对齐，一路加过去即可，只差一个**进位**要带着走。

```
[2,4,3] + [5,6,4]   （342 + 465 = 807）
 2+5=7   4+6=10→0 进1   3+4+1=8
→ [7,0,8] ✅
```

## 二、用户主版：原地相加 + 前驱接尾

```
① while l1 and l2：共有位数相加，carry 进 1，l1.val %= 10
② l1 走完 → prev.next = l2 拼接剩余；继续 while l1 传播进位
③ 最终 carry=1 → prev.next = ListNode(1) 补最高位
```

**关键点 `prev`（前驱）**：链表尾插/接续都需要"上一个节点"。`prev` 每轮记录当前节点，循环结束后它指向链表末尾，`prev.next = ...` 就能把剩余链/进位节点**真正挂上去**。

## 三、标准哨兵版：一行 while 全搞定

```python
dummy = ListNode(0)
cur = dummy
carry = 0
while l1 or l2 or carry:
    v = carry
    if l1: v += l1.val; l1 = l1.next
    if l2: v += l2.val; l2 = l2.next
    cur.next = ListNode(v % 10)
    cur = cur.next
    carry = v // 10
return dummy.next
```

- `while l1 or l2 or carry`：任一还有货（或还有进位）就继续——**天然覆盖** 谁长谁短、双空、最高位进位 三种情况；
- 每轮新建一个节点，不需要拼接/换链/前驱，结构最简单；
- **代价**：新建 O(n) 个节点（不原地），但输出链表本来就要 O(n) 个节点，不算浪费。

## 四、两版对比

| | 用户主版（原地） | 标准哨兵版 |
|---|---|---|
| 思路 | 原地改 l1 + 前驱接尾 | 新建 dummy 逐个生成 |
| 空间 | O(1)（只新建进位节点） | O(n)（输出节点，正常） |
| 边界处理 | 需空链守卫 + prev 拼接 | 循环条件天然覆盖 |
| 现场默写 | 用户更熟 | 面试官更常见 |

## 五、复杂度

- 时间：O(n)，n = max(len(l1), len(l2))
- 空间：主版 O(1) / 标准版 O(n)

## 六、一刷 vs 二刷

- 一刷（9-10 ~ 9-13）：两阶段 while + 拼接，WA×2 → AC×3 演进（踩过"尾 0 现象力扣按数值判题接受"）；
- 二刷（10-19）：用户版先漏最终进位（自查修复加 prev）→ 力扣 AC；对拍又抓出空 l1 崩溃（补守卫）。**力扣 AC ≠ 无 bug 的又一实证**。

## 八、一句话记住

> **两数相加 = 逆序链表天然从低位加起，逐位求和 + 进位；原地版要记"指针赋值≠挂上链表，前驱 prev 才能接尾"，标准版 `while l1 or l2 or carry` 一行覆盖全部边界。**
