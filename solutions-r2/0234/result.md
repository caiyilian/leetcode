## 用户纠正：不是一次 AC（本地失败记录）

力扣提交历史今天只有一条 AC（755600761），但 **leetgo 本地测试失败**——根因是快慢指针找中点的 while 循环结束后，**忘了把 `p_fast` 重置回 `head`**：

```python
while p_fast and p_fast.next:   # 循环结束后 p_fast 已走到链表尾（None / 尾节点）
    p_slow = p_slow.next
    p_fast = p_fast.next.next
# ❌ 这里漏了 p_fast = head
p_slow = self.reverseList(p_slow)
while p_slow:                    # p_fast 此时不在头部 → 比较错位 / 逻辑错误
    ...
```

补上 `p_fast = head` 后在线一次 AC。

**小错误大教训**：快慢指针循环会"消耗"两个指针，**复用指针前先想清楚它现在停在哪**——找中点用的 `p_fast` 和比较阶段用的 `p_fast` 不是同一个位置，重置是必须的。
