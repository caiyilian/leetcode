# 234. 回文链表 · 解析（二刷）

## 一、核心思路：三段式组合拳

回文 = 前后对称。链表不能倒着读，所以**把后半段反过来**再和前半比较：

```
① 找中点：快慢指针（fast 走 2 步 / slow 走 1 步）
② 反转后半段（206 的 reverseList）
③ 前半 vs 反转后的后半，逐节点比较
```

```
[1, 2, 3, 2, 1]    奇数：slow 停在中点 3
  ↑slow             反转后半（含中点）→ [1,2,3]
  fast 走到尾        比较 p_fast[1,2,3] vs p_slow[1,2,3] → True

[1, 2, 2, 1]       偶数：slow 停在右半头
  ↑slow             反转后半 → [1,2]
  fast 到 None       比较 [1,2] vs [1,2] → True
```

## 二、为什么奇数不用特判

奇数长度时反转的后半段**包含中点**（`[1,2,3]`），和前半 `[1,2,3]` 长度相同——中点自己和自己比，天然通过。唯一要注意的是**快慢指针的停点**：`while p_fast and p_fast.next` 保证偶数时 fast 停在 None、奇数时停在尾节点——这是"中点正确"的前提（一刷踩过：快指针 next 为 None 就得停）。

## 三、为什么能 O(1) 空间

三段都只用了指针变量（无栈、无数组）：快慢指针 2 个 + 反转 3 个 + 比较 2 个——全是常数个变量。**"反转链表"是 O(1) 空间的关键**（206 就是这个特性），所以组合拳整体 O(1)。

## 四、复杂度

- 时间：O(n)（三段各 O(n/2)，合 O(n)）
- 空间：O(1)

## 五、一刷 vs 二刷

- 一刷（9-13）：WA/RE → 4 次演进定稿（奇数坑"快指针 next 为 None 就得停"）；
- 二刷（10-18）：三段式思路一次成型，`while p_fast and p_fast.next` 一次写对；**唯一小失误是快慢指针循环结束后忘把 `p_fast` 重置回 `head`（本地测试暴露，补上后在线一次 AC）**。
