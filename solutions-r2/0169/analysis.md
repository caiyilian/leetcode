# 169. 多数元素 · 解析（二刷）

## 一、题目

- 中文：多数元素
- English：Majority Element
- 难度：简单
- 问题：出现次数 > n/2 的元素（题目保证存在）

## 二、核心思路：摩尔投票（Boyer-Moore）

**思想**：把数组看成"投票"——两个不同的数互相抵消，多数元素（> n/2）**抵消不完，必剩**。

```
[2,2,1,1,1,2,2]
now=2 count=1 → 遇2 count=2 → 遇1 count=1 → 遇1 count=0（换 now=1 count=1）
→ 遇1 count=2 → 遇2 count=1 → 遇2 count=0（换 now=2 count=1）
返回 2 ✅
```

**代码**：
```python
now, count = nums[0], 1
for i in range(1, len(nums)):
    if nums[i] == now: count += 1
    else:
        count -= 1
        if count == 0:
            now = nums[i]          # 换候选人
            count = 1              # ⚡ 必须重置！(WA 复盘)
return now
```

**为什么对**：多数元素出现 > n/2 次，和其他元素最多两两抵消，抵消后必剩它。O(n)/O(1) 是唯一同时满足"线性 + 常数空间"的解。

## 三、⚡ 易错点（本次 WA）

**换候选时忘记重置 count = 1**：归零意味着"当前候选和对手完全抵消"，新候选**已经自带 1 票**——不重置会导致计数错乱（变负数、提前换人）。这是摩尔投票最经典的笔误点。

## 四、复杂度

- 时间：O(n)
- 空间：O(1)

## 五、关联题目

| 题 | 关系 |
|----|------|
| **169 本题** | 摩尔投票——"抵消"思想原型 |
| **136 只出现一次的数字**（⚡ 已做）| 异或抵消——同源"抵消"思维（异或 vs 投票）|

**识别信号**："出现超过一半 / 众数" → 摩尔投票；"出现一次" → 异或。都是 O(n)/O(1) 的"抵消"套路。

## 六、一句话记住

> **169 = 摩尔投票：相同 +1、不同 -1、归零换人（⚡ 换人时重置 count=1）；多数元素 > n/2 抵消不完必剩；O(n)/O(1)。**
