## 是否最优解？✅ 是（O(n log k) + O(n)）

| 考察点 | 结论 |
|--------|------|
| 时间复杂度 | ✅ O(n log k)——计数 O(n) + 堆维护 O(m log k)（m 为不同数字数） |
| 空间复杂度 | ✅ O(n)（计数 dict + 堆） |
| 正确性 | ✅ **5000 组随机验证**（含并列频次任选判定）全过 + 官方示例 |
| 思路 | ✅ 计数 + 最小堆维护前 K = 官方解法一（另有桶排序 O(n)） |

## 解法核心：两个阶段——计数 + Top-K 堆

**阶段 1**：`Counter`（或手写 dict）统计每个数字频次；
**阶段 2**：把 `(频次, 数字)` 放进**大小为 k 的最小堆**（按频次排）——堆顶 = 前 K 高里频次最低的，遍历其余"频次更高就替换"（和 215 一模一样的 Top-K 模板）。

```python
count_dict = {}
for n in nums: count_dict[n] = count_dict.get(n, 0) + 1

freq2num = [(v, key) for key, v in count_dict.items()]
heap = freq2num[:k]
heapq.heapify(heap)
for i in range(k, len(freq2num)):
    if freq2num[i][0] > heap[0][0]:           # 频次高于堆顶 → 替换
        heapq.heappushpop(heap, freq2num[i])
return [n[1] for n in heap]                   # 答案顺序任意
```

**⚡ 并列频次任选合法**：当第 k 名有多个并列频次时，力扣 special judge 接受其中任意 k 个（对拍验证过：返回集合满足"必含所有更高频次者 + 频次不低于第 k 大"即合法）。

## 其他解法（面试可提）

- **桶排序**：频次最大值 ≤ n，建 n+1 个桶按下标存"该频次的数字"，从高往低取 k 个——O(n)，比堆更快；
- **快选**：按频次做快速选择，期望 O(n)。
