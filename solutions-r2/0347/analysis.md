# 347. 前 K 个高频元素 · 解析（二刷）

## 一、核心思路：计数 + Top-K 最小堆

**问题**：返回数组中出现频次最高的 k 个数字（顺序任意）。

**两个独立子问题**：
1. **统计频次**：哈希表 O(n)；
2. **取前 K 高**：和 215 一模一样的 Top-K 套路——**大小为 k 的最小堆**，堆顶作为"门槛"，更高的替换。

**为什么不能直接排序**：全排序 O(n log n)，而堆只维护 k 个 → O(n log k)，k 通常远小于 n。

## 二、代码（用户 AC 版）

```python
count_dict = {}
for n in nums:
    count_dict[n] = count_dict.get(n, 0) + 1          # 计数

freq2num = [(v, key) for key, v in count_dict.items()]  # (频次, 数字)
heap = freq2num[:k]
heapq.heapify(heap)                                    # 最小堆（按频次）
for i in range(k, len(freq2num)):
    if freq2num[i][0] > heap[0][0]:                    # 频次 > 堆顶（门槛）
        heapq.heappushpop(heap, freq2num[i])
return [n[1] for n in heap]                            # 只要数字
```

## 三、⚡ 关键点

1. **堆按元组第一个元素（频次）排序**：`(freq, num)` 放进 heapq 自动按 freq 比较；
2. **heappushpop 一步替换**：弹掉最小的（频次最低的），加入新的，堆大小保持 k；
3. **并列频次任选**：返回值顺序无关 + 并列第 k 名可任选（specal judge 接受），不要求全列；
4. **边界**：k 一定 ≤ 不同数字数（题目保证），堆初始化和遍历安全。

## 四、复杂度

- 时间：O(n log k)（计数 O(n) + 堆操作 m 次 × O(log k)）
- 空间：O(n)（dict + 堆）

## 五、其他解法（面试可讲）

| 方法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 计数 + 最小堆（本题） | O(n log k) | O(n) | 简单可靠 |
| 计数 + 桶排序 | O(n) | O(n) | 频次上界 n，桶按频次放，从高取低 |
| 计数 + 快选 | 期望 O(n) | O(n) | partition 按频次分区 |

## 六、一刷 vs 二刷

- 一刷（9-18）：堆 AC ×2；
- 二刷（10-31）：一次 AC——215 的 Top-K 模板迁移到频次场景，直接默写。

## 八、一句话记住

> **前 K 高频 = 计数（dict）+ 最小堆维护前 K（(频次,数字) 元组入堆，高于堆顶就 pushpop）；并列任选顺序任意；进阶桶排序 O(n)。**
