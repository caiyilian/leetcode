# 739. 每日温度 · 解析（二刷）

## 一、核心思路：单调递减栈（"下一个更大元素"经典）

**问题**：对每个温度，求它之后**第一个更高温度**的天数距离，没有则 0。本质 = **"下一个更大元素的下标差"**。

**暴力 O(n²)**：每个 i 向后找第一个 `t[j] > t[i]`——全递增时很慢（TLE，初刷实测 2882ms）。

**单调栈 O(n)**：维护**温度递减**的栈（存下标）。核心观察——
> 栈里等待的元素去找"第一个更高的"，**一到更高的就直接结算**；更矮的排在后面（更不可能是栈顶的高温），不用重复比。

## 二、为什么是"单调递减"？（⚡ 记牢方向）

栈底 → 栈顶：温度**严格递减**。因为：
- 新温度到来，只要栈顶比它小→栈顶找到了答案（它是栈里"最接近"的等待者）；
- 弹到栈顶 ≥ 当前，当前入栈——**栈里依旧递减**（后面更高的都结算走了）。

```
[73,74,75,71,69,72,76,73]
i=0 栈=[0]                     73 等
i=1  74>73 → 结算 0 得 1；栈=[1]
i=2  75>74 → 结算 1 得 1；栈=[2]
i=3  71<75 入栈 → 栈=[2,3]
i=4  69<71 入栈 → 栈=[2,3,4]
i=5  72>69 结算 4 得 1；72>71 结算 3 得 2；栈=[2,5]
i=6  76>72 结算 5 得 1；76>75 结算 2 得 4；栈=[6]
i=7  73<76 入栈 → 栈=[6,7]
结果 [1,1,4,2,1,1,0,0] ✓
```

## 三、代码（用户 AC 版）

```python
results = [0] * length
stack = []                        # 存下标，温度递减
for i in range(length):
    while stack and temperatures[stack[-1]] < temperatures[i]:
        index = stack.pop()
        results[index] = i - index    # 栈顶温度 < 当前 → 第一个更高 = i
    stack.append(i)
return results
```

## 四、复杂度

- 时间：O(n)——每元素入栈出栈至多一次
- 空间：O(n)

## 五、⚡ 易错点

1. **比较用 `<`（严格）**：等温不算更高（`[7,7,8]→[2,1,0]`）；写成 `<=` 会错误把相等当天结算成 1；
2. **存下标**：要算距离差，存值还得查位置，多一层；
3. **循环顺序**：先结算后入栈——当前元素本身也要入栈等更高。

## 七、一句话记住

> **每日温度 = 单调递减栈：while 栈顶温度 < 当前 → 弹出结算距离 i-弹；⚡ 严格 <（相等不结算）、存下标、先结算后入栈；"下一个更大/更小"一律先想单调栈。**
