## 解法核心：单调递减栈（存下标）

**问题**：对每个温度，找它之后**第一个更高温度**的距离；没有则 0。

**单调栈的直觉**：维护一个"温度递减"的栈（栈底温度最高→栈顶最低）。遇到新温度 i：
- **只要栈顶温度 < 当前温度** → 栈顶元素找到了它的"第一个更高温度"（就是当前 i）→ 弹出并结算 `res[弹] = i - 弹`；
- 新温度 i 入栈（它比栈里更小的都"更大"，那些已经结算走了）。

```python
stack = []                     # 存下标，温度递减
results = [0] * length
for i in range(length):
    while stack and temperatures[stack[-1]] < temperatures[i]:
        index = stack.pop()
        results[index] = i - index      # 栈顶温度 < 当前 → 结算距离
    stack.append(i)                     # 当前天入栈等待更高温度
return results
```

**为什么 O(n)**：每个下标最多入栈 1 次、出栈 1 次，while 总执行 ≤ n 次。

## 三个细节（⚡ 面试必答）

1. **相等不结算**：`<` 严格——等温天不算"更高温度"，相等元素留在栈里，等真正的更高温度到来一起结算（`[7,7,8]` → `[2,1,0]` 验证）；
2. **存下标不存值**：计算距离需要下标差；温度值通过 `temperatures[栈顶]` 取；
3. **没结算的保持 0**：最后一天/后面无更高温度的下标留在栈里，`results` 初始全 0 恰好正确。
