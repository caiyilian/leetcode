# 41. 缺失的第一个正数 · 解析（二刷）

## 一、核心洞察：答案范围收缩到 [1, n+1]

长度为 n 的数组，答案**只可能是 [1, n+1] 里的一个数**：

- 若 1~n 全都在 → 答案 = n+1；
- 否则缺哪个，答案就是哪个。

**推论**：数组中值在 [1, n] 之外的数（负数、0、>n）全是"无关垃圾"，可以无视——它们不可能占住答案的位置。

## 二、归位法：数组即哈希表（O(1) 空间的关键）

不能开哈希表，就把**数组本身当哈希表**：映射关系取最自然的

```
值 v  →  下标 v-1     （1 放下标 0，2 放下标 1，…）
```

**归位循环**：凡是"值在 [1,n] 且不在自己该待的位置"的数，交换到 `nums[v-1]` 去：

```python
for i in range(n):
    while (nums[i] != i+1) and (1 <= nums[i] <= n) and (nums[i] != nums[nums[i]-1]):
        target_index = nums[i] - 1          # ★ 冻结下标（Python 元组交换坑）
        nums[i], nums[target_index] = nums[target_index], nums[i]
```

三个条件分别防什么：
| 条件 | 防什么 |
|------|--------|
| `1 <= nums[i] <= n` | 范围外数值不归位（垃圾） |
| `nums[i] != i+1` | 已就位的不动 |
| `nums[i] != nums[nums[i]-1]` | **重复值死循环**——目标处已有同值，交换无意义且无限循环 |

## 三、为什么总复杂度是 O(n) 而不是 O(n²)

每个 [1,n] 内数值**最多被交换一次**：交换后它落在正确位置 `nums[v-1]`，此后 while 条件 `nums[i] == i+1` 对该位置成立，不再进入。总交换次数 ≤ n → **O(n)**。

## 四、本地死循环坑：Python 元组交换的求值顺序

```python
# ❌ 死循环：
nums[i], nums[nums[i]-1] = nums[nums[i]-1], nums[i]

# ✅ 正确：
target_index = nums[i] - 1
nums[i], nums[target_index] = nums[target_index], nums[i]
```

Python 元组交换：**右侧先整体求值（全用旧值），左侧按下标从左到右依次赋值**。左侧第二个下标 `nums[nums[i]-1]` 里的 `nums[i]` 在求值时**已经是第一步赋过的新值** → 下标算错 → 写错位置 → 死循环。

**通用规则**：单行交换中，左侧下标若依赖同一列表的其他下标，先冻结成局部变量。

## 五、复杂度

- 时间：O(n)
- 空间：O(1)

## 六、一刷 vs 二刷

- 一刷（9-12）：set 版 O(n) 空间不达标 → 3 版演进定稿归位法；
- 二刷（10-14）：**先自主推断"多遍遍历 + 数组即存储"→ 提示归位映射后一次 AC**，且自己悟出防重复条件 + 踩了 Python 交换坑并自行修复。

## 八、一句话记住

> **归位法：值 v 归位到下标 v-1，O(n) 交换 O(1) 空间；交换时先冻结下标（Python 元组交换坑），重复值要判相等防死循环。**
