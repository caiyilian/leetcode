# 35. 搜索插入位置 · 解析（二刷）

## 一、核心思路：二分查找 = 找第一个 ≥ target 的位置

**问题**：有序数组，找 target 下标；不存在则返回"应插入的位置"。这正是 `bisect_left` 的语义。

**关键洞察**：插入位置 = **第一个 >= target 的元素下标**（若 target 存在则就是它本身的下标）：
```
[1,3,5,6] target=2 → 第一个 >=2 的是 3(下标1) → 1
[1,3,5,6] target=7 → 全小于7 → 末尾 4
[1,3,5,6] target=5 → 命中 → 2
```

## 二、代码（用户 AC 版）——左闭右闭模板

```python
left, right = 0, len(nums) - 1
while left <= right:
    mid = (left + right) // 2
    if nums[mid] == target:
        return mid
    elif nums[mid] > target:
        right = mid - 1
    else:
        left = mid + 1
return left          # ★ 退出时 left = 第一个 >= target 的位置
```

**为什么返回 left 是对的**（循环不变量）：
- 每次调整都保持 `nums[left-1] < target`、`nums[right+1] >= target`；
- 循环退出（left > right）时，left 就是第一个 ≥ target 的下标——既覆盖"存在"（命中提前 return）也覆盖"不存在"（插入位）。

## 三、⚡ 二分三大模板速查（机考必背）

| | 标准查找 | 左边界 | 右边界 |
|---|---|---|---|
| 区间 | [l, r] 闭 | [l, r) 开 | [l, r) 开 |
| while | `l <= r` | `l < r` | `l < r` |
| 命中 | `return mid` | `r = m` | `l = m + 1`（记 ans）|
| 未命中 | `l = m+1; r = m-1` | `l = m + 1` | `r = m` |
| 返回 | mid / l | l（左边界）| ans / l-1 |
| 对应题 | **704 二分查找**、**35** | **278 第一个坏版本**、34 | 34 右边界 |

**死记要点**：
- `while l <= r`（闭区间）→ 更新必须 ±1（`l=m+1`/`r=m-1`），否则死循环；
- `while l < r`（开区间）→ 更新必须 `l=m`/`r=m`（m 本身可能还是答案，不能 ±1）；
- 求 mid 防溢出（Python 无所谓，面试写 `l + (r-l)//2` 显专业）。

## 四、复杂度

- 时间：O(logn)
- 空间：O(1)

## 五、一刷 vs 二刷

- 一刷（9-17）：二分 AC ×2；
- 二刷（10-29）：一次 AC，模板直接默写，3 万组对拍（vs bisect_left）零漂移——**⚡ 机考二分母题标记confirmed**。

## 六、关联题目（二分家族）

| 套路 | 相关题 |
|------|--------|
| 标准二分 | **704 二分查找**（⚡ 姊妹题）、35 本体 |
| 左/右边界 | 34 在排序数组中查找元素的第一个和最后一个位置、278 第一个坏版本 |
| 二分答案 | 875 爱吃香蕉的珂珂、1011 在 D 天内送达包裹的能力、410 分割数组最大值 |

**35 → 704 → 34 是二分三部曲**：35 弄懂"返回 left 的语义"，704 是纯查找，34 是左右边界合一（两个二分）。

## 七、一句话记住

> **搜索插入位置 = 二分找第一个 ≥ target 的位置：左闭右闭 while l<=r，命中 return mid，未命中 return left（循环不变量保证 left 即答案）；等价 bisect_left。**
