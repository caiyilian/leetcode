## 解法本质：找第一个 ≥ target 的位置

本题 = `bisect_left(nums, target)`（Python 标准库语义）。插入位置就是"第一个 >= target 的位置"：

```
nums=[1,3,5,6]  target=2 → 第一个>=2 的是 3（下标1）→ 返回 1
                 target=7 → 全部<7，插入到末尾 → 返回 4（len(nums)）
```

**为什么退出时 `left` 就是答案**：循环不变量——`nums[left-1] < target` 且（若 right+1 在界内）`nums[right+1] >= target`。跳出时 `left == right+1`，此时 left 恰好是第一个 >= target 的下标。

## ⚡ 二分三大模板（机考必背，本母题串起）

| 模板 | 区间 | 循环 | 边界 | 适用 |
|------|------|------|------|------|
| **标准查找** | 左闭右闭 [l,r] | `while l <= r` | `r=m-1` / `l=m+1` | 找精确值（704） |
| **左边界** | 左闭右开 [l,r) | `while l < r` | `r=m` / `l=m+1` | 第一个 ≥ target（35 变体、278） |
| **右边界** | 左闭右开 | `while l < r` | `r=m` / `l=m+1`（成功时记） | 最后一个 ≤ target |

35 用**标准查找模板**（命中提前返回，未命中返回 left）最直观，且能同时覆盖"存在返回下标 / 不存在返回插入位"两个需求。
