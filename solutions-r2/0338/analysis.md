# 338. 比特位计数 · 解析（二刷）⚡ 考前复习公式

## 一、题目

- 中文：比特位计数
- English：Counting Bits
- 难度：简单（位运算 DP）
- 问题：返回 `[0..n]` 每个数的二进制中 1 的个数

## 二、核心技术：位运算 DP（一句话公式）

**核心观察**：`i` 的二进制 = `(i >> 1)` 的二进制 **后面补上 i 的最低位**。

```
i = 5  (101)     i>>1 = 2 (10)      i&1 = 1
     "101" = "10" + "1"
1 的个数：popcount(5) = popcount(2) + 1 = 1 + 1 = 2
```

**所以**：
```
dp[i] = dp[i >> 1] + (i & 1)
dp[0] = 0
```

**为什么能 DP**：`i>>1 < i`（对 i≥1 恒成立），子问题下标总是更小 → 自底向上一次遍历即可。

## 三、代码（用户 AC 版）

```python
dp = [0] * (n + 1)
for i in range(1, n + 1):
    dp[i] = dp[i >> 1] + (i & 1)   # ⚡ 括号必须加！
return dp
```

**复杂度**：O(n) 时间、O(n) 空间（结果数组本身）。

## 四、⚡ 括号坑（用户亲自踩，重点记）

**为什么 `(i&1)` 括号不能去**？Python 运算符优先级：

```
() > ** > * / // % > + - > << >> > & > ^ > | > 比较
```

**`+`（加法）比 `&`（按位与）优先级高**：
```
dp[i>>1] + (i&1)     ✅ 解析为 dp[i>>1] + (i&1)，先取 i 的最低位再加
dp[i>>1] + i & 1     ❌ 解析为 (dp[i>>1] + i) & 1，先加再取最低位——完全错
```

实测 `i=3`：正确 `1+(3&1)=2`，去掉括号 `(1+3)&1=0`——完全不同的数。

**记忆锚点**：**位运算（& | ^ << >>）的优先级全部低于算术运算符（+ - * /）**——当你把位运算和数学运算写在同一行时，位运算是"最底层"的，必须加括号保护。这是一道送分题的经典失分点。

## 五、其他解法（对比认知）

| 解法 | 时间 | 说明 |
|------|------|------|
| **DP（本题）** | O(n) | 递推最小，面试首选 |
| `i & (i-1)` 技巧 | O(n) | `dp[i] = dp[i&(i-1)] + 1`——去掉最低位的 1（另一条递推）|
| 内置 `bit_count()` | O(n) | 一行解，可提但面试别当主解 |

## 七、一句话记住

> **338 = dp[i] = dp[i>>1] + (i&1)：i 的 1 个数 = 去掉最低位后的 1 个数 + 最低位；⚡ 位运算优先级低于加减，混用必加括号；(i&1) 的括号不能去！**
