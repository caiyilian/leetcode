# 461. 汉明距离 · 解析（二刷）

## 一、题目

- 中文：汉明距离
- English：Hamming Distance
- 难度：简单（位运算收尾题）
- 问题：两个整数的二进制中，**对应位不同的个数**

## 二、核心：三种典型写法（从 338 的知识递进）

**汉明距离的本质**：两个数的二进制"同位不同"的个数 = `(x ^ y)` 中 **1 的个数**（异或：相同 0、不同 1）。

| 写法 | 代码 | 特点 |
|------|------|------|
| **逐位比较**（用户）| `while x or y: if x%2 != y%2: count++ ; x>>=1; y>>=1` | 直观、不用异或，O(位数) |
| 异或 + bit_count | `return (x ^ y).bit_count()` | 最简洁（C 实现最快）|
| 异或 + 手动数位 | `while z: cnt += z&1; z>>=1` | 不依赖内置 |

三种都 O(log max(x,y))，**面试讲"异或 + 数 1"最标准**（正好复用 338 学到的数 1 技巧）。

## 三、代码要点（用户 AC 版）

```python
count = 0
while x or y:                # 两个数都归零才停（一个数先归零也可以继续）
    if x % 2 != y % 2:       # ⚡ 最低位不同 → 该位汉明距离 +1
        count += 1
    x = x >> 1               # 右移看下一位
    y = y >> 1
return count
```

**最高位处理**：`while x or y` 会在两个数都归零时结束——高位补的 0 不用比较（都为 0 不会增加计数），所以自然正确处理**位数不同的数**（如 1 和 4）。

## 四、⚡ 易错点

1. **循环条件**：`while x or y`（或 `while x or y` 保证处理完长数的更高位），不要只 `while x`（会漏 y 的剩余位）；
2. **最低位判断**：`x % 2` 与 `x & 1` 等价（都取最低位），本题用 `%` 可以（无优先级坑），但要意识到等价关系；
3. **0 的特例**：任何数与 0 的距离 = 该数二进制 1 的个数（如 0 与 2³¹-1 → 31）。

## 五、复杂度

- 时间：O(log max(x,y))（位数）
- 空间：O(1)
