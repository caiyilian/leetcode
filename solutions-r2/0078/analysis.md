# 78. 子集 · 解析（二刷）

## 一、核心思路：子集 = 搜索树的所有路径节点

**问题**：返回 nums 的所有子集（含空集）。元素不重复。

**本质**：每个元素"选/不选"→ 2^n 种组合。回溯树的**每个节点**代表一个子集：

```
nums=[1,2] 的搜索树（start 不回头）：
            []          ← 空集
          /    \
       [1]      [2]     ← 收集
      /          \
   [1,2]        (结束)
```
所有节点 = [[], [1], [1,2], [2]] = 全子集 ✅

**关键视角**：和其他回溯题不同，子集**不需要"走到叶子才收集"**——**每一步的中间路径都是合法答案**，所以"一进节点就收集"。

## 二、代码（用户 AC 版）

```python
result = [[]]                        # 空集
def fun(path, start):
    if len(path) == length:
        return path
    for i, n in enumerate(nums[start:]):
        path.append(n)
        result.append(path.copy())   # ★ 一进节点就收集
        path = fun(path, start+i+1)  # 不回头
        path.pop()
fun([], 0)
return result
```

- `start+i+1`（相对位置 i + start 再 +1）保证不回头——如果不这样，会出现 [1,2] 和 [2,1] 两个重复子集；
- `result = [[]]` 预先放入空集，配合"进入节点收集"覆盖全量。

## 三、复杂度

- 时间：O(n×2^n)（2^n 个子集 × 复制 O(n)）
- 空间：O(n)（递归栈 + path）

## 四、一刷 vs 二刷

- 一刷（9-16）：WA 1 次 → AC ×2；
- 二刷（10-29）：**一次 AC，"一进节点就收集"视角一次想到**——start 模板已能灵活变形。

## 六、一句话记住

> **子集 = 回溯 start + 一进节点就收集（子集就是所有路径节点，含空集 result=[[]]）；start 不回头去重；选/不选二分是等价的更通用写法。**
