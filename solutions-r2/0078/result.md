## 是否最优解？✅ 是

| 考察点 | 结论 |
|--------|------|
| 时间复杂度 | ✅ O(n×2^n)——2^n 个子集，每个复制 O(n) |
| 空间复杂度 | ✅ O(n)（递归栈 + path）+ 输出 O(n×2^n) |
| 正确性 | ✅ 官方示例 + n=0（[[]]）/n=1 边界，**5 千组随机对拍**（vs 选/不选回溯 + 迭代幂集双参照）0 不一致 |
| 思路 | ✅ 回溯 start 模板 = 官方解法一（DFS） |

## 解法核心：子集 = 搜索树的所有节点

**子集的本质**：`[1,2,3]` 的子集 = 每个元素"选/不选"的 2^n 种组合。回溯树里**每个节点对应一个子集**——所以"每进入一个节点就收集当前 path"天然覆盖所有子集：

```python
result = [[]]                        # 空集先放进去
def fun(path, start):
    for i, n in enumerate(nums[start:]):
        path.append(n)
        result.append(path.copy())   # ★ 一进节点就收集（子集=所有路径）
        path = fun(path, start+i+1)  # start 不回头（去重，防止 [1,2]/[2,1]）
        path.pop()
fun([], 0)
```

- **start 不回头**（39 组合同款）：子集是组合不是排列；
- **一进节点就收集**：这是和"组合总和"唯一的差别——组合要凑够目标才收集，子集是**任何中间路径都是合法答案**。

**等价写法（选/不选二分）**（更通用，扩展到 90/491 好加去重）：
```python
def dfs(i, path):
    if i == len(nums): res.append(path.copy()); return
    path.append(nums[i]); dfs(i+1, path); path.pop()   # 选
    dfs(i+1, path)                                     # 不选
```

## 其他解法（面试可提）

- **迭代（幂集）**：`res = [[]]; for n in nums: res += [s + [n] for s in res]`——每来一个数，给已有子集都加上它（2^n）；
- 位运算：用 0~2^n-1 的二进制位表示选/不选（不推荐手写，面试讲思路即可）。
