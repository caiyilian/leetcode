# 647. 回文子串 · 解析（二刷）

## 一、题目

- 中文：回文子串
- English：Palindromic Substrings
- 难度：中等
- 问题：字符串中回文子串的**个数**（子串 = 连续）

## 二、核心思路：中心扩展计数（同 5 题模板）

**与 5 最长回文子串的关系**：同一套"枚举中心向两侧扩展"，5 取最长区间，**647 每命中一次就 count += 1**——扩展过程中经过的每个回文区间都是一个答案：

```
奇数中心 (i,i)：    a b a ← 扩展 3 次命中 3 个回文（"a"/"aba"/"b"）
偶数中心 (i,i+1)：  a b b a ← 扩展 2 次命中 2 个回文（"bb"/"abba"）
```

```python
result = 0
for i in range(n):                  # 奇数中心
    l = r = i
    while l >= 0 and r < n and s[l] == s[r]:
        result += 1                 # 每命中 = 一个新回文
        l -= 1; r += 1
for i in range(n - 1):              # 偶数中心
    l, r = i, i + 1
    while ...:
        result += 1
return result
```

**为什么能全数不重不漏**：每个回文子串有唯一中心（奇数/偶数二选一），从中心向外扩展恰好经过它一次 → 每个回文被计数恰好一次。

## 三、两种标准解法对比

| | 中心扩展（用户）| DP 表 |
|---|---|---|
| 思路 | 枚举中心向外扩 | dp[i][j]=s[i:j+1] 是否回文 |
| 时间 | O(n²) | O(n²) |
| 空间 | **O(1)** | O(n²) |
| 代码 | 短 | 按区间长度填表 |

同 O(n²) 下中心扩展空间 O(1) 更优——面试首选。

## 四、复杂度

- 时间：O(n²)（2n-1 个中心 × 每次扩展 O(n)）
- 空间：O(1)

## 五、⚡ 易错点

1. **命中即计数**：`while s[l]==s[r]` 每轮循环 = 一个回文，`count += 1` 要写在**扩展前/中**（先数当前区间再扩），不要等扩展完再数；
2. **边界**：`l >= 0 and r < n` 先判再访问，防越界；
3. **全同串特例**：`"aaaa"` 有 n(n+1)/2 = 10 个回文——可用于快速自测（无重复串答案 = n）。
