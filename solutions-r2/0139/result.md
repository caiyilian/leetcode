## 解法核心

**关键洞察**：`dp[i]` 表示 s 前 i 个字符能否被完全拆分。判断时只需要看**最后一段**：是否存在 j，使 `dp[j]` 为真且 `s[j:i]` 是字典中的单词。

**你的实现用"反向排除"**——默认全为 True，只要找不到任何可接的 j 就标 False：

```python
dp = [True] * (length + 1)            # 默认都能拆
for i in range(1, length + 1):
    for j in range(i):
        if dp[j] and s[j:i] in wordDict:
            break                     # 找到一个拆法
    else:                             # for 没被 break → 无拆法
        dp[i] = False                 # 标不可拆
return dp[-1]
```

**for-else 是 Python 特色**：`else` 在循环体未 `break` 时执行，正好表达"遍历完所有 j 都没有接得上的"。这是一个面试能加分的写法。

## 验证方式（对拍用）

标准正向版（`dp[0]=True` + 找到可拆置 True）作参照：
