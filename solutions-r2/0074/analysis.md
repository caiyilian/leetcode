# 74. 搜索二维矩阵 · 解析（二刷）

## 一、核心思路：矩阵整体有序 → 拍平成一维二分

**关键条件**：每行从左到右递增，且每行的第一个整数 > 上一行的最后一个整数。

→ 把矩阵**按行展开**，就是一个严格递增的一维数组：

```
matrix[0][0] < ... < matrix[0][n-1] < matrix[1][0] < ... < matrix[m-1][n-1]
```

**所以**：`searchMatrix = 在一维递增数组上做标准二分`，唯一多一步是**下标换算**：

```python
mid → (mid // n, mid % n)
```

## 二、代码（用户 AC 版）

```python
left, right = 0, m * n - 1
while left <= right:
    mid = (left + right) // 2
    i, j = mid // n, mid % n          # ★ 一维→二维换算
    if matrix[i][j] == target:
        return True
    if matrix[i][j] < target:
        left = mid + 1
    else:
        right = mid - 1
return False
```

就是 35 的左闭右闭模板，只换了"取值方式"（`matrix[mid//n][mid%n]` 代替 `nums[mid]`）。

## 三、vs 240 搜索二维矩阵 II（⚡ 区分记忆）

| | 74 搜索二维矩阵 | 240 搜索二维矩阵 II |
|---|---|---|
| 有序性 | **整矩阵严格递增**（行尾<行头） | 仅每行/每列各自递增 |
| 解法 | 一次二分 O(log(m×n)) 或两次二分 | **右上角阶梯法** O(m+n) |
| 关键 | 能拍平成一维 | 不能拍平（无全局序） |

面试最爱问这个对比——**先判断能不能"拍平"，能则二分，不能则阶梯法**。

## 四、复杂度

- 时间：O(log(m×n))（一次二分）/ 两次二分 O(log m + log n)
- 空间：O(1)

## 五、一刷 vs 二刷

- 一刷（9-17）：二维拍平二分，RF→AC ×2；
- 二刷（10-29）：一次 AC——26（数组有序）拍平思想 + 35 二分模板直接迁移，2 万组对拍零漂移。
