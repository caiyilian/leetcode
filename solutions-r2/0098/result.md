## 解法是否标准？✅ 是，细节到位

用户用的**中序遍历递增法**，是两种标准解法之一（另一是上下界法）。几个细节都踩对了：

1. **`float('-inf')` 哨兵**——首节点必然 > -inf 天然放行；且能处理 val 恰为 int 下限 `-2^31` 的情况（-inf < -2^31 成立）；
2. **`>=` 判重**——BST 要求**严格递增**，相等必须返回 False（写 `>` 会漏判重复值 [1,1]）；
3. **剪枝**——左子树返回 False 立即 return，不继续遍历；
4. **`last = [float('-inf')]` 列表包一层**——闭包里 `last[0] = val` 不会创建新局部变量（直接 `last = val` 会 UnboundLocalError），这是 Python 闭包改外层变量的常用技巧。

## 两种标准解法

| 解法 | 思路 | 特点 |
|------|------|------|
| **中序递增法**（本次） | 遍历中序，检查 `last >= val` 即 False | 代码短，需注意闭包 |
| **上下界法** | 递归传 `(lo, hi)`，每节点 `lo < val < hi`，左子树收 hi、右子树收 lo | 直观，不用闭包 |
