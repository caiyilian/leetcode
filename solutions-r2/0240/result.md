## 核心洞察：右上角 = "分水岭"，一次比较消除一个维度

右上角 `matrix[top][right]` 同时掌握两个方向信息：
- **左方**（同一行）：全部 < 右上角值（行递增）；
- **下方**（同一列）：全部 > 右上角值（列递增）。

```
x > target → 整列都 > target → 排除整列（right--）
x < target → 整行都 < target → 排除整行（top++）
```

**每步必排除一行/一列 → 最多 m+n 步 → O(m+n)**——"一次比较消除一个维度"，和 BST 每次比较排除一半同构。
