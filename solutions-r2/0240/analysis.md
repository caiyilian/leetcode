# 240. 搜索二维矩阵 II · 解析（二刷）

## 一、核心思路：右上角阶梯搜索

矩阵特性：**每行递增、每列递增**（不是全局有序！）——所以不能直接二分。

**关键观察**：右上角 `matrix[top][right]` 是"分水岭"：

```
左方（同一行）全部 < x     （行递增）
下方（同一列）全部 > x     （列递增）
```

```
x > target → target 不可能在右上角这一列（该列最小都是 x）→ 排除整列 right--
x < target → target 不可能在右上角这一行（该行最大都是 x）→ 排除整行 top++
```

```
从右上角出发，像爬楼梯一样走：
  太大 → 左移（排除一列）
  太小 → 下移（排除一行）
  相等 → 找到
最多 m+n 步 → O(m+n)
```

```
矩阵（右上角 15）：
1  4  7  11 15 ← top=0,right=4
2  5  8  12 19
3  6  9  16 22
10 13 14 17 24
18 21 23 26 30
target=5：15>5 → 左移(排除第5列)
          11>5 → 左移    7>5 → 左移    4<5 → 下移
          5==5 → True ✅
```

## 二、为什么不能"直接对行二分"或"对列二分"

行递增但**跨行不保证有序**（第 1 行的末尾 15 可能比第 2 行的开头 2 大）——对每行二分再逐行扫是 O(m log n)，不如 O(m+n)。
右上角法的价值：**一次比较同时用上行和列的序信息**，消除一整行或一整列。

## 三、复杂度

- 时间：O(m+n)（最坏走 m+n 步：先 m 次下移、再 n 次左移或反之）
- 空间：O(1)

**O(m+n) 是这题的最优**（不读全矩阵但至少要排除到边界）。

## 四、变体对比

| 题 | 矩阵性质 | 最优解 |
|----|---------|--------|
| 74 搜索二维矩阵 | 每行有序 **且下一行首 > 上一行尾**（整体拉平有序） | 拉平二分 O(log(mn)) |
| **240 搜索二维矩阵 II** | 每行/每列有序但**跨行不整体有序** | **右上角阶梯 O(m+n)** |

74 可以当一维数组二分；240 不行（跨行有穿插），只能用阶梯搜索。**"整体有序 vs 局部有序"决定能否二分**。
