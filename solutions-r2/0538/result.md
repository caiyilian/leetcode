## 解法说明：反中序累加，代码极简

**核心洞察**：累加树要求每个节点 = **原树中大于等于它的所有值之和**。BST 中序升序 → **反中序（右→根→左）就是降序**——按降序一路累加，`acc` 恰好就是"当前节点 + 所有比它大的值"：

```python
acc = [0]
def fun(root):
    if root:
        fun(root.right)      # 先右（更大值）
        acc[0] += root.val
        root.val = acc[0]    # 当前值 = 累计和
        fun(root.left)       # 再左（更小值）
```

**为什么对**：中序升序 [0,1,2,3,4,5,6,7,8]，反中序遍历顺序 [8,7,6,5,4,3,2,1,0]。走到 7 时 acc 已经 = 8+7=15，正是"≥7 的和"。
