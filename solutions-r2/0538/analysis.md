# 538. 把二叉搜索树转换为累加树 · 解析（二刷）

## 一、核心思路：反中序 = 降序 = 累加器

**累加树定义**：每个节点的值替换为"原树中 ≥ 它的所有值之和"。

**关键性质**：
- BST 中序（左→根→右）= **升序**；
- 反过来**反中序（右→根→左）= 降序**。

按降序一路遍历，用一个累计器 `acc` 把"已经见过的更大值"加起来——**当前节点的新值 = acc（含自己）**：

```
原中序: [0,1,2,3,4,5,6,7,8]
反中序: [8,7,6,5,4,3,2,1,0]
        acc: 8,15,21,26,30,33,35,36,36   ← 恰为"≥当前值的和"
```

## 二、代码（用户 AC 版，4 行核心）

```python
acc = [0]
def fun(root):
    if root:
        fun(root.right)      # 先右（更大值）
        acc[0] += root.val
        root.val = acc[0]    # 当前值 = 累计和（含自己）
        fun(root.left)       # 再左（更小值）
fun(root)
return root
```

两个细节：
- `acc = [0]` 列表包一层：闭包里改外层变量（同 94/230 的 last/result 套路）；
- **原地改值**：直接 `root.val = acc[0]`，无需新树（题目要求）。

## 三、为什么反中序可行（本质）

中序是升序 → "大于等于某节点的所有节点" = 排在它**后面**的所有中序节点。从后往前（反中序）累积后缀和，就是每个节点的答案。**同一棵树上，遍历顺序决定了答案的统计方向**——这是"遍历变形"类题的心法。

## 四、复杂度

- 时间：O(n)
- 空间：O(h)（递归栈）

## 五、一刷 vs 二刷

- 一刷（9-25）：反中序累加 AC ×2；
- 二刷（10-25）：一次 AC，核心 4 行——**"反中序=降序累加"完全内化**。
