# 49. 字母异位词分组 · 二刷解析

## 题目回顾

给一组字符串，把字母异位词（相同字母、不同排列）分到同一组。

## 核心思路：找到"异位词的本质特征"当 key

**一句话**：字母异位词的共同点是**各字母出现次数完全相同** → 用"26 个字母的计数数组"作为分组 key。

```
["eat","tea","tan","ate","nat","bat"]

eat → a:1 e:1 t:1 → (1,1,0,...,1)  ┐
tea → a:1 e:1 t:1 → (1,1,0,...,1)  ├→ 同一组
ate → a:1 e:1 t:1 → (1,1,0,...,1)  ┘
tan → a:1 n:1 t:1 → (1,0,...,1,1)  → 另一组
bat → a:1 b:1 t:1 → (1,1,0,...,1,0) → 又一组
```

## 两种 key 方案对比（二刷重点）

| | 排序法 | **计数法（你的）** |
|--|--------|------------------|
| key 生成 | `''.join(sorted(word))` | `tuple([0]*26 计数)` |
| 每词耗时 | O(k log k)（排序） | **O(k)**（扫一遍计数） |
| 本质 | 把字母"排序成规范形" | 直接统计"出现次数" |

**为什么计数法更好**：异位词不关心字母顺序，只关心出现次数——排序法先把字母排好序再比较，多做了"排序"这件事；计数法直接刻画本质特征（频次向量），少一步排序。**思路：找特征，而不是做变换。**

## 实现细节（二刷回顾）

1. **`tuple(cnt)` 当 key**：dict 的 key 必须可哈希，`list` 不可哈希会报 `TypeError: unhashable type: 'list'`——转成 `tuple` 就解决了。这是计数法最容易踩的坑，你一次写对。
2. **`defaultdict(list)`**：不需要 `if key not in d: d[key]=[]` 判空，直接 `d[key].append(word)`。一刷时你也用过普通 dict + `setdefault`，二刷直接用 defaultdict，更省。
3. **`ord(c)-97`**：'a' 的 ASCII 是 97，这样把字母映射到 0~25 的下标。也可以用 `ord(c) - ord('a')`，可读性更好。
