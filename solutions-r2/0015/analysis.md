# 15. 三数之和 · 二刷解析

## 题目回顾

数组 `nums`，找出所有和为 0 的三元组，**要求去重**（不能含重复三元组，如 `[-1,0,1]` 只能出现一次）。

## 核心思路：排序 + 固定 i + 双指针夹逼

**一句话**：排序后，固定第一个数 `nums[i]`，剩下两个数用双指针在 `i` 右侧夹逼找 `-nums[i]`；找到记录，并跳过所有重复值。

```
nums = [-1,0,1,2,-1,-4] 排序 → [-4,-1,-1,0,1,2]

i=0 (-4)  → target=4，l=1(r=-1) r=5(2)：-1+2=1<4 → l++；... -1+2=1... 0+2=2<4 → l++；1+2=3<4 → l++ → l>r 结束
i=1 (-1)  → target=1，l=2(-1) r=5(2)：-1+2=1 ✓ 记录 [-1,-1,2]；l=3(0) r=4(1)：0+1=1 ✓ 记录 [-1,0,1]
i=2 (-1)  → target=1 与上次重复 → 跳过（去重 i）
i=3 (0)   → target=0，l=4(1) r=5(2)：1+2=3>0 → r-- → 结束
i=4 (1)   → target=-1，l=5(2) 无配对 → 结束
结果：[[-1,-1,2],[-1,0,1]] ✓
```

## 为什么排序是关键

1. **双指针夹逼需要有序**：`l` 右移和变大、`r` 左移和变小，才能根据"当前和 vs target"决定动哪边（O(n) 找两数和，替代哈希表 O(n) 且省空间）；
2. **重复元素相邻**：排序后相同值挤在一起，去重只需 `while nums[left] == left_val: left++` 这种相邻跳跃。

## 去重三处（本题最大坑，一刷栽过）

| 位置 | 原因 | 做法 |
|------|------|------|
| **去重 i** | `nums[i]` 相同 → 双指针结果相同 | `if target == last: continue`（或标准 `nums[i]==nums[i-1]`） |
| **去重 l** | 同一 i 下 l 指向相同值 → 三元组重复 | 找到记录后 `while nums[left]==left_val: left++` |
| **去重 r** | 同上 | `while nums[right]==right_val: right--` |

**一刷你悟出的「去重本质 = Δj+Δk=0」**：找到一组后 l 和 r 同时收缩，跳过的值方向相反、抵消——保证不重不漏。这次你已经自然写对了。

## 复杂度为什么是最优

- 结果集本身可能达到 **O(n²) 个三元组**（如 `[-1]×n` 类输入产生大量组合）→ 输出下界 O(n²)；
- 任何算法至少要输出所有答案 → **O(n²) 是理论下界**，你的算法达到下界 → 最优。
