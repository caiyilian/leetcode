# 438. 找到字符串中所有字母异位词 · 二刷解析

## 题目回顾

字符串 `s` 和 `p`，找出 `s` 中所有 `p` 的**字母异位词**子串的起始下标。

## 核心思路：定长滑动窗口 + 计数数组

**一句话**：异位词长度必然等于 len(p) → 用长度固定的窗口在 s 上滑动；**字母异位词 = 计数相同**，用"26 位计数数组"判断窗口是否命中。

```
s = "cbaebabacd", p = "abc"（计数 {a:1,b:1,c:1}）

窗口 [0,2]="cba" → 计数 {c:1,b:1,a:1} = p 计数 ✓ → 记录 0
窗口 [1,3]="bae" → 计数 {b:1,a:1,e:1} ≠       ✗
...
窗口 [6,8]="bac" → 计数 {b:1,a:1,c:1} = p 计数 ✓ → 记录 6
答案 [0,6] ✓
```

## 关键技巧：增量更新（不是每步重新数）

**朴素做法**：每滑一步，重建窗口的 Counter → O(len_p) / 步 → 总 O(n·len_p) ❌ 慢。

**增量做法（你的）**：窗口每滑一步，只改两个位置——
```
右边界进一个字符：now[新字符] += 1     # 进
左边界出一个字符：now[旧字符] -= 1     # 出
```
更新是 O(1)，比较是 O(26)（常数）→ 总 **O(n)** ✓ 快一个量级。

```
窗口 "cba" → "bae"：出 'c'(-1)、进 'e'(+1)，只改 2 个计数
```

这就是"**滑动窗口 + 增量统计**"的通用模板——3 无重复子串、76 最小覆盖子串都是这个骨架的变体（一个定长一个变长）。

## 边界细节（二刷重点：RE 的根因）

1. **s 比 p 短**：`if len_s < len_p: return []`——否则初始化窗口那行 `now[ord(s[i])-97] += 1` 会越界（`p` 比 `s` 长时 `s[i]` 不存在）。**这是"循环长度 vs 访问数组"的经典边界**；
2. **第一个窗口单独判断**：窗口初始化后（滑动循环开始前）就要比较一次（`[0, len_p-1]`），不然漏掉第 0 个窗口；
3. 记录的是**窗口起点** `i - len_p + 1`（不是窗口终点）。

## 复杂度

- **O(len_s + len_p)**：init 填 p 和首窗口 O(len_p)，滑动 O(len_s)，每步比较 O(26) 常数；
- **O(1)**：两个 26 长度数组（不随输入增长）。

**已是最优**（必须看每个字符至少一次）。
