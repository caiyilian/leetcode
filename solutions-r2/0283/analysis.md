# 283. 移动零 · 二刷解析

## 题目回顾

原地把数组中的 0 移到末尾，同时保持非 0 元素的**相对顺序**。要求**原地修改（不能返回新数组）**。

## 核心思路：快慢指针（双指针）

**一句话**：慢指针 `j` 指向"下一个非 0 该放的位置"，快指针 `i` 扫描整个数组——遇到非 0 就把它换到 `j` 处，`j` 前进。

```python
j = 0
for i in range(len(nums)):
    if nums[i] != 0:
        nums[i], nums[j] = nums[j], nums[i]
        j += 1
```

手推：`[0,1,0,3,12]`
```
i=0 j=0: 0 → 不动
i=1 j=0: 1 → 与 nums[0] 交换 → [1,0,0,3,12], j=1
i=2 j=1: 0 → 不动
i=3 j=1: 3 → 交换 → [1,3,0,0,12], j=2
i=4 j=2: 12 → 交换 → [1,3,12,0,0] ✅
```

## 关键洞察：`i == j` 时自交换就是"无操作"

- 如果前面**没有 0**（数组本来有序），`i` 和 `j` 始终相等，每次都是 `nums[i], nums[i] = nums[i], nums[i]`——交换了个寂寞，但**无害**，代码因此不用特判"前面有没有 0"；
- 一旦遇到 0，`j` 会停在 0 的位置，之后的非 0 都换到 `j`——**0 自动被换到后面去**。

这就是快慢指针版的优雅之处：**一个指针维护"目标位置"，一个指针维护"扫描位置"，`i==j` 自交换兜底，无需任何分支约束**。

## 用户二刷原版 vs 改进版

用户原版手动做了三件事：p2 找非 0、p1 停在 0 上、交换后都前进——语义完全正确，但需要 `p1 < p2` 约束 + `if p1 != p2` 判断，比快慢指针版绕。

**本质相同，表达不同**：原版"显式找 0 的位置"，快慢版"隐式让 j 落在 0 上"。面试时快慢版更快写完、更少出错。

## 两种变体知识（面试加分）

| 变体 | 做法 | 适用 |
|------|------|------|
| 交换法（本题） | 非 0 与 `j` 交换 | 要求**保持相对顺序** |
| 覆盖法 | 非 0 依次前移，最后补 0 | 不要求顺序（如快排分区） |

快排的 partition 就是覆盖法思想的变体——**移动零 = 快排 partition 的简化版**，这个关联面试时可以说。
