## 解法要点

**双指针交换（用户原版）**：p1 指向第一个 0，p2 向右扫找非 0、找到就与 p1 交换。O(n)/O(1)，保持非 0 相对顺序。

**改进版（快慢指针，归档推荐）**：`j` 永远指向"下一个非 0 该放的位置"，i 遇到非 0 换到 j、j 前进；`i==j` 时自交换天然兜底（省掉 p1<p2 约束和 if p1!=p2 判断）。语义等价，代码从约 20 行降到 4 行。

## 验证

- **对拍**：2 万组合 0 随机数组，校验"0 全在尾部 + 非 0 保持相对顺序"，**0 非法** ✅
- 与标准快慢指针版 **1 万组结果完全一致** ✅
- 样例 `[0,1,0,3,12]→[1,3,12,0,0]`、`[0,0,1]→[1,0,0]`、`[1,2,3]→[1,2,3]`、`[]→[]` 全对

## 是否最优解

**是，复杂度已达最优**：O(n) 时间 + O(1) 空间（原地），且满足题目"保持非 0 相对顺序"要求。改进空间在**代码简洁性**（快慢指针版更易读、面试更讨喜），不在复杂度。
