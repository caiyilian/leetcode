# 96. 不同的二叉搜索树 · 解析（二刷）

## 一、核心思路：枚举根节点，左右子树独立计数（DP 卡特兰数）

**问题**：n 个节点（值 1..n）能构成多少种不同的 BST。

**关键洞察**：BST 的根节点把问题一分为二——任取根 k，左子树只能用 {1..k-1}（k-1 个），右子树只能用 {k+1..n}（n-k 个），**左右子树完全独立**。所以：

```
dp[i] = Σ_{j=0}^{i-1} dp[j] * dp[i-1-j]
```

- `j` = 左子树节点数（0..i-1 枚举）
- `i-1-j` = 右子树节点数（总 i 个，去掉根占 1 个）
- 根为"第 j+1 大"的值时，左 j 个右 i-1-j 个，方案数相乘；所有根位置求和

## 二、代码（用户 AC 版）

```python
dp = [0] * (n + 1)
dp[0] = 1          # 空树 1 种
dp[1] = 1          # 单节点 1 种
for i in range(2, n + 1):
    for j in range(i):
        dp[i] += dp[j] * dp[i - 1 - j]   # 左 j 个 × 右 i-1-j 个
return dp[n]
```

## 三、⚡ 一个关键认知：这就是卡特兰数

**Catalan C(n) = Σ C(j)·C(n-1-j)**，闭式 `C(2n,n)/(n+1)`。序列：

```
n:   1   2   3   4    5     6     7      8
C:   1   2   5   14   42   132   429   1430
```

**识别卡特兰数的场景**（看到就 3 秒反应）：
- 不同 BST 数量（本题）
- 括号匹配数量（n 对括号 22 题）
- 出栈序列数量、凸多边形三角剖分、不交叉连线段

**卡特兰数是"子树分治 + 求和"的闭式表达**——会写 DP 递推就够，闭式锦上添花（面试若被问"能不能 O(n)"再亮）。

## 四、复杂度

- 时间：O(n²)（双层循环）
- 空间：O(n)

## 五、一刷 vs 二刷

- 一刷（9-21）：AC ×2；
- 二刷（11-01）：一次 AC——"枚举根 + 子树相乘求和"的模型已内化，注释手推小案例防下标错。
