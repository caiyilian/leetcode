## 解法核心

**关键洞察**：把问题分解成"枚举根节点 + 左右子树独立计数"。

对节点 1..n，任取根节点 k：
- 左子树 = 节点 {1..k-1}（共 k-1 个，记为 j）
- 右子树 = 节点 {k+1..n}（共 n-k 个）
- **左右子树互不影响**（BST 性质：左小右大）→ 根为 k 的方案数 = 左子树方案数 × 右子树方案数

```
dp[i] = Σ_{j=0}^{i-1} dp[j] * dp[i-1-j]
       ↑ 左子树 j 个节点       ↑ 右子树 i-1-j 个节点（i 个节点去掉根占 1 个）
dp[0] = dp[1] = 1（空树/单节点都算 1 种）
```

**这就是卡特兰数**：C(0)=1, C(1)=1, C(2)=2, C(3)=5, C(4)=14... 前 8 项 1,2,5,14,42,132,429,1430 全部命中。

```python
dp = [0] * (n + 1)
dp[0] = dp[1] = 1
for i in range(2, n + 1):
    for j in range(i):
        dp[i] += dp[j] * dp[i - 1 - j]
return dp[n]
```

## 验证方式（对拍用）

**双重参照**交叉验证：
1. **卡特兰数闭式**：`C(n) = C(2n, n) // (n+1)`（组合数公式，独立来源）
2. **递归分治 + 记忆化**：`total = Σ ref(j) * ref(n-1-j)`，自顶向下，正确性直观

- 官方示例：n=3 → 5 ✅；n=1 → 1 ✅
- 全量 n=1..19 三者完全一致（bad=0）
- 前 8 项 = 标准卡特兰序列 ✅
