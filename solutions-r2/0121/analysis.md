# 121. 买卖股票的最佳时机 · 解析（二刷）

## 一、核心思路：一次遍历维护"历史最低买入价"

**问题**：只能买卖一次（先买后卖），求最大利润。

**关键洞察**：对任意卖出日 i，最优策略是**在 i 之前的最低价那天买入**。所以：

- 维护 `min_val` = 到目前为止遇到的最低价；
- 走到 i 时，`prices[i] - min_val` 就是"以 i 为卖出日"能拿到的最大利润；
- 全程取 max 即为答案。

```
[7,1,5,3,6,4]
min=7 ↓ 1 → min=1  结果0
     ↓ 5 → 4        结果4
     ↓ 3 → 2        结果4
     ↓ 6 → 5        结果5 ✓
     ↓ 4 → 3        结果5
```

**贪心在哪**：买入点永远取"更低的"（后出现更低就直接换更优买入点），卖出只看差值——两者独立迭代，正确性由"卖出日最优买入点是历史最低"保证。

## 二、代码（用户 AC 版）

```python
min_val = prices[0]
result = 0
for i in range(1, len(prices)):
    if prices[i] < min_val:
        min_val = prices[i]                     # 更优买入点
    else:
        result = max(prices[i] - min_val, result)
return result
```

**⚡ 细节**：
- 更新最低价用 `if prices[i] < min_val` 分支而非 `min()`——顺手避免在同一轮既更新 min 又算利润的混乱（逻辑等价）；
- 全跌时 result 保持 0（不亏），与题意一致（可以不做交易）。

## 三、股票系列家族（⚡ 状态机一统）

| 题 | 限定 | 解法 |
|----|------|------|
| **121 本体** | 买卖 1 次 | 一次遍历维护最低价（或 DP 一维状态机）|

**121 → 122 → 123 是必刷主线**：121 一维、122 贪心、123 状态机开始展露——只要把 121 的"单一 min"升级成"状态数组"，系列全通。

## 四、复杂度

- 时间：O(n)
- 空间：O(1)

## 五、一刷 vs 二刷

- 一刷（9-18）：暴力 TLE → 一次遍历 AC ×2；
- 二刷（10-31）：一次 AC——"买入点是历史最低"的模型已经内化，5 万组对拍零漂移。
