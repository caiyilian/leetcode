## 解法核心：卖出当天的利润 = 当天价 - 历史最低买入价

**关键洞察**：只买卖一次，**卖出点确定后，最优买入点就是卖出日之前的最低价**。所以遍历时维护两个量：

```python
min_val = prices[0]    # 历史最低买入价（贪心：越低的买入点越优）
result = 0             # 历史最大利润
for i in range(1, len(prices)):
    if prices[i] < min_val:
        min_val = prices[i]                  # 发现更优买入点
    else:
        result = max(prices[i] - min_val, result)   # 今天卖出能赚多少
return result
```

- **为什么对**：任意卖出日 i 的最优收益只取决于 `prices[i] - 在此之前的最小值`——min_val 一路贪心地取最低，result 一路取最大，互不干扰；
- **全跌返回 0**：一直更新 min_val，result 保持 0（不亏不赚，买入卖出同日不产生收益）。

## 与 DP 状态机的联系（⚡ 股票题家族的核心）

121 是股票系列**最简形态**，可用一维 DP 状态机统一理解：
```
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])   # 不持有（要么继续空仓，要么今天卖出）
dp[i][1] = max(dp[i-1][1], -prices[i])               # 持有（要么继续持有，要么今天买入）
答案 = dp[n-1][0]
```
一次买卖 → 持有态的转移只用 `-prices[i]`（只有一次买入机会）。**121 的"维护最低价"正是这个状态机的压缩版**。
