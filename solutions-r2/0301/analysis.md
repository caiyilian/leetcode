# 301. 删除无效的括号 · 解析（二刷·困难题）

## 一、核心思路：BFS 分层逼近"最少删除"

**问题**：删最少的括号，使字符串合法（括号匹配 + 可含字母），返回所有可能的合法串。

**为什么 BFS**：要"最少删除"，就按删除次数**逐层扩大搜索**——BFS 天然保证**第一个出现合法串的层 = 最少删除层**，不用自己算删除上限，也不用回溯（DFS 需要先求最少删除数才能剪枝）。

```
层 0： s            （删 0 个）
层 1： 删 1 个括号的所有结果
层 2： 删 2 个括号的所有结果
...
首层出现合法 → 收集该层所有合法 → 返回
```

**例子** `"(a)())()"`：
```
删 1 个：得到 "(a())()" 与 "(a)()()" —— 都合法 → 就是答案（2 个）
```

## 二、代码（用户 AC 版）

```python
def isPair(s):                         # 合法性（20 题的计数器法）
    left = right = 0
    for c in s:
        if c == "(": left += 1
        elif c == ")":
            right += 1
            if right > left: return False    # 中途右不超左
    return left == right                     # 结尾平衡

def removeInvalidParentheses(self, s):
    result = []
    hash_set = {s}
    while hash_set and not result:
        next_set = set()
        for cur in hash_set:
            if isPair(cur):
                result.append(cur)           # ★ 本层合法 → 收集
            else:
                for i in range(len(cur)):
                    if cur[i] not in "()": continue     # 只删括号
                    if cur[:i] + cur[i+1:]:
                        next_set.add(cur[:i] + cur[i+1:])  # ★ set 去重
        hash_set = next_set
    return result if result else [""]
```

## 三、三个细节（⚡ 必背）

1. **set 去重是灵魂**：删字符串的不同位置可能得到同一个串（如 `)(` 删左或删右都得 `)`），不去重 → 指数爆炸 + 重复结果；
2. **只删括号**：字母删不删都不影响合法性（删了反而缩短，不会更优），所以跳过；
3. **空串守卫**：`s=""` 是合法输入，答案 `[""]`（不是 `[]`——v1 的隐患，v2 已修）。

## 四、语义说明

- `while hash_set and (not result)`：**找到合法层才停**；若某一层全非法则继续下一层；
- `return result if result else [""]`：兜底（如 `")("` 删到空串才合法 → 返回 `[""]`）。

## 五、复杂度

- 时间：O(2^n)（n = 字符串长度，每层组合数指数级，n 通常 ≤ 25 可过）
- 空间：O(2^n)（每层集合）

## 六、一刷 vs 二刷

- 一刷（9-26）：BFS，RE/WA → AC ×3；
- 二刷（10-30）：BFS 分层一次写对，2 万组对拍零漂移；边界的空串问题是**本人自查修复**（②）。**困难题也用昨天的 BFS 思路直接打通。**

> **删除无效括号 = BFS 分层：每层删 1 个括号（set 去重、只删括号），首层合法即最少删除，收集返回；合法性用计数器（20 题）；空串答案 [""]。**
