## 是否最优解？✅ 是（标准 BFS 分层解）

| 考察点 | 结论 |
|--------|------|
| 时间复杂度 | ✅ O(2^n)——每层删 n 个位置，最坏指数（n 小，可过） |
| 空间复杂度 | ✅ O(2^n)——同层去重集合 |
| 正确性 | ✅ 官方三示例 + 2 万组随机对拍（vs 标准 BFS 参照，含字母混合/纯右括号/空串）0 不一致 |
| 思路 | ✅ BFS 分层 = 官方解法（逐层删，首个合法层即最少删除） |

## 解法核心：BFS 按"删除次数"分层

**关键**：要"删最少"，就把删 0 个、删 1 个、删 2 个……的字符串**逐层生成**，第一个出现合法串的层就是最优层：

```
第0层: s = "(a)())("          ← 先判合法性，非法才继续
第1层: 删1个括号的所有结果（set 去重）
第2层: 删2个… 
   ↓ 首个合法层（这里第1层就有答案）
返回该层所有合法串
```

```python
hash_set = {s}                          # 当前层
while hash_set and not result:
    next_set = set()
    for cur in hash_set:
        if isPair(cur):
            result.append(cur)          # 合法 → 收集（本层即最少删除层）
        else:
            for i, ch in enumerate(cur):
                if ch not in "()": continue        # 只删括号
                next_set.add(cur[:i] + cur[i+1:])  # ★ set 去重
    hash_set = next_set
return result if result else [""]
```

## 两个必做细节

1. **每层 set 去重**：删 `(())` 的位置 1 或 2 都得到 `()`——不去重会指数爆炸 + 重复结果；
2. **只删括号**：字母不参与删除（也不影响合法性）。

## 可优化方向（面试提一句即可）

- **DFS + 预计算最少删除数**：先扫一遍数出多余左/右括号数（删除量），再 DFS 恰好删这些——比 BFS 快，但实现更绕；BFS 是"先讲通"的版本；
