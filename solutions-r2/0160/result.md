## WA→AC 教训（必须记住）：链表题"判断 vs 移动"的顺序

```python
# WA：先移动再判断 → 若交点恰好在头部/换边后第一个节点，直接跳过
pA = pA.next; pB = pB.next
if pA is pB: return pA

# AC：先判断再移动 → 覆盖头部相交
if pA is pB: return pA
pA = pA.next; pB = pB.next
```

**2 万组 WA 错 4430 组（≈22%）实证**——链表循环里"检查当前节点"和"前进到下一节点"的顺序就是生死线。

## 隐藏 bug 提醒（力扣数据没测到，但对拍暴露）

**一个链表为空时**（如 headA=None, headB=[1,5]）：用户的 AC 版会误返回 B 的头——

```
pA=None → pA=headB，此时 pB 还是 headB → pA is pB → 误判相交 ❌
```

**标准写法免疫**：先 `if not headA or not headB: return None`，或 `while pA is not pB` + 条件换边（空链表时两指针最终同时 None，循环退出返回 None）。
