# 406. 根据身高重建队列 · 解析（二刷）

## 一、核心思路：排序让"插入"不影响已放好的元素

**问题**：每个人 (h, k) 表示身高 h、前面恰好有 k 个身高 ≥ h 的人。给定打乱列表，重建队列。

**核心难点**：插入一个元素会改变别人看到的"前面"。要想简单，必须**找到一个顺序让插入操作不影响已放好的元素**——用"先高后矮"：
- 高个子先放好，矮个子插入时，**已放的高个子不会统计矮个子**（"≥h"里矮的不算）→ 高个的 k 不受影响；
- 所以从高到矮逐个 insert(k)，每个都"自己的 k 自己说了算"。

## 二、代码（用户 AC 版）

```python
people.sort(key=lambda x: (-x[0], x[1]))   # 主键身高降序，次键 k 升序
result = []
for p in people:
    result.insert(p[1], p)                 # 插到下标 k 处
return result
```

## 三、⚡ 两个细节

1. **排序 key 写法**：`-x[0]` 表示身高降序，`x[1]` 同身高 k 升序——负号是最简洁的降序写法；
2. **为什么同身高 k 也升序**：同等身高互相"≥"，后插的会排到前面；k 升序保证先插 k 小的，后面 k 大的插到其后 → 相对顺序正确（如 `[[5,0],[5,1]]` → 先插 [5,0] 再插 [5,1]）。

## 四、复杂度

- 时间：O(n²)——sort O(n log n) + n 次 insert O(n)（list 插入移位）
- 空间：O(n)

**注**：n ≤ 2000（适用本函数），O(n²) 足够；若 n 大可用平衡树/树状数组优化到 O(n log n)，面试提一句即可。

## 五、一刷 vs 二刷

- 一刷（9-25）：AC ×2；
- 二刷（10-31）：一次 AC——套路已记牢："先高后矮 + k 升序插入"。

## 七、一句话记住

> **406 = 先高后矮排序（-h, k）+ 依次 insert(k)——高个先放，矮个插入不扰已定 k；⚡ 同身高 k 升序是防错细节。**
