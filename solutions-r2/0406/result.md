## 解法核心：先排"大个子"，矮个插队不影响大局

**关键洞察**：**k 只数"身高 ≥ 自己"的人**。如果把较高的先放好，再插入矮的——矮的插在哪里都不会改变"已放好的高个子"前面的计数（因为他们只看更高的，而矮的不是更高）。

所以策略：
1. **按身高从高到低排**，同身高按 k 从小到大排：`key = (-h, k)`；
2. **依次把每个人 insert 到下标 k 的位置**——因为此时"已插入的都是比我高/等于我的"，我把前面空出 k 个位置，恰好有 k 个更高/等高的在我前面。

```python
people.sort(key=lambda x: (-x[0], x[1]))   # 身高降序 + k 升序
result = []
for p in people:
    result.insert(p[1], p)
return result
```

**为什么等身高 k 也要升序**：同身高互看也是"≥"，后插入的同等身高若 k 更小却先插，会破坏先插者的相对位置。**k 升序保证同身高内部按 k 正确插入**（如 `[[5,0],[5,1]]` → 先插 `[5,0]` 再插 `[5,1]`）。

## 验证方式（对拍用）

重建结果是否合法 = 对每个位置 i 检查 `前面身高 ≥ 自己` 的人数 == 自己的 k：
```python
def is_valid(queue):
    for i, (h, k) in enumerate(queue):
        if sum(1 for j in range(i) if queue[j][0] >= h) != k:
            return False
    return True
```
