## WA→AC 核心（必须记住）：为什么必须 min(三邻)

```python
# WA：if matrix[i-1][j]=='1' and matrix[i][j-1]=='1': dp = 1 + dp[i-1][j-1]
# AC：dp = 1 + min(dp[i-1][j-1], dp[i][j-1], dp[i-1][j])
```

**反例**（构造复现）：

```
[1,1,0]
[1,1,1]
[1,1,1]
以 (2,2) 为右下角：左/上格子都是 1 → WA 算 dp=1+2=3 → 面积 9 ❌
正确：3×3 需要上、左、左上三方向都能提供边长 2，但 (1,1) 的 dp=2（只有 2×2），
      min(2,2,2)+1=3 但实际 (1,2) 上方是 0 卡住 → 正确面积 4 ✅
```

**根因**：dp[i][j] 要扩成边长 k，**上、左、左上三个方向都必须能提供 k-1 的边长**（短板效应）——只查"相邻格子是 1"不够，要看三个方向的 dp 值取 min。

## 与 85 最大矩形的对比（矩阵最大题族）

| | 85 最大矩形 | 221 最大正方形 |
|--|------------|---------------|
| 形状 | 可长可宽 | **必须等边** |
| 解法 | 逐行柱状图 + 单调栈 | **dp = 1 + min(三邻)** |
| 复杂度 | O(m×n) | O(m×n) |

正方形因为"等边"约束，天然适配 DP（三邻短板）；矩形因为"任意宽高"，用单调栈更自然——两题反映"约束决定解法"。
