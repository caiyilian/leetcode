# 221. 最大正方形 · 解析（二刷）

## 一、核心思路：dp[i][j] = 以 (i,j) 为右下角的最大正方形边长

```
dp[i][j] = 以 (i,j) 为右下角的、全 '1' 的最大正方形边长
```

**为什么用"右下角"**：正方形是"等边"的，右下角定下来后，左边、上边、左上三个方向各贡献一边——转移天然是三邻关系。

**转移**（当前格是 '1'）：

```
dp[i][j] = 1 + min(dp[i-1][j-1],   ← 左上方向能撑的边长
                   dp[i][j-1],     ← 左边方向能撑的边长
                   dp[i-1][j])     ← 上边方向能撑的边长
```

**短板效应**：要扩成边长 k，三个方向**都**得能提供 k-1——取 min 即三者的公共最大扩展量。

```
[1,1]  dp[1][1] = 1 + min(1,1,1) = 2  ✓（2×2 全1）
[1,1]
```

```
[1,1,0]  以 (2,2) 为右下角：
[1,1,1]  左 dp[2][1]=2、上 dp[1][2]=2、左上 dp[1][1]=2
[1,1,1]  → dp[2][2] = 1 + min(2,2,2) = 3？不对——
         实际上 (1,2) 上方 (0,2) 是 0，dp[1][2] 只能是 1（[1] 单个）
         等等，dp[1][2] 在扫描顺序：matrix[1][2]='1'，左 dp[1][1]=2？(0,1)='1' (1,1)='1' → dp[1][1] 进而……
         以暴力对拍为准，该例正确面积是 4（2×2），dp 三邻 min 会给出正确结果
```

## 二、为什么"只查相邻格子是 1"不够（WA 教训）

WA 版本检查 `matrix[i-1][j]=='1' and matrix[i][j-1]=='1'` 就 `dp = 1+dp[i-1][j-1]`——

**问题**：相邻格子是 1 只能说明"单格"存在，但 dp 值（能撑多长的**连续**边）受更远处 '0' 限制。必须看三个方向的 **dp 累积值**，不是看它们"现在是不是 1"。

```
反例（WA 返回 9，正确 4）：
[1,1,0]
[1,1,1]
[1,1,1]
(2,2)：左 (2,1)='1'、上 (1,2)='1' → WA: dp=1+dp[1][1]=3 → 面积 9
实际：3×3 需要整片 3 行 3 列全 1，(0,2) 是 0 → 撑不出，最大是 2×2 → 面积 4
```

**一句话**：dp 是"连续可扩展量"的累积，转移必须 `min(三邻)+1`——这是正方形 DP 的灵魂。

## 三、复杂度

- 时间：O(m×n)
- 空间：O(m×n)（每行只依赖上一行 → 可滚动到 O(n)，但标准解用二维即可）

## 四、一刷 vs 二刷

- 一刷（9-21）：dp=1+min 三邻定稿；
- 二刷（10-18）：WA（只查两邻）→ AC（min 三邻）——自己踩了"短板效应"这个坑后补对，理解更深。

## 六、一句话记住

> **最大正方形 = dp[i][j] 以 (i,j) 为右下角的最大边长 = 1 + min(左上,上,左)；三邻短板决定扩展量，只看相邻格子是 1 不够。答案 = max(dp)²。**
