# 46. 全排列 · 解析（二刷）

## 一、核心思路：回溯 + used 标记

**问题**：给 n 个**不重复**的数，返回所有排列。排列 = 顺序不同算不同。

**关键**：每个位置可以放**任意一个没用过的数**——所以每次都要**从头扫全部数**，用 **used 标记**跳过已用的：

```
nums=[1,2,3]  （长度 3）
第1位：1/2/3 任选
第2位：从剩下 2 个数中选
第3位：最后一个
→ 3×2×1 = 6 个排列
```

```
        ""
      /  |  \
     1   2   3          ← 第1位
    / \  ...
  2    3                ← 第2位（回头选未用）
 / \  / \
3   2 1   1 ...         ← 第3位
```

## 二、代码（用户 AC 版）

```python
def fun(path, exist):
    if len(path) == length:
        result.append(path.copy())     # ★ copy
        return path
    for n in nums:                     # ⚡ 每次都从全部数里选（回头）
        if n in exist:
            continue                   # 已用过 → 跳过
        exist.add(n)                   # 选
        path.append(n)
        path = fun(path, exist)        # 递归
        path.pop()                     # 撤销
        exist.remove(n)                # 撤销标记（成对出现！）
    return path
```

**exist 必须成对 add/remove**（和 path.append/pop 同步）——漏了 remove 会让某些数永远"被用"。

## 三、⚡ 组合 vs 排列（回溯两大模板）

| | 组合（39/40/77/216） | 排列（46/47） |
|---|---|---|
| 顺序是否区分 | 不区分 | 区分 |
| 去重机制 | **start** 索引不回头 | **used** 标记回头 |
| 每次选的范围 | `candidates[start:]` | 全部未用 nums |
| 核心代码 | 递归传 start/`i+1` | 用 set/数组标记已用 |

**记法**：组合是"从我往后挑"（start），排列是"没用过的都要试"（used）。

## 四、复杂度

- 时间：O(n×n!)——排列总数 n!，每个结果构造/复制 O(n)
- 空间：O(n)——递归栈 + path + used

## 五、一刷 vs 二刷

- 一刷（9-16）：回溯 AC ×2；
- 二刷（10-29）：一次 AC——**39 的"start 不回头"和 46 的"used 标记"分野实战验证成功**，回溯两大模板都掌握了。

## 七、一句话记住

> **全排列 = 回溯 + used 标记：每层从头扫全部数，没用过的都试（add/remove 成对）；⚡ 组合用 start 不回头、排列用 used 回头，两大模板之二。**
