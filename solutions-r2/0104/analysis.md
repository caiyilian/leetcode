# 104. 二叉树的最大深度 · 解析（二刷）

## 一、核心思路：最大深度 = 层数（BFS 视角）

深度 = 从根到最远叶子经过的节点数 = **树有几层**。BFS 一层层走，数层数就是深度：

```
    3         第0层
   / \
  9   20      第1层
     /  \
    15   7    第2层   → 深度 = 3 层
```

## 二、BFS 层数计数（用户 AC 版，复用 102 套路）

```python
if not root:
    return 0
q = deque([root])
result = 0
while q:
    for _ in range(len(q)):     # 按层快照：当前队列里的就是这一层
        node = q.popleft()
        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)
    result += 1                 # ★ 一层处理完，深度 +1
return result
```

**和 102 层序遍历唯一区别**：102 把每层节点存进 `now` 列表，这里不需要收集、只数层数 `result += 1`——代码结构完全同源。

## 三、递归版（经典解法，一刷定稿）

```python
def maxDepth(self, root):
    if not root:
        return 0
    return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

**思路**：当前节点深度 = 1（自己）+ 左右子树较深的一侧。空树返回 0。
- 优点：3 行，最简洁；
- 缺点：递归栈 O(h)，**深链树（如 10 万层）会 RecursionError**——BFS 无此问题。

## 四、复杂度

- BFS：时间 O(n) / 空间 O(n)（队列最宽一层）
- 递归：时间 O(n) / 空间 O(h)（栈）

## 五、一刷 vs 二刷

- 一刷（9-14）：先写 deep 传参版（慢 48%）→ 经典 1+max 定稿；**击败率陷阱实证：经典版也只有 7ms/12%，ms/击败率≠算法优劣**；
- 二刷（10-24）：BFS 层数计数一次 AC，套路复用 102——**"按层快照"心法一题多用**。
