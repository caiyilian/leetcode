## 用户踩的坑（已自己发现并标注）

**矩阵元素是字符串 '0'/'1' 不是 int 0/1**：

```python
if matrix[i][j] == '0':    # ★ 必须带引号！否则判断永远不成立
    heights[j] = 0         #   所有高度都累加 → 结果全错
```

**通用提醒**：矩阵/字符串类题先看输入类型（str/int），'0' vs 0 是高频失误点。
