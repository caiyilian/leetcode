## WA → AC 复盘（本次核心教训）

**WA 最小复现用例**：`[1,2,None,3]`（节点 2 只有左孩子 3，无右孩子）——WA 输出 `[1,2]`（丢 3），AC 输出 `[1,2,3]`。

**根因**：递归函数约定返回 `(展平链头, 展平链尾)`。当某节点**只有左子树、右子树为空**时：

```python
root.right, right_last = fun(root.right)   # fun(None) → right_last = None
...
return root, right_last if right_last is not None else root
# ↑ right_last 是 None → 返回的"链尾"变成了 root 自己（错！真正的链尾是左链尾 left_last）
```

于是父级拼接时 `left_last.right = root.right` 只接到了 root，**左子树里更深的后缀丢了**。

**修复**（一行）：拼接后如果右子树为空，把链尾修正为左链尾：

```python
if right_last is None:
    right_last = left_last    # ★ 右子树空 → 链尾就是左链尾
```

**教训**：**"返回 (头,尾)" 的递归约定，必须保证"尾"永远正确**——它错一个，父级拼接就错一片。凡是返回"尾"的递归（尤其子树可能为空时），一定要检查空子树时尾该是谁。
