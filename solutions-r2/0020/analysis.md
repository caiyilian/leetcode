# 20. 有效的括号 · 解析（二刷）

## 一、核心思路：栈 + 哈希映射

**问题**：判断括号串是否有效（正确闭合 + 正确嵌套顺序）。

**栈的天然优势**：括号匹配是最典型的"后进先出"——**最后遇到的左括号，必须最先被右括号闭合**。

```
"([{}])"
( → 栈 [ ( ]
[ → 栈 [ (, [ ]
{ → 栈 [ (, [, { ]    -> 遇到 }：弹 {，匹配 ✓
                        -> 遇到 ]：弹 [，匹配 ✓
                        -> 遇到 )：弹 (，匹配 ✓
栈空 → True
```

**哈希映射**：`{ "(":")", "{":"}", "[":"]" }`（左 → 右）。

## 二、代码（用户 AC 版 v4）

```python
hash_map = {"(": ")", "{": "}", "[": "]"}
stack = []
for c in s:
    if c in hash_map:            # 左括号 → 压栈
        stack.append(c)
    else:                        # 右括号 → 弹栈比对
        if not stack or hash_map[stack.pop()] != c:   # ★ 先查空栈（or 短路）
            return False
return not stack                 # 栈空 = 全匹配
```

## 三、⚡ 核心坑：判空栈必须在 pop 之前（本次 RE + WA 双踩）

| 版本 | 写法 | 问题 |
|------|------|------|
| v1 RE | `stack.pop()` 直接弹 | 多余右括号 → 空栈 IndexError |
| v3 WA | `hash_map[stack.pop()] != c or not stack` | **or 左侧先执行**，pop 还是先跑（顺序反） |
| v4 AC | `not stack or hash_map[stack.pop()] != c` | **or 短路**：not stack 为 True → 直接 False，不 pop ✅ |

**本质**：`or` 从左到右求值，把 `not stack` 放最前就是"先判空、空则短路"，右侧 pop 只在非空时执行。等价写法 `if not stack: return False` 单独一句更直白，二选一。

## 四、复杂度

- 时间：O(n)
- 空间：O(n)（栈）

## 五、一刷 vs 二刷

- 一刷（9-14）：栈+映射 AC ×3；
- 二刷（10-30）：**逻辑全对，栽在空栈顺序**（RE→WA→AC 三连）——典型"会思想、代码边界没兜住"。**记住口诀：pop 前必查空**。

## 七、一句话记住

> **有效的括号 = 栈 + 左→右映射：左压栈、右弹栈比对；⚡ pop 前必查空栈（or 短路把 not stack 放最前）；最后 return not stack。**
