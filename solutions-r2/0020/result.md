## ⚡ 本次踩坑复盘：空栈判断的先后顺序（核心教训）

**v1 RE**：遇到多余右括号（如 `")"`）直接 `stack.pop()` → 空栈 IndexError。

**v3 WA**：把判断写成
```python
if hash_map[stack.pop()] != c or not stack:   # ❌ or 左侧先执行 pop → 还是炸/错
```
**`or` 左侧先求值**，所以 `stack.pop()` 还是先执行了——空栈没防住。

**v4 AC**：
```python
if not stack or hash_map[stack.pop()] != c:   # ✅ or 短路，先查 not stack
```
**`or` 左侧 `not stack` 为 True 就直接短路，不再执行右侧 pop**——先判空、空则 False，非空才 pop。

**记忆口诀**：**判空栈必须在任何 pop 之前**（用 or 短路把 `not stack` 放最前，或单独 `if not stack: return False`）。一刷 0020 记录里 142 环形链表 II 也有"先判断再移动"的同款教训——这是链式操作题的通用坑。

## 解法要点

- 左→右映射（压左括号，弹出来和右括号比）最直观；
- 遍历完 `return not stack`：右括号多 → 中途 return False；左括号多 → 栈非空 → False；完美匹配 → 空栈 True；
- 空串 `""` → True（栈空，恒成立）。
