# 763. 划分字母区间 · 解析（二刷）

## 一、核心思路：字母"最后出现位置"定右边界（贪心区间扩展）

**问题**：把字符串分成尽可能多的段，每段的字母不能出现在其他段中。

**关键洞察**：一个字母只要出现在当前段内，**段的右边界就必须 ≥ 该字母最后一次出现的位置**——否则它在后面还会出现，就"跨段"了。所以遍历时维护"当前段必须覆盖到的最远位置"，扫到它时切一刀。

## 二、代码（用户 AC 版）

```python
end_dict = {}
for i in range(len(s)):
    end_dict[s[i]] = i          # ① 每个字母的最后出现位置

end, start = 0, 0
results = []
for i in range(len(s)):
    end = max(end, end_dict[s[i]])   # ② 当前段的右边界被最晚字母撑开
    if i == end:                     # 扫到边界 → 段内字母已完成，切段
        results.append(end - start + 1)
        start = end + 1
return results
```

## 三、⚡ 为什么贪心正确（为什么"到边界就切"不违反"尽可能多"）

- 段的右边界 `end` 由**段内所有字母的最后出现位置取 max** 决定——这是该段能存在的最短右边界（不能再小了，再小就有字母跨段）；
- 一旦 `i == end`，说明当前段内所有字母的最后位置都已被包含，**后面不会再出现本段字母** → 此刻切割必然合法；
- 在"最早必须切"的点切，段短 → 段数自然最多。不存在更早的合法切点（那会漏掉还在后面的段内字母）。

**和 55/45 跳跃的"end 墙"完全同构**：`end` 是当前层/段的最远边界，`i` 撞墙才结算。这就是"区间贪心"的通用骨架。

## 四、复杂度

- 时间：O(n)（两遍线性扫描；26 字母常数空间）
- 空间：O(1)（end_dict 最多 26 键）

## 五、一刷 vs 二刷

- 一刷（9-18）：AC ×2；
- 二刷（11-01）：一次 AC，套路已内化。
