## 解法核心

**关键洞察**：每个字母**最后一次出现的位置**决定了——只要这个字母在当前段内，段的右边界就至少要"够到"它的最后位置。

```
① 第一遍：end_dict[ch] = ch 最后出现的下标
② 第二遍：end = max(end, end_dict[s[i]])   ← 当前段右边界不断被"最晚字母"撑开
          当 i == end  → 段内所有字母的最后位置都被覆盖 → 可以切！
```

```python
end_dict = {}
for i in range(len(s)):
    end_dict[s[i]] = i          # 最后出现位置（顺带覆盖成最新）

end = 0
start = 0
results = []
for i in range(len(s)):
    end = max(end, end_dict[s[i]])
    if i == end:                # 扫描到边界，段内字母不会出现在后面
        results.append(end - start + 1)
        start = end + 1
return results
```

**为什么贪心正确**：段内字母的最后位置决定了段的最短右边界，取 max 就是"不得不覆盖到的最晚位置"；一旦扫到该位置，后面不会再有当前段内字母，此时切割必然合法且让每段尽量短（段的边界由最早出现的字母链锁定，不存在中间可切点）。

## 验证方式（对拍用）

两个独立校验：
1. **数值参照**：`rfind` 暴力法（每段从首字母 rfind 起，循环扩展 rfind 区间直到收敛）——独立实现，交叉验证；
2. **合法性校验**：拼接结果 === 原串，且任一段内的字母不出现在其他段。
