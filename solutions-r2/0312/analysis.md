# 312. 戳气球 · 解析（二刷·困难）

## 一、题目

- 中文：戳气球
- English：Burst Balloons
- 难度：困难（区间 DP 经典代表作）

## 二、核心思路：区间 DP + "最后戳破的 k"逆向思维

**问题**：戳破所有气球，每个气球得分 = 它左边最近未戳 × 它 × 右边最近未戳。求最大总分。

**为什么不能顺序 DP**：戳的顺序会影响左右邻居，状态纠缠（戳掉的气球改变别人得分）。

**关键逆向思维——枚举"最后戳破的气球 k"**：
- 在开区间 `(i, j)` 里，最后戳破的 k，被戳时**中间其他气球已全部戳光** → 它的左右邻居恰好就是两端哨兵 i、j 本身；
- 得分 = `nums[i] * nums[k] * nums[j]`，且左右子问题 `(i,k)`、`(k,j)` **完全独立**（互不影响）；
- 于是：`dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])`。

**两端补哨兵**：`nums = [1] + nums + [1]`，值 1 不影响乘积、永不戳破，作为开区间的"墙"免去边界讨论。

```
[3,1,5,8] → 哨兵 [1, 3, 1, 5, 8, 1]
             下标  0  1  2  3  4  5
dp[0][5] = 开区间 (0,5) 内全戳破的最大分 ← 答案
```

## 三、代码骨架（递推法，O(n³)）

```python
nums = [1] + nums + [1]
n = len(nums)
dp = [[0] * n for _ in range(n)]
for each_len in range(2, n):            # ⚡ 外层按区间长度（小区间先算）
    for i in range(0, n - each_len):
        j = i + each_len
        dp[i][j] = max(
            dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j]
            for k in range(i + 1, j)    # k 是最后戳破的气球（开区间内）
        )
return dp[0][n - 1]                     # ⚡ 开区间端点 = 左右哨兵下标 0 和 n-1
```

（自顶向下等价写法：DFS 记忆化 `f(i,j)`，边界 `j-i<=1` 返回 0——见 SolutionMemo。）

## 四、⚡ 两个必踩的坑（本次实战验证）

1. **循环顺序**：区间 DP 必须**按区间长度从小到大**枚举——`dp[i][j]` 依赖的更短区间 `dp[i][k]`/`dp[k][j]` 必须先算好；如果 `for i` 固定左端、`for j` 扩右端，大区间先算，子问题全是 0，结果全是 0；
2. **端点下标**：加了哨兵后数组长度 n，右哨兵下标是 **n-1**——`dp[0][n-1]` 才是"开区间包住全部真实气球"；`dp[0][n]` 越界且从没被算过（一刷新错误）。

## 五、复杂度

- 时间：O(n³)（区间数 O(n²) × 每区间枚举 k O(n)）
- 空间：O(n²)
