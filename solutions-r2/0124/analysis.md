# 124. 二叉树中的最大路径和 · 解析（二刷）

## 一、核心思路：两腿更新答案 / 单腿喂父节点（543 直径同款骨架）

路径可以任意起止（不必过根）。**关键：对每个节点，区分"过它的路径"和"通过它向上延展的单链"**：

```
        10           节点 10：两腿 = 9 + 10 + 20 + 15 + 7（过根路径，更新答案）
       /  \          单腿 = 10 + max(左贡献9, 右贡献20+15) = 45（喂给父）
      9   20
         /  \
        15   7
```

- **两腿**（左贡献 + 自己 + 右贡献）：这条路径在节点处"拐弯"，**用它更新全局答案**；
- **单腿**（自己 + 较大一侧）：这条链还要继续向上走，**作为返回值喂给父节点**。

**这就是"返回值 ≠ 题目答案"的典型**——返回值只是单腿，答案在全局变量里。

## 二、代码骨架（用户 AC 版）

```python
result = [float('-inf')]          # ⚡ 全局答案：-inf 起（全负树也要选节点）
def fun(root):
    if root:
        left_max = max(fun(root.left), 0)    # 左单腿贡献（负数截断为 0 = 不选）
        right_max = max(fun(root.right), 0)
        result[0] = max(result[0], root.val + left_max + right_max)  # 两腿更新
        return root.val + max(left_max, right_max)                   # 单腿喂父
    return 0
fun(root)
return result[0]
```

## 三、两个关键细节（⚡ 必考坑）

1. **`max(..., 0)` 截断负贡献**：路径可以绕过负分支——"不选"比"选负的"更好。所以向上传的单腿，负贡献直接变 0；
2. **答案初始 `float('-inf')`**：题目要求路径至少含一个节点。若初始为 0，全负树（如 `[-3]`）会错误返回 0（应该是 -3）。**用 -inf 保证第一次比较一定被真实节点值覆盖**。

## 四、复杂度

- 时间：O(n)
- 空间：O(h)（递归栈）

## 五、一刷 vs 二刷

- 一刷（9-15）：WA 1 次（细节：初值/截断）→ AC；
- 二刷（10-24）：一次 AC——两个坑（-inf 初值、max 截断）直接写对，骨架内化。
