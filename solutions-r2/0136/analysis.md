# 136. 只出现一次的数字 · 解析（二刷）

## 一、题目

- 中文：只出现一次的数字
- English：Single Number
- 难度：简单（位运算经典入门）
- 要求：除一个数出现一次外，其余都出现两次；**进阶 = O(n) + O(1)**

## 二、核心思路：异或（唯一同时满足 O(n)/O(1) 的解）

**异或三条性质**：
```
① a ^ a = 0      （相同抵消）
② a ^ 0 = a      （与 0 异或不变）
③ 交换律、结合律  （顺序无关）
```

**解法**：把所有数全部异或：
```
nums = [4, 1, 2, 1, 2]
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1^1) ^ (2^2)     ← 结合律分组
= 4 ^ 0 ^ 0
= 4                      ← 单身数字
```
成对的数全部抵消为 0，剩下的就是唯一出现一次的数。

**为什么其它方法不满足进阶**：
| 方法 | 时间 | 空间 | 能否进阶 |
|------|------|------|---------|
| 哈希表计数 | O(n) | O(n) | ❌ 空间不达标 |
| 排序后找 | O(n log n) | O(1) | ❌ 时间不达标 |
| **异或** | **O(n)** | **O(1)** | ✅ **唯一达标的解** |

## 三、代码（用户 AC 版）

```python
result = nums[0]
for i in range(1, len(nums)):
    result ^= nums[i]      # a^a=0 成对抵消，剩单身
return result
```

（等价写法 `result = 0; for n in nums: result ^= n`——从 0 起 xor 更通用：`0 ^ x = x`。）

## 四、⚡ 易错点

1. **负值也适用**：异或是按位运算，负数同样满足 `a^a=0`（Python 整数是无限位补码），无需特判；
2. **空数组**：题目保证至少一个元素（`1 <= nums.length`），不用处理；
3. **进阶约束是"死命令"**：这题是面试问"面试官要求 O(1) 空间时你想到什么"的典型——答案就是异或，别的都白搭。

## 五、复杂度

- 时间：O(n)（一次遍历）
- 空间：O(1)（一个变量）
