# 226. 翻转二叉树 · 解析（二刷）

## 一、核心思路：递归交换左右子树

翻转 = 每个节点的左右子树互换，子树内部也要翻转——所以递归到底：

```
    4               翻转后        4
   / \                           / \
  2   7         →                7   2
 / \ / \                       / \ / \
1  3 6  9                     9  6 3  1
```

对每个节点：先翻转左子树、翻转右子树，然后左右互换（**后序**）。

## 二、代码（用户 AC 版）

```python
def fun(root):
    if root:
        root.left, root.right = fun(root.right), fun(root.left)  # ★ 元组赋值交换
        return root
```

**元组赋值是考点**：`a, b = f(b), f(a)` 右侧**先整体求值**（先翻转右、再翻转左），然后一次性赋给左边——天然完成交换，**不需要临时变量**。如果用普通写法要小心顺序（先换再递归会覆盖指针）：

```python
# 普通写法（需要临时变量）
tmp = root.left
root.left = self.invertTree(root.right)
root.right = self.invertTree(tmp)
```

## 三、边界

- **空树**：`if not root: return None`（入口守卫）；
- **单节点/叶子**：`fun(leaf)` 里 left/right 为 None，`fun(None)` 返回 None，赋值后叶子左右仍为 None——天然正确。

## 四、复杂度

- 时间：O(n)
- 空间：O(h)（递归栈）

## 五、一刷 vs 二刷

- 一刷（9-14）：递归 + 元组赋值，0ms/100%（⚡ 元组赋值考点标记）；
- 二刷（10-24）：同一写法一次 AC——完全内化。

## 七、一句话记住

> **翻转二叉树 = 递归后序交换：root.left, root.right = fun(right), fun(left)——元组赋值先算后赋，天然省临时变量。**
