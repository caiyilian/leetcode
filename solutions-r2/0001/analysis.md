# 1. 两数之和 · 二刷解析

## 题目回顾

给定整数数组 `nums` 和目标值 `target`，找出和为 `target` 的两个整数，返回下标。题目保证唯一解，且不能重复使用同一元素。

## 核心思路：哈希表一次遍历

**一句话**：边遍历边问"我缺的那个数（target - 当前数）之前出现过吗？"——用哈希表记下"值 → 下标"。

```
nums = [2, 7, 11, 15], target = 9

i=0: 2  缺 7，哈希表空 → 存入 {2:0}
i=1: 7  缺 2，哈希表有 2! → 返回 [1, 0] ✓
```

**为什么先查再存**：保证不会"自己配自己"（同一个元素用两次）。当前元素还没存入哈希表，查到的补数必然是**之前**遍历过的元素。

## 与暴力法的对比

| | 暴力双重循环 | 哈希表一次遍历 |
|--|------------|--------------|
| 时间 | O(n²) | **O(n)** |
| 空间 | O(1) | O(n)（哈希表） |
| 思想 | 枚举所有对 | **空间换时间**（用空间换一次遍历） |

哈希表解题的核心套路：**把"找某个值"从 O(n) 遍历变成 O(1) 查询**。这一招在后缀题里大量复用（如 49 字母异位词分组、128 最长连续序列、560 和为 K 的子数组）。

## 边界细节（二刷重点回顾）

1. **`value = 0` 的下标**：答案可能是 `[1, 0]`，哈希表里存了 `{2:0}`，`get(2)` 返回 0——用 `is not None` 判断（而不是 `if hash_map[target-nums[i]]` 这样的真值判断），0 不会误判为"不存在"。
2. **负数 target / 负数元素**：`target - nums[i]` 可能是负数，哈希表照常按值查找，没有特殊处理。
3. **重复元素**：如 `[3,3] t=6`——遍历到第二个 3 时，哈希表已存了第一个 3，查到补数 3，返回 `[1,0]`。后出现的元素覆盖下标值（但本题唯一解，覆盖不影响）。
