## 解法说明

用户"秒了"——标准递归中序，内嵌 `fun` + 闭包共享 `result`（和一刷完全一致，一刷的记忆还在）：

```python
def fun(root):
    if root:
        fun(root.left)
        result.append(root.val)
        fun(root.right)
```

**注意**：`if root:`（先判非空再递归）能正确处理空树——`fun(None)` 直接返回，无需特判。
