# 94. 二叉树的中序遍历 · 解析（二刷）

## 一、核心思路：左中右

中序遍历 = 左子树 → 根 → 右子树。对于**二叉搜索树（BST）**，中序遍历的结果是**升序数组**——这是 BST 最重要的性质（98 验证二叉搜索树就是用它）。

```
    1
     \
      2
     /
    3
中序：左(1 无)→1→右子树(2: 左3→2) = [1,3,2]
```

## 二、递归版代码

```python
result = []
def fun(root):
    if root:            # 先判非空（空子树直接返回）
        fun(root.left)      # 左
        result.append(root.val)  # 中
        fun(root.right)     # 右
fun(root)
return result
```

两处细节：
- **闭包共享 result**：不用返回值层层传，内嵌函数直接改外层列表（简单直观）；
- **`if root:` 天然处理空树**：空树/空子树都返回，无需额外特判。

## 三、迭代栈版（面试可能问非递归）

```python
res, stack = [], []
cur = root
while cur or stack:
    while cur:              # 一路压左
        stack.append(cur)
        cur = cur.left
    cur = stack.pop()       # 弹栈 = 访问"中"
    res.append(cur.val)
    cur = cur.right         # 转右子树
return res
```

**本质**：用显式栈模拟递归栈。递归栈深 O(h)，迭代栈显式 O(h)——空间一样，但迭代不爆栈（递归在深度很大的链树会 RecursionError）。

## 四、复杂度

- 时间：O(n)
- 空间：O(h)（递归栈 / 显式栈）；输出列表不计（力扣口径）
- **Morris 遍历**可以 O(1) 空间（线索指针），较冷门，面试遇到再说

## 五、一刷 vs 二刷

- 一刷（9-14）：递归版 0ms/100%（+ 迭代版归档）；
- 二刷（10-22）：**秒了，一次 AC**——二叉树基础已内化。

## 七、一句话记住

> **中序 = 左中右；递归版闭包共享 result + `if root:` 判空；迭代版"一路压左、弹栈访问、转右"；BST 中序 = 升序数组。**
