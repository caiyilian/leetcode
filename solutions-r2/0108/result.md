## 解法说明

**核心洞察：平衡靠构造，不靠检查**——只要每次取区间中点做根，左右子树节点数差 ≤1，天然高度平衡（AVL 性质）；有序数组保证了 BST 的"左<根<右"。两个性质由构造方式直接保证，无需事后验证。

```python
middle = (end - start) // 2 + start   # 中点取根
root.left = fun(start, middle)        # 左半含中点：left_num = middle-start
root.right = fun(middle+1, end)       # 右半不含中点
```

**`if left_num > 0` 守卫**：区间为空就不建子树（对应 `if not nums` 的递归版）。
