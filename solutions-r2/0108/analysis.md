# 108. 将有序数组转换为二叉搜索树 · 解析（二刷）

## 一、核心思路：平衡靠构造，不靠检查

两个性质要同时满足：
1. **BST**：左子树全 < 根 < 右子树全——有序数组天然给好了顺序（中序 = 数组本身）；
2. **高度平衡**：左右子树高度差 ≤1——只要**每次取当前区间中点做根**，左右子树节点数差 ≤1，构造出来的树就是平衡的（AVL）。

**平衡不是检查出来的，是构造出来的**——这是本题的灵魂。中点取根 → 左半建左子树、右半建右子树，递归下去，天然平衡。

## 二、下标版代码（用户 AC 版，进阶 O(1) 额外空间）

```python
if not nums:
    return None
length = len(nums)

def fun(start, end):                # 当前区间 [start, end)
    middle = (end - start) // 2 + start    # ★ 中点（偏左：左半 ≥ 右半，差 ≤1）
    root = TreeNode(nums[middle])
    left_num = middle - start              # 左半边节点数（不含中点）
    right_num = end - middle - 1           # 右半边节点数
    if left_num > 0:
        root.left = fun(start, middle)     # 左半含中点前
    if right_num > 0:
        root.right = fun(middle + 1, end)  # 右半中点后
    return root

return fun(0, length)
```

**用下标圈区间而不是切片**：切片 `nums[:mid]` 每层复制数组 → O(n log n) 空间；下标法零复制，**满足进阶 O(log n) 递归栈**。

## 三、边界细节

- **空数组**：`if not nums: return None`（入口守卫）；
- **中点取法** `(end-start)//2 + start` 偏左——数组长度偶数时左半比右半多 1 个，仍然平衡（AVL 允许差 1）；
- **`if left_num > 0` 守卫**：区间没有元素就不建子树，避免无限递归。

## 四、复杂度

- 时间：O(n)——每个元素恰好建一个节点
- 空间：O(log n)——递归栈（下标版无切片拷贝）；若用切片版则是 O(n log n) 空间

## 五、一刷 vs 二刷

- 一刷（9-15）：分治+中点取根，下标版 AC ×2（**平衡靠构造不靠检查**；⚡进阶传下标 O(n)）；
- 二刷（10-24）：独立写出一次 AC——中点取根 + 下标圈区间的两处要点都在（坐标计算 left_num/right_num 一次写对）。

## 七、一句话记住

> **有序数组转 BST = 中点取根 + 左右半边递归：平衡靠构造（中点天然均分），BST 靠有序（中序=数组）；下标圈区间零拷贝 O(log n) 栈。**
