# 416. 分割等和子集 · 解析（二刷）

## 一、题目

- 中文：分割等和子集
- English：Partition Equal Subset Sum
- 难度：中等（**0-1 背包**）
- 问题：能否把数组分成两个和相等的子集 → 等价于"能否选出若干数，恰好凑出 sum/2"

## 二、核心思路：0-1 背包

**转化**：总和必须为偶数（否则直接 False）；target = sum/2。问"能否**不放回**地取一些数凑出 target"——每个数**用一次**，这正是 **0-1 背包**（区别于 322 零钱兑换的完全背包可无限用）。

**状态定义**：
```
dp[t] = 能否用已处理的数凑出和 t（bool）
dp[0] = True（一个都不选，恒成立）
转移：dp[t] = dp[t]（不选当前数）or dp[t - x]（选当前数，前提 t >= x）
答案：dp[target]
```

## 三、代码（用户 AC 版，一维滚动）

```python
if sum(nums) % 2 != 0:
    return False
target = sum(nums) // 2
dp = [False] * (target + 1)
dp[0] = True
for x in nums:
    for t in range(target, x - 1, -1):   # ⚡ 倒序遍历！
        dp[t] = dp[t] or dp[t - x]
return dp[target]
```

## 四、⚡ 两个核心坑（本次实战验证）

1. **倒序遍历（0-1 背包的灵魂）**：正序时 `dp[t-x]` 可能是本轮刚更新的（已含 x）→ 同一个数被用多次，退化成完全背包语义。**倒序保证 `dp[t-x]` 是"处理当前 x 之前"的旧值**——每个数至多用一次。对照：322 零钱兑换是正序（允许无限用），**一正一倒别混**；
2. **WA 变体复盘**（18:30 那版）：内层写成 `for j in range(nums[i], target+1)` 直接跳过了 `j < nums[i]` 的情况——**漏了"容量不够时继承上一行 dp[i-1][j]"**，导致小容量格子全部没继承，结果错误。二维版每个格子要么放要么继承，都要处理。

**内存坑（一刷踩过/注释里有）**：`[[0]*n]*m` 是浅拷贝，改一格全行变——建二维数组必须用列表推导式 `[[0]*n for _ in range(m)]`。

## 五、复杂度与性能对比

| 版本 | 时间 | 空间 |
|------|------|------|
| 二维 DP | O(n·target) | O(n·target)（实测 49MB）|
| **一维滚动** | O(n·target) | **O(target)**（实测 19MB，快 4.2 倍）|

**伪多项式**：复杂度正比于 target 数值。本题约束 nums[i]≤100、n≤200 → sum≤20000、target≤10000，O(n·target) = 2×10⁶ 完全可行——**题目用数值约束保证背包题可行**，面试可提"伪多项式时间"。

## 六、关联题目：背包家族

| 题 | 背包类型 | 语义 |
|----|---------|------|
| **416 本题** | 0-1 · 可行性 | 能否恰好凑出 target（bool）|
| **322 零钱兑换**（⚡ 已做）| 完全背包 · 最少 | 无限用，求最小数量 |
| **518 零钱兑换 II** | 完全背包 · 方案数 | 无限用，求方案总数 |
| **279 完全平方数**（⚡ 已做）| 完全背包 · 最少 | 平方数无限用（与 322 同模板）|

**识别信号**："每个元素最多用一次 + 凑出某个和/容量"→ 0-1 背包倒序；"每个物品无限用"→ 完全背包正序。

## 七、一句话记住

> **416 = 0-1 背包可行性：sum 偶数、target=sum/2；dp[t] 能否凑 t，dp[0]=True；⚡ 内层 t 从大到小倒序（防重复用），答案 dp[target]；二维能滚成一维 bool，4 倍提速。**
