# 448. 找到所有数组中消失的数字 · 解析（二刷）

## 一、题目

- 中文：找到所有数组中消失的数字
- English：Find All Numbers Disappeared in an Array
- 难度：简单（数组即哈希）
- 问题：长度 n、值域 1..n 的数组，找没出现过的数字（进阶 O(n)/O(1) 额外空间）

## 二、核心思路：归位法（数组即哈希表）

**关键观察**：值 v 应放在下标 v-1（值域 1..n 与下标 0..n-1 一一对应）。把每个元素换到它"该在的位置"，最后位置错乱的下标就是消失的数字：

```
[4,3,2,7,8,2,3,1]
归位后 → [1,2,3,4,3,2,7,8]     ← 4 在 4 位、7 在 7 位...
下标 4（值 3）和 5（值 2）位置错乱 → 缺失 5 和 6 ✅
```

**用户 AC 版的两个条件合并**：
```python
while nums[i] != (i + 1) and nums[i] != nums[nums[i] - 1]:
    target = nums[i] - 1
    nums[i], nums[target] = nums[target], nums[i]
```
- 条件 1 `nums[i] != i+1`：当前位没归位；
- 条件 2 `nums[i] != nums[nums[i]-1]`：目标位置还不是正确值——**防止重复值进死循环**（如 [3,3,3]：把 3 换到下标 2 后，另一个 3 的目标位已有正确值，停止）。

## 三、同族方法对比（进阶解不止一个）

| 方法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| **归位法（本题）** | O(n) | O(1) | 交换到应属位置 |
| 负数标记法 | O(n) | O(1) | 出现过 → 对应下标标负（SolutionMark）|
| set 差集 | O(n) | O(n) | 简单但空间不达标 |

两者都 O(n)/O(1) 满足进阶；归位法思路更直观，标记法代码更短。

## 四、⚡ 易错点

1. **防死循环**：交换前必须判断目标位是否已是正确值（重复元素会导致无限交换）——`nums[i] == nums[nums[i]-1]` 时 break；
2. **与 287 的区分**：448 **允许修改原数组**（归位法合法），287 **禁止修改**（必须快慢指针）——同样"值域映射下标"，约束不同解法不同；
3. **结果顺序**：答案是下标顺序的 i+1，天然升序（题目要求升序返回）。

## 五、复杂度

- 时间：O(n)（每个元素至多交换一次）
- 空间：O(1)（结果数组除外）
