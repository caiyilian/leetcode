## 自底向上归并 O(1)（力扣进阶，本次补归档）

**和递归版本质区别**：

| | 递归版（自顶向下） | 自底向上版 |
|---|---|---|
| 过程 | 先切到底（单节点）再合并上来 | 从 1 个节点一组开始，段长 1→2→4 逐层翻倍合并 |
| 空间 | O(log n)（递归栈） | **O(1)**（纯迭代） |
| 实现 | 递归切半 + merge | 每层手动 split 断开 + merge + prev 推进 |

三步：
1. **数长度 n**——决定外层循环轮数；
2. **外层循环 `while step < n`**：段长翻倍。内层从左往右 `left=cur; right=split(cur,step); cur=split(right,step); prev.next=merge(left,right); prev 推进到合并结果末尾`；
3. **`_split` 切断**：`head.next = None` 是灵魂——不断开，merge 会并到整条链尾，把后面没处理的段也卷进来。

**两个易翻车点**：① `split` 的 `head.next=None`（断开）；② `prev` 必须推进到合并结果末尾（`while prev.next: prev = prev.next`）。

## 插曲复盘：忘 `if not head: return head` → AttributeError

用户一开始在 `sortList` 里没写空链表守卫，`fun(None)` 直接执行 `if p.next is None` → **AttributeError: 'NoneType' object has no attribute 'next'**。补上 `if not head: return head` 后 AC（复现确认）。

**教训**：**递归分治/快慢指针类题目，空链表守卫是"默认开场动作"**——`fun` 的递归基（`p.next is None`）只能处理"单节点"，处理不了"零节点"，必须在入口就把空链表挡掉。208 题的教训类似（`head is None` 特判）。
