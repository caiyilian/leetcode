# 62. 不同路径 · 解析（二刷）

## 一、题目

- 中文：不同路径
- English：Unique Paths
- 难度：中等（二维 DP 入门）
- 问题：m×n 网格从左上到右下，只能向右/向下，求路径数

## 二、核心思路：二维 DP（到达每个格子的路径数）

**状态**：`dp[i][j]` = 从起点 (1,1) 到格子 (i,j) 的路径数。

**转移**：只能从上方或左方进格子 → `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。

**用户 AC 版的小技巧（1 索引 + 全 1 初始化）**：
```python
dp = [[1] * (n + 1) for _ in range(m + 1)]   # 第 1 行/第 1 列全 1（只有一条路）
for i in range(2, m + 1):
    for j in range(2, n + 1):
        dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
return dp[m][n]
```
- 多开一圈：`dp[1][1]` 起点，`dp[1][j]`/`dp[i][1]` 第一行/列天然是 1（只能一路向右/向下）；
- 从 (2,2) 开始填，**省掉所有越界判断**——比 0 索引 + 边界 if 更清爽（和 85 最大矩阵的哨兵思想同源）。

**数学等价**：总共走 `m+n-2` 步，其中选 `m-1` 步向下 → `C(m+n-2, m-1)`。

## 三、复杂度

- 时间：O(m·n)
- 空间：O(m·n)（组合数公式可 O(1)；每行只依赖上一行 → 可滚动 O(n)）

## 四、⚡ 一刷复盘（为什么二刷要一次过）

一刷 9-19：WA（边界）→ **TLE（DFS 深搜）**→ AC×3。**TLE 的教训**：这题 DFS 会走大量重复路径（同格子被多条路经过，无记忆化是指数级）——**"数路径"类题目要想到 DP 而不是 DFS**；若用 DFS 必须带记忆化（本质就是 DP）。

## 五、关联题目：路径系列

| 题 | 区别 |
|----|------|
| **62 本题** | 无障碍物，全 1 边界技巧顺滑 |

## 六、一句话记住

> **62 = 二维 DP：dp[i][j] = dp[i-1][j] + dp[i][j-1]（从上+从左来）；1 索引 + 全 1 边界免判越界，从 (2,2) 填起；等价组合数 C(m+n-2, m-1)；⚡ 数路径题别用裸 DFS（会 TLE），DP 或记忆化。**
