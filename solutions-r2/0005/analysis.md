# 5. 最长回文子串 · 解析（二刷）

## 一、题目

- 中文：最长回文子串
- English：Longest Palindromic Substring
- 难度：中等
- 标签：字符串、动态规划（**DP 是解法之一，不是唯一**）

## 二、用户 AC 版：中心扩展法（O(n²)/O(1)）

**核心观察**：回文要么长度为奇数（以一个字符为中心），要么为偶数（以两个相邻字符为中心）。枚举所有可能中心，向两侧扩展直到两端不等，记录最长区间：

```
奇数中心 (i, i)：    a b a   ← 以 b 为中心
偶数中心 (i, i+1)：  a b b a ← 以 bb 为中心
```

```python
for i in range(n):                    # 奇数中心
    l, r = i, i
    while l >= 0 and r < n and s[l] == s[r]:
        l -= 1; r += 1                # 向两侧扩展
    # 记录 s[l+1:r]（长度 r-l-1）
for i in range(n - 1):                # 偶数中心
    l, r = i, i + 1
    # ... 同上
```

**为什么没漏**：任意回文都有唯一中心（奇偶二选一），枚举全部中心 = 枚举全部回文——不漏不重。总中心数 2n-1 个，每个最多扩 O(n) → O(n²)。

## 三、对比：官方四种解法（面试按需选讲）

| 解法 | 时间 | 空间 | 说人话 |
|------|------|------|--------|
| 暴力枚举子串 | O(n³) | O(1) | 全枚举 + 反转判断（5.3s，TLE 边缘）|
| **DP**（标签来源）| O(n²) | **O(n²)** | 大回文 = 小回文 + 两端相等 |
| **中心扩展**（本次）| O(n²) | **O(1)** | 从中心向两边扩 |
| Manacher | O(n) | O(n) | 贪心利用对称性（面试装杯）|

**结论：中心扩展是官方标准解，且同 O(n²) 下空间 O(1) 优于 DP——面试写它完全没问题。**

## 四、⚡ 这版到底算不算 DP？（用户提问点）

**不算。** DP 的要义是"**用已算好的子问题答案递推**"。这版每个中心独立向外扩展，**全程没有复用任何之前的计算结果**——它是"枚举中心 + 双指针贪心扩展"，本质是**枚举/模拟**，不是 DP。

**为什么力扣标 DP**：标签 = 该题所有已被接受的解法的**并集**。本题存在 DP 解法，所以标签里有 DP——但**不代表每份 AC 代码都得是 DP**。你写中心扩展，解法不是 DP，照样是标准解。

**DP 版长什么样**（对比感受差别）：
```
dp[i][j] = s[i]==s[j] 且 (j-i<=2 或 dp[i+1][j-1])
```
它**引用了子问题 dp[i+1][j-1] 的答案**——这才是"动态规划"。按区间长度从小到大填表（和 312 戳气球同款遍历节奏）。

## 五、复杂度

- 时间：O(n²)（中心数 2n-1 × 每次扩展 O(n)）
- 空间：O(1)（只存答案，无额外表）
