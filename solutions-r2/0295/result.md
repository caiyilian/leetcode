## 解法核心：双堆对半分

**模型**：把数据**对半拆成两个堆**——
- **small（最大堆，存较小的一半）**：堆顶 = 较小一半的最大值；
- **big（最小堆，存较大的一半）**：堆顶 = 较大一半的最小值。

只要维护 **`len(small) >= len(big)` 且差 ≤ 1**，中位数就在两个堆顶之间：
```
奇数个 → 中位数 = small 堆顶（small 恰好多 1 个）
偶数个 → 中位数 = (small 堆顶 + big 堆顶) / 2
```

```python
addNum(num):
    if num <= big 堆顶: 进 small（最大堆，存 -num）
    else:              进 big（最小堆）
    # 平衡：small 比 big 多超过 1 → 移一个给 big；big 更多 → 移一个给 small
```

**⚡ 用户亮点：inf 哨兵**——两个堆初始化都塞一个 `float('inf')`：
- 长度上相互抵消（各 1 个，差值不受影响）；
- 省掉了"堆是否为空"的判断（空堆取堆顶会越界）——`big_heap[0]` 永远安全；
- findMedian 里哨兵也参与长度计算但数量相等不影响奇偶判断。

## 边界

- 负数/重复/大数据量随机插入查询混合对拍全过；
- 首个数字进堆：num <= inf → 进 small，此时 small=[-x, inf...]，big=[inf]，奇数 → -small[0]=x ✓。
