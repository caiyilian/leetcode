| 考察点 | 结论 |

| 正确性 | ✅ 官方示例 + 空候选 + 不可达 target 等边界，**2 万组随机对拍**（vs 标准索引回溯）0 不一致 |

## 解法核心：一个 start 管两件事（⚡ 用户妙点）

```python
for n in candidates[start:]:          # 从 start 开始 → 不回头（去顺序重复）
    if now_sum + n > target:
        break                          # 已排序，后面更大 → 剪枝
    path.append(n)
    path = fun(path, now_sum+n, start) # 递归仍传 start → 可重复选当前数
    path.pop()
    start += 1                         # 本层循环自增 → 下一个数才开始
```

- **递归传 `start`**：允许**重复选**当前数（组合总和允许重复，如 [2,2,3]）；
- **循环内 `start += 1`**：本层已试过 index `start`，**向后移动**——这样不会回头产生顺序重复（如 [2,3] 和 [3,2] 只出现一次）。

**标准索引版等价写法**（更直观，归档附 SolutionClean）：`dfs(i, path, cur)` 选当前（可重复 `dfs(i, ...)`）或不选当前（`dfs(i+1, ...)`）。

## 其他要点

- **排序 + break 剪枝**：排序后 `now_sum + n > target` 即可 break（后面更大），比 continue 更快；
- **`path.copy()` 收集**：path 是共享列表，加入 result 必须深拷贝，否则回溯 pop 会改坏已存结果（⚡ 经典坑）；
- 边界：空候选、target 不可达（如 [3]→7、[2,4,6]→7）都返回 []。
