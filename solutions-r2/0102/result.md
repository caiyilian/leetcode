## 解法亮点

```python
while q:
    now = []
    for _ in range(len(q)):        # ★ 关键：先取 len(q) 快照，再弹这层
        node = q.popleft()
        ...
    result.append(now)
```

**`for _ in range(len(q))` 是层序灵魂**：`len(q)` 在循环开始时一次性求值，正好等于"当前层尚未处理的节点数"；这一层处理完（弹空），队列里剩的全是下一层。一层一个子列表，天然分组。

## 一刷 vs 二刷：同一题两种解法

- 一刷（9-14）：**DFS + dep 分组**（用户自创 = 官方解法二）——层序本质是按深度分组；
- 二刷（10-24）：**BFS 按层快照**（官方解法一）——标准 BFS。

**两种解法都掌握了**：面试问"DFS 能做层序吗"能答上（dep 分组），问"BFS 怎么按层切"也能写（len(q) 快照）——这就是一题多解的价值。
