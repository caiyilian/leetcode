# 72. 编辑距离 · 解析（二刷）⭐ 考前重点

## 一、题目

- 中文：编辑距离
- English：Edit Distance（Levenshtein Distance）
- 难度：中等（面试高频，两字符串 DP 的母题）
- 操作：插入 / 删除 / 替换，求 word1 → word2 的最少操作数

## 二、核心思路：二维 DP（状态 = 两个前缀）

**状态**：`dp[i][j]` = word1 前 i 个字符 → word2 前 j 个字符的最少操作数。

**四格看穿本质**（永远画这张表）：
```
             j=0   j=1   j=2   j=3
             ''    r     ro    ros
i=0  ''      0     1     2     3     ← 空→word2：只能插入，dp[0][j]=j
i=1  'h'     1
i=2  'ho'    2
i=3  'hor'   3
i=4  'hors'  4
i=5  'horse' 5     ← word1→空：只能删除，dp[i][0]=i
```

**转移**（看 word1[i-1] 与 word2[j-1] 是否相等）：
```
相等：dp[i][j] = dp[i-1][j-1]                    ← 不用操作，直接继承
不等：dp[i][j] = min( 替换 dp[i-1][j-1]
                    插入 dp[i][j-1]
                    删除 dp[i-1][j] ) + 1
```

**三个操作的落点（痛点记忆）**：
| 操作 | 从哪来 | 直观理解 |
|------|--------|---------|
| 替换 | `dp[i-1][j-1]` | 让两串各退一个字符，改掉这个字符 |
| 插入 | `dp[i][j-1]` | word2 多出一个字符，word1 插入补齐对齐 |
| 删除 | `dp[i-1][j]` | word1 多出一个字符，删掉它 |

## 三、⚡ 二刷卡点：边界初始化（最值钱的一课）

**错误**：`dp = [[1]*(n+1) ...]` 全填 1 → `horse/ros` 算出 1（应 3）。3 万组对拍错 25785。

**根因**：边界格子的语义是"空串那侧的代价"，**必须按行号列号填**：
```python
for j in range(n+1): dp[0][j] = j    # 空→word2[0:j]：插入 j 次
for i in range(m+1): dp[i][0] = i    # word1[0:i]→空：删除 i 次
```
**记忆锚点**："编辑距离的边界 = 行号列号（i / j），不是 1——首行首列表达的是空串变换的线性代价。"

（连线：这类"二维表 + 边界是前缀语义"的题——62/64 路径的边界是"前缀和/1"，72 是"前缀长度"，都是边界承载语义。）

## 四、复杂度

- 时间：O(m·n)
- 空间：O(m·n)（可滚动到 O(n)，见 SolutionRoll——只依赖上一行 + 一个对角 prev）

## 五、关联题目：双字符串 DP 家族

| 题 | 关系 |
|----|------|
| **72 本题** | 双串"最小代价变换"——母题 |
| **1143 最长公共子序列**（候选 ⭐）| 双串"最长公共部分"——同一张表，转移只差一个叛较短判断（相等 +1，不等取 max）|
| **10 正则匹配**（困难候选）| 双串匹配——dp[i][j] 表 + 字符类判断 |

**识别信号**："两个字符串 + 求最少操作/最长公共/能否匹配" → 二维 DP `dp[i][j]`，i/j 是两串前缀长度，转移看 `word1[i-1]` vs `word2[j-1]`。

## 六、一句话记住

> **72 = 双串二维 DP：dp[i][j] = word1 前 i → word2 前 j 的最少操作；⚡ 边界 = 行号列号（dp[0][j]=j 插入 / dp[i][0]=i 删除，空串线性代价，不是 1！）；转移：相等继承对角，不等 min(替换 diag、插入 left、删除 up)+1；可滚动 O(n)。**
