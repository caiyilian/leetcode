# 337. 打家劫舍 III · 解析（二刷）

## 一、题目

- 中文：打家劫舍 III
- English：House Robber III
- 难度：中等（树形 DP 入门题）
- 特点：二叉树结构，相邻父子不能同时偷

## 二、核心思路：树形 DP（后序遍历 + 二元组）

**198 打家劫舍（数组）** 的邻居约束是"左右相邻"；**本题**换成了"父子相邻"——顺理成章用**树上状态机**。

**状态定义**：每个节点返回二元组 `(no, yes)`：
```
no  = 以该节点为根的子树，"本节点不偷"的最大收益
yes = 以该节点为根的子树，"本节点偷"的最大收益
```

**转移（后序遍历，先算完子树再算自己）**：
```
偷当前节点：子节点必须不偷
    yes = root.val + no_left + no_right

不偷当前节点：子节点偷不偷都可以
    no = max(偷左, 不偷左) + max(偷右, 不偷右)
```

**为什么必须后序**：父节点依赖两个子树的完整信息——递归返回时正好从叶子往上带。

**答案** = `max(no, yes)`（根节点偷或不偷里选大的）。

## 三、代码（用户 AC 版）

```python
def fun(root):
    if root:
        no_rob_left, robed_left = fun(root.left)
        no_rob_right, robed_right = fun(root.right)
        yes = root.val + no_rob_left + no_rob_right      # 偷：子必须不偷
        no = max(robed_left, no_rob_left) + max(robed_right, no_rob_right)  # 不偷：子随意
        return no, yes          # 注意返回顺序 (不偷, 偷)
    return 0, 0
no, yes = fun(root)
return max(no, yes)
```

## 四、⚡ 易错点

1. **返回顺序别搞混**：二元组解包 `no_rob_left, robed_left = fun(root.left)` 和返回 `return no, yes` 的语义要一致（第 0 位是不偷、第 1 位是偷）；
2. **空子树返回 `(0, 0)`**：不偷/偷都是 0 收益——递归基；
3. **与 198 的一一对应**：198 的 `dp[i] = max(dp[i-1], dp[i-2]+nums[i])` 本质就是"不偷 i / 偷 i"两状态——树版只是把"前一个"换成了"子树"，公式完全同构。

## 五、复杂度

- 时间：O(n)（每个节点恰好访问一次）
- 空间：O(h)（h = 树高，递归栈；最坏链状 O(n)，平衡树 O(log n)）

## 六、关联题目：从线性到树

| 题 | 结构 | 状态 |
|----|------|------|
| **198 打家劫舍**（⚡ 已做）| 一维数组 | dp[i] 选/不选 i |
| **213 打家劫舍 II** | 环形数组 | 拆成两个 198（去掉首/尾各一次）|
| **337 本题** | 二叉树 | 树形 DP 二元组 (不偷, 偷) |

**树形 DP 识别信号**：树上"选/不选""包含/不包含"类最优化 → 节点返回多状态，后序自底向上合并（543 直径、124 最大路径和都是同款骨架：**树的递归返回值承载子树信息**）。

## 七、一句话记住

> **337 = 树形 DP：后序返回 (不偷, 偷)——偷则子必须不偷（val + no左 + no右），不偷则子随意（max 各自相加）；空树 (0,0)，答案 max(no, yes)；与 198 同构，只是邻居换成父子。**
