## 解法核心

**关键洞察**：乘积和加法最大的差别——**负数会翻转大小关系**。只记"以 i 结尾的最大乘积"不够：`[-2,3,-4]` 中，第 3 个数 -4 的最大乘积 24 来自**最小的 -6**（-2×3）× -4。所以必须**同时维护最大和最小两个状态**：

```
max_prod[i] = max(nums[i], max_prod[i-1]*nums[i], min_prod[i-1]*nums[i])
min_prod[i] = min(nums[i], max_prod[i-1]*nums[i], min_prod[i-1]*nums[i])
```

三个候选：① 重新开始一段 ② 乘前段最大 ③ 乘前段最小（nums[i] 为负时这是翻盘来源）。

**滚动版**（只依赖前一个位置）：

```python
result = dp_max = dp_min = nums[0]
for i in range(1, len(nums)):
    r1 = dp_max * nums[i]
    r2 = dp_min * nums[i]
    result = max(nums[i], r1, r2, result)
    dp_max = max(nums[i], r1, r2)
    dp_min = min(nums[i], r1, r2)
return result
```

## 验证方式（对拍用）

暴力 O(n²) 枚举所有子数组乘积作参照：
- 官方 [2,3,-2,4] → 6 ✅；[-2,0,-1] → 0 ✅
- **关键反例** [-2,3,-4] → 24 ✅（单状态解法必挂的用例）
- 5 万组随机（含 0/负数/全正/全负）0 不一致
- 边界：单元素 [-5] → -5、全负 [-1,-2,-3] → 6、含0 → 0、两负 [-2,-1] → 2 ✅
