# 152. 乘积最大子数组 · 解析（二刷）

## 一、核心思路：双状态 DP（负负得正）

**问题**：找乘积最大的连续子数组（至少一个元素）。

**关键洞察**：乘法与加法的本质区别——**负数会把大小关系翻转**。看反例：

```
nums = [-2, 3, -4]
以第2个数结尾（3）的最大乘积：3（最优 3，不是 -6）
以第3个数结尾（-4）的最大乘积：(-2×3)×(-4) = 24  ← 来自"最小的" -6 翻成"最大的"
```

只维护"最大"一个状态，到 -4 会拿 3×(-4)=-12——答案却是从最小状态翻出来的 24。**所以必须 max/min 双轨同步推进。**

## 二、转移方程（三个候选）

```
max_prod[i] = max(nums[i],  max_prod[i-1]*nums[i], min_prod[i-1]*nums[i])
min_prod[i] = min(nums[i],  max_prod[i-1]*nums[i], min_prod[i-1]*nums[i])
```

三个候选的物理意义：
1. **nums[i] 自己**——前面乘积是 0/负到没法要了，重新开一段；
2. **× 前段最大**——nums[i] 为正，延续"最好"；
3. **× 前段最小**——nums[i] 为负，把"最差"翻盘成"最好"（本题灵魂）。

## 三、代码（用户 AC 版：滚动双状态）

```python
result = dp_max = dp_min = nums[0]
for i in range(1, len(nums)):
    r1 = dp_max * nums[i]
    r2 = dp_min * nums[i]
    result = max(nums[i], r1, r2, result)   # 全局答案（可任意位置结尾）
    dp_max = max(nums[i], r1, r2)           # 同一轮内 r1/r2 用的是旧值 → 先算后更新
    dp_min = min(nums[i], r1, r2)
return result
```

## 四、⚡ 两个必踩的坑

1. **旧值顺序**：`dp_min` 的候选要用**更新前**的 `dp_max`——所以先 `r1 = dp_max*x`、`r2 = dp_min*x` 存下来，再更新两个状态（不存在"用新值污染"）；
2. **答案是全程 max 的 result**，不是最后时刻的 dp_max——最大子数组可以以任意位置结尾（`[1,-2]` 答案 1 在第 0 位，不是末尾的 dp_max=-2）。

**0 的处理**：候选里有 `nums[i]` 自己兜底——乘 0 大不了重新开始，不会全盘崩（`[-2,0,-1]` → 0 正确）。

## 五、复杂度

- 时间：O(n)，空间：O(1)（滚动；数组版 O(n)）
