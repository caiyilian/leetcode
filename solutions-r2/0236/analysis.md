# 236. 二叉树的最近公共祖先 · 解析（二刷）

## 一、核心思路

最近公共祖先（LCA）：p、q 离根最远的共同祖先。二叉树上两个节点 p、q 的 LCA 就三种情况：
1. **p、q 分别在当前节点的左右子树** → 当前节点就是 LCA；
2. **p 是 q 的祖先（或反过来）** → 这个祖先就是 LCA；
3. 都在某一边 → 递归进那一边。

```
      3            p=5(左), q=1(右) → 分居两侧 → LCA=3
     / \
    5   1          p=5, q=4(都在5的子树) →    LCA=5
   / \
  6   2
      /\
     7  4
```

## 二、官方解法一：递归返回节点（⚡ 机考 10 行版）

```python
def lowestCommonAncestor(self, root, p, q):
    if not root or root is p or root is q:
        return root                 # 空 / 遇到目标 → 返回（自己可能是答案）
    l = self.lowestCommonAncestor(root.left, p, q)
    r = self.lowestCommonAncestor(root.right, p, q)
    if l and r:
        return root                 # 左右都有 → 当前是 LCA
    return l or r                   # 有一侧 → 返回那一侧（可能是 p/q 或 LCA）
```

**为什么对**：递归是"自底向上"的，`l and r` 出现的**第一个（最深的）节点**就是 LCA。p 是 q 祖先时，`not root or root is p` 直接返回 p——不会继续往下，天然正确。

## 三、用户解法：后序计数法（等价变体）

思路同官方，只是用"个数"代替"返回节点"：

- `fun(root)` 返回子树里 p、q 出现的个数（0/1/2）；
- 后序自底向上，**第一个凑齐 2 的节点 = LCA**；
- 自己就是 p/q 时 +1（配合一侧已找到的另一目标）。

**与官方递归本质相同**（都是后序自底向上 + 第一个"两边都有"判定），但：
- ✅ 对拍正确、思路自洽；
- ⚠️ 代码更绕（全局 result + 计数），不如官方 10 行直观。

## 四、复杂度

- 时间：O(n)
- 空间：O(h)（递归栈）

## 五、一刷 vs 二刷

- 一刷（9-15）：官方递归 10 行 AC ×3（⚡机考复习标记）；
- 二刷（10-25）：自创后序计数法一次 AC——等价但绕；**机考复习仍推荐官方递归版**（归档两份都留）。
