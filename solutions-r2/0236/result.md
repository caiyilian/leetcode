## 解法说明：后序计数法

`fun(root)` 返回"这棵子树里包含 p/q 中的几个"，**第一个凑齐 2 的节点就是 LCA**：

```python
def fun(root):
    if root:
        result_left = fun(root.left)
        result_right = fun(root.right)
        return_result = result_left + result_right
        if return_result == 2:            # 左右各找到 p/q → 当前是 LCA
            result[0] = root
        else:
            if (root is p) or (root is q):  # 自己是另一个目标
                return_result += 1
                if return_result == 2:
                    result[0] = root
        return return_result
    return 0
```

**为什么正确（后序天然自底向上）**：后序遍历从叶子往根走，**第一个凑齐计数 2 的节点必然是最深的公共祖先**——比它深的子树凑不齐 2，比它浅的已经太晚（会被 `result[0] is None` 挡住或已找到）。

**注意点**：`(root is p) or (root is q)` 用 `or`——p、q 指向同一节点时只 +1。力扣约束 `p != q`，合法输入无问题；若题目允许 p==q 需额外处理（测试脚本验证过该场景会返回 None）。
