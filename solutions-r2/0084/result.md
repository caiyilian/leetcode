## WA→AC 灵魂差异（必须记住）

```python
# WA：area = now_value * (i - now_index)      ← 错
# AC：area = now_value * (i - stack[-1] - 1)  ← 对
```

**结算柱子 now_index 的宽度 = 左右第一个比它矮的柱子之间的距离**：
- 右边第一个更矮 = 当前 `i`；
- **左边第一个更矮 = 弹掉它之后的新栈顶**（栈单调增，栈顶下全是 ≤ 它的）。

`i - now_index` 只算了"从自己到右界"，**丢掉左边能撑的柱子**——2 万组对拍 WA 版错 9457 组实证。

## 是否最优解？✅ 是

| 考察点 | 结论 |
