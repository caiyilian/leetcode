# 84. 柱状图中最大的矩形 · 解析（二刷）⚡机考复习

## 一、核心思路：单调栈 + 结算时机

**问题本质**：对每个柱子，求"以它为高能撑起的最宽矩形" = 它左右两边**第一个比它矮**的柱子之间的距离 × 它的高度。

**单调栈（递增）** 的作用：栈里存下标，柱高单调递增。**遇到更矮的柱子时**，栈顶柱子"撑到头了"（右边第一个更矮出现了）→ 弹出结算。

```
heights = [2,1,5,6,2,3]
i=2(5) i=3(6) i=4(2)：6 比 2 高 → 弹 6 结算：宽 = 4-2-1 = 1 → 6×1=6
                     再弹 5 结算：宽 = 4-1-1 = 2 → 5×2=10 ✅ 最大
```

**宽度公式（本题灵魂）**：

```
area = heights[now] × (i - stack[-1] - 1)
                  ↑        ↑         ↑
                弹出柱高  当前i(右界) 新栈顶(左界)
```

- `i` = 右边第一个比它矮的柱子（当前遍历位置）；
- `stack[-1]` = 弹掉后新的栈顶 = 左边第一个比它矮的柱子；
- **不是 `i - now_index`**——那只是"从自己到右界"，漏掉了左边所有能撑到它的柱子（实证 2 万组 9457 组错）。

## 二、哨兵：为什么 `[0] + heights + [0]`

| 哨兵 | 作用 | 为什么需要 |
|------|------|-----------|
| **头 0** | 结算时 `stack[-1]` 永不越界 | 弹到栈空时，`stack[-1]` 是头哨兵 0 的下标，宽 = i-0-1 仍正确 |
| **尾 0** | 遍历结束强制结算所有剩余柱子 | 0 比任何柱都矮，最后一定触发全部弹出 |

**对比 42 接雨水**：42 弹出条件是"遇更高"，尾 0 永不触发 → 无用（你二刷 42 时问过）；84 弹出条件是"遇更矮"，尾 0 是**必须的**（否则最后单调递增的柱子欠结算）。

## 三、复杂度

- 时间：O(n)——每个下标入栈一次、出栈最多一次
- 空间：O(n)——栈

## 四、一刷 vs 二刷

- 一刷（9-17）：单调栈定稿；
- 二刷（10-17）：WA（宽度公式）→ AC，**把"左界=新栈顶"这个最核心公式自己踩出来**——2 万组对拍实证 WA/AC 差异。踩坑后对"结算谁就看谁的左右矮邻"理解更扎实。

## 六、一句话记住

> **单调递增栈遇更矮弹栈结算：宽 = i（右矮邻）- 新栈顶（左矮邻）- 1；`[0]+heights+[0]` 双哨兵（头兜空、尾清栈）。O(n)。**
