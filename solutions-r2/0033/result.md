## 解法核心：先判"有序半段"，再区间定位

**旋转数组特性**：`mid` 把数组切成两半，**至少有一半是有序的**。判断 target 是否落在那半：

```
nums = [4,5,6,7,0,1,2]    target = 0
mid=3 → nums[3]=7
nums[left]=4 <= nums[mid]=7 → 左半 [4,5,6,7] 有序
  4 <= target(=0) < 7 ? 否 → target 不在左半 → left = mid+1
  现在 [0,1,2]，mid=1 → nums[1]=1，右半 [1,2] 有序… → 找到 0
```

**标准写法（推荐）**：
```python
while left <= right:
    mid = (left+right)//2
    if nums[mid] == target: return mid
    if nums[left] <= nums[mid]:                    # 左半有序
        if nums[left] <= target < nums[mid]:       # target 在左半内
            right = mid - 1
        else:
            left = mid + 1
    else:                                          # 右半有序
        if nums[mid] < target <= nums[right]:      # target 在右半内
            left = mid + 1
        else:
            right = mid - 1
return -1
```

**只需两路**（左半有序 / 右半有序），每次用"区间包含"判定去留。
