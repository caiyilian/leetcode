## 用户疑问解答：为什么 if 多却运行时间很短？

**if 判断是常数级附加，不改变复杂度**：
- for 循环体（真正干活）：每个元素执行一次 → 总 **O(m×n)**；
- if 守卫（步间检查）：每条边执行一次 → 总 O(层数) ≈ O(min(m,n))，**远小于 m×n**。

力扣判的是**复杂度量级**（O(m×n) 即最优），不是"写了几个 if"——4 个 if 和 0 个 if 都是 O(m×n)。"判断多 ≠ 慢"。
