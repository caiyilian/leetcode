# 54. 螺旋矩阵 · 解析（二刷）

## 一、核心思路：四边界收缩

用 `top/bottom/left/right` 四个变量圈住**还没遍历的区域**，按固定顺序收割：

```
右→下→左→上（循环），每收完一条边，对应边界向内缩一格
```

```
    left        right
   top ╔═════════════╗
       ║ ①→→→→→→→→→ ║
       ║ ↓           ↓ ║
       ║ ④   区域   ② ║
       ║ ↓           ↓ ║
  bottom╚←←←←←←←←←←←╝
           ③
```

```python
while right >= left and bottom >= top:          # 区域还活着
    for j in range(left, right+1): result.append(matrix[top][j])   # ① 上
    top += 1
    if bottom >= top and right >= left:
        for i in range(top, bottom+1): result.append(matrix[i][right])  # ② 右
        right -= 1
    if right >= left and bottom >= top:
        for j in range(right, left-1, -1): result.append(matrix[bottom][j])  # ③ 下
        bottom -= 1
    if bottom >= top and right >= left:
        for i in range(bottom, top-1, -1): result.append(matrix[i][left])  # ④ 左
        left += 1
```

**为什么 ① 前面不用检查**：while 条件已保证进入时区域非空；
**为什么 ②③④ 要检查**：每收一条边后边界收缩，区域可能在"中途"变空（如只剩一行的矩阵，① 收完就空了）——不检查会重复收割已收区域（实践：曾产出重复的 6）。

## 二、为什么"if 多但时间快"（复杂度观）

**分清楚两个量**：

| 动作 | 执行次数 | 量级 |
|------|---------|------|
| for 循环体（append 元素） | 每个元素 1 次 | **O(m×n)**（大头） |
| if 守卫（步间检查） | 每条边 1 次 | O(层数) ≈ O(min(m,n))（小头） |

整体 = O(m×n) + O(min(m,n)) = **O(m×n)**——if 只是常数级附加，量级不变。
**力扣判复杂度量级不判代码行数；O(m×n) 是本题下界（必须访问每个元素），达到即最优**。

## 三、复杂度

- 时间：O(m×n)
- 空间：O(1) 额外（结果数组不算）

## 四、两种解法对比

| 方法 | 思路 | 代码量 | 备注 |
|------|------|--------|------|
| **四边界收缩（用户二刷）** | 4 个边界收割收缩 | ~15 行 | 标准最优，推荐 |
| 方向数组模拟（一刷） | dir 索引 + visited/边界数组 | ~30 行 | 思路直观但代码长，易错 |

## 五、一刷 vs 二刷

- 一刷（9-13）：方向数组 + dir_max 四边界数组，4 个 if/elif 分支，代码长且丑；
- 二刷（10-17）：**用户主动求简洁写法** → 四边界收缩，调试"重复 6"后补齐步间检查，一次 AC。
