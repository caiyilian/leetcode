# 31. 下一个排列 · 解析（二刷）

## 一、题目

- 中文：下一个排列
- English：Next Permutation
- 难度：中等（"背模板"型经典题，字典序）
- 要求：**原地修改**（不返回）、O(1) 额外空间；已是最大排列时返回最小排列

## 二、核心思路：三步模板（从右往左）

**问题**：给定排列（可含重复），求字典序上"恰好大一点"的排列。

**为什么能 O(1) + 原地**：排列的"变与不变"有结构——右侧尽量保持降序不变，只动左边一个关键点：

```
① 从右往左找第一个升序对 nums[i-1] < nums[i]
   → i-1 就是要动的"关键位"（它的右边都是降序，再往右没有可增空间）
② 在右侧降序段里找"最小的大于 nums[i-1] 的数"，与 nums[i-1] 交换
   → 换过来的数比 nums[i-1] 稍大，排列变大了一点
③ 反转 nums[i:]（降序 → 升序）
   → 右侧变最小，保证这是"恰好下一个"（而不是更大一截）
全降序（找不到升序对）→ 整个反转 = 最小排列
```

## 三、两步优化点（⚡ 本次 WA + 自觉）

1. **等号边界（v1 WA 的坑）**：步骤②在右侧找目标时，要用 `<=` 跳过**等于** nums[i-1] 的元素（`[1,5,1]` 这类重复值会选错）。标准写法：`while nums[j] <= nums[i]: j -= 1`，交换 `nums[j]`——从右往左第一个 `>` 的就是目标；
2. **O(1) 空间自觉（v2→v3）**：`sorted(nums[i:])` 能 AC 但申请 O(n) 辅助空间，**不满足进阶要求**；降序段反转 = `reversed` / 双指针，严格 O(1)。题目明说"常数空间"，这两处都得用原地操作。

## 四、代码要点（标准三步 vs 用户写法）

| 步骤 | 标准写法（SolutionStd） | 用户写法 |
|------|------------------------|---------|
| ① 找 i | `while i>=0 and nums[i]>=nums[i+1]: i-=1` | `while index>0: if nums[index-1]<nums[index]` |
| ② 交换 | 右侧从右扫第一个 `>nums[i]` | 从左扫第一个 `<=` 的前一个 + else 兜底 |
| ③ 反转 | `nums[i+1:] = reversed(...)` | 双指针 while |

两版等价（对拍 5 万组 0 不一致），标准版更短、面试好背；用户版逻辑自洽且同样 O(1)。

## 五、复杂度

- 找 i：O(n)；找交换位：最坏 O(n)；反转：O(n) → 总 **O(n)**
- 空间：**O(1)**（只用了索引变量）

## 七、一句话记住

> **31 = 三步：从右找升序对 i-1 → 右侧找第一个 > nums[i-1] 交换（⚡ 跳过相等用 <=）→ 反转右侧；全降序则整体反转；⚡ 原地 O(1) 空间（反转用双指针，别用 sorted）。**
