## 解法核心：二分"短数组的切分点"

**关键思想**：把两个数组各切成左半/右半，并让**左半合计 = 右半合计（或左半恰多 1 个）**。中位数由左半最大值 / 右半最小值决定——只要左半最大 ≤ 右半最小就行。

**只在短数组 nums1 上二分切分点 i**（nums2 的切分点 j 自动算出）：
```python
# 保证 m <= n（在短数组上二分，复杂度 log min(m,n)）
if m > n:
    nums1, nums2 = nums2, nums1
    m, n = n, m

half_length = (m + n + 1) // 2    # 左半元素总数（奇数时左半恰多 1，中位数在左半）
left, right = 0, m
while left <= right:
    i = (left + right) // 2        # nums1 左半取 i 个
    j = half_length - i            # nums2 左半取 j 个 ← 自动约束
    # 四个边界值（越界用 ±inf 占位）
    A1 = nums1[i-1] if i > 0 else -inf   # nums1 左半最大
    B1 = nums2[j-1] if j > 0 else -inf   # nums2 左半最大
    A2 = nums1[i] if i < m else inf      # nums1 右半最小
    B2 = nums2[j] if j < n else inf      # nums2 右半最小

    if A1 > B2:          # ↑ 往左移
        right = i
    elif B1 > A2:        # ↓ 往右移
        left = i + 1
    else:                # ★ 平衡：左半最大 <= 右半最小
        if (m+n) % 2 == 0:
            return (max(A1,B1) + min(A2,B2)) / 2   # 偶数取平均
        return max(A1, B1)                          # 奇数取左半最大
```

**要点**：
- 交换使 `m <= n` → 二分只在短的上面跑，复杂度 O(log min(m,n))；
- `j = half - i` **不要减 1**（切分点定义：左半包含前 i/j 个）；
- 越界（i=0 / i=m / j=0 / j=n）用 ±inf——保证比较恒成立、不越界报错；
- 奇数时左半多 1 个 → 中位数 = `max(A1,B1)`；偶数 → 两个中间值平均。

## ⚡ 用户发现：while 永远不自然退出（平衡点唯一性保证）

**现象**：对拍 5 万组，`left > right` 的自然退出**一次都没发生**——全部在循环体内 else 分支 return。

**为什么**（数学保证，不是巧合）：
1. **平衡切分存在且唯一**（两个有序数组的中位数分割唯一）；
2. **三分支互斥且完备**：切大（往左）/切小（往右）/平衡（返回）必居其一；"切大+切小"同时成立会推出 `A[i-1] > A[i]`，与有序性矛盾；
3. 本实现用 `right = i`（**保留 mid**）而非 `right = i-1`——区间永远包含平衡点 i\*，最终收敛到 i\* 时 else 必命中。

**结论**：这版 while 条件（`left <= right`）理论上安全，但**面试时 "while 为什么能停" 容易被追问**——更常规、无需解释的写法是 `right = i - 1`（归档附 SolutionStd）。两者等价，推荐面试用标准版防杠。

## 边界

- **空数组**：`[] + [1]` → 1；力扣约束 `1 <= m+n`，双空不在测试集（双空时用户版返回 nan，无碍）；
- 全等数组 `[1,1,1]+[1,1,1]` → 1.0 ✓。
