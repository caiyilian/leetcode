# 4. 寻找两个正序数组的中位数 · 解析（二刷·困难）

## 一、核心思路：二分"短数组切分点"，另一数组自动约束

**目标**：O(log(m+n)) 内找两个有序数组合并后的中位数（不让真的合并，否则 O(m+n)）。

**关键模型**：把两个数组各切成左右两半，让 **左半总数 ≥ 右半总数（奇数恰多 1）**，且 **左半最大值 ≤ 右半最小值**——此时中位数只取决于切点附近的 4 个值：

```
nums1: [...切点...]  |  [...]
nums2: [...切点...]  |  [...]
        └─ 左半 k 个 ─┘  └─ 右半 ─┘
切点满足：max(左半) <= min(右半)
```

**为什么只二分短数组**：nums1 的切分点 i（0~m）定了，nums2 的 j = k - i 就自动算出来（总数约束）——切分点是**一维**的，二分它 O(log m)；让 m 是短的 → O(log min(m,n))，这是题目要求的最优复杂度。

## 二、代码（用户 AC 版）

```python
if m > n: nums1, nums2 = nums2, nums1; m, n = n, m   # 保证 m 是短的

k = (m + n + 1) // 2            # 左半总数（奇数时左半多 1）
left, right = 0, m
while left <= right:
    i = (left + right) // 2
    j = k - i

    A1 = nums1[i-1] if i > 0 else -inf    # nums1 左半最大
    B1 = nums2[j-1] if j > 0 else -inf    # nums2 左半最大
    A2 = nums1[i]   if i < m else  inf    # nums1 右半最小
    B2 = nums2[j]   if j < n else  inf    # nums2 右半最小

    if A1 > B2:      right = i            # nums1 拿多了 → 左移
    elif B1 > A2:    left = i + 1         # nums1 拿少了 → 右移
    else:                                  # 平衡！
        # 奇数: max(A1,B1)；偶数: (max(A1,B1)+min(A2,B2))/2
```

## 三、⚡ 三个易错点（本次/常见踩坑）

1. **`k = (m+n+1)//2` 不是 `(m+n)//2`**：`+1` 让奇数时左半恰好多 1 个元素，中位数直接是左半最大——避免去讨论"中位数在左还是右"；
2. **`j = k - i` 不要减 1**：切分 i 定义为"左半含 nums1 前 i 个"，j 同理，两者相加 = k；
3. **越界用 ±inf**：i=0（nums1 左半空）/ i=m（nums1 右半空）/ j=0 / j=n 都要占位，否则访问越界；±inf 让不等式恒成立。

## 四、⚡ 用户深度观察：while 为什么从不"自然退出"？

- 实测 5 万组随机：`left > right`（自然退出）**0 次**，全在循环体 else 里 return；
- 原因：**平衡点唯一存在**（两个有序数组的中位数分割唯一），且三分支互斥完备（切大/切小/平衡，前两者不可能同时成立，否则推出 `A[i-1] > A[i]` 与有序矛盾）；
- 本实现 `right = i`（保留 mid）进一步保证平衡点永远不被排除 → 循环必然走到 else 返回。

**面试提示**：这个写法正确但"while 永不退出"反直觉，面试官可能追问。更通用的写法是 `right = i - 1`（标准二分，归档有 SolutionStd）——逻辑等价，但"循环一定收敛并自然退出"更符合大众二分认知。**推荐面试写 `right = i-1` 版**，本地/刷题用哪版都行。

## 五、复杂度

- 时间：O(log min(m,n))（二分短数组）
- 空间：O(1)

> **双数组中位数 = 二分短数组切分点 i（保证 m<=n），j=k-i 自动算出；k=(m+n+1)//2；平衡判左半最大<=右半最小（±inf 占越界）；奇数返回左半最大、偶数取平均；⚡ right=i 版永不自然退出，面试用 right=i-1 更常规。**
