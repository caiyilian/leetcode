# 621. 任务调度器 · 解析（二刷 ⚡⚡⚡ 重点复习）

## 一、核心思路：以"最高频任务"为骨架的贪心公式

**问题**：任务列表（同种任务必须间隔至少 n 个单位），求最短完成时间（可插 idle 冷却坑）。

**关键洞察**：出现次数最多的任务（max_count）决定了**下界**——它每出现一次，下一次必须隔 n 格。把它排成"轮"：

```
轮1: [X] [坑] [坑] ... [坑]     ← X = 任一最高频任务，后面 n 个冷却坑
轮2: [X] [坑] [坑] ... [坑]
…（共 max_count-1 轮）
尾:  [X] [Y] ...                ← 并列最高的 count_max 种任务各 1 个收尾
```

- 前 `(max_count-1)` 轮：每轮 `1 + n` 格 → `(max_count-1)*(n+1)`
- 末尾：`count_max` 格（最高频的那几种，最后 1 个各出现 1 次）
- 公式：**`(max_count-1)*(n+1) + count_max`**

**冷却坑里优先放其他任务**（不放 idle），所以这个公式给出了"带冷却约束的最短长度"。

## 二、⚡⚡⚡ 必踩的坑：漏掉 `len(tasks)` 兜底

**公式是"下界建模"，不是"精确答案"**——当其他任务足够多、把冷却坑全部填满甚至富余时，真实排布**零 idle**，长度 = 任务总数，比公式短。

**反例（官方例2）**：`A,C,A,B,D,B`，n=1
- max_count=2（A、B 各 2 次），count_max=2
- 公式：`(2-1)*(1+1)+2 = 4` ❌
- 真实排布：`A→B→C→D→A→B` 共 6 格，零空闲 ✅
- 答案 = `max(4, 6) = 6`

**本质**：题面是"相同任务**至少**相隔 n"，不是"冷却坑恰好在每轮都占 n 格"。种类多时冷却坑被填充，时长收敛到任务总数。

## 三、代码（用户 AC 版）

```python
count = {}
max_count = 0
for c in tasks:
    count[c] = count.get(c, 0) + 1
    max_count = max(max_count, count[c])
count_max = sum(1 for v in count.values() if v == max_count)
return max(len(tasks), (max_count - 1) * (1 + n) + count_max)
```

## 四、复杂度

- 时间：O(n)（两次遍历；Counter 一行亦可）
- 空间：O(1)（任务类别 ≤ 26 种，计数字典常数大小）

## 五、复习锚点（下次 3 秒想起）

> **公式：`(max_count-1)*(n+1) + count_max`，最后必须 `max(公式, len(tasks))`。**
> 背：**"骨架=最高频，兜底=任务总数"**——公式是下界，答案不能短于任务数。
