# 17. 电话号码的字母组合 · 解析（二刷）

## 一、核心思路：回溯（DFS 逐层选字母）

每个数字对应一组字母（2→abc, 7/9→4 个，其余 3 个）。**逐位选一个字母，选完 n 位就是一个组合**：

```
digits = "23"
位0('2'): a────────b────────c
位1('3'): d e f    d e f    d e f
       → ad ae af bd be bf cd ce cf
```

这就是一棵多叉树的 DFS：每层选当前数字的一个字母，深到 `i == n` 收集结果，然后**撤销选择（pop）回溯**上一层继续。

## 二、代码（用户 AC 版）

```python
if not digits:
    return []                            # ⚡ 空串守卫（题目约定返回 []）
result = []
hash_map = {"2":"abc", ..., "9":"wxyz"}
length = len(digits)

def fun(i, path):
    if i == length:                      # 选完所有位 → 收集
        result.append("".join(path))
        return path
    for c in hash_map[digits[i]]:
        path.append(c)                   # 选这个字母
        path = fun(i+1, path)            # 递归下一层
        path.pop()                       # ★ 撤销选择（回溯）——试下一个字母
    return path

fun(0)
return result
```

**回溯三件套**（46 全排列同款）：① 先选（append）→ ② 递归（dfs）→ ③ 撤销（pop）。撤销是灵魂——不撤销，path 会越叠越长。

## 三、两个边界/习惯（⚡）

1. **空串守卫**：`digits = ""` 时若不加守卫会返回 `[""]`（v1 的 bug），题目要求 `[]`——**枚举类题目空输入是必测**；
2. **`path=[]` 可变默认参数**：本次因 append/pop 严格配平无恙，但这是 208 踩过的坑。规范写法：

```python
def fun(i, path):          # 显式传 path（dfs(0, []) 就叫 dfs(0, [])）
    ...
# 或
def fun(i, path=None):
    if path is None:
        path = []
    ...
```

## 四、复杂度

- 时间：O(4^n × n)——最坏 4 个字母/位（7、9），n 位；构造每个结果要 O(n)（join）
- 空间：O(n)——递归栈 + path

## 五、一刷 vs 二刷

- 一刷（9-16）：回溯 AC ×2；
- 二刷（10-29）：思路一次写对，**空串边界返回错 → 一行守卫修复 AC**——回溯模板掌握，边界意识继续强化（208 同源）。
