## ⚡ 本次踩坑：空串边界（隐藏用例隐患，已修）

```
输入 ""：正确结果 []
你的 v1：返回 [""]
```

**根因**：`digits=""` 时 `length=0`，`fun(0)` 直接 `i==length` 命中，`"".join([])` 得到空串。力扣约定空输入返回 `[]`。

**修复**（一行守卫）：`if not digits: return []`

**教训**：这类"枚举组合"题**空输入是必测边界**——和 208 一样，本地自测往往跳过空串，正是隐藏用例翻车点。

## ⚠ 另一个提醒：path=[] 可变默认参数（建议改）

```python
def fun(i, path=[]):   # 可变默认参数（208 同款坑）
```

**这次没炸是侥幸**：递归里 append/pop 严格配平，每次调用结束 path 回到空，默认值跨调用共享也没残留。但按 208 的教训，规范写法是 `def fun(i, path=None)` + 体内 `path = [] if path is None else path`，或 `dfs(i, [])` 显式传参。归档附了 SolutionClean 参考版。
