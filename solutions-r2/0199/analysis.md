# 199. 二叉树的右视图 · 解析（二刷）

## 一、核心思路：右视图 = 每层最右边的节点

从右侧看二叉树，能看到的就是**每一层最右边的那个节点**。所以解法退化为：层序遍历 + 收集每层最后一个节点。

```
    1         从右看：
   / \         第0层 → 1
  2   3        第1层 → 3（右边）
 / \   \       第2层 → 4
4   5   4      结果 [1,3,4]
```

**为什么"每层最右"就是答案**：右视图从左到右=从上到下，每个深度只能看到一个节点，就是该深度的最右节点（BFS 从左往右遍历，最后一个 = 最右）。

## 二、BFS 解法（用户 AC 版，官方解法一）

```python
if not root:
    return []
result = []
q = deque([root])
while q:
    for _ in range(len(q)):     # 按层快照（102 同款）
        node = q.popleft()
        if node.left:
            q.append(node.left)
        if node.right:
            q.append(node.right)
    result.append(node.val)     # ★ for 结束后 node = 本层最后一个 = 最右
return result
```

**核心洞察**：`for _ in range(len(q))` 循环结束后，`node` 变量恰好停在本层**最后一个**出队的节点——不用额外变量记录"最右"，循环外直接 `node.val` 就是答案。

## 三、另一种解法：DFS 右优先（空间 O(h) 更优）

```python
def dfs(node, dep):
    if not node:
        return
    if dep == len(res):       # 第一次到这个深度 = 最右（因为先走右）
        res.append(node.val)
    dfs(node.right, dep + 1)  # 先右
    dfs(node.left, dep + 1)   # 后左
dfs(root, 0)
```

**先右后左**：每层第一个访问到的节点必然是最右节点，`dep == len(res)` 判断"第一次访问该层"。

## 四、复杂度

- BFS：时间 O(n) / 空间 O(n)（队列最宽一层）
- DFS：时间 O(n) / 空间 O(h)（递归栈）

## 五、一刷 vs 二刷

- 一刷（9-15）：层队列 → deque 快照版（自驱优化）；
- 二刷（10-24）：直接复用快照版一次 AC——**102 按层快照的心法复用**。

## 六、关联题目

| 套路 | 相关题 |

| 按层快照 | **102 层序遍历**（同源）、104 最大深度（层数计数） |

## 七、一句话记住

> **右视图 = 每层最右节点：BFS 按层快照，for 结束后 node 就是本层最后一个，直接收集；或 DFS 先右后左，每层第一个即最右。**
