| 考察点 | 结论 |
|--------|------|
| 时间复杂度 | ✅ O(n)——每个节点访问一次 |

| 正确性 | ✅ 4 个手工用例（标准/单边/单节点/空树）+ 3 万组随机树对拍（vs DFS 右优先参照版）0 不一致 |

## 解法亮点

复用 102 层序遍历的按层快照套路，**唯一区别在取数**：

```python
while q:
    for _ in range(len(q)):   # 102 同款：按层快照
        node = q.popleft()
        ...
    result.append(node.val)   # ★ for 结束后 node = 本层最后一个节点 = 最右
```

**`for _ in range(len(q))` 循环跑完后，`node` 恰好停在本层最后一个节点**——它就是这一层的右视图（BFS 从左到右遍历，最后一个 = 最右边）。一刷踩过的"for 结束 node=本层最右"这个洞察，二刷直接复用。

## 另一种解法：DFS 右优先（面试可提）

```python
def dfs(node, dep):
    if not node:
        return
    if dep == len(res):      # 第一次到达该深度 = 最右节点（因为先走右）
        res.append(node.val)
    dfs(node.right, dep + 1)
    dfs(node.left, dep + 1)
```

先右后左 DFS，**每层第一个访问到的就是最右**——空间 O(h) 更省，是另一种标准解。
