# 53. 最大子数组和 · 解析（二刷）

## 一、DP 状态定义（这题的关键一步）

```
dp[i] = 以 nums[i] 结尾的最大子数组和
```

**为什么必须"以 i 结尾"**：加了这个约束，子数组才保证连续（要么自己开头，要么接着前面的最优尾巴）。

## 二、状态转移（两个选择取 max）

```
dp[i] = max(
    nums[i],              ← 选择 1：自己单干，从 i 重新开始（丢弃负数家底）
    dp[i-1] + nums[i]     ← 选择 2：接力，带上"前面攒下的最佳家底"
)
```

**大白话**：`dp[i-1]` 是家底，`nums[i]` 是今天的收入——家底是负数就白手起家，家底是正的就带上一起冲。

**答案** = `max(dp[0..n-1])`（最大子数组不一定以最后一个元素结尾）

## 三、DP 数组版（完整写法）

```python
dp[0] = nums[0]                            # 第一个数只能自己
for i in range(1, n):
    dp[i] = max(nums[i], dp[i-1] + nums[i])
return max(dp)
```

手推 `[-2, 1, -3, 4]`：

| i | nums[i] | dp[i] |
|---|---------|-------|
| 0 | -2 | -2 |
| 1 | 1 | max(1, -2+1) = 1 |
| 2 | -3 | max(-3, 1-3) = -2 |
| 3 | 4 | max(4, -2+4) = 4 |

答案 = max = **4** ✅

## 四、滚动变量版 = DP 空间压缩（本质等价）

```python
# 数学等价：max(nums[i], dp[i-1]+nums[i])
# 当 dp[i-1] <= 0 时，dp[i-1]+nums[i] <= nums[i] → max 必取 nums[i]

acc = 0
for i in range(len(nums)):
    if acc <= 0:          # dp[i-1] <= 0 → 单干
        acc = nums[i]
    else:                 # dp[i-1] > 0 → 接力
        acc += nums[i]
    result = max(acc, result)
```

| 写法 | 空间 | 本质 |
|------|------|------|
| dp 数组版 | O(n) | 完整 DP，记录所有状态 |
| 滚动变量版 | O(1) | 同一 DP，只留上一个状态 |

**面试讲法建议**：先讲 DP 数组版（状态定义 + 转移 + 为什么 max），再补一句"可以滚动压缩到 O(1)"——比直接甩滚动版更让人听懂。Kadane 就是滚动 DP 的名字。

## 五、复杂度

- 时间：O(n)（下界，必须看每个数）
- 空间：O(1)（滚动版）/ O(n)（数组版）

## 六、一刷 vs 二刷

- 一刷（9-12）：暴力 TLE → 看视频学 Kadane 独立写出（48ms/48%）；
- 二刷（10-15）：**凭记忆直接写出 Kadane**——DP 套路已是肌肉记忆；疑问"标签为何标 DP" → 讲解后确认"自己写的就是 DP"。
