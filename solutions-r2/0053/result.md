## 重要认知：滚动变量版 = 动态规划的"空间压缩"

用户凭记忆写的 Kadane **本身就是 DP**，只是把 dp 数组压成了一个变量：

```
DP 定义：dp[i] = 以 nums[i] 结尾的最大子数组和
转移：   dp[i] = max(nums[i], dp[i-1] + nums[i])     ← 单干 or 接力

用户代码：acc 扮演 dp[i-1]
  if acc <= 0: acc = nums[i]      ← dp[i-1]<=0 时 max 必取 nums[i]（数学等价）
  else:        acc += nums[i]     ← dp[i-1]>0 时接力
```

用户二刷时"想不出 DP 解法"，其实他记的 Kadane 就是 DP 的空间压缩形态——把 `dp[i] = max(单干, 接力)` 用 if/else 展开了。
