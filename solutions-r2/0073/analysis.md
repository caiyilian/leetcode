# 73. 矩阵置零 · 解析（二刷）

## 一、核心思路：用矩阵自身当标记（O(1) 空间的关键）

**问题**：知道了哪些行/列要置零，但"另存标记"需要额外空间。O(1) 空间的 trick 是——**只存到矩阵自己的第一行和第一列**：

```
第一行 → 记录"哪些列要置零"（matrix[0][j] = 0 表示第 j 列要被置零）
第一列 → 记录"哪些行要置零"（matrix[i][0] = 0 表示第 i 行要被置零）
```

**代价**：第一行/第一列被征用为"标记区"，它们自身的置零信息必须先抓拍保存（flag）。

## 二、四步流程

```
① 抓拍：flag_row = 第一行原本有 0？ flag_col = 第一列原本有 0？
         （否则标记阶段覆盖后，第一行/第一列自身的 0 信息就丢了）
② 标记：遍历内部 (i>=1, j>=1)，遇 0 → matrix[0][j]=0（第 j 列要零）+ matrix[i][0]=0（第 i 行要零）
③ 置零：遍历内部，若 matrix[0][j]==0 或 matrix[i][0]==0 → matrix[i][j]=0
④ 恢复：flag_row 为真 → 第一行全置零；flag_col 为真 → 第一列全置零
```

```python
flag_row = any(x == 0 for x in matrix[0])
flag_col = any(matrix[i][0] == 0 for i in range(m))
for i in range(1, m):
    for j in range(1, n):
        if matrix[i][j] == 0:
            matrix[0][j] = 0
            matrix[i][0] = 0
for i in range(1, m):
    for j in range(1, n):
        if matrix[0][j] == 0 or matrix[i][0] == 0:
            matrix[i][j] = 0
if flag_row:
    for j in range(n): matrix[0][j] = 0
if flag_col:
    for i in range(m): matrix[i][0] = 0
```

## 三、为什么 flag 抓拍是必须的（经典陷阱）

```
[[0,1],[1,1]]：第一行有 0
  ② 内部没有 0 → 标记区不变
  ④ 若没有 flag_row，第一行永远不会被置零 → 错！
```

**根本原因**：`matrix[0][0]` 既是"第 0 行的标记"又是"第 0 列的标记"，标记阶段可能把它改掉，原始信息就丢了。flag 在标记开始前"拍照存档"，最后按照片恢复。

**另一个角度**（用户一刷自悟）：置零逻辑里"标记格子本身的归宿已定"，不需要在标记阶段就处理第一行/第一列——留到最后按 flag 统一处理即可。

## 四、复杂度

- 时间：O(m×n)（两遍扫描，下界——每个格子至少要判断一次是否受影响）
- 空间：O(1)（额外只用了两个 flag 变量）

## 五、空间优化路线对比

| 方法 | 空间 | 思路 |
|------|------|------|
| set 收集行列（朴素） | O(m+n) | 记录所有含 0 的行/列集合 |
| **第一行/第一列标记（本题标准）** | **O(1)** | 标记存进矩阵自己，flag 抓拍首行首列 |
| 双标记变量老写法 | O(1) | 同上，但用两个变量存首行首列标志 |

## 六、一刷 vs 二刷

- 一刷（9-12）：set 版 → 协助写 O(1) 标记板版，用户自悟"标记格子归宿已定无需恢复"；
- 二刷（10-17）：**直接写出完整 O(1) 标记法一次 AC**——含 flag 抓拍这个最易漏的细节，理解已内化。

## 八、一句话记住

> **矩阵置零 O(1) 空间 = 第一行/第一列当标记区（行/列要置零就在首行首列打标），先抓拍首行首列自身 flag 再覆盖，最后按 flag 恢复。any() 判断比列表推导直白。**
