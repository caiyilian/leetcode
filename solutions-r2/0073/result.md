## 解法亮点：正确抓拍"第一行/第一列本身是否有 0"

**经典陷阱**：第一行/第一列在标记阶段会被覆盖成 0（当标记用），若先不记录，`matrix[0][0]` 同时承担"行标记"和"列标记"两个职责，信息会丢。
用户用 `flag_row`/`flag_col` 在标记开始前**抓拍真相**，最后恢复——四个边界用例全对，说明理解了而非背模板。

## 小改进（可选）

`not [r for r in matrix[0] if r == 0]`（列表推导+not）→ `any(x == 0 for x in matrix[0])`：
- any 语义直白（"是否存在 0"），且短路（遇第一个 0 即停），更高效。
