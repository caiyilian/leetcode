## 两次失败要记的教训

### RE（754750861）：辅助代码没贴全
- 力扣代码框里只有 class，`equ()` 函数定义和 `from collections import defaultdict` 漏了。
- **与 301 的 RE 同款坑**：所有辅助函数 + import 必须完整贴进代码框。

### WA（754750930）：状态变量没同步更新
- 找到更短窗口时只更新了 `result`，**漏了 `min_length = now_len`**。
- 后果：`min_length` 永远是 inf，后面所有 `if now_len < min_length` 全被挡下 → 只保留第一个结果。
- **通用教训**：`min_length` 是"状态变量"，更新结果时必须同步更新它——"记录结果"和"维护状态"是两件事，漏一个就坏。

## 是否最优解？

用户 AC 版：✅ 思路正确（右扩→左缩→记录），但 `equ()` 每次全扫字符集 → **O(n × |t|)**，力扣能过但不是严格 O(n)。
标准 missing 计数版：✅ **真 O(n)**——维护"还缺几个字符"计数，O(1) 判断，每个字符进出窗口各一次。
