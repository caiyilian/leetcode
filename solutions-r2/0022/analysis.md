# 22. 括号生成 · 解析（二刷）

## 一、核心思路：回溯 + 两个剪枝条件

**目标**：所有"合法"的 n 对括号。合法性 = 任意前缀中右括号数 ≤ 左括号数，且总左右相等。

**暴力做法**：枚举 2^(2n) 种括号组合再校验——指数级，浪费。

**回溯做法**：**边生成边剪枝**，两个条件保证生成的每一步都合法：

```
加左括号 (  ：左括号数 < n         （还没用完左括号）
加右括号 )  ：右括号数 < 左括号数   （不能超出左括号，否则前缀和 < 0）
```

```
n=2 的搜索树（合法前缀一路剪掉非法分支）：
             ""
          /      \
        "("       (✗ 右括号不能先出现)
       /   \
    "(("   "()"
    /        \
 "(()"      "())"→✗
  /
 "()()"    "(())"
```

**合法性由构造保证**——不用事后校验，这是它比暴力快一个量级的原因。

## 二、代码（用户 AC 版）

```python
def fun(path, num_left=0):
    if len(path) == 2 * n:                  # 填满 → 收集
        result.append("".join(path))
        return path
    if len(path) - num_left < num_left:     # 右括号数 < 左括号数 → 加 )
        path.append(")")
        path = fun(path, num_left)
        path.pop()
    if num_left < n:                        # 左括号数 < n → 加 (
        path.append("(")
        path = fun(path, num_left + 1)
        path.pop()
    return path
```

用户版用 `len(path) - num_left` 算出右括号数（只传一个计数参数）；标准版显式传 `left, right` 两个变量更直观：

```python
def dfs(path, left, right):
    if len(path) == 2*n: res.append("".join(path)); return
    if left < n:          path.append("("); dfs(path, left+1, right); path.pop()
    if right < left:      path.append(")"); dfs(path, left, right+1); path.pop()
dfs([], 0, 0)
```

**回溯三件套**（17 同款）：append → 递归 → pop；pop 撤销才能试下一个分支。

## 三、复杂度

- 时间：O(C_n)——卡特兰数 C_n = C(2n,n)/(n+1) 个结果（n=8 是 1430，n=20 约 6.5e9，指数不可避免但剪枝后只生成合法结果）
- 空间：O(n)——递归栈 + path

## 四、一刷 vs 二刷

- 一刷（9-16）：回溯 AC ×2；
- 二刷（10-29）：一次 AC，两个剪枝条件直接写对——**回溯骨架（17）复用成功**。

## 六、一句话记住

> **括号生成 = 回溯剪枝：左 < n 加 "("，右 < 左 加 ")"（合法性由构造保证，无需校验）——17 三件套 + 两个计数约束。**
