## 解法核心：两个剪枝条件

```python
if len(path) - num_left < num_left:   # 右括号数 < 左括号数 → 可以加 )
if num_left < n:                      # 左括号数 < n → 可以加 (
```

**合法性由构造保证**：右括号永远不超左括号（`right < left` 才加右）→ 前缀和恒 ≥ 0；左右都恰好 n 个 → 最终合法。**不需要事后校验**（比"生成全 2^2n 再判断"快得多的原因）。

用户用 `len(path) - num_left` 推导右括号数（少传一个参数）；标准版显式传 `left, right` 两个变量更直观（归档附 SolutionClean）。

## 边界

- `n=0` → `[]`（力扣约定，已处理）；
- `n=1` → `["()"]`。
