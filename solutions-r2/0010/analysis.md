# 10. 正则表达式匹配 · 解析（二刷）🏁 收官题 · 困难

## 一、题目

- 中文：正则表达式匹配
- English：Regular Expression Matching
- 难度：困难（双串 DP 巅峰）
- 规则：`.` 匹配任意单字符；`*` 匹配**前一个字符**出现 0 次或多次（注意：`*` 不单独出现，前面必有可量化字符）

## 二、核心思路：双串 DP（与 72/1143 同族）

**状态**：`fun(i, j)` = s 前 i 个字符与 p 前 j 个字符是否匹配（自顶向下，下标从末尾起）。

**转移（看末尾）**：
```
① p[j] 不是 '*'：
   fun(i,j) = 能对上（s[i]==p[j] 或 p[j]=='.'）且 fun(i-1, j-1)

② p[j] 是 '*'（它量化 p[j-1]）：
   fun(i,j) = fun(i, j-2)                     ← '*' 匹配 0 次（丢弃 p[j-1]*）
            or (能对上 p[j-1] 且 fun(i-1, j)) ← '*' 匹配 ≥1 次（s 消耗一个）
```

**和 72 编辑距离的对比**（一眼看穿）：
| | 72 编辑距离 | 10 正则匹配 |
|---|---|---|
| 状态 | dp[i][j] 最少编辑次数 | dp[i][j] 是否匹配 |
| 转移 | 等→继承 / 不等→min(3操作) | 字符→看前一对 / `*`→0次或多次 |
| 边界 | 首行首列 = 行列号 | dp[0][0]=True + `x*` 可消空 |

**`*` 的两分支**（`x*` 的完整语义）：
- **匹配 0 次**：p 里 `x*` 直接丢弃（p 退 2 格）→ `fun(i, j-2)`；
- **匹配 ≥1 次**：s 当前位得是 x（或 `.`）→ 消耗一个 s（s 退 1、p 不动）→ `fun(i-1, j)`。
两者是 **or** 关系——"能匹配 0 次或多次都行"。

## 三、⚡ TLE → AC 复盘：短路的艺术（本次最值钱）

```python
# TLE：消耗 s 的递归放 and 左侧 → 每条路径都真钻进
return fun(i, j-2) or (fun(i-1, j) and is_fit(i, j-1))

# AC：O(1) 判断放前面 → 对不上直接被短路，不递归
return fun(i, j-2) or (is_fit(i, j-1) and fun(i-1, j))
```

**本质**：`is_fit` 是 O(1) 字符比较，`fun(i-1,j)` 是整棵递归子树。`and` 左边为 False 时右边不执行——把"能早退的便宜判断"放 `and` 左侧 / `or` 右侧，昂贵递归尽量被短路。**这一条剪枝让无记忆化的递归从指数级变成可过（23ms）。**

**对比标准做法**：带 `@lru_cache` 的记忆化是本钱（O(mn) 状态），你的"短路剪枝"是技巧（靠早退）。记忆化更稳、面试更标准；但理解"为什么短路能救 TLE"本身就是对递归开销的深刻认识。

## 四、⚡ 易错点

1. **`*` 量化的是前一个字符**：`a*` 是一整个原子，转移时 p 要退 2 格（`j-2`），不是退 1 格；
2. **空串与 `x*`**：`dp[0][j]` 边界要允许 `x*` 消空（`""` 能匹配 `c*a*b`）——二维 DP 里用 `dp[0][j] = dp[0][j-2]` 预处理；
3. **`.*` 特判（可省）**：覆盖任意串，直接 True 是优化；不放也对；
4. **连续 `*`**：力扣测试集保证 `*` 前必有字符（不会出现 `**`），不需要处理。

## 五、复杂度

| 解法 | 时间 | 空间 |
|------|------|------|
| 记忆化递归（+lru_cache）| O(m·n) | O(m·n) |
| 用户短路递归（无缓存）| 最佳 O(m+n)，最坏指数（靠剪枝）| O(递归深度) |
| 标准二维 DP | O(m·n) | O(m·n) |
