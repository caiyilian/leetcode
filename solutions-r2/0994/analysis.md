# 994. 腐烂的橘子 · 解析（二刷）

## 一、题目

- 中文：腐烂的橘子
- English：Rotting Oranges
- 难度：中等（**多源 BFS** 经典题）
- 问题：网格中每分钟烂橘子会感染相邻（上下左右）的新鲜橘子，求全部腐烂所需分钟数；若有永远烂不到的鲜橘返回 -1

## 二、核心思路：多源 BFS + 分层扩算时间

**为什么是 BFS 而不是 DFS**：要求"最短时间"，而时间 = 扩散层数——**BFS 天然按层推进，每层恰好 1 分钟**。

**三个要素**：
1. **多源**：可能有多个烂橘子同时感染 → 初始把所有 `grid==2` 的位置全部入队（不能只从一个开始）；
2. **分层（⚡ 灵魂）**：`for _ in range(len(q))` 把"当前队列"固定为一层——这一层处理完 = 1 分钟，`result += 1` 即可，不用给每个格子存时间戳；
3. **鲜橘计数**：`num_one` 记录新鲜橘子数，被感染就 -1——**BFS 结束后 num_one > 0 说明有孤立鲜橘（被 0 隔开/无源），返回 -1**。

**为什么能在感染时改 grid**：一个鲜橘一旦被感染（从 1 变 2）就**立即入队**，且 `num_one -= 1`——不会重复处理（后续再遇到它时条件 `grid==1` 已不满足）。

## 三、代码要点（用户 AC 版）

```python
q = deque()
num_one = 0
for i in range(m):                    # ① 收集多源：所有烂橘入队 + 鲜橘计数
    for j in range(n):
        if grid[i][j] == 2: q.append((i, j))
        elif grid[i][j] == 1: num_one += 1

result = 0
while q and num_one:                  # ② 还有扩散源 && 还有鲜橘才继续
    for _ in range(len(q)):           # ⚡ ③ 分层：len(q) 固定这一层的扩散源
        i, j = q.popleft()
        grid[i][j] = 0                #    已处理的源标记掉（防重复）
        if i-1 >= 0 and grid[i-1][j] == 1:    # ④ 四方向感染
            grid[i-1][j] = 2
            q.append((i-1, j))
            num_one -= 1
        # ... j-1 / j+1 / i+1 同理
    result += 1                       # ⑤ 一层 = 1 分钟
if num_one: return -1                 # ⑥ 有鲜橘永远烂不到
return result
```

## 四、⚡ 易错点

1. **初始检查**：若一开始就没有鲜橘（`num_one==0`），答案为 **0**（不用任何分钟）——while 直接不进入、返回 result=0，天然正确；
2. **无烂橘**：q 为空 → while 不进入 → `num_one > 0` → 返回 -1 正确；
3. **感染后立即处理**：鲜橘被感染要**立刻** `grid=2 + num_one -= 1 + 入队`，三步缺一不可——漏掉 num_one 会算错时间、漏标记会重复感染；
4. **`grid[i][j] = 0` 的时机**：用户每层开头把当前源标 0（防它后面又被当鲜橘），也可不标（感染过的 2 不会被重复感染）——标了更严谨。

## 五、复杂度

- 时间：O(m×n)（每个格子最多出入队一次）
- 空间：O(m×n)（队列最大规模）
