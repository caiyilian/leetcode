# 543. 二叉树的直径 · 解析（二刷）

## 一、核心思路：直径 = 两腿相加，上传 = 单腿

**直径**：任意两节点间最长路径的**边数**（路径不必过根）。

**关键观察**：任何一条"直径路径"，必然在某个节点处**拐弯**——路径 = 该节点左子树的一条单链 + 右子树的一条单链。

```
      1            直径 3（边数）：4→2→1→3 或 5→2→1→3
     / \
    2   3          节点 2 处：左链(4) + 右链(5) = 2 条边
   / \
  4   5            过根 1：左链(2 的最深) + 右链(3) = 3 条边 ← 答案
```

所以对每个节点：
- **两腿**：`left单链 + right单链`（过当前节点的候选直径）→ 更新全局答案；
- **单腿**：`max(left, right) + 1`（自己向上走只能选一侧）→ 作为返回值喂父节点。

## 二、代码（用户 AC 版）

```python
result = [0]
def fun(root):
    if root:
        left = fun(root.left)
        right = fun(root.right)
        result[0] = max(result[0], left + right)   # 两腿：更新答案
        return max(left, right) + 1                # 单腿：喂父
    return 0
fun(root)
return result[0]
```

**⚡ 心法：递归返回值 ≠ 题目答案**——返回值是"单链高度"（只能走一侧），答案在全局变量里（两侧相加拐弯）。和 124 最大路径和完全同款（124 数权值和、543 数边数）。

## 三、边界口径

- **空树**：0（没有边）；
- **单节点**：0（没有边）；
- 每侧链长 = 边数（节点数 -1），所以 `left + right` 天然是边数口径，无需 +1/-1 修正。

## 四、复杂度

- 时间：O(n)
- 空间：O(h)（递归栈）

## 五、一刷 vs 二刷

- 一刷（9-14）：两腿/单腿 AC ×2（⚡ 重点标记）；
- 二刷（10-27）：一次 AC——**刚在 124 练过同骨架（10-24），543 直接复用**，心法内化。

## 七、一句话记住

> **直径 = 两腿更新答案、单腿喂父节点：left+right 更新全局最大，max(left,right)+1 返回；返回值是单链高、答案是两边拐弯——124 同款骨架（数边数口径）。**
