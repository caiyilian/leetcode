## 解法核心（⚡ 与 124 完全同款）

```python
def fun(root):
    if root:
        left = fun(root.left)     # 左子树最长单链
        right = fun(root.right)   # 右子树最长单链
        result[0] = max(result[0], left + right)   # 两腿：过当前节点 = 左链+右链（更新答案）
        return max(left, right) + 1                # 单腿：较长一侧 + 1（喂父）
    return 0
```

**关键心法：递归返回值 ≠ 题目答案**
- **返回值** = 单链高度（只能走一侧），喂给父节点；
- **答案** = 两腿相加（过当前节点拐弯），存全局 result。

**口径注意**：543 直径数**边数**（节点数 -1），所以空树返回 0，单节点返回 0，`left+right` 天然是边数口径（每侧链长 = 边数）。
