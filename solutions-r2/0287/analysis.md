# 287. 寻找重复数 · 解析（二刷）

## 一、题目

- 中文：寻找重复数
- English：Find the Duplicate Number
- 难度：中等（进阶：不能改数组 + O(1) 额外空间 + O(n) 时间）
- 约束：长度 n+1，值域 1..n，恰有一个数重复（可能重复多次，如 [3,3,3,3,3]）

## 二、核心思路：快慢指针（Floyd 判圈）——数组当链表

**关键洞察**：把数组看成一个"链表"——**`nums[i]` 是下标 i 指向的下一个节点**。因为值在 1..n，永远指向合法下标（不会越界），所以从任意点出发必有环：

```
[1, 3, 4, 2, 2]
0 → 1 → 3 → 2 → 4 → 2 → 4 → 2 ...
                 ╰─ 环：重复数 2 是环的入口 ─╯
```

**为什么重复数 = 环入口**：有两个下标都"指向"同一个值（重复出现）→ 该值有两条入边 → 它是环的入口。**这就是 142 环形链表 II 的模板**——找环入口。

**两阶段**：
```
第一阶段：快慢指针（快走两步、慢走一步），必在环内相遇
第二阶段：慢指针回起点，快慢同速走，再次相遇点 = 环入口 = 重复数
```

## 三、代码（用户重做 AC 版，值比较写法）

```python
left, right = nums[0], nums[nums[0]]        # 慢=走一步，快=走两步
while nums[left] != nums[right]:            # 找相遇点
    left = nums[left]
    right = nums[nums[right]]
left = 0                                     # 回起点
while nums[left] != nums[right]:             # 同速走，相遇 = 环入口
    left = nums[left]
    right = nums[right]
return nums[left]
```

**⚡ 用户写法特点**：比较 `nums[left] != nums[right]`（值的比较）而非 `left != right`（索引比较）——因为最终要返回的是**重复值**，值比较版少一步转换。语义与标准版等价（穷举 17203 组验证过），但**理解上容易绕**，面试建议写标准索引版（SolutionStd），思路更直白。

## 四、⚡ v1 归位法的坑（本次重做的原因）

**归位法**（交换 nums[i] 到 i-1 位，`nums[i] != i+1` 即重复）：答案对、时间 O(n)、但**交换修改了原数组** ❌——违反题目"**不能更改数组**"的进阶约束。

**教训**：力扣判题只校验返回值、不检测是否修改输入数组（287、283 moveZeroes 这类"原地"题是允许改的，但 287 明确说了**不能改**）。**提交 AC ≠ 满足全部约束**——面试时约束是硬指标，重做快慢指针正是对的。

## 五、复杂度

- 时间：O(n)（追及 + 二次相遇都是线性）
- 空间：O(1)（两个指针）
- 只读：不修改原数组 ✅
