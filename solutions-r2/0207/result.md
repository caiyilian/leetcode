| 考察点 | 结论 |

## ⚡ 用户解法 vs 标准 Kahn

**用户多轮扫描版**（正确，但不优雅）：
- 每轮扫全表找入度 0，学到就 `learned.add`，直到学不完或学完；
- 逻辑清晰（"每轮能学的课全学掉"），但 **O(n²)**。

**标准 Kahn（队列版，O(n+e)）**：

```python
indeg = [0] * numCourses
out = defaultdict(list)
for a, b in prerequisites:
    indeg[a] += 1
    out[b].append(a)
q = deque([i for i in range(numCourses) if indeg[i] == 0])   # 初始零入度
cnt = 0
while q:
    u = q.popleft()
    cnt += 1
    for v in out[u]:
        indeg[v] -= 1
        if indeg[v] == 0:       # 减到 0 立即入队，不用全量扫描
            q.append(v)
return cnt == numCourses        # 学完 = 无环
```

**差异本质**：用户版"每轮重新扫全表找零入度"，Kahn 版"**入度减到 0 就入队**"——用队列把 O(n²) 降到 O(n+e)，代码更短。

## 拓扑排序两板斧（面试必背）

| 方法 | 核心 | 复杂度 | 适用 |
|------|------|--------|------|
| **Kahn（BFS）** | 入度 0 入队，减到 0 再入 | O(n+e) | 判环/排课（207/210） |
| DFS 三色 | 灰-白-黑 检测回边 | O(n+e) | 判环（207 的另一解）/拓扑序 |
