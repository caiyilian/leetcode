# 581. 最短无序连续子数组 · 解析（二刷）

## 一、核心思路：找两个"乱序点"边界

**未排序区间的特征**：
- **右边界** = 最后一个"小于左边最大值"的元素位置——它右边所有元素都 ≥ 左边最大值，有序；
- **左边界** = 最后一个"大于右边最小值"的元素位置——它左边所有元素都 ≤ 右边最小值，有序；
- 中间 `[左边界, 右边界]` 就是必须排序的最小区间。

```
nums = [2, 6, 4, 8, 10, 9, 15]
            ↑           ↑
          左边界?    右边界=5（9<10 乱序）
  排序 [6,4,8,10,9] → 整个数组有序，答案 = 5
```

## 二、双向扫描（O(n)/O(1)）

```python
# 第一趟（左→右）：max_left = 左边已见过的最大值
#   nums[i] < max_left → i 是乱序点 → 更新右边界（取最后一个）
#   nums[i] >= max_left → 更新 max_left（相等也达标，不触发）
left = None; max_left = float('-inf')
for i in range(length):
    if nums[i] < max_left:
        left = i
    else:
        max_left = nums[i]
if left is None:          # 单调递增 → 全有序
    return 0

# 第二趟（右→左）：max_right = 右边已见过的最小值
#   nums[j] > max_right → j 是乱序点 → 更新左边界（取最后一个）
right = None; max_right = float('inf')
for i in range(length):
    if nums[length-1-i] > max_right:
        right = length-1-i
    else:
        max_right = nums[length-1-i]

return left - right + 1   # 右边界 - 左边界 + 1
```

**为什么"最后更新的位置"就是边界**：第一趟从左往右，每遇到乱序点就覆盖 left，结束时 left = 最后一个乱序点 = 区间的右端点（它右边全有序）；第二趟对称，right = 第一个乱序点 = 区间的左端点。

## 三、等号坑（一刷踩过、二刷直接写对）

**相等元素必须算进区间**。例：`[1, 3, 2, 2, 2]` → 排序后 `[1,2,2,2,3]`，未排序区间是 `[3,2,2,2]`（4 个元素）。

- 若用 `>` 判断：左扫时 `2 > 3`? 否 → 只标到 3 的位置（r=1），漏掉后面三个 2 → 答案错；
- 用 `>=`（用户版 `else` 分支的语义）：`2 >= 3`? 否 → 不更新 max_left，2 < max_left=3 → 触发 left 更新 → 三个 2 都被算进区间 ✅。

**一句话**：找边界时"达标"必须含相等（`>=` 才更新哨兵），"乱序"才触发边界更新（严格 `<`/`>`）。

## 四、复杂度

- 时间：O(n)（两次扫描，可并为一趟但分两趟更清晰）
- 空间：O(1)

## 五、三种解法对比

| 方法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 排序比较法（思路最直白） | O(n log n) | O(n) | clone 后排序，找第一个/最后一个不同 |
| **双向扫描（本题标准）** | **O(n)** | **O(1)** | 左右哨兵，本题最优 |
| 单调栈 | O(n) | O(n) | 等价的另一种写法，空间不如双向扫描 |

## 六、一刷 vs 二刷

- 一刷（9-25）：WA（等号）→ AC，2 万组对拍 AC 版 0 错、WA 版 4383 错实证；
- 二刷（10-16）：**凭记忆直接写出 O(n) 版，等号一次写对**——一刷的教训成了肌肉记忆（用户确认没偷看）。

## 八、一句话记住

> **找最后一个小于左最大值（右界）+ 最后一个大于右最小值（左界），答案 = 右界 - 左界 + 1；相等元素算达标（>= 更新哨兵），严格不等才触发边界。单调递增返回 0。**
