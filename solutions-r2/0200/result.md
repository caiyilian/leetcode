## 解法核心（洪水填充母题）

**遍历网格，遇到 `'1'` 计数 +1，然后把它所在的整片相连 `'1'` 全部置 `'0'`（淹没）**——下次遍历不会再碰到这片岛，天然避免重复计数：

```python
for i in range(m):
    for j in range(n):
        if grid[i][j] == '1':
            fun(i, j)      # DFS 淹没整片
            result += 1
```

**关键细节**：
- **原地置 0**：`grid[i][j] = '0'` 代替 visited 集合，省空间；
- **边界检查**：`i<0 or j<0 or i>=m or j>=n or grid[i][j]=='0'` 越界/海水直接返回；
- **四方向**：上/下/左/右（对角不算相连）。
