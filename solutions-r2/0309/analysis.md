# 309. 买卖股票的最佳时机含冷冻期 · 解析（二刷）

## 一、题目

- 中文：买卖股票的最佳时机含冷冻期
- English：Best Time to Buy and Sell Stock with Cooldown
- 难度：中等
- 特点：无限次交易，但**卖出后第二天不能买入**（冷冻期 1 天）

## 二、核心思路：四状态 DP（用户 AC 版）

**和 121/122 的区别**：冷冻期让"昨天卖了"和"昨天空仓观望"在今天的行为不同——必须区分"昨天刚卖"这个记忆，于是状态从 2 个变成 4 个。

**四个状态**（dp[i][s] = 第 i 天结束，处于状态 s 的最大收益）：

| 下标 | 状态 | 含义 |
|------|------|------|
| 0 | 持有 | 手里有股票 |
| 1 | 保持卖出 | 空仓、**非冷冻**（可以随时买） |
| 2 | 当天卖出 | 今天刚卖掉 |
| 3 | 冷冻 | 今天处于冷冻期（不能买） |

**转移方程**（每个状态只可能从哪些前一天状态来）：

```
持有   dp[i][0] = max(持有(继续拿), 保持卖出买入, 冷冻后买入)
                 = max(dp[i-1][0], dp[i-1][1]-prices[i], dp[i-1][3]-prices[i])

保持卖出 dp[i][1] = max(dp[i-1][1], dp[i-1][3])    ← 昨天空仓非冷冻，或昨天冷冻

当天卖出 dp[i][2] = dp[i-1][0] + prices[i]         ← 昨天必须持有

冷冻   dp[i][3] = dp[i-1][2]                       ← 昨天必须刚卖
```

**关键约束**（冷冻的本质）：
- **买入只能从"保持卖出"或"冷冻"来**——不能从"当天卖出"来（今天卖明天才能再买）；
- **卖出只能从"持有"来**；
- **冷冻只能由"当天卖出"产生**，冷冻结束自然进入"保持卖出"。

答案 = max(最后一天所有状态)（>最后一天不必持有，四种状态取最大）。

## 三、与标准三状态的等价关系

| | 四状态（用户）| 三状态（标准、滚动 O(1)） |
|---|---|---|
| 状态 | 持有/保持卖出/当天卖出/冷冻 | 持有 f0 / 刚卖冷冻 f1 / 空仓非冷冻 f2 |
| 买入来源 | 保持卖出 或 冷冻 | f2（空仓非冷冻，含冷冻结束后的）|
| 空间 | O(n)（可滚动优化）| O(1) |
| 直观性 | 状态拆得细，逻辑直白 | 代码短，但 f1/f2 定义较绕 |

**你的四状态版和一刷三状态版对拍等价**（3 万组随机 0 不一致）——四状态多两行，但可读性更好，面试讲状态图更清楚。

## 四、⚡ 易错点

1. **卖出后不能立刻买**：`dp[i][0]` 的买入来源**不能**包括 `dp[i-1][2]`（当天卖出）——三状态版的体现是 `f0 = max(f0, f2-prices[i])` 用的是**冷冻结束后的 f2**，不是 f1；
2. **dp[0] 初始化**：第 0 天只能"买入"（持有 = -prices[0]），其余状态 0；
3. **答案取 max 而非 dp[n-1][0]**：最后一天可以卖（当天卖出/保持卖出/冷冻）都比被迫持有好。

## 五、复杂度

- 时间：O(n)
- 空间：O(n)（四状态数组，可滚动到 O(1)，见 Solution3State）

## 六、关联题目：股票系列全家桶

| 题 | 场景 | 解法核心 |
|----|------|---------|
| **121** 一次交易 | 只能买卖一次 | 一次遍历记录最低价（⚡ 已做）|
| **122** 无冷冻无限次 | 任意次 | 贪心累加每段上涨（或 DP 持有/空仓两状态）|
| **309 本题** | 无限次 + 冷冻 1 天 | **三/四状态 DP**（卖出 → 冷冻 → 空仓）|
| **714** 含手续费 | 无限次 + 手续费 | 两状态 DP：买入时扣 fee |

**记忆锚点**：冷冻期 = 给"昨天刚卖"一个特殊状态 → 状态机从 2 态变 3/4 态；股票系列全都能用"持有/空仓(+/冷冻)状态机"统一理解。

## 七、一句话记住

> **309 = 股票状态机 + 冷冻态：买入只能从"空仓非冷冻"来，卖出后进冷冻，冷冻结束回空仓——四状态(持有/保持卖出/当天卖出/冷冻)或三状态(f0/f1/f2)等价，答案取最后一天所有状态 max。**
