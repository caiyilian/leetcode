## ⚡ 考前注意（用户标记：醍醐灌顶）

**238 的标准答案 = 输出数组当"前缀积" + 反向滚动后缀积变量**——"输出数组不算额外空间"是这道题最重要的 trick：

```python
result = [1]
for i in range(length - 1):
    result.append(result[-1] * nums[i])     # 第一趟：前缀积
R = 1
for i in range(length):
    result[length - i - 1] *= R             # 前缀积 × 后缀积
    R *= nums[length - i - 1]               # 后缀积滚动
return result
```

**核心洞察**：`ans[i] = nums[0..i-1] 的积 × nums[i+1..n-1] 的积`——前半用输出数组存，后半用一个变量滚动，空间从 O(n) 降到 O(1)。
