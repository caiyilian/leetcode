# 238. 除自身以外数组的乘积 · 解析（二刷）

## 一、核心洞察：一个答案 = 左半乘积 × 右半乘积

```
ans[i] = nums[0..i-1] 的乘积（左半边） × nums[i+1..n-1] 的乘积（右半边）
```

**不含除法**（题目禁止）→ 用"前缀积"和"后缀积"拼出每个位置的答案。

## 二、两种写法对比

### 写法 A：前后缀双数组（用户第一版，O(n) 空间）

```python
forward = [1]    # forward[i] = nums[0..i-1] 的积
backward = [1]   # 从右往左累计
ans[i] = forward[i] * backward[length-i-1]
```

思路清晰，但**两个辅助数组 = O(n) 额外空间**，不满足进阶要求。

### 写法 B：输出数组当前缀积 + 滚动后缀积（用户终版，O(1) 空间 ✅）

**关键 trick：输出数组不算额外空间**——让它先当"前缀积数组"，再反向遍历用一个变量滚动存后缀积：

```python
length = len(nums)
result = [1]
for i in range(length - 1):
    result.append(result[-1] * nums[i])     # 第一趟：result[i] = 前缀积
R = 1                                       # 第二趟：R = 当前后缀积
for i in range(length):
    result[length - i - 1] *= R             # 前缀积 × 后缀积 = 答案
    R *= nums[length - i - 1]               # 后缀积滚一个位置
return result
```

```
[1,2,3,4]：
  第一趟后 result = [1, 1, 2, 6]（前缀积）
  第二趟（从右往左）：
    i=0: result[3]=6×1=6 → R=1×4=4
    i=1: result[2]=2×4=8 → R=4×3=12
    i=2: result[1]=1×12=12 → R=12×2=24
    i=3: result[0]=1×24=24 → R=24×1=24
  结果 [24,12,8,6] ✅
```

**为什么反向遍历**：R 从最右边开始滚，`R = nums[i+1..n-1]` 的积——先乘进 ans[i]，再乘上 nums[i] 让 R 往左扩展一格。

## 三、为什么不能先算"全体乘积再除以自己"

题目**明确禁止除法**——而且数组含 0 时除法会崩（`[-1,1,0,-3,3]` 有 0，全体积 = 0，除以 0 无意义）。前缀积 + 后缀积天然免疫 0。

## 四、复杂度

- 时间：O(n)（两趟遍历）
- 额外空间：O(1)（不算输出数组）

## 五、一刷 vs 二刷

- 一刷（9-12）：WA → 4 版演进定稿 O(1) 版；
- 二刷（10-15）：第一版用了 O(n) 双数组（思路对但空间退步）→ 提示"输出数组不算额外空间"后**独立复现 O(1) 版**（23:03 AC）——trick 理解但未完全肌肉记忆，二刷提醒后捡回。

## 七、一句话记住

> **除自身乘积 = 前缀积 × 后缀积；输出数组先存前半，一个变量滚动存后半 → 额外空间 O(1)。禁止除法，前缀后缀天然免疫 0。**
