# 32. 最长有效括号 · 解析（二刷）困难题

## 一、题目

- 中文：最长有效括号
- English：Longest Valid Parentheses
- 难度：困难（括号系列巅峰，三种主流解法）
- 问题：**连续**的最长有效括号子串长度（注意是"子串"不是"子序列"，`')'` 可中断）

## 二、核心思路一：栈存下标（用户 AC 版 + 标准版）

**栈里存"下标"而不是字符**——这是匹配类问题的关键：既能配对，又能算长度（`i - 左边界`）。

**标准哨兵栈版（面试推荐）**：
```python
stack = [-1]                                # ⚡ 哨兵：栈底存"段起点前一位"
for i, ch in enumerate(s):
    if ch == '(':
        stack.append(i)
    else:                                    # ')'
        stack.pop()                          # 弹：可能是配对的 '('，也可能是哨兵/墙
        if stack:                            # 栈非空 → 配成了对
            best = max(best, i - stack[-1])  # 以新栈顶为左边界结算
        else:                                # 栈空 → 这个 ')' 是"墙"
            stack.append(i)                  # 它成为新段起点（入栈当下一个哨兵）
```

**为什么栈底总是"最后一个未匹配的右括号"**：无法配对的 `')'` 把前面的有效段"隔断"，它入栈后作为下一段的左边界——这就是"墙"的思想。

**用户 AC 版（left_num + start + 栈存 '(' 下标）**：思路等价，但用 `left_num` 计数 + `start` 段起点替代哨兵。结算时左边界要么是段起点前一位、要么是**栈顶剩余 '(' 的前一位**（见 result.md WA 复盘）——比标准版绕，但正确。

## 三、核心思路二：DP（dp[i] = 以 i 结尾的最长有效括号长度）

**两种转移**（只处理 s[i] == ')' 的位）：
```
① s[i-1] == '('：  dp[i] = dp[i-2] + 2              （成对 "()"）
② s[i-1] == ')'：  找匹配 '(' 在 i - dp[i-1] - 1 处
                   dp[i] = dp[i-1] + 2 + dp[i - dp[i-1] - 2]（内层 + 外层拼接）
```
**dp 思想**（双串 DP 之外的一维串 DP 示例）：能"拼接"（子问题合并）是 DP 的关键——`()(())` 里 2 和 4 能拼成 6。

## 四、⚡ 易错点（本次 WA 教训 + 通用）

1. **"子串"=连续**：`')'` 是天然的分隔符——它要么配对、要么当墙隔断；**不能跳过 ')' 去凑**（那是子序列题，如 1143）；
2. **结算用位置不用数量**（WA 根因）：残留 '(' 的"个数"和"位置"是两回事——按数量扣减会把残留 '(' 到当前 ')' 的区间误算成有效段（`'()(()'` → 4），必须按位置（栈顶/墙的下标）结算；
3. **哨兵 -1 免判空**：栈底 -1 让"栈空结算"变成天然处理，代码更稳；
4. **'(' 不结算**：只有 `')'` 会结束或延长一个有效段，`'('` 只入栈。

## 五、复杂度（三种）

| 解法 | 时间 | 空间 |
|------|------|------|
| 栈（用户/标准）| O(n) | O(n) |
| DP | O(n) | O(n) |
| 双指针计数（左右两遍扫）| O(n) | **O(1)**（进阶，可提）|

## 七、一句话记住

> **32 = 栈存下标 + 墙：栈底永远是最新"未匹配右括号"（墙），')' 配成对就用 i - 栈顶结算，栈空就自己当墙入栈；⚡ 结算按位置不按数量（残留 '(' 会污染 start 计数）；标准版 -1 哨兵打底，DP 版看 s[i-1] 两种转移。**
