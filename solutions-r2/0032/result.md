## ⚡ WA → AC 复盘（本次最值钱）

**WA 版**：`result = max(result, i - start + 1 - left_num)`——用 `start`（段起点）当左边界，再减去 `left_num`（剩几个 '('）。

**错在哪**（穷举长度≤12 找到 2096 个反例，如 `'()(()'`）：当段内既有"已配对的 ()"又有"残留没闭合的 '('"时，`i - start + 1` 把**残留 '(' 到当前 ')' 的整段**都算进去了，减 `left_num` 又只减数量、不减位置——位置和数量是两码事。`'()(()'` 被算成 4（把 0~3 的 `()((` 误当有效），正确是 2。

**AC 版修复**：`left_index = (start - 1) if left_num == 0 else stack[-1]`——左边界要么是段起点前一位（段内已无残留 '('）、要么是**栈顶剩余 '(' 的前一位**。这样结算窗口永远以"真正的 '(' 对"为边界，残留的 '(' 被排除在外，只算真正闭合成对的长度。**这是"位置感知" vs "数量扣除"的区别——必须按位置，不能按数量。**
