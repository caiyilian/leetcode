# 279. 完全平方数 · 解析（二刷）

## 一、核心思路：完全背包 DP（枚举最后一个平方数）

**问题**：n 最少由几个完全平方数相加得到。

**关键洞察**：凑 i 的**最后一块**一定是某个平方数 `j²`（j² ≤ i），前面部分是 `i-j²`。所以：

```
dp[i] = min( dp[i - j*j] + 1 )  ，j = 1..√i
dp[0] = 0，dp 初始 inf；答案 dp[n]
```

**这本质是"完全背包"**：每个平方数（1², 2², 3²...）是可重复使用的物品，求凑满容量 n 的最少件数——所以这题被归入 DP 背包经典，但实际还有更优解法。

## 二、⚡⚡ 性能坑：内层上界 n vs i（二刷实测 3938ms → 2538ms）

```python
# ❌ 初版：对每个 i 都扫满到 √n（i 小时大量白扫）
for j in range(n + 1):
    if j ** 2 > n: break

# ✅ 定稿：只扫 j² ≤ i（dp[i-j²] 下标非负才有意义）
for j in range(i + 1):
    if j ** 2 > i: break
```

**教训**：DP 内层上界要跟着**当前子问题 i** 走，别用全局 n——`dp[负数下标]` 是无效状态，为它花的时间全是浪费。同款坑还会出现在其他"枚举最后一块"的题里（如 322 零钱兑换改成 `j<=amount` 就慢）。

## 三、更优解①：BFS（图论视角）

**把 n 看作图的起点**，每次操作 = 减一个平方数 j²，目标是 0。求最短步数 = BFS 层数：

```
n=13：13 →(9)→ 4 →(4)→ 0    2 步 ✅
```

**四平方和定理保证答案 ≤4 → BFS 最多 4 层**，每层扩展 O(√n) 个邻居，总复杂度 O(√n · 4)，秒杀 DP。这是"最短路"思路，和 127 单词接龙同款。

## 四、更优解②：数学法（拉格朗日四平方和定理）

**答案只可能是 1/2/3/4**，分四步判定：

```
① n 本身是平方数           → 1
② 存在 a，n-a² 也是平方数    → 2（枚举 a 到 √n）
③ n = 4^k·(8m+7)          → 4（三平方定理推论：恰为 4 个)
④ 其余                    → 3
```

O(√n)，实测 <1ms（n=10⁵ DP 要 24s 时数学法 0ms）。

## 五、复杂度对照

| 方法 | 时间 | 空间 | 实测 n=10⁴ |
|------|------|------|-----------|
| DP（标准） | O(n√n) | O(n) | ~0.5s |
| BFS | O(√n) 层 | O(n) | ~ms |
| 数学法 | O(√n) | O(1) | <1ms |
