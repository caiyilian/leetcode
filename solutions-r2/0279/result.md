## ⚡⚡ 性能实证：一行改动，3938ms → 2538ms

你的初版把内层循环上界写成 `√n`（对每个 i 都扫满到 √n），即使 i=1 也要跑完 100 个 j。改成 `√i`（j²≤i）后，内层工作量从"恒为 √n"降到"随 i 增长"，总复杂度从 O(n√n) 的常数巨大版变成标准 O(n√n)。

```
v1（3938ms）：for j in range(n+1): if j**2 > n: break     ← 上界用 n
v2（2538ms）：for j in range(i+1): if j**2 > i: break     ← 上界用 i ✅
```

**同一个算法，同样的 O(n√n)，只因内层上界不同差了 1.5 倍。** 这是"复杂度对了但常数写飞了"的典型案例——`dp[i-j²]` 当下标小于 0 时毫无意义，别为不存在的状态浪费计算。

## 是否最优解？⚠️ DP 不是本题最优（但及格）

| 考察点 | 结论 |
|--------|------|
| 时间复杂度 | ✅ O(n√n)（标准 DP；但本题有更优解见下） |
| 空间复杂度 | ✅ O(n) |
| 正确性 | ✅ 官方 n=12→3、n=13→2 + **全量 n=1..2000 对拍**（vs 标准 while 写法）一致 |
| 更优解 | **BFS**（图最短步数）或**数学法**（四平方和定理，答案只可能 1/2/3/4，<1ms，~5000×） |

**力扣击败率低不全是常数问题，是 DP 不是本题最优解**：n≤10⁴ 时 BFS/数学法显著更快，Python 下 DP 都在 1~4s 量级（一刷你也 1.5~4.6s）。

## 解法核心

**关键洞察**：把"最少的完全平方数个数"看作 DP——凑出 i，最后一块一定是某个 `j²`，前面部分是 `i-j²`。

```
dp[i] = min(dp[i - j*j] + 1)  for j = 1..√i
dp[0] = 0，dp 初始 inf
```

```python
dp = [float('inf')] * (n + 1)
dp[0] = 0
for i in range(1, n + 1):
    for j in range(i + 1):
        if j ** 2 > i:
            break
        dp[i] = min(dp[i - j ** 2] + 1, dp[i])
return dp[n]
```

## 验证方式（对拍用）

标准 while 写法（`while j*j <= i`）作参照，全量 n=1..2000 逐一比对 0 不一致；边界 n=1→1、n=2→2、n=4→1、n=16→1 全对。
