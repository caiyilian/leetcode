## 解法核心：分层贪心（end/far）

**问题**：求最少跳跃次数（题目保证可达）。

**关键洞察**：把跳跃看成**按"层"覆盖**——
- 第 0 层起点 0，**覆盖范围 `[0, nums[0]]`**（第 1 跳可达）；
- 在第 1 层覆盖范围内任意点再跳，最远能到 `max(i+nums[i])` → 这是**第 2 层的右边界**；
- 层数 = 跳跃次数 → **BFS 按层遍历**。

```python
step = 0
far = 0    # 墙内所有格子能摸到的最远（下一层的墙）
end = 0    # 当前这层的墙（右边界）
for i in range(length - 1):
    far = max(far, nums[i] + i)   # 每步更新最远
    if i == end:                  # 踩到墙 → 这层走完，结算一步
        step += 1
        end = far                 # 墙推进到 far
return step
```

**为什么不是"每步选最远跳跃"**：每层内部所有格子都是"这一跳能到的"，**先走完一层再结算**才是"最少次数"——和"尽可能多覆盖"的每步贪心不同。

## ⚡ 二刷 WA 复盘（和 55 一样的坑 + 新的错）

v1（WA）写法：
```python
while i < length - 1:
    step += 1                    # ❌ 一开始就加步数（把起点跳算成一步）
    next_start = nums[i] + i + 1 # ❌ 直接跳到这层的右侧作为下个起点（跳层）
    for j in range(i, next_start): ...
    i = next_start               # ❌ 跳过层内其他位置
```
- **重复计数**：`[3,2,1]`（一步到终点 3≥2）→ while 里 step=1，for 里 far≥末尾又 `return step+1=2`——算成 2 步；
- **漏看层内位置**：`i = next_start` 直接跳层，层内更优的跳跃点被跳过。

**教训**：**跳跃 II 别用"跳层" while 写，用 for 逐格 + 踩墙（i==end）才 step+1**——层内每个点都过一遍，far 自然取到最大；终点本身（`range(length-1)` 排除）不参与起跳，避免"末尾 0"误判（55 同款坑）。
