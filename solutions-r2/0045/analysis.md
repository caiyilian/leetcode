# 45. 跳跃游戏 II · 解析（二刷）⚡⚡⚡ 重点复习

## 一、核心思路：分层贪心（BFS 视角）

**问题**：最少跳几次到达最后一个下标（保证可达）。

**为什么普通贪心会想岔**：不能直接选"跳得最远的下一步"——因为**当前这一步的覆盖范围是连续的**（从 i 能跳到 [i+1, i+nums[i]] 任意点），"这一步能到哪"由**这一层所有格子**决定，不是单点。

**分层模型**（等价 BFS 按层遍历）：
```
第1层: 起点 0 覆盖 [0, nums[0]]            → 跳 1 次可达
第2层: 第1层内所有点再跳，最远 max(i+nums[i]) → 跳 2 次可达
第 k 层: 第 k-1 层内所有点再跳的最远          → 跳 k 次可达
答案 = 覆盖到最后一个下标的层数
```
**每一层 = 一次跳跃**，层数即次数——这是"最少"的来源（就像 BFS 的最短路）。

## 二、代码（用户 AC 版）

```python
step = 0
far = 0    # 墙内所有格子向前够的最远（下一层墙）
end = 0    # 当前这层墙（右边界）
for i in range(length - 1):        # ⚡ 只到 n-1（终点不参与起跳）
    far = max(far, nums[i] + i)    # ① 每走一格更新最远
    if i == end:                   # ② 踩到墙 → 结算一步
        step += 1
        end = far                  #    墙推到 far
return step
```

**手动走 `[2,3,1,1,4]`（答案 2）**：
```
i=0 far=2  i==0(墙) → step=1, end=2     （第1层覆盖 0~2）
i=1 far=4  i≠2 不动                     （墙内：偷瞄到 4=终点）
i=2 far=4  i==2(墙) → step=2, end=4     （第2层：已覆盖终点）
i=3 far=4  i≠4 不动 （循环到 n-2=3 停）
return 2 ✓
```

## 三、⚡⚡⚡ 二刷 WA 复盘（务必记住，别再犯）

**v1 的错误写法**：
```python
while i < length - 1:
    step += 1                          # ❌ 一开始就 +1（把起点跳算一步）
    next_start = nums[i] + i + 1       # ❌ 直接跳层
    for j in range(i, next_start):
        if nums[j] + j > far:
            far = nums[j] + j
            if far >= length - 1: return step + 1   # ❌ 又 +1 → 重复
    i = next_start                     # ❌ 跳层内位置
```
**两个 bug**：
1. **重复计数**：一步能到终点时（如 `[3,2,1]`），while 已经 `step=1`，for 里 far≥末尾又 `return step+1` → 2 步；
2. **漏看层内**：`i = next_start` 把这一层的中间点全跳过了（那里面可能有更优的跳跃），far 没取最大。

**正确姿势**：`for i` 逐格走、每格都更新 far、**只有 `i == end` 才 step+1**——层内全部看过，far 是极大值；"一步到终点"在第一次踩墙时 step 就是对的，无重复。

## 四、复杂度

- 时间：O(n)
- 空间：O(1)

## 五、一刷 vs 二刷

- 一刷（9-18）：AC ×2（但花很久，说明当时没真正建立"分层"模型）；
- 二刷（10-31）：WA×1 → AC——v1 犯了"跳层+重复计数"，换 for 逐格+踩墙后一次过；
- **2026-10-31 用户标记 ⚡⚡⚡**：这题是不直觉题，考前必看分层模型。

## 七、一句话记住

> **最少跳跃 = 分层贪心：for i 逐格 {far=每步max；i==end时 step++、end=far}；⚡ 别用 while 跳层+开头 step+=1（重复计数），终点不参与起跳（range(n-1)）。**
